# shenlun-judge — 申论阅卷人 Skill

申论批改训练助手（国考/省考/联考/事业单位），配置于工作区 `.dsh/skills/shenlun-judge/`，
由 DeepSeek Harness 的 filesystem skill provider 自动发现加载。

## 安装（一键）

```bash
npx github:ye0619/Shenlun-SKILL          # 直接从 GitHub 安装
npx shenlun-skill                        # 已发布到 npm 时
node bin/install.js --dir <目标工作区>    # 仓库内本地安装
```

安装器会把 skill 复制到目标工作区的 `.dsh/skills/shenlun-judge/`，把两个配套脚本放到工作区
`工具/`（`count_chars.py` 字数核验、`ref_independence.py` 参考答案同源检测），并按需创建五个材料目录
（`真题/`、`参考答案/`、`作答记录/`、`批改报告/`、`批改规范/`，各带一份 README 模板）。
常用参数：`--dir <路径>`、`--force`（清空重建 skill 目录）、`--dry-run`、`--no-workspace`、`--help`。

仓库：<https://github.com/ye0619/Shenlun-SKILL>。
npm 包只含 **skill 本体 + 两个配套脚本（`工具/`）+ `bin/` + `templates/`**；个人材料目录与真题数据不入包。

## 评分依据：官方公开要求为最高层，模拟口径必须标注

**最高层依据（L1）= 官方公开的考试要求与能力维度**：题面作答要求（"观点明确、见解深刻"
"联系实际""不超过 300 字"等）、大纲/公告公开的测查能力、考场硬规则（如"超出答题区域的作答无效"）。

**由于官方阅卷细则与具体采分表通常不完全公开**，本 skill 中**档位划分、三小档、分值换算、
采分点拆分属模拟阅卷模型（经验口径，L3）**；工作区 `参考答案/` 的真题参考答案与机构解析、
`批改规范/`（机构或自拟）属**经验校准（L4）**；**`批改规范/` 若来自官方公开，则按 0.3 升级为
L1/L2，优先于本 skill 的模拟口径**。所有 L3/L4 内容输出时必须标注，**绝不表述为官方规定**
（层级定义、禁用/正确话术、置信度判定见 `references/scoring-standards.md` 0.1–0.4、
`SKILL.md` 9.2）。

## 两阶段流程：先试批改标定，再批改用户答卷（2026-09）

真实阅卷是"**先试批改 → 定标尺 → 再正式阅卷**"。本 skill 照此分两阶段：

### 阶段 A｜评分标准标定（Calibration）

**批改用户答卷之前**，若该题有 **≥2 家独立来源**的参考答案／参考作答／样卷／范文／评分示例：

1. **不得把参考答案当唯一标准答案**——要**拿参考答案自己试批改一遍**：
   逐份核对五件事——**命中／漏写／多写（无据·超范围）／表述方式／舍弃了什么**；
2. **交叉比较得三类结论**：**共同点**（≥2 家 → 核心采分点）／**差异点**（1 家 → 低权点；
   同义不同词 → "可接受的同义表达"清单）／**边界情况**（各家"多写少写"的分歧 →
   部分命中规则、**不应机械扣分的情况**）；
3. 生成**本题《动态评分规范》**，**必须含 7 项**：① 核心采分点 ② 可接受的同义表达
   ③ 部分命中规则 ④ **不应机械扣分的情况** ⑤ 材料使用要求 ⑥ 联系实际要求
   ⑦ 大作文档次锚点（引用梯队**参照档**）；
4. **落盘**：小题 → `批改规范/{省份}/{卷ID}-第N题-动态评分规范.md`；
   **大作文 → 并入** `{省份}/{卷ID}-大作文批改规范.md`（该文件的"四样 ＋ 档次锚点"）；
   均标"**助手对本题参考答案试批改提炼（L4 经验校准，非官方）／待用户确认（草稿）**"。
   **试批改过程记录**写入 `批改报告/.采分点共识/{卷ID}-第N题-共识表.md` 的「**试批改记录**」段
   （大作文的试批改＝`.大作文刻度/` 的三件）。

### 阶段 B｜用户答卷评分

**用阶段 A 形成的规范**批改用户答卷：先读《动态评分规范》逐条对照，再按采分点共识模型定价、
逐条语义核对给分。

### 材料不足时

**无参考答案／仅 1 家／全同源** → **不执行阶段 A**，改用原有 L3 模拟机制，
**并在报告中明确说明**："本题评分依据主要来自**通用评分规则**（L3 模拟口径），
**未做本题参考答案试批改**"；**该题置信度上限为"中"**。
（**脚本不可用＝家数未知**，资料可判性不足，**它不在"中"这一档里**——
属"低"，见 `scoring-standards.md` 0.4 与本文档"三层口径"表第 3 行。）

> **禁止**：把参考答案当唯一标准答案；**跳过阶段 A 直接批改**（材料不足除外，且必须声明）；
> 把《动态评分规范》说成"官方评分规范"；**用试批改给参考答案打分再据此折算考生分数**。
> 口径唯一出处：`references/small-questions.md` 第四节阶段 A。

## 与旧 skill 的区别（为什么写这个）

工作区原有 `shenlun-skill/`（模板化题型方法）与 `Shenlun.skill/`（按"单主题/AB 型/
ABC 型/多主题"类型判断定分）存在一个共同问题：**把"模板/类型"当成了评分标准**。

本 skill 的解法：**评分以官方公开的考试要求与能力维度为最高层依据**
（小题按语义采分点给分；公文先查任务/身份再按点赋分；大作文按"**档位锚定 + 档内定位**"划档赋分），
具体档位与采分点明确标为**本 skill 的模拟口径**；类型框架与结构模板一律降级为"构思脚手架"，
**绝不参与打分**——即 **评分纪律：形式不参与定档**（结构维度的检查项只有
点题／展开／收束 ＋ 层次是否分明、衔接是否顺畅，**绝不因"不符合某类型／某模板"扣分**，
套模板也不加分；细则与判语黑名单见 `references/essay-judging.md` 1.2）；
**"创新/金句/巧妙结构"不设独立加分项**。

## 大作文定档模型：档位锚定 + 硬伤修正 + 档内定位

**第一步｜大档锚定**：对题意、内容、结构、语言四维各给判定 + 原文证据，再**综合锚定大档**
（一类/二类/三类/四类，按满分占比 ≥80%／60–80%／30–60%／<30%，边界点归上一档）。
**不取最低档、不数维度计票**；某一维偏弱本身不构成整篇降档理由。本步**只锚定大档，不出分数**。

**第二步｜硬伤修正**（只封顶/降档，多项命中取最严一条）：明显跑题 → 上限四类；
偏题 / 核心任务遗漏严重 / 论点与材料主旨明显冲突 → 上限三类；大面积无法辨认或严重语言障碍
→ 下调一档。**未命中硬伤不降档**。

> ⚠ **"立意稍微模糊"不是硬伤**：中心论点方向正确、只是表述不够鲜明或概括不够精准时，
> **只在题意维度扣质量**（体现为档内定位下移），**不自动封顶二类、不降档**；
> 只有达到"只谈相邻概念／仅抓住次要概念"的实质偏题，才按偏题封顶三类。

**第三步｜档内定位（上／中／下三小档）**：本大档内分**上、中、下三个小档**（各占该大档区间的
上／中／下三分之一），按**五项**——**①题意质量 ②内容质量 ③论证深度 ④结构完成度 ⑤语言质量**——
的实际表现定位：**上**＝**≥4 项**达本档上沿（**从紧，2026-09-22**）；**中**＝**≥3 项**达本档中位；
**下**＝仅勉强达本档下限。（**两处门槛不同，别混**：中看"中位"、上看"上沿"。）
**边界值取到 0.5 刻度、归上一小档（落点值查表）；落分不得越出本大档区间**。
**取消旧的"基准分 = 区间中位数 ±1／±0.5"机械加减**；亮点只在**五项**定位中体现，不另加分。
40 分卷示例（**写落点值，不写区间**）：一类 下 32–34／中 34.5–37／上 37.5–40；
二类 下 24–26／中 26.5–28.5／上 29–31.5；三类 下 12–15.5／中 16–19／上 19.5–23.5；四类 ≤11.5（不再细分）。
（本表用**简写**：`下 a–b` ＝ **从 a 到 b 全部可落**，等价于 `[a, b+0.5）`，**b+0.5 起属下一小档**
——如二类"下 24–26"＝24／24.5／25／25.5／26（5 个）、"中 26.5–28.5"＝26.5／27／27.5／28／28.5（5 个），
三档首尾相接；**权威形式（半开闭区间＋逐值枚举）见 `references/scoring-standards.md` 三.1**。）
其余分值卷查 `references/scoring-standards.md` 三.1。

**第四步｜区间与置信度（必给）**：主分之外给**建议区间 + 评分置信度（高/中/低 + 理由）**；
置信度不到"高"时不得输出"28.5 分"式精确结论。**判"高"须已完成阶段 A**——
**大作文**：已建刻度（T1 单向／双向）／仅 1 篇范文已记"单篇参照"／无范文但已用 ≥2 家参考答案试批改，
三者之一即可；**"无范文、不建刻度 ＋ 未做试批改"不算完成阶段 A**（按未完成处理，上限"中"，
报告不得写"阶段 A 已完成"）。**双向刻度且来源指纹可核**时可**上调半档**
（"中"→"中偏高"，**不得直接到"高"**），单向刻度不上调。
**不设"范文分数锚点"**——禁止"某篇范文＝一类文＝某分"或据此**插值**折分；
但**刻度必须参与定档**（见下节四个接入点）：参照档约束大档、画像定档内位置、
可撤掉不成立的扣分项。**禁止的只是"分数锚点／插值"，不是刻度的参与**。

> 四维框架与四字档位描述来自公开描述（L2）；**档位区间、三小档、换算表、硬伤清单、扣分量级
> 全部是本 skill 的模拟口径（L3 经验口径，官方细则未公开）**，输出须标注，不得说成官方标准。

## 大作文的两个参照系：'深刻'刻度与范文梯队

> 两者都是 **L3 模拟口径 ＋ L4 经验校准（非官方）**，都**不单独加分**。
> 但**参与定档的方式不同**：
> **"深刻"刻度辅助定档**（通过**题意维度**参与四维综合，可影响档内定位；**不得单独定档**）；
> **范文梯队刻度参与定档**（参照档约束大档、画像定档内位置、可撤掉不成立的扣分项）。
> 权威出处：`references/essay-judging.md` 1.7 与 `references/essay-exemplars.md` 第 4 节。

### 参照系一："深刻"四级刻度（治"没有参照系"）

- **先承认**："深刻"**没有官方统一标准**，它只是题面"见解深刻／观点独到"这类
  **公开作答要求（L1）**的定性描述，**不是一个可独立打分的维度**，也不单独加分。
- **三个来源（＋1 个可选）**：

  | 来源 | 要回答什么 |
  |---|---|
  | ① **因果链** | "为什么会这样／根子在哪" |
  | ② **边界条件** | 条件、限度、分寸、转化；**不绝对化** |
  | ③ **一般化** | 把具体案例上升为**有适用范围的判断** |
  | ④ **纠正默认预期**（可选） | 抓住题干被忽略的一侧（如"有与无"重心落在"无"） |

- **四级刻度**（在**题意维度**及其对论证深度的联动里体现，**不单独加分**）：

  | 刻度 | 表现 | 对应档位 |
  |---|---|---|
  | **复述型** | 把材料换个说法 | 三类 |
  | **明理型** | 是什么 ＋ 为什么，**1 层因果** | 二类 |
  | **见地理型** | 上升到一般判断、**点出边界** | 一类下／中 |
  | **洞见型** | **纠正默认预期** ＋ 结构性解释 ＋ **落到具体机制** | 一类上 |

- **三条边界（2026-09 修订）**：
  1. **题面许可原则（改口径）**——题面**没写**"见解深刻／观点独到"时，**深度仍然参与题意判定**
     （立意有没有想透），只是**不得仅凭"文采一般／不够玄妙"扣分**；
     题面**明确要求**"见解深刻"时，它是**题意维度的重点评分项**；
  2. **点名层次原则**——说"不够深刻"**必须点名缺的是因果／边界／一般化／纠偏哪一层**，
     并引原文、说明影响哪一维；**说不出层次，该评语作废**；
  3. **不得单独定档**——深刻度必须写进**四维综合理由**（说明它是支撑还是拖后腿），
     **不得**用"明理型＝二类"这类刻度直接定档。
- **明确排除**：排比句式、名言堆砌、辞藻华丽、小标题漂亮——那些只在**语言维度**评。
- 细则：`references/essay-judging.md` 1.7 与 `references/essay-exemplars.md` 第 8 节。

### 参照系二：范文梯队刻度（相对刻度，不作分数锚点）

- **三条防线**：
  ① **不做分数锚点**——禁止"这篇范文＝一类文＝34 分，你比它差所以 28 分"；
  ② **不提取形式特征**——禁止从范文提取结构形态／句式／开头结尾套路／小标题写法当评分特征
  （机构范文模板化，提取了会把模板风格固化成"一类文特征"，反噬上面的形式纪律）；
  ③ **不冒充来源**——**范文 ≠ 一类文**，机构老师自评二类的情形要**如实登记**，一律标 L4。
- **梯队与成刻度条件**：

  | 梯队 | 含义 | 来源优先级 |
  |---|---|---|
  | **T1** | 该题最高水平样本 | **用户手动标注 ＞ 多篇机构范文一致 ＞ 助手推断（须标 L4 ＋ 附证据 ＋ 标"待用户确认"）** |
  | **T2** | 中等／合格线附近样本 | 用户历史批改被判"二类"的作文、机构中较平实的范文 |
  | **T3** | 明显不足样本（**确有才用**） | 用户历史批改中的低分作文 |

  **成刻度条件（2026-09 修订：分级，不再是"全有或全无"）**：**先数范文**——
  打开本卷该题参考答案文件（`参考答案/{省份}/{卷ID}/第N题.txt`，含大作文那题），
  **数清几篇、哪几家**（可用 `工具/ref_independence.py` 顺手判同源），再按下表定档；
  **报告必须写出"本卷大作文范文 N 篇（来源：…）"**：

  | 手上有的素材 | 建什么 | 能用来干什么 |
  |---|---|---|
  | **T1 ≥2 篇**（多机构范文／用户标注的一类文） | **T1 单向刻度**（默认形态，**该建就建**） | 六项对照 → 改进方向 ＋ "好在哪"；**并可用于档内定位的"上沿一侧"**（多数贴近 T1 → 本档上）；声明"**下沿无锚**" |
  | **T1 ≥2 篇 ＋ T2 ≥2 篇** | **双向刻度**（升级形态） | 档内定位的直接依据（上/中/下都能对照） |
  | **只有 1 篇** | **单篇参照（T1-lite）** | **只用于改进方向**；不作定位依据 |
  | 一篇都没有／该题不是大作文／素材无关 | **不建** | 报告写"刻度：未建（原因）"，照常按四步批改 |

  **"T1 与 T2 都要有"不再是建刻度的前提**（旧口径已废止）：T2（用户历史批改的二类样本）
  往往"以后才有"，**不能因为没有 T2 就整段放弃参照**；先建 T1 单向刻度，有了 T2 再升级。
  **建刻度时必须给每个梯队标"参照档"**（如"T1 参照档＝二类上"，**只标档位、绝不标分数**）——
  没有参照档，刻度就无法参与定档。
- **六项特征卡（唯一可提取的内容）**：**立意方向／论点覆盖／因果层次／边界意识／落点具体度／
  材料运用**，各一句判定 ＋ 一句**原文证据** ＋ 强/中/弱。**禁止**记录"分了几个自然段"
  "用了几个小标题""开头是不是排比"。
- **梯队画像**：同梯队特征卡合并成 **200–300 字**画像；**批改时只读画像，不读范文原文**。
- **怎么用：四个接入点（刻度参与划档与评分）**
  1. **标参照档**（建刻度时必做）——梯队整体档位，只标档位不标分数；
  2. **约束大档**——六项**不低于 T1** → 大档**不得低于 T1 参照档**；**明显低于 T2** →
     **不得高于 T2 参照档**；介于两者 → 在两者之间取；
  3. **定档内位置**——T1／T2 是**外部相对锚**（各自可能落在不同小档／大档），
     **只在参照档与当前大档重叠时**用于档内定位（多数贴近 T1 → 上；介于 T1／T2 → 中；贴近 T2 → 下）；
     **④结构完成度／⑤语言质量不参与刻度对照**（按四维描述判，防"提取形式特征"）；
  4. **检验扣分项合法性**——用户某项**不弱于 T1** → 该项**不得**作为降档/扣分理由。
  **仍禁止**：分数锚点与插值、"像范文"加减分、默认"机构范文＝一类文"、提取形式特征；
  报告要写出"**刻度改了哪一处判断**"（写不出＝机制空转）。
- **该卷大作文批改规范提炼**：提炼**立意梯度／核心论点池（3–5 个）／常见失分点／硬性与禁止口径**四样
  **＋ 第⑤项「档次锚点」**（T1／T2 各梯队的**参照档**，只标档位不标分数——这是阶段 A 的落地产物），
  **不提炼分数分界**（一类／二类的分界线要有反例样本才能提）；落盘
  `批改规范/{省份}/{卷ID}-大作文批改规范.md`，文件头须写"来源：助手从 N 篇机构范文 ＋ M 篇用户标注样本
  提炼（L4 经验校准，非官方）／状态：☐ 待用户确认 ☑ 用户已确认／刻度集／生成日期"；
  **待确认草稿可用于批改，但报告必须注明"未确认草稿"**；**用户手写规范优先、不覆盖**
  （草稿另存 `{卷ID}-大作文批改规范(助手提炼).md`）。
- **缓存与指纹**：`批改报告/.大作文刻度/` 下 `{卷ID}-素材清单.md`（来源指纹 ＝
  文件路径/来源/年份/**字节数/修改时间** ＋ 生成日期）、`{卷ID}-特征卡.md`、`{卷ID}-梯队画像.md`；
  **指纹变了就重建**、**可删可重建**。
- **token 纪律（硬性）**：

  | 场合 | 读什么 | 量级（粗略） |
  |---|---|---|
  | 建刻度（**本卷大作文首次批改时，一次性**） | 每篇范文全文 | 每篇 1–2k tokens，**仅此一次** |
  | **之后每次批改** | **只读** `{卷ID}-梯队画像.md` ＋ 该卷规范 | 约 500–1k tokens |
  | **禁止** | 每次批改重读范文原文 | —— |

- **"首次必须建一次"的三步**（省 token 的最小路径）：**数范文 → 六项卡 → 画像＋参照档**，
  合计约 3–8k tokens，**一劳永逸**；只有素材指纹变化时才重做。
- **确实不建时也别省参照行**：落到"不建"那一行（一篇范文都没有／该题不是大作文／素材与本题无关；
  **另有"用户明确指定这次不用刻度"**——那属用户指令，报告写"刻度：未建（**用户指定跳过**）"，
  并说明刻度未参与本次定档）时，
  按四步流程照常批改，报告写"**刻度：未建（原因）**"——**"有刻度集时必写"的旧口径已废止**：
  **无论建或不建，这一行都必须出现并说明原因**；**不得因为"没有刻度"降低批改完整度或拒评**。
  ⚠ **"只有机构范文、没有 T2 样本"不是免做的理由**（那正是 T1 单向刻度的默认情形）。

## 三条判分禁令（本次新增，最容易踩的坑）

1. **同义表达与异构论证一律允许**（基本原则 = **语义等价 + 逻辑等价**）：
   参考答案写"科技赋能基层治理"，考生写"利用数字技术降低治理成本、提升服务效率"
   → **语义等价，按同一采分点给分**。**禁止**"没出现'×××'这几个词就判偏离／扣分"、
   "与参考答案论证角度不同，扣分"。判定三问：意思是否等同于采分点／参考立意？逻辑是否成立？
   是否围绕题干核心概念？三问成立即给分。（`SKILL.md` **1.2 纪律 7**、`essay-judging.md` 1.5）
2. **具体案例不是采分点**：材料中某个具体案例本身不构成采分点，**未引用某个材料案例本身
   不得作为扣分理由**；只有当该案例承载的观点／事实／逻辑**无法被考生其他内容替代**时，
   才可能表现为内容不足/论证不足，且扣的是**质量分**（理由写"缺支撑"）。
   题干"联系实际"≠"必须引用材料案例"。（`SKILL.md` **1.2 纪律 8**、`essay-judging.md` 1.6）
3. **"立意稍微模糊"不封顶**（见上）。

## 小题采分点共识模型（治"模型自己发明给分点"）

> **L3 模拟口径**（官方采分表未公开）＋ **L4 经验校准**（工作区 `参考答案/`），非官方规定。
> 权威出处：`references/small-questions.md` 第四节。它治的失真：**模型自己"发明"一个看着很重要、
> 但各家机构答案都没有的给分点**，再按不低的分值扣分。做法是**先用多源参考答案给每个采分点
> 定"来源等级"与权重，再给分**。

**五等级（每个采分点必须归一类；权重随独立来源家数递减，2026-09 修订）**

| 来源等级 | 判定（家数＝**独立**来源家数） | 分值待遇 |
|---|---|---|
| **强共识点** | **≥3 家**，或 **2 家且占独立来源 ≥50%**，且材料有据 | **主池高值**；共识点合计占满分池 **70%–80%** |
| **弱共识点** | **恰好 2 家**且占独立来源 **<50%** | **主池低值**（高于任何单源点） |
| **单源点** | **恰好 1 家**命中，且材料有据 | **低权**；**单点分值不高于共识点** |
| **材料推定点**（**提醒项**） | **0 家**命中，但材料原文**确凿支持** | **※ 分三层**：①资料完整且 ≥2 家独立来源 → **不计分（0 分）**、进"提醒区"；②家数已判明但 0／1 家／全同源 → **全部低权计分**（置信度中）；③家数未知或资料残缺 → **全部低权计分**（置信度低）。**详见下方"三层口径"** |
| **争议点** | 各来源对同一材料得出**不同结论／不同归因** | **不计分、不占分母**；答任一方都算命中 |

**两条铁律（先于一切）**

1. **材料原文依据是硬门槛**：每个采分点**必须给出材料原文出处**（写成 `材料X第Y段"……"`）；
   **拿不出就删除**，不进采分点表。
2. **参考答案是校准尺，不是判据；但它决定"算不算分"**：
   **不排除材料确凿的点**——机构集体漏点是常态，这些点**必须照列**，
   但列为"**提醒项**"、**不计分**（**不得悄悄删掉**）；
   **也不拿它给用户算分**——机构答案集体没有的点，**大概率不在实际采分表里**，
   计入分值就是**失真**（用户会为"专业答案都没写的点"丢分）。
   **唯一例外**：该题**参考资料本身不完整**（脚本报"疑为节选"／**未做同源检测**／脚本不可用而家数未知）→
   "机构没写"不能证明"不是采分点" → 此时提醒项**按低权计分、进入计分表**，
   报告显著标注、**置信度按 0.4 判定（资料残缺／家数未知＝低）**。
   **注意区分**（2026-09-19 修订）：**"仅 1 家独立来源"与"无参考答案"不是"低"的触发条件**——
   家数已判明、资料本身完整，只是校准口径单一 → **置信度"中"**（见 0.4 表"中"行）。

**"0 家点"三层口径（上表「材料推定点」行的展开；`SKILL.md` 4.1 同口径）**

| 情形 | 0 家点怎么处理 | 置信度 |
|---|---|:--:|
| **≥2 家独立来源、资料完整、同源检测完成** | 进**提醒区**、**不计分** | 中／高 |
| **家数已判明，但只有 0 家／1 家／全同源**（走"无共识点"路径） | **全部按低权计分**（点不退出计分） | **中** |
| **家数未知（未做同源检测／脚本不可用）或资料残缺（疑为节选）** | **全部按低权计分**，报告显著标注 | **低** |

> **"0 家＝0 分"不是绝对规则**——前提是"**资料完整且有足够独立来源**"；
> **"参考资料不完整"这个唯一例外只覆盖第 2、3 两行**。

**同源只算一家（`工具/ref_independence.py`）**：机构之间大量互相转抄，**独立来源家数 = 分组数，
不是文件数**。对同一题的参考答案两两算文本重合率并分组：`--same`（默认 **0.80**）同源转抄、
`--near`（默认 **0.60**）疑似同源（保守同组）；**只有 1 家、或全部同源 → 该题没有共识点**。

可复制命令：

```bash
python 工具/ref_independence.py 参考答案/{省份}/{卷ID} --question N
```

> 提示：**给分不用文本相似度**；`ref_independence.py` 的相似度**只用于参考答案之间判同源**。

**分值池纪律**：**分值池恒等于题目总分**——某点退出计分（**0 家收录**／争议点）时，
**其分值回补到剩下的计分点**（不得把题总分调低、也不得让满分拿不到）。
**共识点合计 70%–80%、低权点（单源点）20%–30%（目标区；硬上限 40%）、单点分值 10%–35%**；
**冲突顺序：① 池合计＝题目总分 → ② 单点 10%–35% → ③ 共识点>单源点（排序）→ ④ 目标区让位**；
**10–15 分题不适用 40% 上限**；**共识点不足 3 个时**：① 合并后仍 <3 个、但该题原本有 **≥2 家独立来源**（只合并出 1–2 个共识点）→ **单源点转入提醒区、不计分**；② 该题**根本没有共识点**（0／1 家／全同源）→ **点全部按低权计分**——两者不要混；
**漏掉低权点只扣该点小分值，不得据此判定"内容不全面"或整体降档**；**提醒区更不影响得分**。
**例外**（参考资料残缺或家数未知／未做同源检测）：提醒项按低权计分并进入计分表，
此时低权池 ＝ 单源点 ＋ 材料推定点，**不受 20%–30% 目标区与 40% 上限约束**
（该题本就没有共识点，低权池必然接近 100%）。**无共识点** → 整题退回**模拟重构（L3）**。
**逐点回退**（不是整题开关）＋**冲突分型**（同义表达／粒度差异／漏点／真争议／正误分歧，
只有"对同一材料得出不同结论／归因"才是争议点）细则见 `references/small-questions.md` 第四节 5–6。

**共识表与试批改记录缓存**：`批改报告/.采分点共识/{卷ID}-第N题-共识表.md`，
内含**「试批改记录」段**（阶段 A 的逐份试评＋共同点/差异点/边界情况），
表头记录参与归并的参考答案**文件清单 ＋ 字节数 ＋ 修改时间**（**来源指纹**）；
同卷再批**直接复用**，**指纹变了就重建**。

来源与本年卷不符、只覆盖部分题目的一律不因此上调置信度。规则见 `references/reference-answers.md`。

## 功能

- 大作文"档位锚定 + 硬伤修正 + 档内定位（上/中/下）"评判（含原文证据、区间与置信度）
- **形式不参与定档（判语黑名单）**：结构维度只查**点题／展开／收束 ＋ 层次 ＋ 衔接**，
  **检查项里没有"是否符合某类型／某模板／某名师框架"**；出现"不符合五段三分""归类困难按三类处理"
  "套模板扣 X 分"（反向"用了某框架加分"同样作废）等判语，**该处判分一律作废并删除**
  （本 skill 评分纪律，非官方；`references/essay-judging.md` 1.2 判语黑名单）
- **"深刻"四级刻度 ＋ 两条硬纪律**：复述型 → 明理型 → 见地理型 → 洞见型；
  **题面未明确要求"见解深刻"时，深度仍参与题意判定**（立意有没有想透），
  但**不得仅凭"文采一般／不够玄妙"降档**（那是语言维度的事）；题面明确要求时它是重点评分项；
  **说"不够深刻"必须点名缺哪一层**
  （因果／边界／一般化／纠偏），**说不出层次该评语作废**（四级刻度属 L3 模拟口径，非官方；`essay-judging.md` 1.7）
- **范文梯队刻度（六项特征卡／参与定档的相对标尺，不作分数锚点）**：T1/T2 梯队＋**参照档**
  ＋六项特征对照 —— **参照档约束大档、画像定档内位置、可撤掉不成立的扣分项**；
  **不作分数锚点／不插值、不因"像范文"加分**；缓存于 `批改报告/.大作文刻度/`，
  日常批改只读梯队画像（`references/essay-exemplars.md` 第 4 节，L3/L4 非官方）
- 小题**多源共识采分（五等级，权重随家数递减）**：强共识点／弱共识点／单源点／
  **材料推定点**（**0 家且次要 → 提醒区不计分；0 家但重要 → 按弱共识计分**，2026-09-22）／争议点；
  **机构 0 家收录的点先判"重不重要"**（重要按弱共识计分，次要才入"提醒区"）；
  共识点占 70%–80%、低权点（单源）20%–30%（目标区，硬上限 40%），
  **分值池恒等于题目总分**（退出的分值回补）；**每个采分点必须给出材料原文依据**；
  拆为"核心动作｜核心对象｜关键限定/结果"，**不设 80%/40% 覆盖率阈值**；
  采分点为 L3 模拟重构；**同义表达照给分**
- **两阶段流程**：**先试批改参考答案标定 → 生成本题《动态评分规范》→ 再批改用户答卷**；
  材料不足则不标定并声明（见上文）
- 公文先查**任务目的与身份场景**，再查内容/格式/语言，按点赋分（占比为训练参照，非官方比例）
- 作答与构思指导（立意 / 结构 / 分论点 / 论证，全部标注"辅助工具"）
- 规范表达与八大主题金句素材
- **工作区真题库匹配**（`真题/{省份}/真题库/INDEX.md`，按需加载，不占 skill 体积）与命题预判
- **批改规范引用**（`批改规范/`）、**参考答案校准**（`参考答案/`，L4）
- **评分置信度（采样与校准口径）**：每次批改都给"建议区间 + 置信度 + 理由"
- **字数核验（脚本统计，非估算）**：`工具/count_chars.py` 输出答题卡口径字数
- **依据层级标注**：L1 / L2 / L3 / L4，每份报告都带"评分依据声明 + 置信度"

## 真题源优先级（重要）

判分基准按以下顺序取用，**不得跳过前几级凭记忆重构采分点**：

1. **工作区 `批改规范/`**（该卷规范，**有就必须引用**；官方公开 → L1/L2，优先于模拟口径）。
2. **工作区 `参考答案/`**（L4 经验校准，非官方）：校准宽严与粒度，须登记来源。
3. **工作区本地官方 PDF 原件**（L1 题面与材料）：`真题/{国考|河南|浙江}/{卷ID}.pdf`。
4. **已入库真题 md**：`真题/{省份}/真题库/{卷ID}.md`（含重构参考采分点，见同目录 `INDEX.md`）。
5. **用户直接提供的题目原文**（以此为准）。
6. **模型自身知识**（仅在前几级都不可用时，且必须标注"未经核验"）。

> 新环境默认**没有**真题库（`真题/` 为空）→ 直接走通用流程，不报错、不臆造题库。
>
> **小题按共识模型定价**（见 `references/small-questions.md` 第四节）：先按 `参考答案/`
> 判**强共识点／弱共识点／单源点／材料推定点（0 家且次要→提醒区；0 家但重要→弱共识）／争议点**，再给分
> （L3 模拟口径 ＋ L4 校准，非官方）；**0 家收录的点先判"重不重要"**——重要按弱共识计分、
> 次要才单列提醒区（2026-09-22 修订）。
> **顺序是"先试批改标定、再定价给分"**（阶段 A → 阶段 B）。

## 批改前六步（`SKILL.md` 第三节）

⓪ **卷级隔离**：先立"批改上下文锚"（本卷卷ID、口径来源、上一次批的卷），同一对话多卷不串味；
① **材料归位与命名检查**（散落文件先自动分类归位，含糊的先问用户）；
② **定位用户作答**（对话已贴则优先，否则到 `作答记录/` 找）；
③ **引用批改规范**（该卷有规范就必须引用；大作文规范、《动态评分规范》逐条对照）；
④ **查参考答案**：有就用并**登记独立来源家数**（本步只登记家数，**不做定价**）；
⑤ **获取题面与给定资料（L1，必做）**：根目录 PDF → `真题/{省份}/` → 联网；
   取不到必须声明"题面未经核实、置信度低"；
⑥ **试批改标定（阶段 A，必做）**：拿参考答案自己试批改 → 生成《动态评分规范》→ **然后才批改**。
   材料不足（无参考答案／仅 1 家／全同源／脚本不可用）时不标定，**并声明依据为通用评分规则**。
