# shenlun-judge — 申论阅卷人 Skill

申论批改训练助手（国考/省考/联考/事业单位），配置于工作区 `.dsh/skills/shenlun-judge/`，
由 DeepSeek Harness 的 filesystem skill provider 自动发现加载。

## 安装（一键）

```bash
npx github:ye0619/Shenlun-SKILL          # 直接从 GitHub 安装
npx shenlun-skill                        # 已发布到 npm 时
node bin/install.js --dir <目标工作区>    # 仓库内本地安装
```

安装器会把 skill 复制到目标工作区的 `.dsh/skills/shenlun-judge/`，把两个配套脚本放到工作区
`工具/`（`count_chars.py` 字数核验、`ref_independence.py` 参考答案同源检测），并按需创建五个材料目录
（`真题/`、`参考答案/`、`作答记录/`、`批改报告/`、`批改规范/`，各带一份 README 模板）。
常用参数：`--dir <路径>`、`--force`（清空重建 skill 目录）、`--dry-run`、`--no-workspace`、`--help`。

仓库：<https://github.com/ye0619/Shenlun-SKILL>。
npm 包只含 **skill 本体 + 两个配套脚本（`工具/`）+ `bin/` + `templates/`**；个人材料目录与真题数据不入包。

## 评分依据：官方公开要求为最高层，模拟口径必须标注

**最高层依据（L1）= 官方公开的考试要求与能力维度**：题面作答要求（"观点明确、见解深刻"
"联系实际""不超过 300 字"等）、大纲/公告公开的测查能力、考场硬规则（如"超出答题区域的作答无效"）。

**由于官方阅卷细则与具体采分表通常不完全公开**，本 skill 中**档位划分、三小档、分值换算、
采分点拆分属模拟阅卷模型（经验口径，L3）**；工作区 `参考答案/` 的真题参考答案与机构解析、
`批改规范/`（机构或自拟）属**经验校准（L4）**；**`批改规范/` 若来自官方公开，则按 0.3 升级为
L1/L2，优先于本 skill 的模拟口径**。所有 L3/L4 内容输出时必须标注，**绝不表述为官方规定**
（层级定义、禁用/正确话术、置信度判定见 `references/scoring-standards.md` 0.1–0.4、
`SKILL.md` 9.2）。

## 与旧 skill 的区别（为什么写这个）

工作区原有 `shenlun-skill/`（模板化题型方法）与 `Shenlun.skill/`（按"单主题/AB 型/
ABC 型/多主题"类型判断定分）存在一个共同问题：**把"模板/类型"当成了评分标准**。

本 skill 的解法：**评分以官方公开的考试要求与能力维度为最高层依据**
（小题按语义采分点给分；公文先查任务/身份再按点赋分；大作文按"**档位锚定 + 档内定位**"划档赋分），
具体档位与采分点明确标为**本 skill 的模拟口径**；类型框架与结构模板一律降级为"构思脚手架"，
**绝不参与打分**——即 **评分纪律：形式不参与定档**（结构维度的检查项只有
点题／展开／收束 ＋ 层次是否分明、衔接是否顺畅，**绝不因"不符合某类型／某模板"扣分**，
套模板也不加分；细则与判语黑名单见 `references/essay-judging.md` 1.2）；
**"创新/金句/巧妙结构"不设独立加分项**。

## 大作文定档模型：档位锚定 + 硬伤修正 + 档内定位

**第一步｜大档锚定**：对题意、内容、结构、语言四维各给判定 + 原文证据，再**综合锚定大档**
（一类/二类/三类/四类，按满分占比 ≥80%／60–80%／30–60%／<30%，边界点归上一档）。
**不取最低档、不数维度计票**；某一维偏弱本身不构成整篇降档理由。本步**只锚定大档，不出分数**。

**第二步｜硬伤修正**（只封顶/降档，多项命中取最严一条）：明显跑题 → 上限四类；
偏题 / 核心任务遗漏严重 / 论点与材料主旨明显冲突 → 上限三类；大面积无法辨认或严重语言障碍
→ 下调一档。**未命中硬伤不降档**。

> ⚠ **"立意稍微模糊"不是硬伤**：中心论点方向正确、只是表述不够鲜明或概括不够精准时，
> **只在题意维度扣质量**（体现为档内定位下移），**不自动封顶二类、不降档**；
> 只有达到"只谈相邻概念／仅抓住次要概念"的实质偏题，才按偏题封顶三类。

**第三步｜档内定位（上／中／下三小档）**：本大档内分**上、中、下三个小档**（各占该大档区间的
上／中／下三分之一），按四项实际表现定位：**上**＝多数达本档上沿；**中**＝大体达本档中位；
**下**＝仅勉强达本档下限。**边界点归上一小档；落分不得越出本大档区间**。
**取消旧的"基准分 = 区间中位数 ±1／±0.5"机械加减**；亮点只在四项定位中体现，不另加分。
40 分卷示例：一类 上 37.5–40／中 34.5–37.5／下 32–34.5；二类 上 29–31.5／中 26.5–29／
下 24–26.5；三类 上 19.5–23.5／中 15.5–19.5／下 12–15.5；四类 ≤11.5（不再细分）。
其余分值卷查 `references/scoring-standards.md` 三.1。

**第四步｜区间与置信度（必给）**：主分之外给**建议区间 + 评分置信度（高/中/低 + 理由）**；
置信度不到"高"时不得输出"28.5 分"式精确结论。**不设"范文分数锚点"**——禁止
"某篇范文＝一类文＝某分"或据此插值折分；但**允许**用**多篇标注样本**组成 **T1/T2 梯队作相对刻度**
（见下节），刻度**不参与定档**、**不得因"像范文"加分**。

> 四维框架与四字档位描述来自公开描述（L2）；**档位区间、三小档、换算表、硬伤清单、扣分量级
> 全部是本 skill 的模拟口径（L3 经验口径，官方细则未公开）**，输出须标注，不得说成官方标准。

## 大作文的两个参照系：'深刻'刻度与范文梯队

> 两者都是 **L3 模拟口径 ＋ L4 经验校准（非官方）**，只服务于"**档内定位与改进方向**"，
> **都不参与定档、都不单独加分**。权威出处：`references/essay-judging.md` 1.7 与
> `references/essay-exemplars.md`。

### 参照系一："深刻"四级刻度（治"没有参照系"）

- **先承认**："深刻"**没有官方统一标准**，它只是题面"见解深刻／观点独到"这类
  **公开作答要求（L1）**的定性描述，**不是一个可独立打分的维度**，也不单独加分。
- **三个来源（＋1 个可选）**：

  | 来源 | 要回答什么 |
  |---|---|
  | ① **因果链** | "为什么会这样／根子在哪" |
  | ② **边界条件** | 条件、限度、分寸、转化；**不绝对化** |
  | ③ **一般化** | 把具体案例上升为**有适用范围的判断** |
  | ④ **纠正默认预期**（可选） | 抓住题干被忽略的一侧（如"有与无"重心落在"无"） |

- **四级刻度**（在**题意维度**及其对论证深度的联动里体现，**不单独加分**）：

  | 刻度 | 表现 | 对应档位 |
  |---|---|---|
  | **复述型** | 把材料换个说法 | 三类 |
  | **明理型** | 是什么 ＋ 为什么，**1 层因果** | 二类 |
  | **见地理型** | 上升到一般判断、**点出边界** | 一类下／中 |
  | **洞见型** | **纠正默认预期** ＋ 结构性解释 ＋ **落到具体机制** | 一类上 |

- **两条硬纪律**：
  1. **题面许可原则**——题面**没写**"见解深刻／观点独到"时，**不得以"不够深刻"为由降档或
     扣题意分**（只能用"观点明确、准确"这一档要求）；
  2. **点名层次原则**——说"不够深刻"**必须点名缺的是因果／边界／一般化／纠偏哪一层**，
     并引原文、说明影响哪一维；**说不出层次，该评语作废**。
- **明确排除**：排比句式、名言堆砌、辞藻华丽、小标题漂亮——那些只在**语言维度**评。
- 细则：`references/essay-judging.md` 1.7 与 `references/essay-exemplars.md` 第 8 节。

### 参照系二：范文梯队刻度（相对刻度，不作分数锚点）

- **三条防线**：
  ① **不做分数锚点**——禁止"这篇范文＝一类文＝34 分，你比它差所以 28 分"；
  ② **不提取形式特征**——禁止从范文提取结构形态／句式／开头结尾套路／小标题写法当评分特征
  （机构范文模板化，提取了会把模板风格固化成"一类文特征"，反噬上面的形式纪律）；
  ③ **不冒充来源**——**范文 ≠ 一类文**，机构老师自评二类的情形要**如实登记**，一律标 L4。
- **梯队与成刻度条件**：

  | 梯队 | 含义 | 来源优先级 |
  |---|---|---|
  | **T1** | 该题最高水平样本 | **用户手动标注 ＞ 多篇机构范文一致 ＞ 助手推断（须标 L4 ＋ 附证据 ＋ 标"待用户确认"）** |
  | **T2** | 中等／合格线附近样本 | 用户历史批改被判"二类"的作文、机构中较平实的范文 |
  | **T3** | 明显不足样本（**确有才用**） | 用户历史批改中的低分作文 |

  **每梯队 ≥2 篇才成刻度**（单篇不成刻度），且 **T1 与 T2 都要有**——只有 T1 回答不了"二类在哪"。
- **六项特征卡（唯一可提取的内容）**：**立意方向／论点覆盖／因果层次／边界意识／落点具体度／
  材料运用**，各一句判定 ＋ 一句**原文证据** ＋ 强/中/弱。**禁止**记录"分了几个自然段"
  "用了几个小标题""开头是不是排比"。
- **梯队画像**：同梯队特征卡合并成 **200–300 字**画像；**批改时只读画像，不读范文原文**。
- **怎么用**：先按四维**独立定档**（**刻度不参与定档**）→ 再读画像做**六项对照**
  → 结论**只用于档内定位（上/中/下）与改进方向**；**禁止反推分数**、**禁止因"像范文"加分**、
  **禁止因"不像范文"扣分**。
- **该卷大作文批改规范提炼**：只提炼**立意梯度／核心论点池（3–5 个）／常见失分点／硬性与禁止口径**四样，
  **不提炼分数分界**（一类／二类的分界线要有反例样本才能提）；落盘
  `批改规范/{省份}/{卷ID}-大作文批改规范.md`，文件头须写"来源：助手从 N 篇机构范文 ＋ M 篇用户标注样本
  提炼（L4 经验校准，非官方）／状态：☐ 待用户确认 ☑ 用户已确认／刻度集／生成日期"；
  **待确认草稿可用于批改，但报告必须注明"未确认草稿"**；**用户手写规范优先、不覆盖**
  （草稿另存 `{卷ID}-大作文批改规范(助手提炼).md`）。
- **缓存与指纹**：`批改报告/.大作文刻度/` 下 `{卷ID}-素材清单.md`（来源指纹 ＝
  文件路径/来源/年份/**字节数/修改时间** ＋ 生成日期）、`{卷ID}-特征卡.md`、`{卷ID}-梯队画像.md`；
  **指纹变了就重建**、**可删可重建**。
- **token 纪律（硬性）**：

  | 场合 | 读什么 | 量级（粗略） |
  |---|---|---|
  | 建刻度（**一次性**） | 每篇范文全文 | 每篇 1–2k tokens，**仅此一次** |
  | **日常批改** | **只读** `{卷ID}-梯队画像.md` ＋ 该卷规范 | 约 500–1k tokens |
  | **禁止** | 每次批改重读范文原文 | —— |

- **无刻度时正常批改**：没有刻度集 → 按常规四步正常批改，只是**不给"刻度参照"一段**，
  **不得因此降低批改完整度或拒评**，也不要为了凑刻度去读一堆范文。
- **何时建议建刻度**：同一道题反复写（≥2 稿）／重点备考卷／已有 ≥2 篇同梯队样本；
  **只有单篇或只批一次 → 不要建**。

## 三条判分禁令（本次新增，最容易踩的坑）

1. **同义表达与异构论证一律允许**（基本原则 = **语义等价 + 逻辑等价**）：
   参考答案写"科技赋能基层治理"，考生写"利用数字技术降低治理成本、提升服务效率"
   → **语义等价，按同一采分点给分**。**禁止**"没出现'×××'这几个词就判偏离／扣分"、
   "与参考答案论证角度不同，扣分"。判定三问：意思是否等同于采分点／参考立意？逻辑是否成立？
   是否围绕题干核心概念？三问成立即给分。（`SKILL.md` 铁律 7、`essay-judging.md` 1.5）
2. **具体案例不是采分点**：材料中某个具体案例本身不构成采分点，**未引用某个材料案例本身
   不得作为扣分理由**；只有当该案例承载的观点／事实／逻辑**无法被考生其他内容替代**时，
   才可能表现为内容不足/论证不足，且扣的是**质量分**（理由写"缺支撑"）。
   题干"联系实际"≠"必须引用材料案例"。（`SKILL.md` 铁律 8、`essay-judging.md` 1.6）
3. **"立意稍微模糊"不封顶**（见上）。

## 小题采分点共识模型（治"模型自己发明给分点"）

> **L3 模拟口径**（官方采分表未公开）＋ **L4 经验校准**（工作区 `参考答案/`），非官方规定。
> 权威出处：`references/small-questions.md` 第四节。它治的失真：**模型自己"发明"一个看着很重要、
> 但各家机构答案都没有的给分点**，再按不低的分值扣分。做法是**先用多源参考答案给每个采分点
> 定"来源等级"与权重，再给分**。

**四等级（每个采分点必须归一类）**

| 来源等级 | 判定 | 分值待遇 |
|---|---|---|
| **共识点** | **≥2 家独立**来源命中 **且** 材料有据 | **主体分值**；共识点合计占满分池 **70%–80%** |
| **单源点** | 仅 **1 家独立**来源命中 **且** 材料有据 | **低权**；**单点分值不高于共识点** |
| **材料推定点** | **无来源命中**但材料原文**确凿支持** | **低权**（与单源点同档） |
| **争议点** | 各来源对同一材料得出**不同结论／不同归因** | **不计入分母**；答任一方都算命中 |

**两条铁律（先于一切）**

1. **材料原文依据是硬门槛**：每个采分点**必须给出材料原文出处**（写成 `材料X第Y段"……"`）；
   **拿不出就删除**，不进采分点表。
2. **共识度不能排除材料确凿的点**：参考答案是校准尺、不是判据，机构集体漏点是常态。

**同源只算一家（`工具/ref_independence.py`）**：机构之间大量互相转抄，**独立来源家数 = 分组数，
不是文件数**。对同一题的参考答案两两算文本重合率并分组：`--same`（默认 **0.80**）同源转抄、
`--near`（默认 **0.60**）疑似同源（保守同组）；**只有 1 家、或全部同源 → 该题没有共识点**。

可复制命令：

```bash
python 工具/ref_independence.py 参考答案/{省份}/{卷ID} --question N
```

> 提示：**给分不用文本相似度**；`ref_independence.py` 的相似度**只用于参考答案之间判同源**。

**分值池纪律**：单源点 ＋ 材料推定点合计 **≤30%**；**漏掉它们只扣该点小分值，
不得据此判定"内容不全面"或整体降档**；**无共识点**（无参考答案／只有 1 家／全同源）→
整题退回**纯模拟重构（L3）**，全部按"材料推定点"，**置信度中／低**。
**逐点回退**（不是整题开关）＋**冲突分型**（同义表达／粒度差异／漏点／真争议／正误分歧，
只有"对同一材料得出不同结论／归因"才是争议点）细则见 `references/small-questions.md` 第四节 5–6。

**共识表缓存**：`批改报告/.采分点共识/{卷ID}-第N题-共识表.md`，表头记录参与归并的参考答案
**文件清单 ＋ 字节数 ＋ 修改时间**（**来源指纹**）；同卷再批**直接复用**，**指纹变了就重建**。

## 批改规范接入（有就必须引用）

工作区 `批改规范/{省份}/{卷ID}-批改规范.md`（整卷）与 `{卷ID}-大作文批改规范.md`（仅大作文）：
**只要存在就必须引用**，**大作文批改规范尤其必须逐条对照**；层级按来源判定
（官方公开 → L1/L2，优先于本 skill 模拟口径；机构/自拟 → L4 校准；
**助手从 N 篇范文／用户标注样本提炼的草稿（L4）→ 文件头须标"待用户确认"，可用于批改但报告须注明
"未确认草稿"，用户手写规范优先、不覆盖**；来源不明 → 只能用来说明
"该卷可能怎么判"，不得当官方标准）；与 L1 题面要求冲突时以题面为准。
报告须登记文件名/来源/年份/层级；提炼口径见 `references/essay-exemplars.md` 第 5 节。

## 参考答案接入（L4 经验校准）

**每道题批改前都先查工作区 `参考答案/{省份}/{卷ID}/`**：命中就登记文件名/来源/年份/独立来源家数，
用它校准同义表述宽严与采分点粒度；未命中就明确写"未找到参考答案"，按 L3 模拟重构，
**不许找替代、不许编造、不许把机构答案说成官方标准**。

**置信度是"采样与校准"口径，不是数量函数**：参考答案只提高"同义宽严、采分点粒度、档位边界"
三项判断的可靠性；**同一来源的多份只算一份**，来源独立且覆盖本题才算有效采样；
来源与本年卷不符、只覆盖部分题目的一律不因此上调置信度。规则见 `references/reference-answers.md`。

## 工作区目录与命名（卷ID 为唯一键）

**卷ID = `{四位年份}{省份}{卷型}`**（如 `2022河南乡镇`、`2026国考行政执法`、`2024浙江A`）。

| 目录 | 放什么 | 规范 |
|------|--------|------|
| `真题/` | 试卷原题 PDF（**L1 题面与材料**）＋ 真题库 md | `{省份}/{卷ID}.pdf`、`{省份}/真题库/{卷ID}.md`、`{省份}/真题库/INDEX.md`、`_TEMPLATE.md` |
| `参考答案/` | 机构/真题参考答案（**L4 校准，非官方**） | `{省份}/{卷ID}/第N题.txt` |
| `作答记录/` | 用户作答（**只收 md/txt**） | `{省份}/{卷ID}.txt`，多稿 `-v2` |
| `批改报告/` | 批改报告（md 母本 + `.字数核验/` 留痕 + `.采分点共识/` 小题共识表缓存 + `.大作文刻度/` 大作文梯队刻度缓存） | `{省份}/{卷ID}-批改报告.md`，多版本 `-v2` |
| `批改规范/` | 某卷（尤其大作文）的批改规范 | `{省份}/{卷ID}-批改规范.md`、`{卷ID}-大作文批改规范.md` |

工作区根目录另有 `工具/` —— **skill 的配套脚本**（`count_chars.py` 字数核验、`ref_independence.py` 参考答案同源检测）；路径固定，请勿改名或移动（skill 的文档按此路径调用它们）。它不是五个材料目录之一，由安装器一并创建。

- **材料不用自己摆**：丢到工作区主文件夹即可，助手会按规范**自动分类归位并重命名**，
  并在对话里列出"原路径 → 新路径"；**命名含糊时（`申论.pdf`、`答案.txt`、`新建文件夹`）
  先向用户确认，绝不猜测**。完整规范见 `references/workspace-layout.md`。
- **图像不是合法作答格式**：检测到图片/扫描件时，助手会**请用户自己先转成文本**
  （OCR 难免字误，会直接影响采分判定），用户明确要求代转才 OCR 并注明转写方式。

## 功能

- 大作文"档位锚定 + 硬伤修正 + 档内定位（上/中/下）"评判（含原文证据、区间与置信度）
- **形式不参与定档（判语黑名单）**：结构维度只查**点题／展开／收束 ＋ 层次 ＋ 衔接**，
  **检查项里没有"是否符合某类型／某模板／某名师框架"**；出现"不符合五段三分""归类困难按三类处理"
  "套模板扣 X 分"（反向"用了某框架加分"同样作废）等判语，**该处判分一律作废并删除**
  （本 skill 评分纪律，非官方；`references/essay-judging.md` 1.2 判语黑名单）
- **"深刻"四级刻度 ＋ 两条硬纪律**：复述型 → 明理型 → 见地理型 → 洞见型；
  **题面没要求"见解深刻"就不得以"不够深刻"降档**；**说"不够深刻"必须点名缺哪一层**
  （因果／边界／一般化／纠偏），**说不出层次该评语作废**（四级刻度属 L3 模拟口径，非官方；`essay-judging.md` 1.7）
- **范文梯队刻度（六项特征卡／相对刻度，不作分数锚点）**：T1/T2 梯队 ＋ 六项特征对照，
  只用于**档内定位与改进方向**；**不参与定档、不因"像范文"加分**；缓存于
  `批改报告/.大作文刻度/`，日常批改只读梯队画像（`references/essay-exemplars.md`，L3/L4 非官方）
- 小题**多源共识采分**：按 `参考答案/` 判共识点／单源点／材料推定点／争议点定价
  （共识点占 70%–80%，单源＋推定 ≤30%），**每个采分点必须给出材料原文依据**；
  拆为"核心动作｜核心对象｜关键限定/结果"，**不设 80%/40% 覆盖率阈值**；
  采分点为 L3 模拟重构；**同义表达照给分**
- 公文先查**任务目的与身份场景**，再查内容/格式/语言，按点赋分（占比为训练参照，非官方比例）
- 作答与构思指导（立意 / 结构 / 分论点 / 论证，全部标注"辅助工具"）
- 规范表达与八大主题金句素材
- **工作区真题库匹配**（`真题/{省份}/真题库/INDEX.md`，按需加载，不占 skill 体积）与命题预判
- **批改规范引用**（`批改规范/`）、**参考答案校准**（`参考答案/`，L4）
- **评分置信度（采样与校准口径）**：每次批改都给"建议区间 + 置信度 + 理由"
- **字数核验（脚本统计，非估算）**：`工具/count_chars.py` 输出答题卡口径字数
- **依据层级标注**：L1 / L2 / L3 / L4，每份报告都带"评分依据声明 + 置信度"

## 真题源优先级（重要）

判分基准按以下顺序取用，**不得跳过前几级凭记忆重构采分点**：

1. **工作区 `批改规范/`**（该卷规范，**有就必须引用**；官方公开 → L1/L2，优先于模拟口径）。
2. **工作区 `参考答案/`**（L4 经验校准，非官方）：校准宽严与粒度，须登记来源。
3. **工作区本地官方 PDF 原件**（L1 题面与材料）：`真题/{国考|河南|浙江}/{卷ID}.pdf`。
4. **已入库真题 md**：`真题/{省份}/真题库/{卷ID}.md`（含重构参考采分点，见同目录 `INDEX.md`）。
5. **用户直接提供的题目原文**（以此为准）。
6. **模型自身知识**（仅在前几级都不可用时，且必须标注"未经核验"）。

> 新环境默认**没有**真题库（`真题/` 为空）→ 直接走通用流程，不报错、不臆造题库。
>
> **小题按共识模型定价**（见 `references/small-questions.md` 第四节）：先按 `参考答案/`
> 判**共识点／单源点／材料推定点／争议点**，再给分（L3 模拟口径 ＋ L4 校准，非官方）。

## 批改前五步（`SKILL.md` 第三节）

① **材料归位与命名检查**（散落文件先自动分类归位，含糊的先问用户）；
② **定位用户作答**（对话已贴则优先，否则到 `作答记录/` 找）；
③ **引用批改规范**（该卷有规范就必须引用，大作文规范逐条对照）；
④ **查参考答案**（有就用并登记来源，没有就说明没有；**小题按共识模型定价**——
见 `references/small-questions.md` 第四节）；
⑤ 真题识别（可选）。
