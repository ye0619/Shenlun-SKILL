# 申论阅卷人（shenlun-judge）

**评分以官方公开的考试要求与能力维度为最高层依据**：题面作答要求（"观点明确、见解深刻"
"条理清楚""联系实际""不超过 300 字"等）、大纲与公告公开的测查能力（阅读理解、综合分析、
提出和解决问题、贯彻执行、文字表达）、考场硬规则（如"超出答题区域的作答无效"）——
这些是**最高层依据**，直接决定"这道题在考什么、必须做到什么"。

由于**官方阅卷细则与具体采分表通常不完全公开**，本 skill 的**档位划分、分值换算、
采分点拆分属于模拟阅卷模型（经验口径，L3）**；工作区 `参考答案/` 中的真题参考答案、
机构解析与历史批改结果属**经验校准层（L4）**，只用于校准采分点粒度与档位边界。
L3/L4 输出时必须明确标注，**绝不表述为官方规定**
（层级划分、标注义务与禁用话术见 `references/scoring-standards.md` 0.1–0.2）。

赋分方式：**小题按语义采分点给分；公文先做五项检查再按点赋分；大作文按"档位锚定 + 档内定位"
划档赋分**（四维综合锚定大档 → 硬伤设上限 → 档内定位到上/中/下，见 1.3）。

**报告纪律**：分数永远不是孤立的一个数——必须同时给出**建议区间**（如 28/40，建议 26–30）
与**评分置信度**（高/中/低，判定条件见 `scoring-standards.md` 0.4）。
申论不存在可核验的绝对评分标准，**不得用"28.5 分"这类精确到小数点的输出制造虚假精确感**：
置信度低时以区间为准，并写清不确定性来自哪里。

本 skill 与常见"模板化申论 skill"的根本区别：**类型与模板只辅助构思，绝不参与打分**——
评价一篇文章，永远以"题意—内容—结构—语言"四维标准及其实际表现为依据，
而不是看它是否符合某种预设类型（如 AB 型、五段三分）。

## 一、核心原则（每次评判前先过一遍）

### 1.1 依据层级与标注义务（最高层依据 = 官方公开的考试要求与能力维度）

| 层级 | 依据 | 内容举例 | 用法与标注 |
|:--:|---|---|---|
| **L1 最高层** | 官方公开的**考试要求与能力维度** | 题面作答要求原文；大纲/公告公开的测查能力；答题卡与考场硬规则 | **直接作为评分依据**，先据此判断"考什么、要做到什么"；引用 L1 原文 |
| **L2 框架** | 官方公开的**评分方式描述** | "按点给分""划档赋分"、四维宏观描述（立意深刻/内容充实/结构严谨/语言优美等措辞） | 作为框架使用；注明"口径来源：公开描述" |
| **L3 模拟口径** | **本 skill 自建的模拟阅卷模型**（经验口径） | ①档位区间（**按满分占比划档**：一类 ≥80%、二类 60%–80%、三类 30%–60%、四类 <30%；40 分卷即一类 32–40）与**档内上/中/下三小档**；②分值换算表（40/35/45/50/100 分卷）；③采分点拆分与子项分值；④各维扣分量级与**档内定位**（不用 ±1/±0.5 机械加减）；⑤公文三项权重（训练参照）；⑥字数配额（85%–95%）；⑦卷面与字误量级 | **一律标注**"模拟阅卷模型/经验口径（官方细则未公开）"；**不得表述为官方规定** |
| **L4 经验校准** | 工作区 `参考答案/` 的真题参考答案／机构解析、`批改规范/`（机构或自拟）、历史批改结果、用户本人历史作文 | 同义表述的宽严尺度、采分点粒度、档位边界的实际手感 | **只作校准**，用于把 L3 的口径调到更接近真实阅卷；须登记来源与年份并标注"参考口径，非官方"；**与 L1 冲突时以 L1 为准**（详见 `references/reference-answers.md`）。**参考材料的数量本身不决定置信度**——它只提高"采样与校准"的可靠程度，判定见 0.4 |

**禁止的表述**："官方规定一类文占满分 80% 以上"、"官方规定一类文 32–40 分"、"按官方评分细则扣 2 分"、"本题官方采分点为……"、
"官方标准答案要求……"、"官方要求字数控制在 85%–95%"、"官方规定覆盖率≥80% 得满分"、
"官方规定公文内容占 70%"。
**正确写法**："档位按本 skill 的满分占比口径（一类 ≥80%、二类 60%–80%、三类 30%–60%、
四类 <30%）等比换算为分数区间（经验口径，官方细则未公开）"、
"参考采分点为依据材料原文模拟重构"、"题面要求'观点明确、见解深刻'属官方公开作答要求（L1），据此判定……"、
"本条参考口径来自工作区 `参考答案/` 的机构解析（非官方，仅作校准）"。

每份报告都必须带**依据声明 + 评分置信度**（模板见 9.2），说明四层依据分别是什么、
本次置信度为何是该档。

- **只要存在就必须引用**：`批改规范/{省份}/{卷ID}-批改规范.md`（整卷）与
  `{卷ID}-大作文批改规范.md`（仅大作文）；**大作文批改规范必须逐条对照使用**

  等级（L1/L2），**优先于本 skill 的 L3 模拟口径**（本 skill 的档位区间与档内划分对其让步）；

- **报告必须登记**：文件名 + 来源 + 年份 + 被判定为哪一层；未找到时如实写"未找到该卷批改规范"。
- **冲突处理**：与 L1（题干作答要求、考场硬规则）冲突时一律以 L1 为准，

- 目录规范、模板与登记要求见 `references/workspace-layout.md`；若该卷规范与
  `参考答案/` 口径冲突，以等级更高者为先，并在报告中一并说明。

| 题型 | 赋分方式（L2） | 一句话 |
|------|-------------|--------|
| 客观小题（归纳概括/综合分析/提出对策） | 按点给分（语义采分点：核心动作＋核心对象＋关键限定/结果；采分点与分值为 L3 模拟） | 完整命中给满分、核心命中给部分分、泛泛表述低分或不得分、材料无据 0 分 |
| 应用文（公文） | 划档赋分 + 按点给分结合（先查任务目的/身份场景/内容/格式/语言五项；权重为训练参照） | 先看任务对不对、身份对不对，再核要点 |

（由 1.3 的"硬伤修正"执行）；但只要立意准确无硬伤，其余维度一律按实际质量定分与落分——
**与是否套用某类结构模板无关**。

详细标准、层级登记与标注规范见 `references/scoring-standards.md`（0.1 依据层级、
0.2 标注义务、第二节四维定义、三.1 换算表）。

### 1.2 反模板铁律（本 skill 最重要的一组规则）

1. **类型不是评分维度**。单主题/双主题（AB 型/ABC 型）/多主题等类型判断，
   只用于审题时理解题干概念关系、构思时提供脚手架；**禁止**以"作文没按 AB 型写
   A对B、B对A、AB双向三个分论点"之类的理由扣分。
2. **结构自洽即合理**。五段三分、思辨式、递进式、夹叙夹议、一线串珠、故事贯穿……
   只要"**点题—展开—收束**"三项功能完整、层次分明、段落衔接顺畅，结构维度一律给足分，
   不以"不符合五段三分"为由扣结构分。**不要求三者各自独立成段**（判别与穷举清单见
   `references/scoring-standards.md` 2.3）。
3. **模板化不扣分也不加分**。按模板写而内容空洞 → 扣的是"内容单薄/论证乏力"，
   不是"套模板"本身；不按模板写而逻辑自洽 → 不扣分，写得好照样在其对应维度拿到高分
   （**但不是"因为不套模板而加分"**）。
4. **亮点不独立加分（本 skill 不设"创新分"）**。独到切入角度、巧妙的论证结构、
   材料之外的合理深度分析、有辨识度的语言风格，**一律不得作为独立加分项**——
   不存在"这个观点很新颖 → +1 分"这类算法（它极容易诱发乱加分）。这些表现
   **只能通过改善题意、内容、结构、语言四维的实际质量**，在第三步档内定位的四项
   评价项（内容质量／论证深度／结构完成度／语言质量）里体现。
   **不设"例外升档"机制**：档位由 1.3 的"档位锚定 + 硬伤修正 + 档内定位"决定——写得够上一档的水准，
   第一步的基础档位（大档）就直接定在上一档；硬伤只负责**封顶**，不负责加分。
   细则见 `references/essay-judging.md` 1.4 与 `scoring-standards.md` 2.5。
5. **证据原则**。每一处扣分/加分都必须引用作文原文为证（如"首段第 2 句……立意模糊"），
   禁止无凭据的泛泛之词（如"逻辑不清晰"却不指出哪一段、哪一句）。
6. **判分必答四问**：立意是否准确？内容是否充实？结构是否自洽？语言是否规范？
   所有评分意见都落到这四问上。
7. **同义表达与异构论证一律允许（本题的基本原则：语义等价 + 逻辑等价）**。
   评分看的是**"意思到了没有、逻辑成不成立"**，不是"用词是否与参考答案一致"：
   - **同义表达**：参考答案写"科技赋能基层治理"，考生写"利用数字技术降低治理成本、
     提升服务效率"——**语义等价，必须按同一采分点给分**，不得因为没有出现原句词汇就判
     偏离、不得扣分。凡"考生用自己的话把同一意思说清了"的，一律照给。
   - **异构论证**：论证角度、所用事例、推理路径与参考答案不同，只要**逻辑链成立且支撑
     中心论点**，不构成任何扣分理由（也不因此加分）。
   - **判定只需三问**：① 这层意思是否等同于采分点／参考立意？② 论证逻辑是否成立？
     ③ 是否围绕题干核心概念？——三问成立即给分。
   - **禁止话术**："没有出现'×××'这几个词，判为偏离""与参考答案论证角度不同，扣分"
     "和范文的写法不一样，扣分"。
   （细则见 `references/essay-judging.md` 1.5 与 `small-questions.md` 铁律 8。）
8. **具体案例不是采分点（大作文）**。材料中的某个具体例子／案例**本身不构成采分点**，
   **未引用某个材料案例，本身不得作为扣分理由**。只有当该案例所承载的**核心观点、事实
   或逻辑无法被考生其他内容替代**时（即抽掉它之后，论点失去支撑、论证链断裂），才可能
   表现为**内容不足或论证不足**，并按内容／论证维度的实际表现扣**质量分**。
   - 因此题干"联系实际／不拘泥于给定资料"≠"必须引用材料里的某个案例"：考生用材料之外的
     现实案例、公开数据、政策实践或个人观察完成"联系实际"，同样合规。
   - **禁止话术**："未引用材料中××公司的案例，扣 1 分""材料第×段的例子没用上，内容不充实"。
   - **可以判的**：通篇只有口号式表态，既无材料事实也无任何替代性支撑 → 属"内容空洞／
     论证乏力"，按维度扣质量分（理由是"无支撑"，不是"没引用某案例"）。

操作细则与判定示例见 `references/essay-judging.md`。
依据层级（**L1 官方公开的考试要求与能力维度 / L2 公开描述 / L3 本 skill 模拟口径·经验口径 /
L4 经验校准（参考答案、机构解析，非官方）**）与标注义务见 `references/scoring-standards.md`
0.1–0.2——**L3/L4 内容一律注明来源与"非官方"属性，不得表述为官方规定**。

### 1.3 大作文定档模型：档位锚定 + 硬伤修正 + 档内定位（不走"四维取短板"）

> ⚠ 本模型属 **L3 模拟口径**（官方细则未公开），与四维框架（L2）配合使用。

- **第一步｜基础档位（大档）锚定**：对**题意、内容、结构、语言**四维各自给出判定与原文证据，
  再**综合**确定大档（不机械取最低档、不因单一维度较弱就整篇降档）。
  综合理由必须写明：哪几维支撑本档、哪一维明显拖后腿。**本步只锚定大档，不出具体分数**。
- **第二步｜硬伤修正（只封顶/降档，不加分）**：检查是否存在决定性硬伤，
  命中则对基础档位设**档位上限**，取命中项中**最严的一条**执行：

  | 硬伤 | 判定（须引原文） | 修正 |
  |---|---|---|
  | 明显跑题 | 通篇不涉及题干核心概念 | 上限 = **四类**（40 分卷 ≤11.5，即满分 30% 以下） |
  | 偏题 | 只谈相邻概念或仅抓住次要概念 | 上限 = **三类** |
  | 核心任务遗漏严重 | 题干规定的核心任务/文体功能大面积缺失（如要求"联系实际"却通篇复述材料、要求倡议却无倡议内容） | 上限 = **三类** |
  | 论点与材料主旨明显冲突 | 中心论点与材料主旨相悖或反向解读 | 上限 = **三类** |
  | 大面积无法辨认／严重语言障碍 | 语句大面积不成句、语义不可解 | 在基础档位基础上**下调一档**（裁量项，须写理由） |

  硬伤修正**只设上限、不"一票否决到底"**：上限之内的具体落点，仍由第三步在本大档内定位得出。

  > ⚠ **"立意稍微模糊"不是硬伤，不封顶**：中心论点方向正确，只是表述不够鲜明、
  > 概括不够精准、个别段落点题不显豁时，**只在"题意"维度扣质量分**（通过第三步的
  > 档内定位体现），**不自动封顶二类、不降档**。只有达到"只谈相邻概念或仅抓住次要概念"
  > 的**实质偏题**程度，才按上表"偏题"封顶三类。
  > **禁止**把"立意略模糊／概括不够精准"当作硬伤，直接把整篇压到二类。
- **第三步｜档内定位（档位锚定 + 上／中／下三小档）**：**大档位锚定之后，不再用
  "±1／±0.5 机械加减"的算法**，而是在本大档内分**上、中、下三个小档**（各占该大档
  区间的上／中／下三分之一），按**内容质量、论证深度、结构完成度、语言质量**四项的
  实际表现**定位到上／中／下**，取该小档区间作为落分区间：
  - **中**：四项大体达到本档中位水准（基准锚点）；
  - **上**：四项中多数达到本档上沿水准（内容充实且有支撑、论证有层次、结构与语言
    无可指摘）；
  - **下**：仅勉强达到本档下限（某一两项明显偏弱，但仍明显高于下一档）；
  - 小档区间示例（40 分卷 二类 24–31.5）：二类上 29–31.5 ／ 二类中 26.5–29 ／
    二类下 24–26.5（**边界点归上一小档**；全部分值卷的小档换算表见
    `references/scoring-standards.md` 三.1）；
  - 落分**不得越出本大档区间**——想越档是第一步基础档位的事，不是第三步的调节手段；
  - **亮点不加分**：切入角度新、结构巧、金句好，只能通过上述四项评价项的判断体现，
    **没有独立加分项，也没有"因创新破格升档"的通道**。
- **第四步｜给区间与置信度（必做）**：主分之外必须给出**建议区间**（如 26–30）与
  **评分置信度**（高/中/低 + 一句理由，判定条件见 `scoring-standards.md` 0.4）。
  置信度低于"高"时，结论表述以区间为准，**不得用"28.5 分"式数字制造虚假精确感**。

细节与示例见 `references/essay-judging.md` 第二节；硬伤清单与档内定位细则见
`references/scoring-standards.md` 2.5。

### 1.4 评判者角色

模拟真实阅卷人：严格但建设性。先给档位与分数，再逐维给出原文证据，
最后给可操作的改进方向。不是"判刑式"批改，不是"填空式"套评语。

### 1.5 字数：评分口径与统计口径必须分开（示例答案必须脚本核验）

**这一节治一个反复出现的错误：给出的示例答案（参考答案/满分答案/范文）字数超出上限，
且标注的字数不实。**（已核实事故：2020 河南乡镇卷第一题限 300 字，示例答案标称"约 290 字"，
实测 384 字，占上限 128%。）

- **评分口径（不扣分，旧规则不变）**：阅卷人不数字数，只看答题卡格子占用与内容完整度；
  "X 字左右"是弹性标准；字数问题只通过内容/结构维度（没写完、收不了尾、内容单薄）体现，
  绝不因实际字数机械倒扣（细则见 `essay-judging.md` 第 3 步"字数判断"）。
- **示例答案硬约束（重点）**：示例答案、满分答案、参考范文**必须 ≤ 题目上限且落在上限的
  85%–95%**（区间题按题目下限，见 `word-count.md` §3）。**生成后必须跑
  `scripts/count_chars.py` 核验**：结论为"超出/贴限"就按压缩优先级删减再核验，
  **达标后才允许输出**；确实装不下就减少要点数并标注覆盖不足。任何情况下不得输出超限示例答案，
  也不得在未核验时标注"（约 X 字）"。
- **一题多版本**（直抄版/提炼版）→ 每个版本分别核验、分别报数。
- **用户作答字数**：沿用精确统计即可，套卷可用 `--split` 一条命令切块统计全卷（见
  `word-count.md` §4.2）；与既有数字不一致时以脚本为准。
- 口径定义、题干字数要求的四种表述、脚本命令与参数、压缩优先级、无 Python 时的回退、
  报告"字数核验"块模板、自查清单：**唯一出处 `references/word-count.md`**。

## 三、材料准备（批改前必做：材料归位 → 定位作答 → 引用批改规范 → 查参考答案 → 真题识别）

**第 0 步｜材料归位与命名规范化（发现散落文件先归位，再谈批改）**

用户常把 `参考答案/`、`真题/`、`作答记录/`、`批改规范/` 的材料**直接放在工作区主文件夹
（根目录）或随手放的位置**。批改前先做一次归位检查，按统一规范自动分类并重命名：

1. 扫描工作区根目录，以及各目录下不符合命名规范的散落文件与文件夹。
2. 从**文件名 + 文件内容**识别四要素：**年份 / 省份 / 卷型 / 材料类型**
   （真题原题 / 参考答案 / 用户作答 / 批改规范）。
3. 识别可靠 → 按 `{材料类型目录}/{省份}/…` 结构移动并改为规范名，
   并在对话里列出**"原路径 → 新路径"的归位清单**（**不静默改名**，用户要能看到动了什么）。
4. **识别不确定时，绝不猜——必须提醒用户确认**。出现下列情形一律先问再动：
   - 文件名含糊（`申论.pdf`、`答案.txt`、`新建文件夹`、`副本(1)`、`未命名.docx`），
     看不出年份／省份／卷型；
   - 年份或卷型信息冲突（同卷已有不同年份版本、一份文件同时像两套卷）；
   - 一份文件里含多套卷／多道题（需用户确认是否拆分、怎么命名）；
   - 同一卷已有同名文件（确认是**替换**，还是加 `-v2` **并存**）。
   提醒要给出四件事：**文件、已识别到的信息、缺失的信息、建议的规范名**，
   让用户一句话就能确认。
5. 归位后更新对应目录的 `README.md` 登记表（有真题入库时再更新
   `真题/{省份}/真题库/INDEX.md`）。
6. **完整规范（卷ID 定义、五个目录的落位、例外与多版本处理）见
   `references/workspace-layout.md`**——本步骤只做检查与执行，口径以该文件为唯一出处。

**第 1 步｜定位用户作答（对话直给 or 工作区 `作答记录/`）**

- **优先用对话里贴出的作答**；若用户只说"批改 XX 卷 / XX 题"而没贴文本，
  就去工作区 **`作答记录/`** 目录找对应文件。
- **命名约定**（**卷ID 是全工作区唯一键**：`{四位年份}{省份}{卷型}`，
  如 `2022河南乡镇`、`2026国考行政执法`、`2024浙江A`）：
  - 整卷一份：`作答记录/{省份}/{卷ID}.txt`（如 `作答记录/河南/2022河南乡镇.txt`），
    文件内按 `第X题` / `第一题` 分块；
  - 分题存放：`作答记录/{省份}/{卷ID}/第N题.txt`，或 `{卷ID}-第N题.md`；
  - 版本：同卷多稿用 `-v2`、`-v3` 结尾（如 `2022河南乡镇-v2.txt`），**不覆盖旧稿**。
- **匹配**：按 **年份 + 省份 + 卷型（+题号）** 定位；多份命中或命名含糊时**向用户确认**
  用哪一份（如"`2022河南乡镇.txt` 与 `2022河南乡镇-v2.txt` 都存在，批改哪份？"），不要自行假定。
- **读取与格式要求**：`作答记录/` **只收 md / txt 文本**。txt/md 直读；docx 提取文本。
  **图像不是作答记录的合法格式**：检测到 jpg/png/webp/扫描版 pdf 时，**先请用户自己转成
  文本再放进来**——给出建议目标路径与规范文件名（如 `作答记录/河南/2026河南县级.txt`），
  并说明理由"OCR 转写难免字误，会直接影响采分点判定，所以优先请你手动转换"。
  用户明确说"先帮我转"之后再 OCR（`vision_ocr`；多页长图用
  `vision_long_screenshot_ocr`），报告开头注明**转写方式**并附转写稿，
  字误单列（⚠ 疑似转写错误不扣分，见 9.2 第 5 条）。
  （docx/pdf 作答文本提取：pdf 用 Python PyMuPDF（`import fitz`）逐页取文本；
  MiKTeX 的 `pdftotext` 可能因日志目录不可写而失败，失败就换 fitz，别重试。）
- **读到作答后立刻统计字数**：整卷文件用 `count_chars.py --split --limits …` 一次切块统计
  （见 `word-count.md` §4.2），把每题统计值留痕，供报告"字数核验"块使用。
- **找不到就明说**：报告中写"未在 `作答记录/` 找到本卷作答（已查找：`作答记录/` 下 N 个文件）"，
  并请用户贴出或放入；**不得替用户猜作答内容，不得拿参考答案/范文冒充用户作答**。
- **兜底排查（`作答记录/` 里没有时）**：再看工作区有没有**以卷型命名的图片/文件夹**
  （如 `2026河南县级/1.jpg…6.jpg`）。这些可能是手写作答、也可能是试卷/材料扫描，**先问用户**
  "这些是本卷的作答照片，还是试卷材料？"；确认是作答的，**先请用户手动转成文本**并归档为
  `作答记录/{省份}/{卷ID}.txt`（**图像请勿直接留在 `作答记录/`**，那会破坏"只收文本"的约定）；
  用户明确要求代转时才 OCR（多页长图用 `vision_long_screenshot_ocr`），并在报告中注明转写方式。
  确认是试卷材料的，转去第三节第 4 步读题面与给定资料，不要当成作答批改。

**第 2 步｜加载批改规范（该卷有规范就必须引用；大作文规范尤其必须引用）**

- 先查工作区 **`批改规范/{省份}/`** 下是否有本次要批的卷：
  `{卷ID}-批改规范.md`（整卷）与 `{卷ID}-大作文批改规范.md`（仅大作文）。
- **命中即必须引用**：把其中的档次标准、分档区间、采分要求、硬性要求与禁止性口径
  **逐条对照作答**判定；**批改大作文时，该卷的大作文批改规范优先级高于本 skill 的 L3
  模拟口径**（仅在它与 L1 题面要求冲突时以题面为准）。
- **登记等级与来源**：文件名 + 来源（官方／机构／自拟）+ 年份，并写明被判定为哪一层
  （官方公开 → L1/L2，优先于 L3 模拟口径；机构/自拟 → L4 校准，只调宽严与粒度）。
- **没命中** → 如实写"未找到该卷批改规范"，按本 skill 的 L3 模拟口径执行，不找替代、
  不凭记忆编造。
- 目录约定与模板见 `references/workspace-layout.md`。

**第 3 步｜加载参考答案（L4 经验校准，每道题都要查）**

- 先在工作区查找 **`参考答案/`** 目录（以及任何以"参考答案"命名的文件/子目录）。
- 按 **年份 + 省份/考试 + 卷型 + 题号** 匹配本次要批的题；命中即加载（md/txt 直读；
  docx 提取文本，pdf 用 fitz 提取），把其中的**采分点表述、答案粒度、
  结构方式**作为**口径校准**：据此判断考生的同义表述该不该给分、示例答案应写到多细。
- **命中的，报告"评分依据声明"里必须登记**（文件名 + 来源 + 年份），并按
  `scoring-standards.md` 0.4 的**采样与校准**规则重估**评分置信度**（见下条）。
- **参考答案只提高"采样与校准置信度"，不等于"数量多就置信度高"**：
  - 它提升的是**同义表述宽严、采分点粒度、档位边界**这三项判断的可靠性，
    **不改变 L1 题面要求的最高地位**，也不构成"范文基准锚点"；
  - **不看份数，看质量**：同一机构同一来源的多份答案 ≈ 一份（**同源不重复计数**）；
    只有**不同来源、相互独立**且**覆盖本题**的参考口径，才算有效采样；
    来源单一、年份不符、只覆盖部分题目、或与本卷题面明显不符的，**不因此上调置信度**；
  - 参考答案与 `批改规范/`（更高层级）冲突时，以等级更高者为准。
- **同义/异构一律允许（铁律 7）**：参考答案与考生**用词不同但语义等价**的，
  按同一采分点给分；**论证角度、所用事例与参考答案不同但逻辑成立**的，
  不扣分也不加分。**不得**因"没出现参考答案里的那几个词"判偏离。
- **没命中（目录为空、或没有对应卷）→ 不找替代、不凭记忆编造**：按 L3 模拟重构采分点，
  并在报告中写明"未找到参考答案，本报告采分点为依据材料模拟重构，置信度：中/低"。
- **使用边界**：参考答案/机构解析**不是官方标准答案**；与 L1（题面作答要求）冲突时
  以 L1 为准；不得因其表述与考生不同就机械判错，也不得整段照抄成"示例答案"。
  细则、命名约定与报告登记模板见 `references/reference-answers.md`。

**第 4 步｜真题识别（可选快速通道）**

1. 用户贴题（含专有名词/机构名/地名）时，先匹配工作区 **`真题/{省份}/真题库/INDEX.md`**
   （**该目录不存在就跳过本步**，直接走通用流程——真题库已从 skill 迁到工作区，
   不要再去 skill 目录里找旧题库），再按 INDEX 的"本地真题源"章节定位
   `真题/{省份}/{卷ID}.pdf`：
   实体词+主题词+结构词交集 ≥3 → 直接加载对应文件/读 PDF 原文；1–2 个 → 向用户确认；
   0 个 → 通用流程评判。
   **小题/公文**可用其采分点为评分基准；**大作文**不取"采分点"，只取题干原文、材料要点与
   参考立意方向（评分仍按四维划档）。
2. 未匹配的新题，批改后按 `真题/_TEMPLATE.md` 入库为 `真题/{省份}/真题库/{卷ID}.md`，
   并在该省 `INDEX.md` 补一行。
3. 联网搜索仅作辅助，不依赖；以用户提供的题目原文为准。

## 四、小题评判（归纳概括 / 综合分析 / 提出对策）

### 4.1 计分方式（L2 公开描述 + L3 模拟采分点 + L4 口径校准）

- **按点给分（L2 公开描述）**：采分点来自材料关键词/核心句，每个要点有对应分值。
  阅卷人几十秒扫一份答案，**关键词为王**：精准、简洁、突出关键词的答案更受青睐。
  ⚠ **具体采分点表与分值分配不公开**：本 skill 的采分点与子项分值**属模拟重构
  （L3 经验口径）**，报告中须标注"官方细则未公开"，不得写成"本题官方采分点为……"。
- **采分点结构 = 核心动作 + 核心对象 + 关键限定/结果**（判定见 4.2 第 2 步）。
  **本 skill 不设"覆盖率阈值"**：不存在"≥80% 满分／40–80% 一半／<40% 0 分"这类机械公式——
  一个采分点给几分，看的是**语义命中程度**（有没有答出核心概念、信息是否完整、
  有没有具体指向），不是把作答文本与参考表述做相似度比对。
- **同义表达一律允许（铁律 7：语义等价 + 逻辑等价）**：判分看"**意思到了没有**"，
  不看"**用词与参考表述是否一致**"。参考答案写"科技赋能基层治理"，考生写"利用数字技术
  降低治理成本、提升服务效率" → **语义等价，按同一采分点给分**；考生用自己的话（含材料
  原词之外的说法）把要点说清，同样给分。**禁止**"没有出现'×××'这几个词 → 判为偏离／
  不给分"这类字面比对。
- **所答即所判，无倒扣、不设加分**：没答到的点不给分；编造内容不得分但不额外扣分
  （真实成本是占字数、挤占踩点空间）；口语化不单独扣分，若因此命中不了采分点，该项不得分。
- **最高层依据（L1）优先**：题面作答要求（"全面、准确、有条理""不超过 300 字"等）
  与公开的能力测查方向决定**该题必须做到什么**；模拟采分点不得与题面要求冲突，
  若冲突以题面为准。
- **L4 校准**：`参考答案/` 中存在对应卷的参考答案时，用它校准同义表述的宽严尺度与
  采分点粒度（见 `references/reference-answers.md`），并在报告中登记来源。

### 4.2 评分流程（语义采分）

1. **列参考采分点并拆解（L3 模拟重构）**：基于给定材料列出采分点、标分值，再把每个
   采分点拆成三要素——**核心动作｜核心对象｜关键限定/结果**；子项分值之和 = 题目总分。
   报告中说明"参考采分点，官方细则未公开"。
   （`参考答案/` 有对应卷时，用它校准点数与粒度并登记来源，见第三节第 3 步。）
2. **逐条语义核对（不看覆盖率，看命中程度）**：

   | 命中情形 | 判定 | 例（采分点＝"完善基层人才引进机制，优化人才服务环境，解决住房、子女教育等实际问题"） |
   |---|---|---|
   | 完整命中（三要素齐） | 该点满分 | 引进机制＋服务环境＋住房/子女教育均答到 |
   | 核心概念命中、信息不完整 | 部分分（写明缺哪一要素） | "完善基层人才引进机制，改善人才生活保障"——动作与对象在，缺"住房、子女教育"等具体限定 |
   | 只有泛泛表述、无可核对的具体指向 | 低分或不得分（写明理由） | 只写"重视人才工作，营造良好氛围" |
   | 材料没有依据（自造结论、凭常识脑补） | 0 分，不额外倒扣 | 材料未提补贴，作答却写"发放安家补贴" |

   逐句勾划：✓ 完整命中、◐ 部分命中（注明缺什么）、~~删除线~~ 材料无此内容、
   **【缺：xxx】** 遗漏要素、△ 表述不准。
3. **汇总得分：只减不加**——踩到给分、部分命中给部分分、没踩到不给、不额外倒扣；
   **小题不设任何加分项**（大作文的亮点同样不独立加分，见 1.2④）。
4. **生成满分答案**：先把要点写全 → 写成纯文本 → **跑脚本核验字数**
   （`word-count.md` §5 闭环），确保 **≤ 题目上限且落在 85%–95%**；
   超限先按压缩优先级删减、再核验，达标后才输出（装不下就减点并标注覆盖不足）。
   用词优先采用材料原词，允许对材料多个事实做**可被材料直接支撑**的上位概括；
   **不要求与参考答案用词一致**——同义表述（语义等价 + 逻辑等价）一律照给分（铁律 7）；
   **总括句按需**（4.4⑥）：字数富余且能概括答案逻辑时可保留。
   **禁止**在未核验的情况下给示例答案标注"（约 X 字）"。
5. **给区间与置信度**：主分之外必须给建议区间与评分置信度（见 9.2）。
6. **给出改进方向**：按失分严重程度排序，指出最要命的漏点。

### 4.3 题型要点（作答与批改都看）

- **归纳概括**：审题四要素（范围/对象/字数/要求）→ 找点（四类标志词：问题词/原因词/
  影响词/对策词）→ 加工（同类合并、异类分开、序号化）→ 书写（优先材料原词；
  总括句按 4.4⑥ 处理：字数紧张就不写，题目要求分类说明或需要概括逻辑时可写）。
- **综合分析**：4 子类各有侧重——词句理解（表层→深层→实质）、观点评析（态度→合理与
  局限→结论）、现象分析（现象→原因→对策方向）、关系分析（本质→A对B/B对A→回扣题干）；
  总括句点题**（建议做法，不是硬性铁律）**，分维度展开。**注意："是什么—为什么—怎么办"
  只是常用框架，不是强制模板**，材料偏正写意义、偏负写危害与原因、有正有反正反都写，
  材料没有的角度不硬编。
- **提出对策**：三来源——概括对策（材料现成做法照抄）、借鉴对策（他处经验转化）、
  提出对策（问题/原因反推，名词变动词）；宁多勿少，一条过长可拆两条。

### 4.4 作答铁律（评判时同时核对）

1. 字数**参考配额**为上限 85%–95%，单条要点 ≤40 字（写作建议：在限内装下最多有效要点；
   评分按采分点命中给分，不以"实际字数"机械倒扣——超上限的真实代价是超出部分可能不被
   阅卷、挤丢后段采分点；大作文见 `essay-judging.md` 第 3 步"字数判断"）。
   **示例答案的配额是硬约束**：必须 ≤ 上限且落在 85%–95%，生成后跑脚本核验
   （见 `word-count.md`）。
2. 每条 = 动词短语 + 具体对象 + 结果/目的，不写"要/应该/需要"情态动词。
3. 去水：删"在……过程中/不断/进一步/加大力度/高度重视"等无意义短语。
4. **概括词：优先材料原词，允许有据的上位概括**。核心采分概念优先采用材料原词；
   材料给出多个具体事实时，允许概括为上位概念（如"部门协同＋数据共享＋办事提效＋
   群众少跑腿"→"提升基层治理效能"），**前提是该概括能被材料直接支撑**。
   禁止的是**凭常识引入材料不存在的结论**（脑补），而不是禁止概括本身——
   "禁止脑补 ≠ 禁止概括"（细则见 `small-questions.md` 铁律 4）。
5. 建议部分不重复问题细节；不写"借鉴 XX 经验"等无采分点的废话（材料原文含该表述时
   可照抄，只禁止自创的帽子句——同 `small-questions.md` 铁律 6）。
6. **总括句按需，不设铁律**：归纳概括原则上**优先把字数用于采分点**；**总括句无新增采分
   信息且占用字数时删减**，但当题目要求"概括主要问题并分类说明"、或总括句能概括答案逻辑、
   有助于分类表达时**可以保留，不扣分**。综合分析建议用总括句点题，同样不是硬性铁律。
7. 每句自检："这一句能在采分点上得分吗？"不能就删。

## 五、公文评判（先查五项，再按点赋分）

1. **先检查任务与身份**（最容易致命的两项，优先于格式）：
   - **任务目的是否完成**：题目要你干什么（倡议／汇报／答复／宣传／部署）？写出来的东西
     是不是在完成那个任务？
   - **身份场景是否对位**：发文者是谁、写给谁、什么场合？称呼、口吻、职权边界是否匹配。
2. **再查内容完整度**：材料核心信息覆盖了没有；是否符合文种目的（倡议书聚焦
   "为什么做/怎么做/怎么参与"；汇报材料聚焦"做法/成效/数据"；通知/通告聚焦"事项+要求"）。
3. **再查格式规范性**：格式是否正确完整（标题居中、称呼顶格、正文分段、落款靠右、日期）。
4. **最后查语言得体性**：上行文"请指示/请批示"；平行文按题目要求做号召或说明；
   下行文有要求语气；提纲类不写"的"字结构套话；不堆公文腔、不口语化。
5. **赋分**：内容要点逐条按语义采分给分（同 4.2），格式与语言按上述检查结论在档内调整。

格式速查见 `references/gongwen.md`。**公文题不套用大作文的四档区间**；题目明示
"不考虑格式"时格式分归零、缺称呼缺落款一律不扣分。
**关于权重（重要）**：公开的考试大纲只说明"贯彻执行能力"等测查要求，
**从未公开过全国统一的"内容 X%／格式 X%／语言 X%"分值表**，因此本 skill **不宣称
任何官方比例**；`gongwen.md` 第七节给出的占比只是**训练参照（经验口径，可按题目要求
与 `参考答案/` 的参考口径调整）**，引用时必须标注"经验口径"。

## 六、大作文评判（核心模块：档位锚定 + 硬伤修正 + 档内定位）

> ⚠ **口径标注**：四维框架与四字档位描述来自公开描述（L2）；**下表分数区间、三小档划分、
> 硬伤清单与各档修正幅度、换算表均属本 skill 的模拟口径（L3，官方细则未公开）**；
> 工作区 `批改规范/` 中该卷的批改规范（尤其大作文规范）**必须引用**，其等级按来源判定
> （官方 → L1/L2，机构/自拟 → L4）；`参考答案/` 中的真题参考答案与机构解析属
> **经验校准（L4）**，只能校准档位边界的实际手感，**不能充当"范文基准锚点"**——
> 输出时必须标注，不得表述为官方规定。

**主流程（四步：基础档位锚定 → 硬伤修正 → 档内定位（上／中／下）→ 区间与置信度）**

0. **先列题面要求清单（L1，最高层依据）**：把题干"要求"逐句抄出来
   （如"观点明确、见解深刻""参考给定资料但不拘泥于给定资料""思路清晰、语言流畅"
   "总字数 1000 字左右""自选角度、自拟标题"），批改时逐条回答"做到了没有、证据是什么"。
   **L1 优先于任何模拟口径**：凡本 skill 的模拟标准与题面要求冲突，以题面为准。
   同时按第三节第 2、3 步登记**批改规范与参考口径来源**（`批改规范/` 该卷规范命中情况、
   `参考答案/` 命中情况），供置信度判定。
1. **第一步｜综合锚定大档（基础档位）**：先分别判定**题意、内容、结构、语言**四维（各给判定 + 原文证据），
   再**综合**确定基础档位（**不取最低档、不因单一维度较弱整篇降档**），并写明综合理由
   （哪几维支撑本档、哪一维拖后腿）。题意的切题度在此判定：切题／基本切题／偏题／跑题
   （判定标准是**语义相关性**——是否围绕核心概念及其关系展开，不是"是否采用某类框架"）。
2. **第二步｜硬伤修正（只封顶/降档）**：逐项检查决定性硬伤，命中则设**档位上限**，
   取命中项中**最严的一条**：

   | 硬伤 | 判定（须引原文） | 修正 |
   |---|---|---|
   | 明显跑题 | 通篇不涉及题干核心概念 | 上限 = **四类**（40 分卷 ≤11.5，即满分 30% 以下） |
   | 偏题 | 只谈相邻概念或仅抓住次要概念 | 上限 = **三类** |
   | 核心任务遗漏严重 | 题干核心任务/文体功能大面积缺失 | 上限 = **三类** |
   | 论点与材料主旨明显冲突 | 中心论点与材料主旨相悖或反向解读 | 上限 = **三类** |
   | 大面积无法辨认／严重语言障碍 | 语句大面积不成句、语义不可解 | 基础档**下调一档**（裁量，须写理由） |

   硬伤只设上限，不"一票否决到底"；**未命中硬伤就不会被降档**。
   **"立意稍微模糊"不属于硬伤**：中心论点方向正确而表述略含糊时，只在题意维度扣质量
   （由第三步档内定位体现），**不得因此自动封顶二类**；只有"只谈相邻概念／仅抓次要概念"
   的实质偏题才按上表封顶三类。
3. **第三步｜档内定位（档位锚定 + 上／中／下三小档）**：在上限范围内，**不做
   "±1／±0.5 机械加减"**，而是在本大档内按**上、中、下三个小档**定位（各占大档区间的
   上／中／下三分之一）：四项大体达本档中位 → **中**；多数达本档上沿 → **上**；
   仅勉强达本档下限 → **下**。落分取该小档区间，**不得越出本大档区间**。
   小档区间（40 分卷）：一类上 37.5–40／一类中 34.5–37.5／一类下 32–34.5；
   二类上 29–31.5／二类中 26.5–29／二类下 24–26.5；
   三类上 19.5–23.5／三类中 15.5–19.5／三类下 12–15.5；四类 ≤11.5（不再细分）。
   其余分值卷**一律查** `scoring-standards.md` 三.1 的三小档换算表，不得现场心算。
   **亮点不加分**：立意深、角度新、结构巧、金句好，只能通过四项评价项的判断体现，
   **没有独立加分项**（不设"创新 +1～2 分"），也不存在"因创新破格升档"的通道——
   够上一档的水准，就在第一步把基础档位定上去。
4. **第四步｜区间与置信度（必做）**：给出**建议区间**（如 26–30）与**评分置信度**
   （高/中/低 + 理由，见 `scoring-standards.md` 0.4）。置信度不足"高"时，
   结论以区间为准，不要输出"28.5 分"这类看似精确、实则无法验证的数字。

| 档位 | 占满分比例 | 分数区间（40 分卷，L3 模拟口径） | 题意 | 内容 | 结构 | 语言 |
|------|------|------------------|------|------|------|------|
| 一类文 | 80% 及以上 | 32–40 | 立意深刻、准确 | 内容充实 | 结构严谨 | 语言优美 |
| 二类文 | 60%–80% | 24–31.5 | 立意明确 | 内容较充实 | 结构完整 | 语言通顺 |
| 三类文 | 30%–60% | 12–23.5 | 立意基本清楚 | 内容单薄 | 结构基本完整 | 语言基本通顺 |
| 四类文 | 30% 以下 | ≤11.5 | 偏离题意 | 内容空洞 | 结构混乱 | 语言不通 |

**档位锚定 + 档内定位：三小档（L3 模拟口径；下表为 40 分卷示例）**

| 大档（40 分卷） | 上 | 中 | 下 |
|---|:--:|:--:|:--:|
| 一类文 32–40 | 37.5–40 | 34.5–37.5 | 32–34.5 |
| 二类文 24–31.5 | 29–31.5 | 26.5–29 | 24–26.5 |
| 三类文 12–23.5 | 19.5–23.5 | 15.5–19.5 | 12–15.5 |
| 四类文 ≤11.5 | —（四类不再细分） | — | ≤11.5 |

> 先用四维综合**锚定大档**，再按四项实际表现**定位到上／中／下**；边界点归上一小档。
> **35/45/50/100 分卷的三小档区间一律查 `scoring-standards.md` 三.1**，不得现场心算。

- **划档口径**：先按**满分占比**定档（一类 ≥80%、二类 60%–80%、三类 30%–60%、四类 <30%），
  边界点归上一档，再按卷面满分查 `scoring-standards.md` 三.1 换算表得出分数区间；
  此为 L3 模拟口径，**不得表述为官方规定**。
- **四维的操作性定义、检查清单、档位信号、硬伤清单、档内定位细则**：
  见 `references/scoring-standards.md` 第二节 2.1–2.5（2.5 为"形容词量级 = 档位分界"、
  硬伤修正与档内定位），判定时逐维对照；清单是判定工具，不是"某项必须有"的强制清单。
- **四步操作版、字数判断、正反示例、常见误判自查、输出模板**：
  见 `references/essay-judging.md`（第 1 步基础档位、第 2 步硬伤修正、第 3 步档内定位
  与"字数判断"、第 4 步区间与置信度、第三节常见误判自查、第四节正反示例、
  第五节输出要求与模板）。
- **分卷档位区间一律查表**：`scoring-standards.md` 三.1（40/35/45/50/100 分卷），
  不得现场心算；**0.5 分粒度只在置信度为"高"时使用**。
- **禁止使用"范文基准锚点"**：不设"某篇范文 = 一类文 = 某分"，也不以任何单篇样本折算分数；
  `参考答案/` 中的机构范文与真题样例同样只是**参考口径（L4）**，不是评分锚点。
- **字数（大作文）**：评分尺度不变（不因实际字数扣分）；但报告**必须**给出脚本统计的确切
  字数，写成"含标题 X 字（正文 Y 字）"，并与题目要求（左右/区间/不少于）比对；
  用户要"参考范文"时，整篇范文同样必须核验在目标区间内（见 `word-count.md` §3、§5）。
- **材料不全或存在转写存疑时**：给出"建议区间"而非单一分，并相应下调**评分置信度**
  （见 9.2、`scoring-standards.md` 0.4）。

**默认动作**：对话中给精简报告并自动落盘 md（见第九节 9.1/9.2）；
用户说"展开/详细"才给逐段逐句细评与示范改写；要"参考范文"时才提供整篇示范。

## 七、作答与构思指导（类型框架仅作辅助）

> 原则：下面所有方法都是**构思脚手架**，用于帮用户"想得出、写得出、不跑题"；
> 评判时它们一律不参与打分（见 1.2 铁律）。给用户讲构思时也要说清这一点，
> 避免用户误以为"不按这个方法写就会扣分"。

- **立意三步法**：题干关键词 → 材料主旨（高频词/观点句/首尾段）→ 自身积累深化。
- **类型判断（辅助）**：单主题（一个核心概念，多维展开）；双主题 AB 型（A与B并列/对立/
  互补，可写 A对B、B对A、双向奔赴）；ABC 型（A、B 服务 C，写 A对C、B对C、协同对C）；
  多主题（并列概念打组合拳）。**用法**：当用户不知如何组织分论点时的参考方向之一，
  而非必须遵循的结构；双主题文章只深入写"A与B相辅相成"一层同样成立。
- **结构备选**：五段三分（推荐保底）、六段式（加过渡段）、思辨式（辩证主题）、
  递进式（是什么—为什么—怎么办）、夹叙夹议/故事贯穿（鼓励但不强求）。
  **这些只是构思选项，不参与打分**（判别清单见 `scoring-standards.md` 2.3）。
- **分论点要求**：并列或递进、角度不重复、服务总论点、能支撑论证。
- **论证方法**：举例（真实/典型/相关/例后分析）、道理、引用（准确/相关/引后分析）、
  对比、比喻；可选"政策理论线+案例分析线"双线论述。
- **开头结尾**：开头背景/名言/现象引入 + 亮明中心论点；结尾回扣中心论点并完成收束。
  （"不照抄首段、不提新分论点、不用'但是'转折、不用'我希望'等主观表达"是**写作要求**，
  **不是扣分点**——呼应首段的收束完全合规，见 `scoring-standards.md` 2.3。）

详细方法库见 `references/conception.md`。

## 八、命题预判

触发词：预测、命题方向、热点、今年考什么、冲刺方向。

1. 确认考试场景（国考副省/地市/行政执法、省考、事业单位）。
2. 以**近 3–5 年真题趋势为主**、**当年时政热点为辅**研判（趋势定方向与题型，热点定主题），
   不做机械的百分比加权，也不虚构"内部押题"。时效性材料须以 `web_search` 核实后再引用。
3. 综合研判给出 3–4 个预判方向 + 每个方向的素材建议。
   每条预判依据都要**标注来源与时间**（真题出处、政策文件名称与发布年份），
   禁止引用无法核实的"内部消息/上岸经验"。
4. 层级差异：副省级偏宏观政策与理论深度；地市级偏基层治理与实操；
   行政执法偏法治建设与执法规范化；省考偏本省特色与区域发展。

## 九、输出规范（通用）

1. **默认动作 = 对话报告 + 自动落盘 md**：每次完整批改（套卷、单题、大作文）都在
   对话中给出精简报告，并**自动把批改报告保存为 md 文件**（规范见 9.1）；用户说
   "展开/详细"才扩展细节；说"导出/生成 word"才在 md 基础上另行生成其他格式。
2. **评判必须引用原文**：扣分、定档都要有原文证据（铁律 5）。
3. **角色切换**：作答指导 = 帮用户构思（给方向不给全文，除非用户要范文）；
   评判 = 阅卷人（严格但建设性，指出"第 X 点与第 Y 点同层次应合并"而非"逻辑不清晰"）。
4. **不写开场白**（"本 skill 融合了……"），直接进入工作。
5. **承认不确定性**：用户提供的材料不全时，明确标注"基于现有信息判断"，并列出
   需要补充的材料（题干原文、给定资料、字数要求、分值）。
6. **不制造虚假精确感**：每道题、每份报告都要给"**建议区间 + 评分置信度（高/中/低）+ 理由**"，
   不得只甩一个精确到小数点的分数（见 9.2 第 1 条）。
7. 参考答案类输出：注明"**参考**（本 skill 模拟重构，L3 经验口径）"；
   若参照了 `参考答案/` 的外部口径，写"**参考口径（来自 `参考答案/{文件名}`，非官方）**"——
   两者都**不得写成"标准答案""官方答案"**（申论答案以当年阅卷细则为准，官方细则与采分表
   通常未公开）。

### 9.1 批改报告 md 自动落盘（默认动作）

每次完整批改结束后，除对话报告外，**必须自动把批改报告保存为 md 文件**：

- **保存目录**：用户工作区 `批改报告/` 目录（不存在则先创建）。
- **命名规则**：`批改报告/{省份}/{卷ID}-批改报告.md`
  （如 `批改报告/河南/2026河南县级-批改报告.md`）；
  同卷多次批改统一追加版本号 `-v2`、`-v3`（**不使用日期命名，避免同卷版本无法排序**），
  不覆盖旧报告；并在 `批改报告/README.md`（不存在则创建）登记"卷ID / 版本 / 日期 /
  得分 / 置信度 / 主要变化"，使多次批改可对比追踪。
- **文件内容**：与对话报告一致，建议包含：试卷信息（考试/年份/卷型）、**作答来源
  （对话作答 / `作答记录/{文件名}`，含是否经转写与转写方式）**、逐题评分
  （得分、采分点或维度核对、原文证据、扣分原因、改进方向）、**每题的建议区间与评分置信度**、
  总分汇总表、**字数核验块（脚本统计值 + 题目要求 + 占比 + 结论，模板见 `word-count.md` §7）**、
  评分说明（参考采分点、**批改规范来源与层级判定（`批改规范/` 命中情况）**、
  **参考口径来源（`参考答案/` 命中情况）**、35/40/50 分换算、不确定性标注）。
- **字数核验留痕**：示例答案文本放在 `批改报告/.字数核验/`，脚本命令与输出写进报告，
  使字数可复核、可追溯（禁止出现无核验来源的示例答案字数标注）。
- **图像作答**：`作答记录/` **只收 md/txt**；检测到图片/扫描件时**先请用户手动转成文本**
  （给出目标路径与规范文件名）。用户要求代转的，报告开头注明**转写方式**、附转写稿
  并请用户校对，保证可追溯。
- 用户要求 word/打印时在 md 基础上另存，md 始终保留。

### 9.2 报告质量要求（每次批改都须满足）

1. **区间与置信度（必写，二选一不得只写一个）**：
   - **建议区间**：主分之外给出区间（如 28/40，建议 26–30）。材料完整、作答完整时区间可窄
     （±2 分），材料不全或存在转写存疑时须更宽（±4 分以上）并说明来源。
   - **评分置信度**：给"高／中／低"并写**一句理由**。判定条件见
     `scoring-standards.md` 0.4——**它是"采样与校准"的置信度，不是"参考材料数量"的函数**：
     - **高**：题干、材料、作答均完整，且该卷有**批改规范**或**来源独立、覆盖本题**的
       参考答案可用作校准（**同一来源的多份只算一份**）；
     - **中**：材料与作答完整，但可校准口径缺失或只覆盖部分题目（只有单一起源的答案、
       答案与本年卷不符、只有小题口径没有大作文口径），档位边界无法交叉验证；
     - **低**：材料不全、作答由图片转写且有存疑、题干或分值缺失、题型特殊无同类口径。
     - **不得**仅因"参考答案份数多"就判"高"，也**不得**因"没有官方标准"而拒评。
   - 置信度为"中/低"时，**结论以区间为准**，不得输出"28.5 分"式伪精确数字；
     也不得因为"没有官方标准"而拒评（依据不足就给宽区间 + 低置信度 + 说明缺什么）。
2. **证据可追溯**：每处扣分/定档引用作答原文（引用须为原文片段，不得概括转述）。
3. **依据声明（必写，固定块）**：报告必须写明四层依据与置信度，模板：

   ```markdown
   ### 评分依据声明
   - **最高层依据（L1，官方公开）**：题干作答要求"……"（引原文）；本题测查能力"……"（公告/大纲公开）；
     考场硬规则"超出答题区域作答无效"。
   - **赋分方式（L2，公开描述）**：小题按点给分；公文划档+按点；大作文划档赋分。
   - **模拟口径（L3，官方细则未公开）**：本题参考采分点为依据材料模拟重构；
     档位区间与分值换算按本 skill 模拟换算表；扣分量级与字数目标区（85%–95%）为训练建议。
   - **该卷批改规范（有就必须引用，大作文尤其）**：`批改规范/{省份}/{卷ID}-批改规范.md`
     （来源/年份）——判定为 L1/L2（官方公开）时优先于本 skill 模拟口径；判定为 L4
     （机构/自拟）时只作校准。（无则写"未找到该卷批改规范"。）
   - **经验校准（L4，非官方）**：`参考答案/{文件名}`（来源/年份；**独立来源 N 家**）——
     仅用于校准同义表述宽严与采分点粒度；**与 L1 冲突时以 L1 为准**；
     **参考答案份数不等于置信度**（同源多份只算一份）。
     （无对应参考答案时写"未找到参考答案，本报告采分点为依据材料模拟重构"。）
   - **评分置信度**：中 —— 材料与作答完整，但缺少该卷批改规范，参考答案只有单一来源且
     覆盖不全，档位边界无法交叉验证，故以区间（26–30）表述。
     **以上 L3/L4 内容均为模拟与参考口径，不代表官方评分细则。**
   ```
4. **参考口径登记**：使用了 `批改规范/`、`参考答案/`、真题库或机构解析时，标注
   **文件名/来源/年份**（批改规范还须写明**层级判定**）并注明"参考口径仅作校准，
   与本地重构口径可能不同"；**标注对象是"评分依据"，不是用户作答**
   （用户作答一律按原文引用，见第 2 条）。细则见 `references/reference-answers.md`
   与 `references/workspace-layout.md`。
5. **作答来源与转写（可追溯）**：作答取自 `作答记录/` 时，报告开头注明**文件名**；
   **`作答记录/` 只收 md/txt**，图像/扫描件一律**先请用户自行转成文本**，
   经用户明确同意代转后才 OCR，并注明**转写方式**、附转写稿；
   字误须区分 **⚠ 疑似转写错误（标注存疑、不扣分，待用户确认）** 与 **作答本身错误
   （按语言维度扣分）**，并在报告中列出字误清单。
   报告同时给出该作答的**脚本统计字数**（命令与结果见"字数核验"块）。
6. **口径一致性**：报告须写明本次使用的档位换算表（分值卷型）、是否使用参考采分点与
   参考口径来源，并声明"官方细则未公开，本报告为参考口径"。
7. **字数核验**：报告的"字数核验"块须列出各题**示例答案**的
   （脚本统计值 / 题目要求 / 占比 / 结论），并附核验命令；示例答案不得超限，
   未核验不得标注字数（用户作答字数沿用精确统计即可）。细则与模板见 `word-count.md`。

## 十一、维护与边界

- **依据层级纪律（改 skill 时同样适用）**：任何新增或修改的规则，都要标明它属于
  **L1（官方公开的考试要求与能力维度）／L2（公开描述）／L3（本 skill 模拟口径·经验口径）／
  L4（经验校准：参考答案、机构解析、历史批改、用户历史作文）**。
  新增 L3/L4 内容必须同时写好标注话术；**发现"把 L3/L4 说成官方"的表述，一律立即修正**，
  并按 `scoring-standards.md` 0.2 的禁用/正确话术对照检查。
  若能核到官方公开的阅卷细则或评分参考，按 0.3 升级其等级并登记出处与年份。
- **不得把"我构建的模型"写成"官方标准"**（本次重构的核心纪律）：档位区间、覆盖率阈值、
  公文百分比、扣分量级等，全部是本 skill 的模拟/经验口径；写作时用
  "本 skill 模拟口径""经验口径""参考口径"作前缀，永远不写"官方规定"。
- 本 skill 取代 workspace 根目录 `shenlun-skill/`（模板化题型方法）与 `Shenlun.skill/`
  （以类型判断定分的评判方式）中**模板化评判**的部分：方法内容可借鉴，评分一律以本
  skill 的四维标准为准。
- 错误修正流程：用户指正 → 先改对该题的评判 → 分析根因（哪条规则理解错了）→
  必要时更新本 skill 或 references 文件。
  - **字数类错误**（示例答案超限、字数标注与实测不符）一律按 `word-count.md` 处置：
    先用 `scripts/count_chars.py` 复核实测值 → 改对该题数字 → 把事故记入
    `word-count.md` §9 历史事故表，防止复发。
  - **口径类错误**（把模拟口径说成官方规定、漏标经验口径）→ 改对该处表述，
    并在 `scoring-standards.md` 0.2 补一条对应的禁用话术。
  - **精确感类错误**（只给一个精确分数、不给区间与置信度，或用小数分制造确定性假象）→
    按 `scoring-standards.md` 0.4 补区间与置信度，并在 `essay-judging.md` 第三节自查表
    增补对应自查项。
  - **参考口径类错误**（漏查 `批改规范/`、漏查 `参考答案/`、用了却没登记来源、把机构答案
    当官方标准）→ 按 `references/reference-answers.md` 第 3 节（匹配规则）、第 5 节
    （使用边界）、第 7 节（报告登记模板），以及 `references/workspace-layout.md`
    （`批改规范/` 接入规范）逐条处置。
  - **材料归位类错误**（把用户材料放错目录、改了名却没说、对含糊文件名擅自猜测）→
    按 `references/workspace-layout.md` 的归位流程处置：先回滚到原路径 → 重新识别 →
    含糊的一律列清单问用户，并把该情形补进该文件的"提醒清单"。
  - **判分尺度类错误**（因未引用某材料案例扣分、因"立意略模糊"直接封顶二类、
    因用词与参考答案不同判偏离）→ 属硬性禁令，改对该题评分后在
    `essay-judging.md` 第三节自查表与 `scoring-standards.md` 0.2 补对应禁用话术。
- **skill 分发与安装**：本 skill 以仓库 `https://github.com/ye0619/Shenlun-SKILL` 分发，
  支持 `npx github:ye0619/Shenlun-SKILL`（已发布到 npm 时亦可用 `npx shenlun-skill`）
  一键安装到任意工作区的 `.dsh/skills/shenlun-judge/`；npm 包的 `files` 白名单**只含
  skill 本体（`.dsh/skills/shenlun-judge`）+ `bin/` + `templates/`**，
  个人材料目录（`参考答案/`、`作答记录/`、`批改报告/`、`批改规范/`、`真题/`）与
  `.miktex/` 一律不入包。**改动 skill 后要跑一次 `npm pack --dry-run` 复核包内容**，
  并确保没有 `__pycache__`、`.pyc` 等垃圾进包。
- 用户要"生成 docx/思维导图/表格"时，由助手直接生成对应文件即可（本 skill 不依赖脚本）。
  现成资产：旧 skill 的导出脚本 `Shenlun.skill/scripts/export_docx.py` 可直接复用（docx 导出
  优先用它，不要重写）；**字数核验脚本 `scripts/count_chars.py` 是本 skill 自带的必用工具**
  （Python 3，标准库实现，无第三方依赖；`--selftest` 可自检）；`shenlun-skill/references/`
  下的名师方法类文件（如名师对比、备考计划、套题复盘）可作为**方法性参考**，但其中任何
  "按类型/模板给分"的表述一律不得进入评分。
- 与行测/面试类 skill 边界：只处理申论内容，行测与面试问题转交对应技能或直接回答。
