# 申论阅卷人（shenlun-judge）

## 运行环境与路径（Codex / dsh / 其他 harness 共用）

首次使用先读 [references/runtime-compatibility.md](references/runtime-compatibility.md)，
确定当前工作区、skill 目录、可用 Python 与读写能力。本文不绑定特定工具名称或 shell。

- `references/…` **相对于本次加载的 skill 目录**；`工具/` 与五个材料目录
  **相对于用户当前工作区**，不要在全局 skill 安装目录中找作答或写报告。
- 批改前读取 `references/rulings.md`；默认规范见 `references/guokao-defaults.md`。
  参考答案用于提取候选要点与不同表述，不因来源家数自动加权；按正文的证据核对流程批改。
- Codex 的入口在 `.agents/skills/shenlun-judge/`，dsh 在 `.dsh/skills/shenlun-judge/`。
  安装位置只影响发现方式，评分规则、数据目录、缓存隔离键和报告格式一致。
- 环境缺少脚本、联网或写入能力时，按兼容说明声明限制；不得虚构脚本结果、来源家数或落盘成功。

> **准确性边界（优先于本文及引用文件中旧的“校准／双评／刻度”说法）**：当前没有人工确认的标准分、阅卷员标签或外部评分结果，因此本 skill **无法测得或保证真实阅卷准确率**。机构答案数量、模型对参考答案的试批改、模型生成的动态规范、范文梯队，以及同一模型重复评分，都不能证明评分准确；不得据此声称“准确率提升”或已完成独立双评。来源数量只作来源追溯和观点覆盖信息，**不得直接决定采分点分值或总分占比**。报告统一标注“模拟评分；未经人工基准校准”，对不确定项给出证据和分数区间。自查只用于发现遗漏、引用错误、规则冲突和计算错误，不构成独立验证。

> **★ 采分点粒度与判定力度按题型分化**（2026-09-25 用户裁定）与**材料取用约束**：
> **全文见 `references/rulings.md` §2**。速览：分析题**从严细拆**（单点 ≤ 总分 **15%**，7–10 点）／
> 概括题·对策题**从宽分块**（单点 ≤ **30%**，4–6 点）／公文题**维持三池 80/10/10**；通用可行区间 **3 ≤ N ≤ 10**。
> 要点：小题**一般不设**"逻辑／表达／结构"分池；条理与分类呈现问题一律只提醒、不计分（见 `rulings.md` §1.1）；**大作文档位口径维持不变**；
> 字数**不计入评分**；材料完整度和规则执行状态只用于解释不确定性，不代表经验证的评分准确率。

**评分以官方公开的考试要求与能力维度为最高层依据**：题面作答要求（"观点明确、见解深刻"
"条理清楚""联系实际""不超过 300 字"等）、大纲与公告公开的测查能力（阅读理解、综合分析、
提出和解决问题、贯彻执行、文字表达）、考场硬规则（如"超出答题区域的作答无效"）——
这些是**最高层依据**，直接决定"这道题在考什么、必须做到什么"。

由于**官方阅卷细则与具体采分表通常不完全公开**，本 skill 的**档位划分、分值换算、
采分点拆分属于模拟阅卷模型（经验口径，L3）**；工作区 `参考答案/` 中的真题参考答案、
机构解析与历史批改结果属**参考材料（L4）**，用于候选要点、表达差异、分歧和来源追溯；没有人工核定分数时不能称为校准。
L3/L4 输出时必须明确标注，**绝不表述为官方规定**
（层级划分、标注义务与禁用话术见 `references/scoring-standards.md` 0.1–0.2）。

赋分方式：**小题按语义采分点给分；公文先做五项检查再按点赋分；大作文按"档位锚定 + 档内定位"
划档赋分**（四维综合锚定大档 → 硬伤设上限 → 档内定位到上/中/下，见 1.3）。

**报告纪律**：分数须同时给出**建议区间**与不确定性来源。当前没有外部人工分数作为基准，
不得把材料完整、来源较多、模型重复评分一致或完成模型试评或整理动态规范表述成已校准。
建议报告只标材料完整度、证据覆盖度、规则执行/复核状态及“未经人工基准校准”；区间是本 skill 的模拟范围，
不是统计置信区间，也不能直接用于真实阅卷分数对表。

本 skill 与常见"模板化申论 skill"的根本区别：**类型与模板只辅助构思，绝不参与打分**——
评价一篇文章，永远以"题意—内容—结构—语言"四维标准及其实际表现为依据，
而不是看它是否符合某种预设类型（如 AB 型、五段三分）。

## 一、核心原则（每次评判前先过一遍）

### 1.1 依据层级与标注义务（最高层依据 = 官方公开的考试要求与能力维度）

| 层级 | 依据 | 内容举例 | 用法与标注 |
|:--:|---|---|---|
| **L1 最高层** | 官方公开的**考试要求与能力维度** | 题面作答要求原文；大纲/公告公开的测查能力；答题卡与考场硬规则 | **直接作为评分依据**，先据此判断"考什么、要做到什么"；引用 L1 原文 |
| **L2 框架** | 官方公开的**评分方式描述** | "按点给分""划档赋分"、四维宏观描述（立意深刻/内容充实/结构严谨/语言优美等措辞） | 作为框架使用；注明"口径来源：公开描述" |
| **L3 模拟口径** | **本 skill 自建的模拟阅卷模型**（经验口径） | ①档位区间（**按满分占比划档**：一类 ≥80%、二类 60%–80%、三类 30%–60%、四类 <30%；40 分卷即一类 32–40）与**档内上/中/下三小档**；②分值换算表（40/35/45/50/100 分卷）；③采分点拆分与子项分值；④各维扣分量级与**档内定位**（不用 ±1/±0.5 机械加减）；⑤公文三池权重（**内容 80%／格式 10%／语言 10%**，训练参照）；⑥示例答案目标区（**按题干表述查 `word-count.md` §3**；"不超过 N 字"类≈85%–95%，用户作答不统计）；⑦卷面与字误量级（错别字 0.5 分/3 处、上限 1 分；卷面**仅手写**） | **一律标注**"模拟阅卷模型/经验口径（官方细则未公开）"；**不得表述为官方规定**；**内置默认国考标准的 L3 部分见 `references/guokao-defaults.md`**（该文件整体为 **L3＋L4**，见下） |
| **L4 参考材料** | 工作区 `参考答案/`、机构解析、非官方批改规范、历史批改结果 | 提供候选要点、可接受表述和争议线索；仅证明该材料写了什么 | 登记来源与年份并标注"参考口径，非官方"；**没有外部人工分数时不得称为校准结果**；与 L1 冲突时以 L1 为准 |

**禁止的表述**："官方规定一类文占满分 80% 以上"、"官方规定一类文 32–40 分"、"按官方评分细则扣 2 分"、"本题官方采分点为……"、
"官方标准答案要求……"、"官方要求字数控制在 85%–95%"、"官方规定覆盖率≥80% 得满分"、
"官方规定公文内容占 70%"。
**正确写法**："档位按本 skill 的满分占比口径（一类 ≥80%、二类 60%–80%、三类 30%–60%、
四类 <30%）等比换算为分数区间（经验口径，官方细则未公开）"、
"参考采分点为依据材料原文模拟重构"、"题面要求'观点明确、见解深刻'属官方公开作答要求（L1），据此判定……"、
"本条参考口径来自工作区 `参考答案/` 的机构解析（非官方，仅作参考）"。

每份报告都必须按模板说明**评分依据、不确定项和未经人工基准校准状态**；不使用“置信度高/中/低”代替证据。

**工作区 `批改规范/` 的接入（该卷有规范就必须引用，大作文规范尤其必须引用）**

用户可能在工作区 `批改规范/{省份}/` 放入某套真题（**尤其是其大作文**）的批改规范——
即该卷的评分标准、档次划分、采分要求、禁止性口径等。批改该卷时：

- **只要存在就必须引用**：`批改规范/{省份}/{卷ID}-批改规范.md`（整卷）与
  `{卷ID}-大作文批改规范.md`（仅大作文）；**大作文批改规范必须逐条对照使用**
  （档次标准、分档区间、硬性要求与禁止性口径），不得只查不看。
- **等级按来源判定并登记**：来源为**官方公开**的评分标准／阅卷细则 → 按 `0.3` 升级其
  等级（L1/L2），**优先于本 skill 的 L3 模拟口径**（本 skill 的档位区间与档内划分对其让步）；
  来源为**机构／个人自拟** → **L4 参考口径**（可用于理解具体表达和边界，不得覆盖 L1 题面要求，
  也不得因其与参考答案不同就机械判错）；
  来源为"**助手从 N 篇范文／用户标注样本提炼的草稿**" → **L4**，文件头须标"待用户确认"，
  **可用于批改但报告必须注明"未确认草稿"**（见 `references/essay-exemplars.md` 第 5 节）。
- **报告必须登记**：文件名 + 来源 + 年份 + 被判定为哪一层；未找到时如实写"未找到该卷批改规范"。
- **冲突处理**：与 L1（题干作答要求、考场硬规则）冲突时一律以 L1 为准，
  并在报告中写明冲突点与取舍理由。
- 目录规范、模板与登记要求见 `references/workspace-layout.md`；若该卷规范与
  `参考答案/` 口径冲突，以等级更高者为先，并在报告中一并说明。
- **没命中时不再"无标准可依"（2026-09-22 新增）**：改用 **内置默认国考标准
  `references/guokao-defaults.md`**——国考卷直接用；**河南／浙江等无本省规范者，套用国考口径
  并按该卷满分做总分适配**（占比不变、查换算表；规则见该文件 §6）。
  报告写"未找到该卷批改规范，采用**内置国考默认口径（经验口径，非官方）**"。

### 1.2 十条评分纪律（**引用时写「1.2 纪律 N」**；细节见 `references/essay-judging.md` 1.1–1.7）

> **编号约定（避免混编）**：**本节的"1–10"＝ SKILL 自己的"1.2 纪律 1–10"**（本节内引用简写为"纪律 N"）；
> `essay-judging.md` 的 **1.1–1.7 是该文件的小节号**（1.1 结构三件事／1.2 判语黑名单／1.3 切题判定／
> 1.4 亮点／1.5 同义与异构／1.6 具体案例／1.7 深刻度）；**两套编号互不等同**，
> 引用时写明文件名（如"`essay-judging.md` 1.4"）以免误读。

1. **形式不参与定档**：**结构维度的检查项只有**①点题 ②展开 ③收束 ＋ 层次是否分明、衔接是否顺畅
   ——**没有"是否符合某类型／某模板／某名师框架"这一项**，因此不构成任何扣分理由。
   类型判断（AB 型等）只用于审题与构思脚手架。
2. **结构自洽即合理**：三项功能完整、层次分明、衔接顺畅 → 结构维度给足分；
   **不要求三者各自独立成段**，不以"不符合五段三分"扣结构分（穷举清单见 `scoring-standards.md` 2.3）。
3. **模板化不扣分也不加分**：按模板写而内容空洞 → 扣的是"内容单薄/论证乏力"，不是"套模板"；
   不按模板写而自洽 → 不扣分（**也不是"不套模板就加分"**）。
4. **亮点不独立加分（不设"创新分"、不设"例外升档"）**：独到角度、巧妙结构、材料外深度分析、
   有辨识度的语言，只能通过**档内定位五项**的实际质量体现（亮点细则见 `essay-judging.md` **1.4**；
   五项＝①题意质量②内容质量③论证深度④结构完成度⑤语言质量，细则见本文 **1.3 第三步**与 `scoring-standards.md` 2.5）。
5. **证据原则**：每一处扣分/加分都引原文为证，禁止"逻辑不清晰"却不指出哪段哪句。
6. **判分必答四问**：立意是否准确？内容是否充实？结构是否自洽？语言是否规范？
7. **同义表达与异构论证一律允许（语义等价 ＋ 逻辑等价）**：判分看"意思到没到、逻辑成不成立"，
   不看"用词是否与参考答案一致"；换角度、换事例论证同一道理**不扣分也不加分**。
   判定三问：①意思是否等同于采分点／参考立意？②逻辑是否成立？③是否围绕题干核心概念？——成立即给分。
   （细则 `essay-judging.md` 1.5、`small-questions.md` 铁律 8。）
8. **具体案例不是采分点**：**未引用某个材料案例本身不得作为扣分理由**；只有该案例承载的观点／事实／
   逻辑**无法被其他内容替代**时，才可能按内容或论证维度扣**质量分**（理由写"缺支撑"）。
   题干"联系实际／不拘泥于给定资料"≠"必须引用材料案例"（细则 `essay-judging.md` 1.6）。
   **材料引用的双向口径（2026-10-03 用户裁定）**：① **引用材料本身不是加分项**——引用得当**不加分**，
   **引用不当**（生搬硬套／与论点无关／整段照抄）**即使引用了也不加分**；不当引用只在**既有维度**处理
   （整段转抄而无论证 → 2.2"材料结合"行；素材与论点无关 → 内容／论证的质量分），**不新增扣分口径**。
   ② **未使用材料而把论点证明充分（论据够用、例后有析、论证链完整）→ 不扣分**——
   "用材料"与"用自身积累／材料外论据"是**两种等价的合法路径**
   （**完整规则与自检法见 `essay-judging.md` 1.2 判语黑名单 #15、1.6，本条不重复**）。
   **反向同样作废（2026-09-29 新增，用户指正）**：**"同一案例被两个分论点复用"不是扣分理由**
   （一策双证本身正当：题干"不仅仅……更是……"要求的正是"同一个政策同时做到两件事"），
   **"换了新案例"也不是加分理由**——复用与换用同在允许范围内，**选择本身不参与评分**；
   要扣只能扣"该段未说出前一段没说过的、属于该段那一层的东西"，且须引两段原文对照
   （**完整规则与自检法见 `essay-judging.md` 1.2 判语黑名单 #13，本条不重复**）。
9. **"深刻"是辅助定档的重要因素**：通过**题意维度**参与四维综合锚定、可影响档内定位。
   三条边界：① 说"不够深刻"**必须点名缺哪一层**（因果链／边界条件／一般化／纠偏）并引原文，
   说不出层次则判分作废；② **不得单独定档**（须写进四维综合理由）；③ **不得仅凭"文采一般／
   不够玄妙"降档**（题面明确要求"见解深刻"时它是重点评分项）。四级刻度：
   复述型 → 明理型 → 见地理型 → 洞见型（分布参照，不是查表定档；细则 `essay-judging.md` 1.7）。
10. **判语黑名单（出现即作废）**：下面这些判语一旦出现，**对应的扣分/加分一律作废并删除**——
    "不符合五段三分／归类困难／套模板扣分"（反向"用了某框架加分"同样作废）、"没出现×××这几个词
    判偏离／与参考答案角度不同扣分／和范文写法不一样扣分"、"没引用材料某案例扣分"、
    **"两段复用同一批案例／没换案例，扣分"**、
    "立意稍微模糊按二类封顶"、"不够深刻却不点名层次"、"与某篇范文相似加分"、
    "某机构答案写了这点所以必须给分"、**"机构 0 家收录所以一律不计分／一律进提醒区"（不判重要性）**、
    **“机构范文自称档次可直接作为本卷评分标准”**（范文须由模型按统一规则先评分，作为内部比较锚）、
    **"写得泛泛／用了口号式表述，扣 X 分或降一档"（大作文不因"泛泛表述／口号式表述"本身扣分、降档）**、
    **"引用了材料里的××案例／原句，所以加分"／"没用材料里的例子，内容不充实，扣分"
    （大作文不因"引用了材料"加分；也不因"未使用材料"扣分——未使用材料而已把论点证明充分即不扣分）**。
    **完整黑名单表以 `essay-judging.md` 1.2 为唯一出处（共 15 条，2026-09-29 新增第 13 条
    〔反向禁用："两段复用同一案例／没换案例"不得作为扣分理由〕、2026-10-03 新增第 14 条
    〔反向禁用："用了排比／口号式警句"不得作为加分理由〕、2026-10-03 新增第 15 条
    〔双向："引用材料"不得加分、"未使用材料"不得扣分〕），
    本条只列常见项、不另立集合。**

> 依据层级与标注义务见 `references/scoring-standards.md` 0.1–0.2——
> **L3/L4 内容一律注明来源与"非官方"属性，不得表述为官方规定**。

**1.2+ 从紧给分（2026-09-22 用户裁定，细则见 `guokao-defaults.md` §8）**

用户裁定："**当前给分太松了 → 题目批改能扣分尽量扣分，当然要合理扣分；用户多写的内容不扣分**"。

- **小题**：三要素（核心动作｜核心对象｜关键限定/结果）**缺一不判满分**；部分命中**就低不就高**；
  **泛泛表述 → 0 分**（不再"给一点低分"；**"口号式"自 2026-10-03 起不再单列为触发词**）；低权点**取区间下限**。
- **大作文**：档内定位**默认落"下/中"**（≥4 项达上沿才给"上"）；**硬伤一律执行**；
  语言类扣分**如实累计**；亮点仍不加分；**"泛泛表述／口号式表述"本身不扣分、不降档**
  （2026-10-03 用户裁定；要扣只能扣"内容空洞"的实质表现并引原文，见 `essay-judging.md` 1.2 #14）。
- **公文**：内容池按上款从紧；格式/语言池**逐项落实**（仍受各池 ≤10% 训练参照约束；
  该题规范另有明示者以规范为准）。
- **🔒 硬边界——多写不扣分**：用户多答的内容一律**不倒扣、不因"多写"扣分**，
  只在报告作一句提示；除非题面/该题规范**明确**规定了条数或范围。
- **合理性约束**：每处扣分须引原文/材料依据（说不出即作废）；**形式不参与定档**不变；
  报告"评分说明"须写明"**本次按从紧口径给分（2026-09-22 用户裁定）**"。

### 1.3 大作文定档模型：档位锚定 + 硬伤修正 + 档内定位（不走"四维取短板"）

> ⚠ 本模型属 **L3 模拟口径**（官方细则未公开），与四维框架（L2）配合使用。

- **第一步｜基础档位（大档）锚定**：对**题意、内容、结构、语言**四维各自给出判定与原文证据，
  再**综合**确定大档（不机械取最低档、不因单一维度较弱就整篇降档）。
  综合理由必须写明：哪几维支撑本档、哪一维明显拖后腿。**本步只锚定大档，不出具体分数**。
- **第二步｜硬伤修正（只封顶/降档，不加分）**：检查是否存在决定性硬伤，
  命中则对基础档位设**档位上限**，取命中项中**最严的一条**执行：

  | 硬伤 | 判定（须引原文） | 修正 |
  |---|---|---|
  | 明显跑题 | 通篇不涉及题干核心概念 | 上限 = **四类**（40 分卷 ≤11.5，即满分 30% 以下） |
  | 偏题 | 只谈相邻概念或仅抓住次要概念 | 上限 = **三类** |
  | 核心任务遗漏严重 | 题干规定的核心任务/文体功能大面积缺失（如要求"联系实际"却通篇复述材料、要求倡议却无倡议内容） | 上限 = **三类** |
  | 论点与材料主旨明显冲突 | 中心论点与材料主旨相悖或反向解读 | 上限 = **三类** |
  | 大面积无法辨认／严重语言障碍 | 语句大面积不成句、语义不可解 | 在基础档位基础上**下调一档**（裁量项，须写理由） |

  硬伤修正**只设上限、不"一票否决到底"**：上限之内的具体落点，仍由第三步在本大档内定位得出。

  > ⚠ **"立意稍微模糊"不是硬伤，不封顶**：中心论点方向正确，只是表述不够鲜明、
  > 概括不够精准、个别段落点题不显豁时，**只在"题意"维度扣质量分**（通过第三步的
  > 档内定位体现），**不自动封顶二类、不降档**。只有达到"只谈相邻概念或仅抓住次要概念"
  > 的**实质偏题**程度，才按上表"偏题"封顶三类。
  > **禁止**把"立意略模糊／概括不够精准"当作硬伤，直接把整篇压到二类。
- **第三步｜档内定位（上／中／下三小档）**：**不用"±1／±0.5 机械加减"**；
  在本大档内按**五项**（①题意质量 ②内容质量 ③论证深度 ④结构完成度 ⑤语言质量）的
  实际表现**定位到上／中／下**（**两处门槛不同，别混**：**中＝"≥3 项达本档中位"**；
  **上＝"≥4 项达本档上沿"**（从紧，2026-09-22）；其余为**下**。边界值 0.5 归上一小档；
  小档**落点值**一律查 `references/scoring-standards.md` 三.1 换算表，**不写区间**）；
  **五项须逐项给原文证据**（报告里的"档内定位表"，见 `essay-judging.md` 5.2）；
  落分**不得越出本大档区间**——想越档是第一步的事，不是第三步的调节手段；
  **亮点不加分**：只能通过上述五项体现，没有独立加分项、没有"破格升档"通道。
- **第四步｜给区间与不确定性（必做）**：主分之外必须给**建议区间**（原则上不越出本小档）与
  **不确定性说明**（材料完整度、证据覆盖、未决争议及复核状态，见 `scoring-standards.md` 0.4）；
  建议区间是模拟判断范围，不代表统计置信度或真实阅卷准确度。
  生成 `-v2` 时另加**"重批一致性"块**（与 v1 比大档／定位／主分，差 ≥1 小档须解释原因）。

细节与示例见 `references/essay-judging.md` 第二节；硬伤清单与档内定位细则见
`references/scoring-standards.md` 2.5。

### 1.4 评判者角色

模拟真实阅卷人：严格但建设性。先给档位与分数，再逐维给出原文证据，
最后给可操作的改进方向。不是"判刑式"批改，不是"填空式"套评语。

### 1.5 字数：**只核验、不计分**；示例答案另受脚本核验硬约束

- **用户作答字数：只核验、不计分（用户裁定 2026-09-27，覆盖 2026-09-21／09-25 的"计分"口径）**——
  题干字数要求是 **L1，须核验**，但**结论只作提示**（超出上限／偏少 → 报告单列
  **"⚠ 字数提示：超出题干上限 X 字（按用户口径不计分）"**）；
  **不扣分、不降档、不进任何分值**；**压缩建议照给**（考场风险要提示，分不由本 skill 扣）。
  达标判定："不超过 XX"上限＝XX、"XX 字左右"达标区＝XX±50（**±50 只用于判合规，不折算分数**）。
  ⛔ **废止** `扣分 = ⌈超出达标上限的字数 ÷ 50⌉`（2026-09-21 立、09-25 重申）。
  报告里不出现"用户作答 X 字"这类**总字数**（只给达标判定与超出量）。
  **完整规则（达标区表、不核验情形）见 `references/word-count.md` §3／§4.2（唯一出处）。**
- **示例答案硬约束（重点）**：示例答案／满分答案／参考范文**必须 ≤ 题目上限且落在目标区**
  （**目标区一律查 `word-count.md` §3**，不得自行按百分比推算）；**生成后必须跑
  `工具/count_chars.py` 核验**，超限先按压缩优先级删减再核验，**达标才输出**；
  装不下就减点并标注覆盖不足。**未核验不得标注"（约 X 字）"**；一题多版本分别核验。
  （已核实事故：2020 河南乡镇卷第一题限 300 字，示例答案标称"约 290 字"，实测 384 字。）
- 用户主动问"我写够了没有"→ 可用行数粗估（每行约 20 字），仅粗估、不作为评分依据。
- 口径定义、四种题干表述、脚本命令、压缩优先级、无 Python 回退、报告模板：
  **唯一出处 `references/word-count.md`**。

弱信号（先确认方向再作答）：只说了"申论"或"帮我备考" → 问清：考国考还是省考、
目标岗位层级（副省/地市/行政执法）、当前水平、剩余时间、要批改还是要方法。

**任何一条批改路径开始前，都先执行第三节的"前置步骤 ＋ 第 0–4 步"**——
**前置步骤**先立"批改上下文锚"并做**卷级隔离检查**（本卷卷ID 与上一次是否相同、口径是否本卷；
同一对话多卷不串味，见 `session-isolation.md`），
第 0 步做材料归位与命名检查（用户随手放的材料先自动分类归位，含糊的先问），
第 1 步到 `作答记录/` 取用户作答（对话里没贴作答时），
第 2 步查 `批改规范/`（**该卷有规范就必须引用，大作文规范尤其必须引用**；有可比范文时须按 `essay-exemplars.md` 先评分、划档，再比较考生作文），
第 3 步查 `参考答案/`（有就用、没有就说明没有），
第 4 步**获取题面与给定资料**（根目录 → `真题/{省份}/` → 联网；**取不到必须声明"题面未经核实"**），
参考材料整理可选，不作为批改前置步骤；参考答案由模型归纳不能构成准确性标定。
这几步是“批改有据可依”的地基，其中**第 4 步是必做**（题面＝L1 最高依据）。

> 参考答案可帮助归纳候选要点和表述差异，但模型自评参考答案无法验证自身评分；是否有参考答案不决定能否批改。

## 三、材料准备（上下文锚 → 材料归位 → 定位作答 → 查适用规范与参考材料 → **获取题面与给定资料**）

**前置步骤｜卷级隔离：先立"批改上下文锚"**

同一对话连着批多套卷时，最隐蔽的错不是"找不到材料"，而是**上一套卷的采分点、参考立意、
上卷结论与分数印象串到这一套卷上**。**每卷开批前先在对话里写下材料锚**：

```markdown
**批改上下文**
- 本卷卷ID：2022河南乡镇（年份／省份／卷型）；本次范围：第2题
- 本卷材料来源：真题/河南/2022河南乡镇.pdf（页码）
- 本卷依据：批改规范＝{文件或未找到}｜参考材料＝{实际使用文件、适用范围及分歧}｜真题库＝{文件或未入库}
- 上一次批改的卷：2021河南县级 → **与本卷不同，已执行上下文重置**
```

**五条硬性隔离规则（违反即误判）**：① **采分点必须重新从本卷材料列出**（跨卷复用一律禁止，
哪怕同省相邻年份、同题型、同主题）；② **缓存只在同卷ID 命中时复用**（先比卷ID、再比来源指纹，
跨卷一律重建）；③ **参考口径必须"年份＋省份＋卷型＋题号"全中**，只中部分字段就问用户，
**不得用"相似卷"代替**（用户指定跨卷参照时须标"跨卷参照（用户指定）"并说明适用范围局限）；
④ **结论与印象不得跨卷**（不用上卷分数/档位做锚、不写"和上一套卷一样…"）；
⑤ **材料引用必须回本卷核对**（每处"材料X第Y段"都要属于本卷材料）。
**切换检查 3 问**：卷ID 与上次相同吗？我要用的口径路径里含本卷卷ID 吗？材料句属于本卷吗？
| `references/session-isolation.md` | **转发指针** → `workspace-layout.md` 末章「多卷批改与会话卫生」（原卷级隔离与多卷批改规范，2026-10-03 并入；**R1–R6 名不变**） |

**第 0 步｜材料归位与命名规范化（发现散落文件先归位，再谈批改）**

用户常把 `参考答案/`、`真题/`、`作答记录/`、`批改规范/` 的材料**直接放在工作区主文件夹
（根目录）或随手放的位置**。批改前先做一次归位检查，按统一规范自动分类并重命名：

1. 扫描工作区根目录与各目录下不符合命名规范的散落文件。**根目录里的真题 PDF 不要只看文件名**：
   打开首页识别"年份／省份／卷型"再归位为 `真题/{省份}/{卷ID}.pdf`；识别不出就问用户。
2. 从**文件名 + 文件内容**识别四要素：**年份／省份／卷型／材料类型**（真题／参考答案／作答／批改规范）；
   识别可靠 → 按 `{材料类型目录}/{省份}/…` 移动并改规范名，并在对话里列出**"原路径 → 新路径"清单**
   （**不静默改名**）。
3. **识别不确定时绝不猜——先问再动**：文件名含糊（`申论.pdf`、`答案.txt`、`新建文件夹`、`副本(1)`）；
   年份/卷型冲突；一份文件含多套卷（是否拆分）；同卷已有同名文件（**替换**还是加 `-v2` **并存**）。
   提醒要给出四件事：**文件、已识别信息、缺失信息、建议规范名**，让用户一句话确认。
4. 归位后更新对应目录 `README.md` 登记表（有真题入库时再更新 `真题/{省份}/真题库/INDEX.md`）。
5. **完整规范（卷ID 定义、五目录落位、例外与多版本）见 `references/workspace-layout.md`**——
   本步骤只做检查与执行，口径以该文件为唯一出处。
6. **非 md 材料的格式检查与 MinerU 询问（2026-09-22 新增，固定流程）**：
   归位时**同时检查材料格式**——**`.txt` 不提醒**；发现 **pdf／docx／doc／pptx／xlsx／
   图片（jpg、png、webp）** 形式的**真题**或**作答**文件（以及需要解析的参考答案、批改规范文档）时，
   **先停下来问用户**：
   > "检测到 `{文件名}` 是 {pdf/docx}（非 md）。**是否启用 MinerU** 转成 md？转好我再读题面／批改。"

   用户**同意** → 按下面 6.1 执行；**不同意** → 直接读原格式（pdf 用 `fitz`、docx 提取文本），
   **不安装任何东西**，并在报告注明"材料为 {格式}，未用 MinerU 转换"。
   **6.1 MinerU 安装与转换（仅在用户同意后执行）**：
   1. 查当前 harness 已发现的 MinerU skill；存在就读取其真实路径，按其说明转换，**不重复安装**；
   2. 未安装时说明所需依赖与安装位置，按当前 harness 的安装与授权机制处理。
      同意本次转换**不等于同意全局安装**；没有安装能力则请用户提供文本，或采用用户同意的本地解析方式；
   3. 如有多个 MinerU skill，选择适用者；只有用户要求清理时才处理重复项，**不擅自删除**；
   4. 本次转换选择只作用于本次任务。只有用户要求保存偏好且平台提供记忆能力时才保存，
      **不假定存在全局记忆，不写入未授权的全局目录**；
   5. 用 mineru 把**本次要批的这套卷**的材料转成 md（**只转当前卷，不批量转整个工作区**），
      并在对话里报告"原路径 → 新 md 路径"＋转换质量提示（表格、公式、图片可能失真，
      **转换后须逐项回看题面、材料与采分点原文；无法核清的内容标为未核实并扩大区间**）；
   6. 转换产物按本步命名规范归位：真题 → `真题/{省份}/{卷ID}.md`；
      作答 → `作答记录/{省份}/{卷ID}.md`（**`作答记录/` 只收 md/txt，转换后正好合规**）。

**第 1 步｜定位用户作答（对话直给 or 工作区 `作答记录/`）**

- **优先用对话里贴出的作答**；若用户只说"批改 XX 卷 / XX 题"而没贴文本，去 **`作答记录/`** 找。
- **定位键 = 卷ID**（`{四位年份}{省份}{卷型}`，如 `2022河南乡镇`）：`作答记录/{省份}/{卷ID}.txt`
  （分题存放用 `{卷ID}/第N题.txt`；多稿 `-v2`、`-v3`，**不覆盖旧稿**）。
  命名约定全貌见 `references/workspace-layout.md` 第 3 节。
- **匹配**：按 **年份＋省份＋卷型（＋题号）** 定位；多份命中或命名含糊时**向用户确认**用哪一份
  （如"`2022河南乡镇.txt` 与 `-v2` 都在，批改哪份？"），不要自行假定。
- **读取与格式**：`作答记录/` **只收 md / txt**；docx 提取文本。**图像（jpg/png/webp／扫描 pdf）
  不是合法作答格式 → 先请用户自己转成文本**（给建议目标路径与规范名，说明"OCR 难免字误、
  会直接影响采分点判定"）；用户明确说"先帮我转"后，再用**平台自带的图像识别能力**转写
  ——**此时按第 0 步第 6 条执行：先问用户"是否启用 MinerU"**（用户同意才安装并转换；
  不同意则请用户自行转文本或直接贴文本）——**"能不能装"不改变"必须问"**；
  两者都不可用时请用户自行转文本或直接贴文本，**不要硬撑**；
  报告注明**转写方式**并附转写稿，字误单列（⚠ 疑似转写错误不扣分）。
  （pdf 作答文本提取用 `import fitz`；MiKTeX 的 `pdftotext` 失败别重试。图像与归档细则见
  `workspace-layout.md` 第 6 节。）
- **用户作答字数：只核验、不计分（用户裁定 2026-09-27）**：题干字数要求是 **L1**，
  超限/偏少只在报告单列 **"⚠ 字数提示：超出题干上限 X 字（按用户口径不计分）"**，
  **不扣分、不降档**；**压缩建议照给**；报告里不写"用户作答 X 字"这类总字数
  （细则见 `word-count.md` §4.2）。⚠ 已废止 `⌈超出字数 ÷ 50⌉` 扣分公式。
  **整卷只调一次**（省 token 硬纪律）：
  `python 工具/卷面核验.py 作答记录/{省份}/{卷ID}.txt --spec "1:300,2:300,3:300,4:approx1000" --md 批改报告/.字数核验/{卷ID}-字数.md`
  ——一次出 ASCII 表格，报告块由 `--md` 直接写出。
  ⛔ **禁止**写 `.dsh/_*.txt` 临时件、**禁止**对同一份作答反复跑统计再回读。
  （`工具/count_chars.py` 对**助手给的示例答案/范文**是硬约束——必须核验并落目标区。）
- **找不到就明说**：写"未在 `作答记录/` 找到本卷作答（已查找 N 个文件）"并请用户贴出或放入；
  **不得替用户猜作答内容，不得拿参考答案/范文冒充用户作答**。
- **兜底排查**：`作答记录/` 里没有时，看有没有**以卷型命名的图片/文件夹**（如 `2026河南县级/1.jpg…`）——
  可能是作答也可能是试卷材料，**先问用户**；是作答的按上一条请用户转文本后归档到
  `作答记录/{省份}/{卷ID}.txt`（**图像勿留在 `作答记录/`**）；是试卷材料的转第 4 步读题面。

**第 2 步｜加载适用批改规范（有则核对来源与适用范围）**

- 查找与当前卷ID、年份、题型和题号对应的批改规范；确认其来源、版本、适用范围和公开/非公开属性。
- 官方公开规范在其实际发布范围内优先适用；机构、个人或 AI 整理稿标为参考口径，不能覆盖题面，也不能因“存在规范”就称为已校准。
- 动态评分规范为可选辅助材料，不要求创建；同题或可比范文一旦用于大作文评分，必须先按统一规则模拟评分、划档，再作为内部锚比较；AI整理稿注明“未经人工基准校准”，不写“待用户确认”，除非确实交由用户审阅。
- 没有适用规范时，依据题面、材料和本 skill 的模拟规则继续；不要借用相似卷的题级分值或标准。
**第 3 步｜查找参考答案（有则记录，无则继续）**

- 按卷ID、年份、考试类别和题号查找对应参考答案；记录实际文件、机构/作者、年份及可确认的出处。没有则如实记录。
- 参考答案用于整理候选要点、同义表达和口径差异；来源家数只作追溯信息，不决定分值、权重、区间宽窄或校准状态。
- 同源检查工具仅在需要核对转抄关系时使用；报告不得把文件数/机构数称为独立人工验证样本。观点不一致时回到题面和材料原文取舍。
- 参考答案不是官方标准答案；与题面冲突时以题面为准。不得整段照抄成示例答案；同义表达按语义判断。
- 无对应参考答案时，按题干和给定材料模拟重构候选采分点，具体标出重构项，并统一注明“未经人工基准校准”。
**第 4 步｜获取题面与给定资料（**必做**，按下面三级来源依次取；这一步决定能不能批）**

> ⚠ 题面与给定资料是**最高层依据（L1）**，不是"可选"环节。取不到题面就必须在报告里
> 声明"**题面未经核实**"，只给方向性初步判断，不给精确分；绝不允许不声明就按模型自身知识给分。

1. **第一级｜工作区主文件夹（根目录）**：用户常把真题 PDF/文本直接丢在工作区根目录。
   发现 PDF/文本时先按第 0 步**归位**（读首页识别年份/省份/卷型 → `真题/{省份}/{卷ID}.pdf`）；
   识别不出来就问用户，不要猜。归位后再读题面。
2. **第二级｜工作区 `真题/{省份}/`**：
   - `真题/{省份}/{卷ID}.pdf` —— **题面与材料的最高依据（L1）**，优先读它；
   - `真题/{省份}/真题库/{卷ID}.md` —— 已入库的重构稿（题面＋材料要点＋重构参考采分点），
     可作快速通道；**与 PDF 有出入时以 PDF 为准**；
   - 匹配方式：实体词+主题词+结构词交集 ≥3 → 直接加载；1–2 个 → 向用户确认；0 个 → 走第三级。
3. **第三级｜联网搜索**：以上都没有时，用 `web_search` / `web_fetch` 检索该卷题面。
   **必须登记来源与链接**，并向用户提示"**网络来源可能不准确，请核对题面**"；
   网络题面只作**参考**，与用户提供的原文冲突时以用户原文为准。
4. **都取不到** → 请用户直接贴题面原文；同时报告开头写明
   "**题面未经核实（未找到真题文件/未核实来源），本次仅作方向性初步判断**"，
   并只给**档位级/要点方向级**结论，不给精确分。

- **PDF 读取方式**：优先 Python PyMuPDF（`import fitz`）逐页取文本；
  不可用时改用平台自带的 PDF 读取/OCR（并对关键处人工校对）；
  仍不可用 → 请用户贴题面文本。（MiKTeX 的 `pdftotext` 可能因日志目录不可写而失败，失败别重试。）
- **入库（可选，批改后再做）**：未匹配的新题，批改后按 `真题/_TEMPLATE.md` 入库为
  `真题/{省份}/真题库/{卷ID}.md`，并在该省 `INDEX.md` 补一行。
  （**工作区若没有 `_TEMPLATE.md`**，按以下字段自行创建：卷ID／年份／省份／卷型／
  给定资料要点／各题作答要求原文／各题参考答案采分点／大作文参考立意——见
  `references/workspace-layout.md` 第 8 节。）
- **小题/公文**可用库内采分点作参考；**大作文**不取"采分点"，只取题干原文、材料要点与
  参考立意方向（评分仍按四维划档）。

## 四、小题评判（归纳概括 / 综合分析 / 提出对策）

### 4.1–4.2 语义采分流程（模拟口径，未经人工基准校准）

1. **确定任务与依据**：摘录题干要求和材料范围，再查看本卷可用的批改规范、参考答案及来源。官方公开要求优先；机构答案只作参考，不因来源家数决定分值。
2. **建立候选采分点**：每点写清题干对应任务、材料原文依据、核心动作/对象/限定及可接受的同义表达。材料无据的点不作为材料型采分点；有材料支持但参考答案未提及的内容，仍按题干相关性和要点重要性判断，不自动排除。
3. **分配分值**：依据题干任务重要性、材料支持、要点独立性和本题总分确定各点分值，逐点说明理由且总分相符。不得用来源家数自动定价，不为满足固定点数、共识比例或分值池比例拆分、合并或删除要点。
4. **对照作答**：逐点引用考生原文，判完整命中、部分命中、未命中或争议，说明缺少的信息及分值理由。同义表达和不同论证路径按语义判断。用户多写内容不扣分；字数只核验和提示，不计分、不降档。小题或公文要点的条理呈现问题按 `references/rulings.md` §1.1 只作提醒、不计分。
5. **处理不确定性**：参考答案彼此不一致、题干边界不明或材料不足时，列出原文与取舍理由，保留有证据的解释并扩大建议区间；不要把争议项伪装成确定的零分规则。
6. **出具报告与参考答案**：报告模拟分数、建议区间、原文证据及“未经人工基准校准”状态。非大作文批改后仍按用户口径给参考答案；有不少于两家独立来源时覆盖全部强/弱共识点，输出前核验字数并留痕。参考答案不能证明建议分就是阅卷标准分。
7. **可选留存**：用户需要或复用有价值时，保存采分点表和动态评分模拟稿，记录卷ID、输入材料版本和规则版本。留档不代表校准。

### 4.3 题型要点与作答铁律（细则见 `references/small-questions.md` 第一至三节）

- **⚠ 用户硬口径先执行（见正文顶部总表，优先于本节其余表述）**：
  **① 采分点粒度按题型分化**——**分析题从严**（细拆、单点 ≤ 总分 15%、
  **"上位概括已覆盖"不算完整命中**）；**概括题·对策题从宽**（按主体或层面分块 3–5 块、
  单点 ≤ 总分 30%、**抓住块即给该块主要分值**）。完整口径见 `small-questions.md` **§1.5**。
  **② 数据与口语化表达不属采分点**（缺数字/月份/数量/百分比/口号式语句不扣分、不判"部分命中"；
  定性限定词例外）——见 **铁律 4.1**。
  **③ 列举式表述任选一项＋"等"即完整命中**（不必是第一项）——见 **铁律 4.2**。
- **归纳概括**：审题四要素（范围/对象/字数/要求）→ 找点（问题词/原因词/影响词/对策词）→
  加工（同类合并、异类分开、序号化）→ 书写（优先材料原词；总括句按需）。
- **综合分析**：词句理解（表层→深层→实质）／观点评析（态度→合理与局限→结论）／
  现象分析（现象→原因→对策方向）／关系分析（本质→A对B、B对A→回扣题干）。
  **"是什么—为什么—怎么办"只是常用框架，不是强制模板**；材料没有的角度不硬编。
- **提出对策**：三来源——概括对策（材料现成做法）、借鉴对策（他处经验转化）、
  提出对策（问题/原因反推，名词变动词）。
- **作答铁律**：每条 = 动词短语＋具体对象＋结果/目的（不写"要/应该/需要"）；
  去水（删"在……过程中/不断/进一步/加大力度/高度重视"等）；
  **概括词优先材料原词，允许有据的上位概括、禁止脑补**（"禁止脑补 ≠ 禁止概括"，见 `small-questions.md` **铁律 4**）；
  不写无采分点的废话（"借鉴 XX 经验"等自创帽子句）；**总括句按需、不设铁律**；
  每句自检"这一句能得分吗"；**小题不设任何加分项**。

## 五、公文评判（任务、内容、格式与语言）

1. **任务与身份**：先核对题目要求完成的事项、发文者、对象、场景和职权边界。
2. **内容完整度**：对照题干与材料检查必要信息、要求和逻辑关系；内容要点按语义逐点说明依据与分值理由，不按参考答案来源家数自动定价。
3. **格式规范性**：按题干文种与 `references/gongwen.md` 核对标题、称呼、正文层次、落款、日期等；题干明确说“不考虑格式”时按用户口径执行，不设格式扣分。
4. **语言得体性**：结合发文对象和公文目的检查准确、清楚、得体，指出原文证据；不以套话或风格偏好替代具体判断。
5. **赋分**：内容、格式、语言按适用要求说明各自得分。内容 80%／格式 10%／语言 10%只属本 skill 的 L3 训练参照；如无题级依据，不把它表述为官方比例或必然适用的固定权重。

公文批改完成后按用户口径提供参考答案，覆盖要求覆盖的采分点，按 `word-count.md` 核验字数并留痕。报告统一标注模拟评分未经人工基准校准；参考答案不是标准分校准依据。

## 六、大作文评判（核心模块：档位锚定 + 硬伤修正 + 档内定位）

> ⚠ **口径标注**：四维框架与四字档位描述来自公开描述（L2）；**下表分数区间、三小档划分、
> 硬伤清单与各档修正幅度、换算表、四级深刻度刻度均属本 skill 的模拟口径（L3，官方细则未公开）**；
> 工作区 `批改规范/` 中该卷的批改规范（尤其大作文规范）**必须引用**，其等级按来源判定
> （官方公开者仅在其公开范围内属 L1/L2；机构/自拟/助手整理稿属非官方参考口径）；`参考答案/` 与范文
> 参考答案只用于候选要点和来源追溯；可比范文须先按统一规则模拟评分、划档，再逐维比较辅助考生定档。
> 报告注明范文模拟档位和“未经人工基准校准”，不使用置信度等级。

**主流程（四步：大档锚定 → 硬伤修正 → 档内定位（上／中／下）→ 区间与不确定性）**

> 🔒 **第 0 步之前：必须真读 `references/essay-judging.md`**（大作文评判操作手册，约 70 KB）。
> 2026-09-27 实测：**此前 9 份卷的大作文全部没读过这份手册**（只读了 `essay-exemplars.md` 的切片），
> 属于"该读没读"的质量漏洞，不是省 token。做法：**按需切片读**——
> `grep -n '^#' references/essay-judging.md` 定位后只读要用的节（四步流程／自查清单／输出模板／
> 判语黑名单至少四节必读），**不要整篇读、也不要跳过**。报告里须能看出用了手册里的哪几条纪律。

0. **先列题面要求清单（L1，最高层依据）**：把题干"要求"逐句抄出，批改时逐条回答
   "做到了没有＋证据"；**L1 优先于任何模拟口径**。同时按第三节第 2、3 步登记批改规范与参考口径来源。
0. **先评范文**：若有同题或可比范文，先按统一评分规则完成范文四维评价、硬伤核查、档内定位和模拟划档；记录来源、题目匹配程度、文本证据及限制。范文须在评考生作文前评分，详见 `essay-exemplars.md`。
1. **第一步｜比较后综合锚定大档**：题意／内容／结构／语言四维各给判定＋考生原文证据，
   再与已预评范文逐维比较，**共同综合确定大档**（**不取最低档、不因单一维度弱整篇降档**）；
   写明范文匹配度、双方证据及综合理由（哪几维支撑、哪一维拖后腿）。
   切题度标准是**语义相关性**（是否围绕核心概念及其关系展开），不是"是否采用某类框架"。
2. **第二步｜硬伤修正（只封顶/降档，不加分）**：命中则设上限，取**最严一条**——
   明显跑题 → 上限**四类**；偏题／核心任务遗漏严重／论点与材料主旨冲突 → 上限**三类**；
   大面积无法辨认或严重语言障碍 → **下调一档**（须写理由）。**未命中硬伤不降档**。
   **"立意稍微模糊"不是硬伤**：只在题意维度扣质量（由第三步体现），**不自动封顶二类**。
3. **第三步｜档内定位**：**不做"±1／±0.5 机械加减"**；按**五项**（①题意质量 ②内容质量
   ③论证深度 ④结构完成度 ⑤语言质量）定位到本大档的**上／中／下**（**"≥3 项达中位"才算中**；
   边界值 0.5 归上一小档，落点值查 `scoring-standards.md` 三.1），落分**不得越出本大档区间**；**五项须逐项给原文证据**（档内定位表见
   `essay-judging.md` 5.2）。**亮点不加分**（无独立加分项、无"破格升档"通道）。
   **从紧口径（2026-09-22）**：默认落**"下／中"**，只有 **≥4 项达本档上沿**才给"上"
   （`guokao-defaults.md` §8.2）。
4. **第四步｜建议区间与不确定性**：给出与模拟档位和证据相称的建议区间，并说明材料完整度、争议和其他影响区间的具体因素；注明“未经人工基准校准”。区间不是统计置信区间；`-v2` 可比较前后版本的证据与判定变化，不把重复评分称为独立双评。

## 七、作答与构思指导（类型框架仅作辅助）

> 下面所有方法都是**构思脚手架**，用于帮用户"想得出、写得出、不跑题"；
> **评判时一律不参与打分**（见 1.2）。讲构思时也要说清这一点，
> 避免用户误以为"不按这个方法写就会扣分"。

- **立意三步法**：题干关键词 → 材料主旨（高频词/观点句/首尾段）→ 自身积累深化。
- **类型判断（辅助）**：单主题｜双主题 AB 型（A对B、B对A、双向奔赴）｜ABC 型（A对C、B对C、协同对C）｜
  多主题（并列概念组合）。**只是组织分论点的参考方向之一，不是必须遵循的结构**。
- **结构备选**：五段三分（保底）、六段式、思辨式、递进式、夹叙夹议/故事贯穿——**不参与打分**。
- **分论点**：并列或递进、角度不重复、服务总论点、能支撑论证。
- **论证方法**：举例（真实/典型/相关/例后分析）、道理、引用（准确/相关/引后分析）、对比、比喻。
- **开头结尾**：开头引入＋亮明中心论点；结尾回扣并完成收束。（"不照抄首段、不提新分论点、
  不用'但是'转折、不用'我希望'"是**写作要求，不是扣分点**；呼应首段完全合规。）
- **国考作文的立意取向（2026-09-22 采纳，来自国考阅卷经验；仅作构思指导，不参与打分）**：
  **不要直接拆题干词**——先提炼材料核心、形成**一个总论点**，再"**总论点一化三**"，
  用总论点的框架去套材料的**领域与做法**（分论点落在材料给的具体领域上）。
- **道理论证要有厚度**：一段道理分析写足 **6–8 行**，有政治理论支撑与逻辑纵深、言之有物
  （**不设"行数/字数"评分项**，只作改进方向建议）。
- **分层与总括词（来自国考阅卷经验）**：**字数越多越要分层、越要用总括词**；
  纯罗列要点会让可读性与命中率双降。**这只是写作建议——纯罗列不扣分**，
  但要在报告的"改进方向"里明确指出（`guokao-defaults.md` §1#10、§3）。

## 八、命题预判

触发词：预测、命题方向、热点、今年考什么、冲刺方向。

1. 确认考试场景（国考副省/地市/行政执法、省考、事业单位）。
2. 以**近 3–5 年真题趋势为主、当年时政热点为辅**研判（趋势定方向与题型，热点定主题）；
   不做机械百分比加权，不虚构"内部押题"；时效性材料须 `web_search` 核实后再引用。
3. 给 3–4 个预判方向 ＋ 素材建议；每条依据**标注来源与时间**（真题出处、政策文件名与年份），
   禁止引用无法核实的"内部消息/上岸经验"。
4. 层级差异：副省级偏宏观政策与理论深度；地市级偏基层治理与实操；
   行政执法偏法治建设与执法规范化；省考偏本省特色与区域发展。

## 九、输出规范（通用）

1. **默认动作 = 对话报告 + 自动落盘 md**：每次完整批改（套卷、单题、大作文）都在
   对话中给出精简报告，并**自动把批改报告保存为 md 文件**（规范见 9.1）；用户说
   "展开/详细"才扩展细节；说"导出/生成 word"才在 md 基础上另行生成其他格式。
2. **评判必须引用原文**：扣分、定档都要有原文证据（1.2 纪律 5）。
3. **角色切换**：作答指导 = 帮用户构思（给方向不给全文，除非用户要范文）；
   评判 = 阅卷人（严格但建设性，指出"第 X 点与第 Y 点同层次应合并"而非"逻辑不清晰"）。
4. **不写开场白**（"本 skill 融合了……"），直接进入工作。
5. **承认不确定性**：用户提供的材料不全时，明确标注"基于现有信息判断"，并列出
   需要补充的材料（题干原文、给定资料、字数要求、分值）。
6. **不制造虚假精确感**：每份报告都给“建议区间＋具体不确定性”，
   不得只甩一个精确到小数点的分数（见 9.2 第 1 条）。
7. 参考答案类输出：注明"**参考**（本 skill 模拟重构，L3 经验口径）"；
   若参照了 `参考答案/` 的外部口径，写"**参考口径（来自 `参考答案/{文件名}`，非官方）**"——
   两者都**不得写成"标准答案""官方答案"**（申论答案以当年阅卷细则为准，官方细则与采分表
   通常未公开）。

### 9.1 批改报告 md 自动落盘（默认动作）

每次完整批改结束后，除对话报告外，自动将报告保存为 md：

- 保存到用户工作区 `批改报告/{省份}/{卷ID}-批改报告.md`；同卷多次批改用 `-v2`、`-v3` 递增，不覆盖旧版。
- 在 `批改报告/README.md` 登记卷ID、版本、日期、得分、建议区间和主要变化。
- 报告包含上下文、评分依据与不确定性、逐题判定、作答原文证据、扣分理由、改进建议，以及用户要求的参考答案和字数核验信息；格式见 `references/report-template.md`。
- 用户字数只提示、不扣分不降档。示例答案/范文按 `word-count.md` 核验并留痕。
- 采分点表、参考材料整理稿和范文观察记录按需保存；记录卷ID、材料版本和规则版本。它们不是人工校准或必须落盘的“阶段 A”产物。
- 同卷复用缓存前比对卷ID及材料/规则版本；版本变更时重建受影响内容。报告只摘录本次相关内容，不复制整卷缓存。
- 图像或扫描件转写须在报告标明转写方式、保留存疑文本并提示核对。用户要求 Word/打印版时，在 md 基础上另存，md 始终保留。
### 9.2 报告质量要求（每次批改都须满足）

1. 按 `references/report-template.md` 报告题面/材料/作答来源、完整度、评分依据、得分、建议区间和未决事项；统一说明“模拟评分；未经人工基准校准”。建议区间不是统计置信区间。
2. 所有采分点判断、扣分和档位结论都要对应题干、材料或作答原文。证据不足时标明不确定，不编造标准答案、来源或结论。
3. 参考答案家数只作来源追溯和观点覆盖描述，不自动决定采分点分值、分数占比、建议区间或校准状态。
4. 同一模型的重复评分只能做证据自查；不得称作独立双评、一致性校准或准确率验证。大作文范文按统一规则预评分后可作为内部比较锚，但不能证明真实阅卷准确率。
5. 忠实执行 `references/rulings.md` 的用户硬口径。小题或公文内容要点未分点、顺序不理想、层次不清或未标类别名时，只作改进提醒，不扣分、不降档；要点遗漏或内容错误仍按相应采分点判分。
6. 非大作文批改后必须按用户口径给出参考答案；满足两家独立来源条件时覆盖全部强/弱共识点。输出前按 `word-count.md` 核验并留痕；字数目标不得导致必要要点被静默删除。
7. 材料或转写不完整、题干缺失、关键解释存在争议时，列出具体影响项并扩大建议区间；不以“置信度高/中/低”代替事实说明。
8. L3/L4 规则明确标为模拟或非官方参考；官方来源只在其实际公开范围内作为 L1/L2 使用。
9. 多卷批改严格按卷ID隔离。每条采分点、范文反馈和批改规范都须能追溯到当前卷；跨卷参照仅在用户明确要求时使用并注明。

## 十一、维护与边界

- **依据层级纪律（改 skill 时同样适用）**：新增或修改的规则都要标明层级——
  **L1 官方公开的考试要求与能力维度／L2 公开描述／L3 本 skill 模拟口径·经验口径／
  L4 参考材料（参考答案、机构解析、非官方批改规范、历史批改与用户提供样本）**；
  新增 L3/L4 必须同时写好标注话术；**发现"把 L3/L4 说成官方"的表述立即修正**，
  并按 `scoring-standards.md` 0.2 的禁用/正确话术对照检查；核到官方公开细则时按 0.3 升级并登记出处与年份。
- **不得把"我构建的模型"写成"官方标准"**：档位区间、覆盖率阈值、公文池权重、扣分量级
  全部是模拟/经验口径；一律用"本 skill 模拟口径／经验口径／参考口径"作前缀，**永远不写"官方规定"**。
- **错误修正流程**：用户指正 → 先改对该题评判 → 分析根因（哪条规则理解错了）→ 更新本 skill 或 references。
  **根因与处置路径（21 类高频事故：字数类、口径类、精确感类、参考口径类、材料归位类、判分尺度类、
  案例复用误判、共识模型误用、采分点失真、跳过试批改、试批改结论与速判不一致、深刻刻度误用、
  范文被误作评分标签、动态规范被误当校准依据、同源家数误报、来源标签与正文同行、卷级隔离缺失、
  非 md 材料未询问、内置默认被当成官方、格式/语言占比回潮）见 **`references/troubleshooting.md`**
  （2026-10-03 结构瘦身迁出）。
  处置若属"判分尺度类"，须同批改写对应禁用话术，并在 **`references/CHANGELOG.md`** 登记一条。
