# 大作文范文评分与比较锚

> **用途与限制**：大作文批改如有可比范文，必须先按本 skill 同一套评分维度对范文评分、划档，再将考生作文与这些范文逐项比较，辅助确定考生档位。范文档位是模型依统一规则生成的**内部比较锚**，不是人工阅卷标签、真实标准分或准确率校准数据。报告应标注“范文为模型模拟评分，未经人工基准校准”。

## 1. 选择范文与适用性

按以下顺序选择本次可用范文：

1. 同一考试、同一题目或同一题干的范文；
2. 同一题目但来源、年份或文本完整度有限的范文；
3. 题目不同但主题、任务和文体接近的范文，仅作弱比较材料。

**范文数量与检索覆盖**：若工作区或本次可用来源中存在多篇完整、可追溯且题目匹配的范文，
不得只因已有一篇就停止比较；应至少选取两篇内容实质不同的范文分别预评分，以观察本题可比参照的范围。
若当前只能确认一篇，仍按下述规则使用，但须说明已检查的材料范围及单篇参照的局限；不能为了凑数纳入重复转载、
正文残缺、题目不匹配或来源无法追溯的文本。若外部检索不可用，不把联网检索设为批改前置条件。
范文篇数与来源独立性只用于描述参照覆盖，不代表阅卷意见、校准强度或准确性。

记录文件/链接、题目匹配程度、来源、年份、文本是否完整及选择理由。机构自称档次只作来源信息，不能直接当作范文得分。无法确认题目或文本完整性时，说明限制；范文与题目差异过大时，不用它锚定档位。

如没有合适范文，按题干、公开要求、用户硬口径和本 skill 评分规则直接评阅，说明“无可比范文”；不得为完成流程临时编造范文或伪造参照档。

## 2. 范文先评、考生后比

范文评分须在评阅考生作文之前完成，避免考生文本影响参照档位。对每篇范文：

1. 按同一题干和同一评分规则，分别评题意、内容、结构、语言四维；按适用要求评论证深度，并记录原文证据。
2. 综合确定基础大档，核查明确硬伤，再按题意质量、内容质量、论证深度、结构完成度、语言质量五项定位上/中/下；依换算表记录模拟分数或档位范围。
3. 记录每篇范文的来源、题目匹配程度、评分理由、限制和模拟档位。多篇范文可形成相对参照带，但不得把样本数量或模型评分重复次数解释成验证强度。

随后按 `essay-judging.md` 评考生作文，逐维对照范文的表现与评分证据，说明考生在哪些维度高于、接近或低于参照范文，并用考生原文支持判断。综合题干标准、四维表现、硬伤和五项档内证据定档；范文比较是必需的辅助步骤，不替代这些判据。

## 3. 比较纪律

- 比较的是题意完成、内容质量、论证深度、结构完成、语言质量等表现及其证据；不按词句相似度、案例相同与否或写作套路判档。
- 不以单篇范文作线性插值，不按“像某档范文”直接赋档，不把范文分数换算成考生分数。
- 范文与考生题目不完全一致时，逐项标记可比与不可比维度；不可比维度回到题干和通用标准判断。
- 范文之间档位矛盾、同一范文用现行规则重评后发生变化，或考生表现落在参照样本之外时，披露差异并扩大建议区间；不得悄悄改写范文档位以贴合考生作文。
- 自查范文和考生作文是否使用同一题干、同一规则版本、同一档位换算表；自查只能发现内部不一致，不构成人工校准或独立验证。

## 4. 报告要求

大作文报告列出实际使用的可比范文及匹配程度；简要给出范文模拟档位/维度锚点；再列出考生作文与参照的关键异同及原文证据，并说明这些比较如何影响档位判断。无可比范文时明确说明并按 `essay-judging.md` 规则直接评阅。

所有分数和档位均标注为模拟判断、未经人工基准校准。范文比较有助于固定本次判分尺度和提高前后一致性，但不能证明真实阅卷准确率，也不能单独支持更窄的建议区间。

范文的归档与来源记录见 `reference-answers.md`、`workspace-layout.md`。大作文评分主流程见 `essay-judging.md`；通用准确性边界以 `SKILL.md` 和 `scoring-standards.md` 为准。

## 5. 报告示例范文（**从参考答案中选最好的一篇，原样照录**，2026-10-22 用户裁定）

> **用户口径**：大作文批改报告中**要给出示例范文**，选法是"**从参考答案中选取你觉得最好的一篇**"。
> 目的：给考生一篇可直接模仿的整篇样板，而不是只给"哪几维弱"的评语。

**5.1 必须做 / 不许做**

- **必须**：凡批改大作文，报告大作文段末附**且仅附一篇**「示例范文」，**整篇原文照录**，
  并注明来源、机构／作者标签、字数与模拟档位。
- **不许**：自行撰写、改写、润色、缩写、拼接参考答案里的范文；把范文标成"标准答案／官方范文"；
  用范文分数替代考生分数；只在正文里摘几句而冒充"整篇范文"。

**5.2 选取方法（"最好的一篇"的可执行定义）**

素材来源限定为工作区该卷参考答案中的大作文文件（`参考答案/{省份}/{卷ID}/第{大作文题号}题.txt`）。

1. **全量粗筛**：对文件里收录的每一篇，先做低成本筛查——是否**同题/同题干**、是否**正文完整**、
   是否符合题干文体与字数上限、是否**来源可追溯**。剔除残缺、跑题、来源不明者（一句话写明剔除理由）。
2. **完整预评分**：对粗筛留下的候选按本文 §2 做四维评价＋硬伤核查＋档内定位＋模拟划档
   （至少两篇；这一动作与 §2 的"范文预评分"是同一件事，**合并执行、不重复计分**）。
3. **择优**：取**模拟档位最高**者；同档时依次比：①与题干／材料的匹配度（切题、覆盖题干要求）
   ②档内五项证据质量 ③字数是否落在题干目标区（`word-count.md` §3）④来源可追溯性。
4. **说明理由**：用 1–3 句写清"为什么选它"（档位＋关键差异，如"切题最准、分论点不交叉、
   论证有材料外支撑"），**不许只写"写得最好"**。

**5.3 呈现格式**

```markdown
### 示例范文（引自参考答案）
- 来源：`参考答案/国考/2018国考副省级/第5题.txt` · 标签：{机构/作者}
- 字数：1032 字（`工具/count_chars.py` 核验；题干要求 1000–1200 字 → 目标区内）
- 模拟档位：二类上（32.5/40；L3 模拟评分，未经人工基准校准）
- 选取理由：{切题最准／论证最实，一句话}

> {整篇范文原文，原样照录，不改一字}
```

- 范文本身**超出题干上限或低于目标区**时：如实标注实际字数与偏差，**不得为凑字数删改范文**；
  确需节选只能**整段省略**并标注"节选，省略第 N 段"。
- 范文段落用 `>` 引用块或独立小节隔离，读者须能一眼分清**范文原文与考生作答**。
- 标注档位只作**写法参照**，不等于考生"照抄即可得此分"。

**5.4 参考答案中没有可用范文时**

- 如实写"**`参考答案/` 未收录本题可用的完整范文（已检查：{文件路径}）**"，**不得编造**（§1 禁令不变），
  也不得拿不相关题目的范文充数。
- 用户**明确要求**"给一篇范文"时，可另给"**AI 模拟范文（非参考答案原文，仅演示写法）**"：
  须按该题材写、**用 `工具/count_chars.py` 核验落在题干目标区**、字数照实标注，
  并且**不得充当范文档位锚**（不参与考生定档比较）。

**5.5 与既有规则的关系**

- 范文预评分仍是**内部比较锚**（§2／§4 不变）；示例范文只是把**已评过的候选里最好的那篇原样呈现**给用户模仿，
  **不新增分数、不改考生得分、不改变档位与区间**。
- 示例范文中的语言特征（结构套路、金句、例证方式）**不构成评分标准**（1.2 纪律 1–4 不变）。
