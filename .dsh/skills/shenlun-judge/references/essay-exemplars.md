# 大作文范文评分与比较锚

> **用途与限制**：大作文批改如有可比范文，必须先按本 skill 同一套评分维度对范文评分、划档，再将考生作文与这些范文逐项比较，辅助确定考生档位。范文档位是模型依统一规则生成的**内部比较锚**，不是人工阅卷标签、真实标准分或准确率校准数据。报告应标注“范文为模型模拟评分，未经人工基准校准”。

## 1. 选择范文与适用性

按以下顺序选择本次可用范文：

1. 同一考试、同一题目或同一题干的范文；
2. 同一题目但来源、年份或文本完整度有限的范文；
3. 题目不同但主题、任务和文体接近的范文，仅作弱比较材料。

**范文数量与检索覆盖**：若工作区或本次可用来源中存在多篇完整、可追溯且题目匹配的范文，
不得只因已有一篇就停止比较；对本题全部通过粗筛的完整可比候选逐篇预评分，有多篇时应包含内容实质不同的参照，不以重复转载充数。
若当前只能确认一篇，仍按下述规则使用，但须说明已检查的材料范围及单篇参照的局限；不能为了凑数纳入重复转载、
正文残缺、不满足上述可比条件或来源无法追溯的文本。异题弱参照须按上述条件及本文 §3 标明可比与不可比范围。若外部检索不可用，不把联网检索设为批改前置条件。
范文篇数与来源独立性只用于描述参照覆盖，不代表阅卷意见、校准强度或准确性。

记录文件/链接、题目匹配程度、来源、年份、文本是否完整及选择理由。异题弱参照另核实其原题题干、给定材料及满分出处，登记可比与不可比维度；原题或满分未核实时不编造数值、不纳入已评分参照，按 `rulings.md` §1.3.1 说明缺失与局限。机构自称档次只作来源信息，不能直接当作范文得分。无法确认题目或文本完整性时，说明限制；范文与题目差异过大时，不用它锚定档位。

如没有合适范文，先按 `rulings.md` §1.17 记录第一阶段的核实范围与原因，再接收考生作答，按题干、公开要求、用户硬口径和本 skill 评分规则评阅，说明“无可比范文”；不得为完成流程临时编造范文或伪造参照档。

## 2. 范文先评、考生后比

严格盲评按 `rulings.md` §1.17 分两次提交：第一阶段只接收题干、材料和参考范文，在看到考生作文前完成并展示固定的预评分记录；第二阶段再接收作答。作答提前出现、记录复用与后续更正按该条处理，不能仅靠调整评分步骤的顺序补称盲评。

寻找参考范文及其原题时也须执行该条的材料读取边界：未分类文件只看文件名／路径，不打开正文、预览首页或转换后辨认；第二阶段接收或指定作答后再继续内容识别。缺少第一阶段必需材料时请用户明确指定，不从匿名文件中逐个试读查找。

第一阶段对每篇范文：

1. 按 `rulings.md` §1.3.1 区分参照类型：同题范文使用本题题干与材料，异题弱参照使用各自原题题干与材料；沿用同一规则版本和四维评分框架，按各自适用要求评论证深度并记录原文证据，不套本题题干判断异题范文是否切题。
2. 综合确定基础大档，核查明确硬伤，再按题意质量、内容质量、论证深度、结构完成度、语言质量五项定位上/中/下（四类文不细分）；查各自原题满分的适用换算表，记录数值模拟得分／满分及模拟档位，允许范文满分不同。无法支持单一落点时按 `rulings.md` §1.3.1 给有据的数值区间／满分，不仅写档位范围。
3. 按 `rulings.md` §1.19 提炼每篇范文的总论点与全部分论点，注明原文依据，连同来源、原文标题写成论点表，随本阶段记录展示并固定；表头及动态扩列见 `report-template.md`。
4. 记录每篇范文的来源、参照类型、原题及满分依据、评分理由、限制和模拟档位，并用原文说明哪些维度可比、哪些不可比。异题分数和档位只描述其在原题下的表现，不与本题原始分或百分比直接排位，也不缩放成考生分数。多篇范文可提供维度表现参照，但不得把样本数量或模型评分重复次数解释成验证强度。

第一阶段记录向用户展示并固定后，再请用户第二次提交考生作文；随后按 `essay-judging.md` 评阅，逐维对照范文的表现与评分证据，说明考生在哪些维度高于、接近或低于参照范文，并用考生原文支持判断。综合题干标准、四维表现、硬伤和五项档内证据定档；范文比较是必需的辅助步骤，不替代这些判据。

## 3. 比较纪律

- 比较的是题意完成、内容质量、论证深度、结构完成、语言质量等表现及其证据；不按词句相似度、案例相同与否或写作套路判档。
- 不以单篇范文作线性插值，不按“像某档范文”直接赋档，不把范文分数换算成考生分数。
- 范文与考生题目不完全一致时，只比较已明确列为可比的维度并引用双方原文；不可比维度不作高低对照，考生该维度回到本题题干与通用标准判断，异题范文的原题得分不能替代本题的题意或内容标准。
- 范文之间档位判断存在矛盾、同一范文按现行规则重评后变化，或考生表现落在参照样本之外时，披露差异并核查其影响。按 `rulings.md` §1.7，只有确实增加本次评分的不确定性时才据此调整建议区间，并列受影响的判断、原文依据及分数范围；未增加时不因此调整。前置记录更正仍按 §1.17 处理，不得悄悄改写范文档位以贴合考生作文。
- 自查范文和考生作文是否沿用同一规则版本与评分框架；同题参照核对同一本题题干和换算表，异题弱参照分别核对各自原题、材料、满分与换算表及已声明的可比范围，不要求异题使用同一题干或同一满分。自查只能发现内部不一致，不构成人工校准或独立验证。

## 4. 报告要求

大作文报告列出实际使用的可比范文及匹配程度；简要给出范文模拟档位/维度锚点；再列出考生作文与参照的关键异同及原文证据，并说明这些比较如何影响档位判断。无可比范文时明确说明并按 `essay-judging.md` 规则直接评阅。
按 `rulings.md` §1.3.1 在本题内直接展示“大作文刻度表”和“范文逐篇评分”，范文ID一一对应，逐篇给数值分数、满分、档位及原文依据；表格格式见 `report-template.md`。过程文件不能代替报告内展示，1—2题免独立建档也不免本项。无材料时保留栏目并写已检查路径与原因。
本题大作文区域还必须展示“论点表”，按 `rulings.md` §1.19 覆盖每篇试评范文的来源、标题、总论点和分论点，与上述两表对应；不只提炼入选全文，不以三列限制原文实际分论点数量。无范文时同样保留本栏目并登记状态、已检查路径和原因。
比较参照与示例全文的可用性按 `rulings.md` §1.3.1 分别核验：没有可照录的本题示例全文时，仅在“示例范文”栏目登记“状态：无可照录的本题完整范文”、已检查路径和原因，已有可比范文的三张表继续正常展示，不能为省略全文把已有参照写成“无可比范文”。

所有分数和档位均标注为模拟判断、未经人工基准校准。范文比较有助于固定本次判分尺度和提高前后一致性，但不能证明真实阅卷准确率，也不能单独支持更窄的建议区间。

范文的归档与来源记录见 `reference-answers.md`、`workspace-layout.md`。大作文评分主流程见 `essay-judging.md`；通用准确性边界以 `SKILL.md` 和 `scoring-standards.md` 为准。

**独立建档条件**：素材清单、特征卡和梯队画像三件套按 `rulings.md` §1.3 判断必建或豁免。建档时依本文 §1—3 保存来源版本、逐篇预评分和比较证据；单篇范文如实标明参照有限，不凑造第二梯队。免建文件时，实际采用范文的预评分与比较证据仍须写入报告。

## 5. 报告示例范文（**从参考答案中选最好的一篇，原样照录**，2026-10-22 用户裁定）

> **用户口径**：大作文批改报告中**要给出示例范文**，选法是"**从参考答案中选取你觉得最好的一篇**"。
> 目的：给考生一篇可直接模仿的整篇样板，而不是只给"哪几维弱"的评语。

收录完整范文的字数按 `rulings.md` §1.8 只核验与提示：超限、偏少或偏离目标区均不影响候选、择优、预评分及模拟档位；这同样适用于本文 §1—4 的范文比较，不按篇幅代理判断内容质量。

**5.1 必须做 / 不许做**

- **必须**：凡批改大作文，报告大作文段末保留「示例范文」栏目；本卷有合格同题完整候选时，附**且仅附一篇**，**整篇原文照录**，
  并注明来源、机构／作者标签、字数与模拟档位。无合格候选时按 §5.4 写缺失说明；这不取消已有可比范文的比较及论点表。
- **不许**：自行撰写、改写、润色、缩写、删段、节选或拼接参考答案里的范文；把范文标成"标准答案／官方范文"；
  用范文分数替代考生分数；只在正文里摘几句而冒充"整篇范文"。

**5.2 选取方法（"最好的一篇"的可执行定义）**

可照录的示例全文来源限定为工作区该卷参考答案中的大作文文件（`参考答案/{省份}/{卷ID}/第{大作文题号}题.txt`，或按工作区规范收录的同题 md 文件）。此处同题完整候选的粗筛只决定示例全文资格，不排除 §1 已确认可比的异题弱参照。

1. **全量粗筛**：对文件里收录的每一篇，先做低成本筛查——是否**同题/同题干**、是否**正文完整**、
   是否符合题干文体、是否**来源可追溯**。剔除实际残缺、跑题、来源不明者（一句话写明剔除依据）；字数偏差不作为筛除条件，不能仅因篇幅短判残缺。
2. **完整预评分**：对粗筛留下的候选按本文 §2 做四维评价＋硬伤核查＋档内定位＋模拟划档
   （所有通过粗筛的完整可比候选均须逐篇评分并入报告；仅一篇时按 §1 记录单篇局限，不虚构第二篇。与 §2 的“范文预评分”合并执行，不重复计分）。
3. **择优**：取**模拟档位最高**者；同档时依次比：①与题干／材料的匹配度（切题、覆盖题干要求）
   ②档内五项证据质量 ③来源可追溯性。字数及其合规状态不作为优先条件。
4. **说明理由**：用 1–3 句写清"为什么选它"（档位＋关键差异，如"切题最准、分论点不交叉、
   论证有材料外支撑"），**不许只写"写得最好"**。

**5.3 呈现格式**

```markdown
#### 示例范文（引自参考答案；置于本题小节内）
- 范文ID：F1（对应本题刻度表及逐篇评分表）
- 来源：`参考答案/国考/2018国考副省级/第5题.txt` · 标签：{机构/作者}
- 字数：1032 字（`工具/count_chars.py` 核验；题干要求 1000–1200 字 → 目标区内）
- 模拟档位：一类下（32.5/40；L3 模拟评分，未经人工基准校准）
- 选取理由：{切题最准／论证最实，一句话}

> {整篇范文原文，原样照录，不改一字}
```

- 范文本身存在字数偏差时：如实标注实际字数与偏差，**整篇原样照录，不得为凑字数删改、删段或节选**；超限和不足均不影响选取、排序与模拟评分，口径见 `rulings.md` §1 口径 11、§1.8。
- 范文段落用 `>` 引用块或独立小节隔离，读者须能一眼分清**范文原文与考生作答**。
- 标注档位只作**写法参照**，不等于考生"照抄即可得此分"。

**5.4 参考答案中没有可用范文时**

- 在“示例范文”栏目分别写“**状态：无可照录的本题完整范文**”“**已检查：{实际文件路径／目录}**”“**原因：{未收录／残缺／不同题等具体依据}**”，**不得编造**（§1 禁令不变），也不得拿异题弱参照充当本题示例全文。有可比范文时仍保留其正常比较、预评分和论点表；仅确实无可比范文时才按 §4 登记参照缺失。
- 用户**明确要求**"给一篇范文"时，可另给"**AI 模拟范文（非参考答案原文，仅演示写法）**"：
  须按该题材写、**用 `工具/count_chars.py` 核验实际字数，再对照 `word-count.md` §3／§4.1 的题干类型与对应生成目标**、字数照实标注，
  并且**不得充当范文档位锚**（不参与考生定档比较）。

**5.5 与既有规则的关系**

- 范文预评分仍是**内部比较锚**（§2／§4 不变）；示例范文只是把**已评过的候选里最好的那篇原样呈现**给用户模仿，
  **不新增分数、不改考生得分、不改变档位与区间**。
- 示例范文中的语言特征（结构套路、金句、例证方式）**不构成评分标准**（1.2 纪律 1–4 不变）。
