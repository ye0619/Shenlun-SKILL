# 公文写作：格式速查与评分要点

（应用文 / 贯彻执行：讲话稿、通知、倡议书、建议书、汇报提纲、公开信、短评、报告、
编者按/导言、工作要点/方案、简报、回应/舆情答复、宣传稿等）

> ⚠ **依据层级**：公文"先查五项（任务目的／身份场景／内容完整度／格式规范性／语言得体性）
> 再赋分"属公开描述（L2）；**"内容／格式／语言"三池的权重数值（训练参照）与池内分值分配
> 属本 skill 的经验口径（L3，官方未公开）**；而文种格式规范与题面要求（如"不考虑格式"）
> 属 L1，优先适用。**公文不设独立档位**——不产生"公文一类文／二类文"这类档位分数，
> 也**不做 ±（正负）机械调整**；若某官方批改规范给了公文档次，则**按该规范执行**
> （以规范为准，属 L1/L2）。工作区 `参考答案/` 中的公文参考答案属**经验校准
> （L4，非官方）**，可用于校准要点粒度与语言风格，但**不得因此宣称任何"官方比例"**
> （标注规范见 `scoring-standards.md` 0.1–0.2）。

---

## 一、评分方式（先检查五项，再三池赋分）

1. **优先检查任务与身份（两项错位即致命，先于格式）**：
   - **任务目的**：题目要你干什么（倡议／汇报／答复／宣传／部署）？写出来的东西是不是
     在完成那个任务？（要求倡议却通篇汇报，属"核心任务遗漏"，分数直接受限）
   - **身份场景**：发文者是谁、写给谁、什么场合？称呼、口吻、职权边界是否对位？
2. **再查内容完整度**：材料核心信息覆盖了没有（按文种目的筛选，见第四节）。
3. **再查格式规范性**：标题、称谓、落款、日期是否齐全规范（见第三节）。
4. **最后查语言得体性**：文体风格是否得当（宣传稿生动、报告严谨、上行文有请示口吻）。
5. **先做阶段 A 试批改，再赋分（2026-09）**：公文题同样走两阶段流程——
   该题有 **≥2 家独立来源**时，**先拿参考答案试批改**（逐份核对"命中／漏写／多写／表述／舍弃"）→
   从**共同点／差异点／边界情况**生成该题《动态评分规范》（含**内容要点**、
   **本卷特有的格式取舍**、**不应机械扣分的格式情形**，如提纲类是否计格式），
   落 `批改规范/{省份}/{卷ID}-第N题-动态评分规范.md`（L4 草稿，待用户确认）；
   **材料不足时不执行**（无参考答案／**仅 1 家**／全同源／**脚本不可用**），
   改用原机制并声明"未做本题试批改、依据为通用评分规则"。
   规范口径唯一出处：`small-questions.md` 第四节阶段 A。
6. **赋分：三池相加，不划档**——公文得分 = **内容池（按点）＋ 格式池（逐项检查）＋
   语言池（逐项检查）**：
   - **内容池**：按**采分点共识模型**给分（强共识点／弱共识点／单源点／
     **材料推定点**（**0 家且次要 → 提醒区不计分；0 家但重要 → 按弱共识计分**，2026-09-22）／争议点；**共识点占该内容池 70%–80%**），
     **唯一出处 `small-questions.md` 第四节**；
     **0 家（机构集体未收录）的点先判"重不重要"**（2026-09-22 修订）：
     **重要 → 按弱共识点计分**（内容池低档）；**次要/牵强 → 不计分、只列"提醒区"**
     ——公文题与小题同口径，同样按家数递减定权；
     **例外**：该题参考资料**残缺或可判性不足**（疑为节选／**未做同源检测（家数未知）**／脚本不可用）时，
     提醒项**按低权计分并进入内容池**（口径见 `small-questions.md` 第四节第 2 节例外条）。
     ⚠ **"仅 1 家独立来源／无参考答案／全同源"不走本例外**——家数已判明时点全部按低权计分
     （与小题同口径），**置信度"中"**；只有家数未知或资料残缺才降"低"。
     **内容池分值恒等于本池分到的分值**（＝题目总分 × 训练参照 **80%**，见第七节；
     **不是**"内容池＝题目总分"）：某点退出计分（**0 家且次要**／争议点）时，其分值**在内容池内部回补**到
     其余计分点，不得把池调小、也不得让该池满分拿不到。
     **两个百分比的分母不同**：本池占题目总分 **80%**（分母＝题目总分），池内共识点 70%–80%（分母＝内容池自身）。
   - **格式池／语言池**：按上面第 3、4 项检查（格式规范性／语言得体性）**逐项检查给分**，
     **不划档、不做 ±（正负）机械调整**；**各池扣分合计 ≤ 题目总分的 10%**（**小额原则**，2026-09-22 用户裁定）。
   - **公文不产生独立的档位分数**：报告里不出现"公文一类文／二类文"这类说法；
     三池权重均为**训练参照（经验口径，非官方比例）**，可按题面要求与 `批改规范/` 的
     参考口径调整（见第七节）。

## 二、三种格式分类

| 类别 | 要素 | 代表文种 |
|------|------|----------|
| 全格式 | 标题 + 称呼 + 正文 + 落款（单位/日期） | 通知、函、请示、报告、倡议书、公开信 |
| 半格式 | 标题 + 称呼 + 正文（无落款或落款可省） | 讲话稿、发言稿、开幕词 |
| 文章类 | 标题 + 正文（完整文章式） | 短评、时评、汇报提纲、调研报告、导学材料、编者按/导言、简报、工作要点/方案 |

**格式判断优先级**：
1. 题目要求"格式正确/符合文体要求" → 四点格式全写；
2. 题目无格式要求 → 标题必写，其他格式可写但不必求全；
3. 题目明示"不必考虑格式/不要求格式" → 标题必须有，正文按文章处理，
   **格式池归零、缺称呼缺落款一律不扣分**（与第七节"特殊情形"同一口径）。

## 三、格式要素速查

| 要素 | 写法 |
|------|------|
| 标题 | 居中；题目给定则照抄；未给则"关于 XX 的 XX（文体）"，过长可换行居中 |
| 称呼 | 顶格，后加冒号；注意身份感（对上级/对群众/对学生称呼不同） |
| 正文 | 开头（目的/背景）+ 主体（分条列点）+ 结尾（号召/请示/结语） |
| 落款 | 右下角：发文单位 + 日期（XX 年 XX 月 XX 日） |
| 语言 | 上行文"请指示/请批示"；平行文按题目要求（生动/号召/得体）；下行文带要求语气 |

## 四、内容按文种目的筛选（核心能力）

| 文种 | 内容聚焦 |
|------|----------|
| 倡议书 | 为什么做 + 怎么做 + 怎么参与；结尾号召，有感染力 |
| 讲话稿/发言稿 | 开场问候 + 肯定成绩 + 部署要求 + 号召收尾；注意身份感 |
| 通知/通告 | 事项 + 时间地点 + 要求；客观简洁 |
| 建议书/提案 | 问题概述 + 具体建议（分条）；语言恳切 |
| 汇报材料/报告 | 做法 + 成效 + 数据 + 问题与打算；客观严谨 |
| 汇报提纲/提纲类 | 一、背景；二、做法；三、成效；四、打算——不写"的"字结构套话 |
| 公开信 | 称谓亲切 + 说明事由 + 回应关切 + 表达诚意 |
| 短评/时评 | 观点鲜明 + 评析结合 + 语言犀利有文采 |
| **编者按/导言/序言** | 交代背景与缘起 + 点明主旨或价值 + 引出正文；短，一段或几段，**不写称呼与落款** |
| **工作要点/实施方案/工作方案** | 目标要求 + 重点任务（分条列项）+ 保障措施 + 时间安排；条目化、动词开头、责任明确 |
| **简报/工作动态/信息稿** | 时间地点主体 + 主要做法 + 成效数据 + 下一步（视要求）；客观简练、标题醒目 |
| **回应/舆情答复/情况说明** | 说明事由与态度 + 核查事实 + 处理措施 + 后续承诺；**先回应关切再讲措施**，语气诚恳不辩解 |
| **宣传稿/推介词/讲解词** | 亮点提炼 + 具体事例 + 价值升华；生动有感染力，但要点必须实 |
| **意见建议/对策清单** | 问题对应建议，逐条可操作（谁来做、做什么、达到什么效果）；不重复问题细节 |

> 通用原则：**先判"这道题要我干什么"（文种目的），再决定写什么**——同一材料写成倡议书、
> 汇报材料与工作要点，内容筛选完全不同；格式要求以题目原文为准（见第二节、第七节）。
> 文种名称与题目表述不一致时（如"拟写发言提纲"），**以题干用词为准**，不要改写成自己熟悉的文种。

## 五、段落组织（五把钥匙，择一而用）

> **这些是写作方法，不是评分项**：按哪把钥匙组织、用几段，均不影响得分；
> 评分只看任务与身份是否对位、内容要点是否命中、格式是否规范、语言是否得体
> （见第一节与第七节）。

1. **讲逻辑（3W）**：是什么—为什么—怎么办（最常规，大多数文体适用）。
2. **讲顺序**：按时间/阶段组织（前中后、分阶段）。
3. **讲过渡**：加过渡段/过渡句衔接不同板块（对策占比大的材料常用）。
4. **讲故事**：背景 → 经过（合并提炼）→ 结果（兜底方法）。
5. **讲规矩**：题目有几问分几段；材料有几部分分几段。

---

## 六、语言风格要求

- 避免"公文腔"堆砌与空话套话，也避免口语化。
- 倡议书类允许适度抒情与号召，但要点必须实（做法要具体可操作）。
- 每条内容 = 概括 + 具体，方便阅卷人快速找到采分点。
- 先写对、再写活：格式对 + 要点齐 = 高分基础，语言风格是锦上添花。

---

## 七、评分输出要点（与小题共用模板）

- 先给"**任务目的 / 身份场景**"两项判定（对不对位），再给内容、格式、语言三项判定；
- **公文不设独立档位**（因此不存在"套用大作文四档区间"的问题；`scoring-standards.md`
  三.1 的换算表只覆盖大作文）；
- **内容池**按**采分点共识模型**核对（强共识点／弱共识点／单源点／
  **材料推定点（0 家且次要 → 提醒区不计分；0 家但重要 → 按弱共识计分）**／争议点，
  口径唯一出处 `small-questions.md` 第四节，**不用覆盖率阈值**）；
  **其中 0 家（机构集体未收录）的点**：**重要 → 按弱共识计分；次要/牵强 → 不计分、只列"提醒区"**
  （2026-09-22 修订）——公文题同样适用
  （避免用户为"专业答案都没写的点"丢分）；
  **例外**（参考资料**残缺或家数未知**／未做同源检测）→ 提醒项按低权计分、进入内容池；
  **"仅 1 家／无参考答案／全同源"同样低权计分（但不降置信度到"低"）**；
  **内容池分值恒等于本池分到的分值**（＝题目总分 × 训练参照 **80%**），退出计分的分值**在池内回补**到其余计分点；
- **格式池／语言池**在**对应池内按检查项逐项给分**（不划档、不做 ± 机械调整），
  **各池扣分合计 ≤ 题目总分的 10%**（小额原则）；
  明确指出格式扣分项（如"缺落款 −1""称呼未顶格 −1"）——量级属经验口径；
- 给出满分版本参考与改进方向；
- **给出建议区间与评分置信度**（判定见 `scoring-standards.md` 0.4）；
- **字数**：公文题常设"不超过 X 字"，满分版本参考同样必须 ≤ 上限且经
  `工具/count_chars.py` 核验（见 `word-count.md`）；公文题的称呼、落款、日期
  按答题卡占格计入字数；字数不合规不等于格式扣分，两者互不替代。

### 内容池／格式池／语言池权重的口径（**训练参照，不是官方比例**）

**前置声明（每次引用都要带上）**：公开的考试大纲只说明"贯彻执行能力"等测查要求，
**从未公开过全国统一的"内容 X%／格式 X%／语言 X%"分值表**；不同考试、地区、题型、
年份的评分细则可能存在差异。因此下表**只是本 skill 为保持多次批改尺度一致而设的
训练参照（经验口径）**，可按题目要求、题目分值构成与 `参考答案/` 的参考口径调整，
**不得表述为官方规定**：

| 采分项 | 训练参照占比 | 常见扣分 |
|--------|---------|---------|
| 内容池（材料核心信息覆盖；共识模型定价） | **80%** | 按采分点语义命中计 |
| 格式池（格式要素） | **10%** | 缺标题 −1；缺落款/日期 −1；称呼未顶格或漏称呼 −1；正文不分段 −0.5~−1（**各池合计 ≤ 总分 10%**） |
| 语言池（语言与文体风格） | **10%** | 文体风格不符（宣传稿写成报告腔）−1~−2；口语化/公文腔堆砌 −0.5~−1；身份感错位（称呼、口吻不对）−1（**各池合计 ≤ 总分 10%**） |

> **口径说明（2026-09-22 调整）**：格式池由 15%–20% 降为 **10%**、语言池由 15%–20% 降为 **10%**，
> 内容池由 60%–70% 升为 **80%**——依据用户裁定"**格式与语言的给分占比过高，应降低**"。
> **格式/语言只作小额修正，不得成为主要区分度来源。**

> **两个百分比的分母不同，两者不冲突**：表中"内容池 **80%**"的分母是**题目总分**
> （内容池权重）；而内容池内部的"**共识点占该内容池 70%–80%、单源点（低权点）
> 20%–30%**"分母是**内容池自身**（口径唯一出处：`small-questions.md` 第四节）；
> 其中 **0 家收录的点**：**重要 → 按弱共识计分**（内容池低档）；**次要/牵强 → 不计分、只列提醒区**
> （2026-09-22 修订），**争议点不计分**。
> **80% 是题目总分口径，70%–80% 是内容池内部口径，两者不冲突。**
> **但"内容池＝题目总分"这个口径不存在**：内容池只等于**它自己分到的分值**；
> 某点退出计分时是**在内容池内部回补**，不是把整个题目总分塞进内容池
> （三池相加才＝题目总分）。
>
> **公文不设大作文式档位**：公文**不产生独立的档位分数**（报告里不出现"公文一类文／
> 二类文"这类说法）；内容池按点（**共识模型定价**），格式池与语言池**逐项检查给分**
> （不划档、不做 ± 机械调整）。若某官方批改规范给了公文档次，则**按该规范执行**
> （以规范为准，属 L1/L2）。
>
> **三池加总口径**：**公文得分 = 内容池（按点，共识模型定价）＋ 格式池（逐项检查）
> ＋ 语言池（逐项检查）**；三池权重为 **内容 80%／格式 10%／语言 10%（训练参照，
> 经验口径，非官方比例）**，可按题面要求与 `批改规范/` 的参考口径调整；
> **无本卷规范时用内置国考默认口径**（`guokao-defaults.md` §4）。

> **不要反向套用**：题目明示"不考虑格式"时**格式池归零（本题没有格式分）**，
> 总分由内容池与语言池按原比例 **8:1** 分担；
> 题目只给 10 分且明确考"内容要点"时，也不必硬按上表凑格式分。
> 判断顺序永远先是"任务与身份对不对"，再是"要点齐不齐、格式规不规范"。

**特殊情形（必须遵守，否则会误伤）**：

- 题目明示"**不考虑格式/不要求格式**"（如"拟写发言提纲，不考虑格式"）→ **格式池归零：
  本题没有格式分**，总分由**内容池与语言池按原比例 8:1 分担**
  （内容＝总分×8/9、语言＝总分×1/9；语言按 0.5 粒度取值、余数归内容）；
  此时**缺称呼、缺落款一律不扣分**，只核内容要点与文体风格。
  （2026-09-23 用户裁定；报告"评分说明"须写明"本题格式池归零，总分按 8:1 由内容与语言分担"。）
- 题目要求"格式正确/符合文体要求"→ 按上表全项核对。
- 提纲类（发言提纲、汇报提纲）：不要求落款，不因"没写落款"扣分；
  但分条列点、层次清楚属于内容表达要求。
