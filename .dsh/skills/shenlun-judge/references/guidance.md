## 第一部分：构思方法库（原 `conception.md`）

# 构思方法库（立意 / 类型判断 / 结构 / 分论点 / 论证）

> **重要定位**：本文件所有方法都是**构思脚手架**——帮用户"想得出、写得出、不跑题"。
> 它们**不是评分标准**（评分见 `scoring-standards.md` 与 `essay-judging.md`）。
> 给用户讲构思时必须同时说明："这些方法用于启发你，不按它们写不会扣分。"
> 尤其是类型判断（单主题/AB 型/ABC 型/多主题），只用于理解题干与组织思路。

---

## 一、立意三步法

1. **题干关键词**：提取题干核心概念与限定词，确定论述对象。
2. **材料主旨**：从材料中找高频词、观点句、首尾段总结，把立意接到材料主线上。
3. **自身积累**：结合时代背景、政策精神、个人思考深化立意。

**立意检验四标准**：正确（符合主流价值观）、明确（观点鲜明）、唯一（一篇文章一个
总论点）、深刻（有分析层次，不止于表面）。

---

## 二、类型判断（辅助工具，不参与评分）

拿到题目先理解题干的概念结构，这能帮你决定"往哪些方向找分论点"：

| 类型 | 识别 | 分论点参考方向（仅作参考） |
|------|------|---------------------------|
| 单主题 | 一个核心概念 | 多维度展开（为什么重要 / 怎么做 / 从哪些方面做） |
| 双主题 AB 型 | 两个并列/对立/互补概念 | ①A 对 B 的作用 ②B 对 A 的作用 ③A 与 B 协同 |
| 双主题 ABC 型 | A、B 共同服务 C | ①A 对 C 的作用 ②B 对 C 的作用 ③A+B 协同对 C |
| 多主题 | 三个及以上并列概念 | 各主题分别的作用，强调"组合拳"整体效应 |

**使用边界（务必遵守）**：
- 这是"不知道怎么写时的参考方向"之一，不是必选结构；
- 双主题只深入写"A 与 B 相辅相成"一个层面、或使用递进/对比等其他组织方式，
  只要围绕核心概念及其关系展开，同样是切题且可能高分的写法；
- 分论点中的核心术语必须来自题干或材料（关键词是找出来的，不是编出来的）。

---

## 三、结构备选（按需选择，自洽即可）

| 结构 | 组织方式 | 适用 |
|------|----------|------|
| 五段三分 | 开头 + 三个并列分论点 + 结尾 | 保底通用，最稳妥 |
| 六段式 | 五段三分 + 过渡段（分析背景/问题） | 需要更多分析空间 |
| 思辨式 | 开头提出辩证观点 + 分论 A + 分论 B + 论 AB 关系 + 结尾 | 辩证主题（发展/保护、守正/创新） |
| 递进式 | 是什么 → 为什么 → 怎么办 → 结尾 | 分析型题目 |
| 夹叙夹议/故事贯穿 | 以案例/故事为主线，边叙边议 | 追求新意（鼓励，不影响评分） |

**段落分工**：开头（引出话题 + 点明问题/意义 + 亮明中心论点，中心论点必须是
最后一句话）、主体（每段 = 分论点句 + 论证 + 小结论，段落字数基本对等）、
结尾（回扣中心论点，用新话术；升华到国家发展、人民幸福层面）。

**结尾禁忌**：不提新分论点、不用"但是"转折、不用"我希望/我相信"等主观表达。

---

## 四、分论点要求

- 并列或递进，逻辑清晰；
- 角度不同，互不重复；
- 服务总论点，围绕中心；
- 对仗工整是锦上添花，不是必需（内容优先于形式）。

---

## 五、论证方法

| 方法 | 要点 |
|------|------|
| 举例论证 | 例子真实、典型、与论点相关，例后必须分析 |
| 道理论证 | 道理正确、逻辑严密、有说服力 |
| 引用论证 | 引用准确、相关，引后要分析（政策、讲话、名言） |
| 对比论证 | 对比鲜明、相关，对比后要分析 |
| 比喻论证 | 贴切、易懂，点到为止 |

**可选技巧：双线论述**——每段内"政策理论线（转述政策精神，点到为止）+ 案例分析线
（简述案例 + 提炼启示）"双线并行，增强说服力与厚度。

---

## 六、开头结尾参考

**开头三式**：背景引入（时代背景 → 主题意义 → 问题 → 对策/目标）、
名言引入（名言 → 揭示道理 → 结合当下 → 亮明论点）、现象引入（现象/案例 → 主题意义）。

**结尾三式**：总结号召、展望未来、引用升华。

## 第二部分：规范表达与素材（原 `language-materials.md`）

# 规范表达与金句素材

---

## 一、规范表达原则（五化）

| 要求 | 说明 | 示例 |
|------|------|------|
| 书面化 | 不用口语 | "搞"→"开展" |
| 规范化 | 用政府用语 | "想办法"→"研究对策" |
| 简洁化 | 不啰嗦 | "进行了研究讨论"→"研究讨论" |
| 逻辑化 | 有条理 | 用"一是、二是、三是" |
| 客观化 | 不主观 | "我觉得"→"据了解" |

### 口语转规范对照

| 口语 | 规范表达 |
|------|---------|
| 搞 / 弄 | 开展、推进、落实、实施 |
| 想办法 | 研究对策、制定措施 |
| 出问题 | 出现问题、存在隐患 |
| 解决了 | 有效解决、妥善处理 |
| 做得好 | 成效显著、扎实推进 |
| 不够好 | 有待加强、仍需完善 |
| 越来越多 | 日益增多、持续增加 |
| 越来越好 | 持续改善、稳步提升 |
| 因为 / 所以 / 但是 | 由于、源于 / 因此、由此可见 / 然而、但 |

---

## 二、政府工作高频用语

### 动词类
- **推进类**：推进、推动、推行、推广、实施、落实、贯彻、执行
- **加强类**：加强、强化、健全、完善、巩固、提升、提高、增强
- **深化类**：深化、拓展、拓宽、扩大、延伸
- **破解类**：破解、化解、解决、消除、克服

### 名词类
- **发展**：高质量发展、新发展理念、新发展格局、新质生产力、创新驱动、双循环
- **治理**：治理体系、治理能力、基层治理、社会治理、网格化管理、一站式服务、"最多跑一次"
- **民生**：获得感、幸福感、安全感、民生福祉、共同富裕、乡村振兴
- **法治**：依法治国、法治政府、执法规范化、公平正义、良法善治
- **生态**：绿水青山就是金山银山、绿色发展、生态文明、碳达峰碳中和
- **文化**：文化自信、以文化人、中华优秀传统文化创造性转化创新性发展
- **科技**：科技自立自强、卡脖子技术、数字中国、人工智能+
- **作风**：初心使命、真抓实干、钉钉子精神、绣花功夫

> 使用原则：搭配要准确（"深化"改革、"完善"制度、"提升"能力），
> 不堆砌、不滥用；大作文中政策术语点到为止，重点还是论证。

---

## 三、八大主题金句素材

### 1. 经济 / 发展
- "发展是解决我国一切问题的基础和关键。"
- "创新是引领发展的第一动力。"
- "推动高质量发展是全面建设社会主义现代化国家的首要任务。"

### 2. 乡村振兴 / 三农
- "民族要复兴，乡村必振兴。"
- "中国要强，农业必须强；中国要美，农村必须美；中国要富，农民必须富。"

### 3. 民生 / 人民
- "人民对美好生活的向往，就是我们的奋斗目标。"
- "治国有常，利民为本。"
- "让人民群众有更多获得感、幸福感、安全感。"

### 4. 生态 / 环境
- "绿水青山就是金山银山。"
- "生态兴则文明兴，生态衰则文明衰。"
- "像保护眼睛一样保护生态环境，像对待生命一样对待生态环境。"

### 5. 文化 / 精神
- "文化自信是更基础、更广泛、更深厚的自信。"
- "一个民族的复兴需要强大的物质力量，也需要强大的精神力量。"

### 6. 科技 / 创新
- "关键核心技术是要不来、买不来、讨不来的。"
- "惟创新者进，惟创新者强，惟创新者胜。"

### 7. 治理 / 法治
- "法治是最好的营商环境。"
- "法安天下，德润人心。"
- "基层治理是国家治理的基石。"

### 8. 作风 / 实干
- "空谈误国，实干兴邦。"
- "一分部署，九分落实。"
- "越是艰险越向前，越是吃劲越不松。"

> 使用原则：金句用于开头引题、段首提领、结尾升华；引用后要接自己的分析，
> 不孤立堆砌；不确定出处与准确表述的句子不要用（宁可不用，不可用错）。

---

## 四、素材使用建议

- 优先使用给定材料中的案例（最稳妥、最贴合）；其次用自身积累的典型案例。
- 案例写作：简述 + 提炼启示，不堆砌细节；有名有姓有细节的案例更有说服力。
- 大作文"抄材料"以 2–3 句为宜：**这是写作建议，不是扣分线**——阅卷只按内容维度
  判断"是否整段转抄材料而无论证"（见 `scoring-standards.md` 2.2"材料结合"），
  不数抄了几句。主体论证必须有自己的分析。
- 举例后必须有分析句（"这启示我们……""这恰恰说明……"），否则论据无效。
