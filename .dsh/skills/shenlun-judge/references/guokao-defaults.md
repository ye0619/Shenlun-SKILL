## 2. 通用阅卷流程与边界

1. **先整理依据，再按证据模拟评阅**：参考答案整理是可选步骤，不是人工标定，也不是批改前置条件。
2. **秒级阅卷 ⇒ 关键词与首尾句为王**：要点写在段首、条理外显（分条/分层/总括词）能提高被看见的概率
   ——这是**写作建议**，不是扣分项。
3. **第 1、2 题往往是得分关键**（客观要点好达成共识）→ 复盘时优先把小题要点找全。
4. **采分点多是题干/材料关键词或稍加改装**；**整段照抄原文**不得分。
5. **阅卷分数存在主观波动** ⇒ 本 skill 报告模拟得分与建议区间，并说明材料、证据或规则上的具体不确定项；
   不使用“高/中/低置信度”，也不把建议区间称为统计置信区间（`scoring-standards.md` 0.4）。
6. **字数不计入评分（用户裁定 2026-09-27）**：题干字数要求是 **L1，须核验**，
   但**只作提示**——超标／偏少都**不扣分、不降档、不进任何分值**；报告单列
   "⚠ 字数提示：超出题干上限 X 字（按用户口径不计分）"，**压缩建议照给**。
   达标判定见 `word-count.md` §3（"不超过 XX"取 XX，"XX 字左右"取 XX±50）。
   ⛔ **废止** 2026-09-21／09-25 的 `⌈超出达标上限 ÷ 50⌉` 扣分公式。

## 3. 小题默认口径（归纳概括／综合分析／提出对策）

| 项目 | 默认口径 |
|---|---|
| 分值主体 | 内容要点按语义采分点模拟评分；每点引用题干/材料依据、考生原文，并说明分值理由。来源家数用于溯源和覆盖信息，不自动定价。 |
| 逻辑/结构/表达 | 小题一般不另设分池；条理、顺序、分点或类别标签的呈现问题只提醒、不计分，无论题干是否明确要求；内容遗漏或错误仍按采分点判分，见 `rulings.md` §1.1。 |
| 分层与总括词 | 写作建议，不单独加分；按题干任务判断是否必要。 |
| 错别字/标点 | 不单独扣分；若导致要点无法辨认，按该点实际表达情况处理。 |
| 字数 | 只核验、不计分、不降档，见 `word-count.md`。 |
| 采分点粒度 | 分析题、概括题和对策题按 `rulings.md` §2 区分处理；不为凑点数或来源比例拆分、合并要点。 |
| 卷面 | 仅在手写原件/照片可见时按适用规则评；电子稿/转写稿不评。 |
| 加分 | 不设独立加分项。 |

参考答案有则记录来源并可整理候选要点；没有则照题干和材料形成模拟采分点。报告注明“模拟评分；未经人工基准校准”。

## 4. 公文默认口径（三池 80/10/10 为训练参照）

> **内容 80%／格式 10%／语言 10%**是本 skill 的训练参照，不是官方统一比例。具体按题干、适用的批改规范和文种要求判断；用户明确写“不考虑格式”时遵照题面与 `rulings.md` 执行。

| 项目 | 默认检查方式 |
|---|---|
| 任务与身份 | 核对任务目的、发文者、对象和场景 |
| 内容 | 对照题干和材料列出候选要点，逐点引用证据并说明分值理由；不按来源家数自动定价 |
| 格式 | 按文种规范逐项检查，题面未要求的要素不自行追加扣分 |
| 语言 | 检查准确、清楚、得体，指出具体原文证据 |

## 5. 大作文默认口径（档位锚定 ＋ 硬伤封顶 ＋ 档内定位）

### 5.1 流程（四步，与 `SKILL.md` 第六节一致）
大档锚定 → 硬伤封顶 → 档内定位（上／中／下）→ 建议区间与不确定性。
**档位区间一律查 `scoring-standards.md` 三.1**（占比 80/60/30 口径，含三小档落点值）。

### 5.2 档位"文字标准"（**采纳自规范 1／2 的措辞**；区间仍按 80/60/30）

| 档位 | 文字标准（题意／内容／结构／语言） | 规范原措辞（补强） |
|---|---|---|
| **一类文** | 立意**深刻、鲜明**；内容**充实、具体**；结构**严谨、条理清楚、详略得当**；语言**简明连贯得体、无病句** | "中心明确、表达方式运用恰当、书写规范工整、卷面整洁美观" |
| **二类文** | 立意**明确**；内容**较充实、具体**；结构**完整、条理清楚**；语言**通顺、基本无病句** | "表达方式运用恰当" |
| **三类文** | 立意**基本清楚**；内容**单薄/比较具体但浅**；结构**基本完整、条理基本清楚**；语言**基本通顺、有个别病句** | "认识基本正确" |
| **四类文** | 立意**偏离题意或不明确**；内容**空洞/偏离**；结构**混乱/不完整**；语言**不通、多处病句** | "认识有错误、字迹潦草难辨" |

> **注意**：文字标准只用于**锚定大档**；"书写工整/卷面整洁"**不进档位判断**（见 5.4）。

### 5.3 分项表的正确用法：**证据清单，不单独计分**（用户裁定）

| 规范分项（35 分卷示例） | 对应本 skill 的档内定位证据项 | 怎么用 |
|---|---|---|
| 标题（4） | **题意质量**（标题是否可追溯核心概念） | 只作取证；**不扣"标题分"**（题干明确要求时按题意如实反映） |
| 观点（7） | **题意质量**（总论点是否明确、有无分析层次） | 取证 |
| 论据（10） | **内容质量**（论据真实典型、结合材料与自身积累） | 取证 |
| 论证（9） | **论证深度**（例后有析、因果/机制/边界） | 取证 |
| 语言结构（5） | **语言质量＋结构完成度** | 取证 |

**禁止**：按 4/7/10/9/5 直接加总给分（那会变成第二套计分体系，与档位锚定冲突）。
分数只由五证据项（①题意质量②内容质量③论证深度④结构完成度⑤语言质量）的档内定位决定。

### 5.4 硬性项（本 skill 口径，**与规范冲突处按用户裁定执行**）

| 项目 | 处理 |
|---|---|
| 错别字/标点 | **0.5 分 / 3 处**，本项**封顶 1 分**（服从 `scoring-standards.md` 2.4 清单） |
| 成语、词语误用 | 0.5 分/处，封顶 1 分 |
| 语病 | 0.5–1 分/处，本维度封顶 1 分 |
| **未写标题** | **提示，不扣分**（**大作文**；公文缺标题见本文件 §4 格式池 −1）；题干明确要求标题含核心概念时，按题意"覆盖"**如实反映**（不二次扣分） |
| 卷面/字迹 | **仅手写原件/照片**：0.5–1 分；电子稿、转写稿不评 |
| **字数** | **只核验、不计分**（用户裁定 **2026-09-27**）：**不扣分、不降档、不进任何分值**；超限/偏少报告单列"⚠ 字数提示（按用户口径不计分）"，**压缩建议照给**；明显截断另按"结构完成度"如实反映。⛔ 废止 2026-09-21／09-25 的扣分公式 |
| 史实/引文/政策表述错误 | 0.5–1 分/处（只在主要归属维度计一次） |
| 严重政治性错误 | 不参与档内定位，**立即指出并建议重写** |

### 5.5 写作指导（**不参与打分**，只进"改进方向"与构思环节）

1. **总论点一化三**：不要直接拆题干词，先把材料核心提炼成**一个总论点**，再用它统摄三个分论点，
   分论点落到材料的**领域与做法**上（来自规范 3 的备考经验）。
2. **道理论证要有厚度**：一段道理分析写足 6–8 行、有政治理论支撑与逻辑纵深，言之有物（不设"行数"评分项）。
3. **条理外显**：分层、总括词、首尾句点题——让阅卷人 10 秒内看到你的骨架。

## 6. 河南／浙江（无本省规范）的总分适配规则

**适配原则：占比不变，分数按该卷满分换算；权重按百分比执行，不随分值改变。**

1. **档位**：查 `scoring-standards.md` 三.1 换算表（40/35/45/50/100 分卷已给；其他分值按比例换算，
   换算结果写进报告"换算表口径"行）。**不得默认 40 分卷**，卷面分值以题目/答题卡标注为准。
2. **公文三池**：内容 80%／格式 10%／语言 10% **永远按百分比算**（20 分题＝16/2/2；30 分题＝24/3/3）。
3. **小题单点分值**：仍由"单点占总分 10%–35%、点数合计＝题目总分"限定（`SKILL.md` 4.1）。
4. **已知卷面结构**（供换算用，均以 PDF 题面为准）：
   - **浙江 A 卷：3 题（20＋30＋50＝100）**，第 3 题为大作文（按 **50 分卷**档位表）。
   - **河南卷：4～5 题合计 100**（如 2026 县级 20/20/25/35；2022 乡镇 20/20/20/40），
     大作文按**该题实际分值**查表（35 分卷、40 分卷等）。
   - **国考**：副省/地市 5 题（10/10/20/20/40 等）；行政执法 5 题（常见 15/20/20/25/… 按卷面为准）。
5. **省际差异**（题型配比、是否有大作文、字数上限）→ 一律以该卷题面为准；
   报告里必须写明"本卷所用分值卷与换算依据"。
6. 日后取得本省规范 → 放 `批改规范/{省份}/`，**其优先级高于本文件**（§0 优先级表）。

## 7. 国考整套试卷的模拟压分修正（**−10，2026-10-22 用户裁定**）

> **性质**：L3 模拟口径（经验口径，官方**从未公布**任何整卷压分规则）。作用＝**模拟国考实际阅卷偏紧**
> 的情形，让模拟总分更贴近考生在国考中的真实体感。它**只作用于合卷汇总**，不改动任何单题判定。

**7.1 触发条件（三条同时满足才执行）**

1. **考试类型＝国考**：卷ID 形如 `{年份}国考…`（副省级／地市级／行政执法），或用户明确说明批改的是国考卷。
   **河南／浙江等省考卷即使套用本文件的国考口径，也一律不执行本条**（§6 只解决总分换算，不含压分）。
2. **批改范围＝整套试卷**：该卷题面的**全部题目**都已作答并**全部批改**。
   缺题、只批其中几题、单题／单篇大作文批改、用户"只改第 3 题"→ **不适用**（按普通单题批改给分）。
3. **用户未否掉压分**：用户未明确说"不要压分／按实际给分／折算成省考体感"。

**7.2 修正值（固定 −10.0，不浮动）**

- **压分后全卷模拟总分 ＝ 各题模拟得分之和 − 10.0**；**建议区间同法下移**（压分前区间之和的两端各 −10.0，区间宽度不变）。
- −10 是**绝对分**，不按卷面满分比例折算；若该卷卷面总分不是 100（国考通常 100），仍减 10，并在报告注明"卷面总分非 100，压分值未按比例折算"。
- **不得为凑出 −10 而微调单题分**：单题得分、档位、采分点、单题区间一律不动，压分只在合卷层面一次性扣。
- **不触底**：修正后小于 0 时取 0.0，并注明"压分修正已触底"（实际极少发生）。
- **幂等**：同卷多次批改（`-v2`／`-v3`）**每次重新计算、只压一次**，不得在旧报告的压分后分数上再减。
- 结果保留 **1 位小数**（与单题粒度一致）。

**7.3 报告写法（必须逐行给出，不得只写结果）**

```markdown
### 全卷模拟总分（国考整套 · 模拟压分修正）
| 项目 | 数值 |
|---|---|
| 各题模拟得分合计 | 68.5 / 100 |
| 国考整套压分修正 | −10.0（模拟国考阅卷偏紧，L3 经验口径，非官方规则） |
| **压分后模拟总分** | **58.5 / 100** |
| 建议区间（压分后） | 54.0–63.0 |
```

- 表中"各题模拟得分合计"必须与上文逐题得分**加总一致**，对不上即报告缺陷。
- 修正依据写进"依据与局限"：**"按用户 2026-10-22 裁定施加国考整套 −10 模拟压分（经验口径，官方未公布此类规则）"**；
  **禁止**"国考官方压 10 分""按官方标准减 10 分""这就是你的国考真实水平"。
- **单题段落不得出现"−10／压分"字样**，避免被误读为单题扣分。

**7.4 与其他口径的关系**

| 项 | 关系 |
|---|---|
| **从紧给分**（§9） | **叠加**：从紧管单题内部的松紧，压分管合卷汇总；报告须同时声明"按从紧口径给分 ＋ 国考整套 −10 模拟压分" |
| **建议区间** | 单题区间之和 → 两端各 −10；不得因压分而收窄或放宽区间 |
| **字数／卷面／形式项** | 压分不恢复任何形式类扣分（`rulings.md` §1 口径 6 不变） |
| **用户口径** | 用户要求不压分、按实际给分或折算省考体感 → **以用户为准**，报告写"按用户要求未施加国考整套压分修正" |
| **登记**（`批改报告/README.md`） | "模拟得分/区间"栏写压分后值并保留压分前：`58.5/100（压分前 68.5）`；"主要变化"栏注明"国考整套 −10" |

## 8. 标注义务与禁用话术

- **正确写法**："档位按本 skill 内置国考默认口径（经验口径，非官方）"；
  "公文三池按训练参照 80/10/10（经验口径，非官方比例）"。
- **禁止**："国考官方规定一类文 32 分以上"、"官方要求公文内容占 80%"、

  并在报告写明冲突点与取舍理由。

## 9. 从紧给分原则（**2026-09-22 用户裁定**）

> **背景**：用户反馈"**当前给分太松了**"，要求"**题目批改能扣分尽量扣分，当然要合理扣分；
> 用户多写的内容不扣分**"。本节的"从紧"只调**给分的松紧**，不改任何扣分项的种类与上限。

**9.1 小题（从紧）**

1. **三要素缺一不判满分**：采分点＝核心动作｜核心对象｜关键限定/结果；缺任一要素 →
   按缺失程度**往下取值**，**不取该点区间的上沿**。
2. **部分命中就低不就高**：给定的部分分区间（如 60%–80%）**取低端**。
3. **泛泛表述不给分**（**判 0 只看"泛泛表述、无可核对的具体指向"；"口号式"自 2026-10-03 起不再单列为触发词**）：
   只有方向性表述（"重视人才工作""营造良好氛围"）而无具体指向 →
   **0 分**（不再"给一点低分"）；材料无据 → 0 分；关键词没落地、表述不准 → 该点**不给分**。
4. **低权点（单源点／按弱共识计分的 0 家点）取区间下限**，不取上限。
5. **结构/条理不设分池，呈现问题只提醒、不计分**：分层清楚、写总括句不加分；纯罗列、点序不同、未写类别名或层次不清均不扣分、不降档。内容遗漏或错误仍按对应采分点判分，细则见 `rulings.md` §1.1。

**9.2 大作文（从紧）**

1. **档内定位默认落在本档"下／中"**；只有五项中 **≥4 项达本档上沿**才给"上"。
2. **硬伤一律执行**：跑题／偏题／核心任务遗漏／论点与材料主旨冲突／严重语言障碍
   **不得因"文采好、结构巧"而跳过**（`SKILL.md` 1.3 第二步）。
3. **语言类扣分如实累计**：错别字 0.5 分/3 处（上限 1 分）、词语误用、语病、史实/政策表述错误
   按 `scoring-standards.md` 2.4 清单**逐处计**，不"意思意思跳过"。
4. **亮点不加分**（1.2 纪律 4 不变）：从紧口径下更不得用"角度新"给分。
5. **"泛泛表述／口号式表述"本身不扣分、不降档（2026-10-03 用户裁定）**：大作文**不得**因为
   "写得泛泛""通篇口号""用了排比警句"而扣分或降档——**"口号式语句"不是采分点**（顶部硬口径 1、
   `small-questions.md` 4.1），**"泛泛"也不是分数依据**。要扣只能落到**实质缺陷**上：
   "**内容空洞**"＝**既无材料事实、也无任何替代性支撑**，或"**论证乏力**"，且须引原文为证。
   本条**不豁免** `scoring-standards.md` 2.2 的"内容空洞／内容单薄"档位信号，也**不改变 2.5 档内定位
   的证据要求**。**反向同样禁**："用了排比／口号式警句"不得加分。
   （**唯一出处：`essay-judging.md` 1.2 判语黑名单 #14；本节不重复**。）
6. **材料引用双向免分（2026-10-03 用户裁定）**：**引用材料本身不是加分项**——引用得当**不加分**；
   **引用不当**（生搬硬套／与论点无关／整段照抄）**即使引用了也不加分**（不当引用只在**既有维度**
   处理：整段转抄而无论证 → `scoring-standards.md` 2.2"材料结合"行；素材与论点无关 → 内容／论证的
   质量分）；**反向**：**未使用材料而把论点证明充分（论据够用、例后有析、论证链完整）→ 不得扣分、
   不得降档**——"用材料"与"用自身积累／材料外论据"是**两种等价的合法路径**。与 **#5** 同类：
   **都是把"伴随现象"从分数依据里摘出去**。
   （**唯一出处：`essay-judging.md` 1.2 判语黑名单 #15；本节不重复**。）

**9.3 公文（从紧）**

1. 内容池逐点按 **9.1** 从紧给分。
2. **格式池／语言池检查项逐项落实**：存在缺失/不得体即扣（仍受"各池 ≤ 总分 10%"训练参照约束；
   **该题规范另有明示时以规范为准**——如 2026 国考行政执法第 1 题照口述执行）。

**9.4 硬边界：多写不扣分（不可越界）**

- 用户**多答的内容**（超出采分点范围、额外补充、材料外的合理延伸、与本题无关但无害的表述）
  **一律不倒扣、不因"多写"扣分**——申论不倒扣，多写是考生的正常策略。
- 处理方式：**只在报告里作一句提示**（"该内容不在本题采分范围／不建议写"），
  不计入扣分，也不作为降档理由。
- **唯一例外**：题面/该题规范**明确**规定条数或范围的（如"超过四个方面扣 1 分"）→ 按题面/规范执行。

**9.5 合理性约束（防"为扣而扣"）**

1. **证据原则不变**：每一处扣分都要引作答原文或材料依据；**说不出依据的扣分一律作废**。
2. **形式不参与定档**：不得因模板/结构形态/卷面（电子稿）扣分（1.2 纪律 1）。
   **字数亦不计入评分**（用户 2026-09-27 裁定：只核验、只提示）——
   即**形式项一律不扣分**；字数若与要求不符，只单列一句提示，**不进总分、不作降档理由**。
3. **不得重复计扣**：同一处问题只在主要归属维度计一次。
4. **报告须声明**：在"评分说明"里写"**本次按从紧口径给分（2026-09-22 用户裁定）**"，
   让用户知道分数偏低是口径而非误差。**国考整套试卷另须**在同一处声明
   "**按用户 2026-10-22 裁定施加国考整套 −10 模拟压分**"（§7）。
