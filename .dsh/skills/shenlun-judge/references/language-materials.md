# 规范表达与金句素材

---

## 一、规范表达原则（五化）

| 要求 | 说明 | 示例 |
|------|------|------|
| 书面化 | 不用口语 | "搞"→"开展" |
| 规范化 | 用政府用语 | "想办法"→"研究对策" |
| 简洁化 | 不啰嗦 | "进行了研究讨论"→"研究讨论" |
| 逻辑化 | 有条理 | 用"一是、二是、三是" |
| 客观化 | 不主观 | "我觉得"→"据了解" |

### 口语转规范对照

| 口语 | 规范表达 |
|------|---------|
| 搞 / 弄 | 开展、推进、落实、实施 |
| 想办法 | 研究对策、制定措施 |
| 出问题 | 出现问题、存在隐患 |
| 解决了 | 有效解决、妥善处理 |
| 做得好 | 成效显著、扎实推进 |
| 不够好 | 有待加强、仍需完善 |
| 越来越多 | 日益增多、持续增加 |
| 越来越好 | 持续改善、稳步提升 |
| 因为 / 所以 / 但是 | 由于、源于 / 因此、由此可见 / 然而、但 |

## 二、政府工作高频用语

### 动词类
- **推进类**：推进、推动、推行、推广、实施、落实、贯彻、执行
- **加强类**：加强、强化、健全、完善、巩固、提升、提高、增强
- **深化类**：深化、拓展、拓宽、扩大、延伸
- **破解类**：破解、化解、解决、消除、克服

### 名词类
- **发展**：高质量发展、新发展理念、新发展格局、新质生产力、创新驱动、双循环
- **治理**：治理体系、治理能力、基层治理、社会治理、网格化管理、一站式服务、"最多跑一次"
- **民生**：获得感、幸福感、安全感、民生福祉、共同富裕、乡村振兴
- **法治**：依法治国、法治政府、执法规范化、公平正义、良法善治
- **生态**：绿水青山就是金山银山、绿色发展、生态文明、碳达峰碳中和
- **文化**：文化自信、以文化人、中华优秀传统文化创造性转化创新性发展
- **科技**：科技自立自强、卡脖子技术、数字中国、人工智能+
- **作风**：初心使命、真抓实干、钉钉子精神、绣花功夫

> 使用原则：搭配要准确（"深化"改革、"完善"制度、"提升"能力），
> 不堆砌、不滥用；大作文中政策术语点到为止，重点还是论证。

## 三、八大主题金句素材

### 1. 经济 / 发展
- "发展是解决我国一切问题的基础和关键。"
- "创新是引领发展的第一动力。"
- "推动高质量发展是全面建设社会主义现代化国家的首要任务。"

### 2. 乡村振兴 / 三农
- "民族要复兴，乡村必振兴。"
- "中国要强，农业必须强；中国要美，农村必须美；中国要富，农民必须富。"

### 3. 民生 / 人民
- "人民对美好生活的向往，就是我们的奋斗目标。"
- "治国有常，利民为本。"
- "让人民群众有更多获得感、幸福感、安全感。"

### 4. 生态 / 环境
- "绿水青山就是金山银山。"
- "生态兴则文明兴，生态衰则文明衰。"
- "像保护眼睛一样保护生态环境，像对待生命一样对待生态环境。"

### 5. 文化 / 精神
- "文化自信是更基础、更广泛、更深厚的自信。"
- "一个民族的复兴需要强大的物质力量，也需要强大的精神力量。"

### 6. 科技 / 创新
- "关键核心技术是要不来、买不来、讨不来的。"
- "惟创新者进，惟创新者强，惟创新者胜。"

### 7. 治理 / 法治
- "法治是最好的营商环境。"
- "法安天下，德润人心。"
- "基层治理是国家治理的基石。"

### 8. 作风 / 实干
- "空谈误国，实干兴邦。"
- "一分部署，九分落实。"
- "越是艰险越向前，越是吃劲越不松。"

> 使用原则：金句用于开头引题、段首提领、结尾升华；引用后要接自己的分析，
> 不孤立堆砌；不确定出处与准确表述的句子不要用（宁可不用，不可用错）。

## 四、素材使用建议

- 优先使用给定材料中的案例（最稳妥、最贴合）；其次用自身积累的典型案例。
- 案例写作：简述 + 提炼启示，不堆砌细节；有名有姓有细节的案例更有说服力。
- 大作文"抄材料"以 2–3 句为宜：**这是写作建议，不是扣分线**——阅卷只按内容维度
  判断"是否整段转抄材料而无论证"（见 `scoring-standards.md` 2.2"材料结合"），
  不数抄了几句。主体论证必须有自己的分析。
- 举例后必须有分析句（"这启示我们……""这恰恰说明……"），否则论据无效。
