# 参考答案接入规范（L4 经验校准 · 唯一出处）

**本文件解决一件事**：批改每一道题时，**都要先看工作区 `参考答案/` 目录里有没有这道题的
参考答案**（用户明确要求"如果有的话"就用）；有就用来校准口径，没有就明说没有——
**不许找替代、不许凭记忆编造、更不许把它说成官方标准答案。**

> ⚠ **依据层级**：`参考答案/` 里的真题参考答案、机构解析属 **L4 经验校准（参考口径，非官方）**。
> 它**不能**取代依据层级表（`scoring-standards.md` 0.1）：官方公开的题面作答要求是 L1，
> 与参考答案冲突时**以 L1 为准**。

---

## 1. 定位：参考答案是"校准尺"，不是"标准答案"

| 它能做什么 | 它不能做什么 |
|---|---|
| 校准**同义表述的宽严**（考生写法与参考表述不同，是否仍算命中） | ❌ 不能被称为"官方答案/标准答案" |
| 校准**采分点粒度**（一段材料该拆几个点、每个点多细） | ❌ 不能整段照抄当作"示例答案"输出 |
| **为小题采分点定价（核心用途）**：判**独立来源家数**后定**强共识点／弱共识点／单源点／材料推定点／争议点**（**0 家但重要 → 按弱共识点计分；0 家且次要 → 提醒区不计分**，2026-09-22），并据此分配分值池（第 6 节） | ❌ 不能因为"多家都写了"就说它是**官方采分点**（多源一致只提高共识度，共识 ≠ 官方） |
| 校准**公文格式与语言**的实际尺度 | ❌ 不能因为它与考生不同就判考生错 |
| 校准**大作文立意梯度与详略** | ❌ 不能当作"范文基准锚点"折算分数（`essay-judging.md` 四） |
| 支撑**评分置信度**判定（见第 6 节） | ❌ 不能用来替代材料原文证据（L1 与材料仍是根本依据） |

## 2. 目录与命名约定

**目录**：工作区 `参考答案/{省份}/{卷ID}/`（缺 `参考答案/` 即视为"没有参考答案"，
不要新建空目录冒充）。**卷ID = `{四位年份}{省份}{卷型}`**（完整定义见 `workspace-layout.md`）。

**支持的格式**：`.md` / `.txt`（直读）＞ `.docx` / `.pdf`（需提取文本，见第 4 节）＞ 图片（OCR）。

**规范命名**：

```
参考答案/
├── README.md                                 # 收录登记表（见第 9 节模板）
├── 河南/
│   ├── 2022河南乡镇/
│   │   ├── 第1题.txt                          # 题号用阿拉伯数字
│   │   ├── 第1题-粉笔.txt                      # 同题多来源：第N题-{来源}.txt
│   │   ├── 第1题-中公.txt
│   │   └── 第5题.txt
│   └── 2026河南县级/
│       └── 第1题.txt …
├── 国考/
│   └── 2026国考行政执法/
│       └── 第1题.txt …
└── 浙江/2018浙江A/                            # 已有第1–3题.txt（2018 浙江 A 卷）
```

- 文件名一律 `第N题.txt`（或 `.md`）；**整卷一份也可以**，但更推荐按题拆分，便于匹配。
- **来源与年份写进文件头**（`参考答案/README.md` 登记表同步登记）：
  `来源：真题参考答案／某机构解析／网友回忆`、`年份：2026`。
- **同卷多来源**：在卷目录里用 `第N题-{来源}.txt` 区分（如 `第1题-粉笔.txt`、`第1题-中公.txt`、
  `第1题-小马哥.txt`、`第5题-中公.txt`），**并在登记表里登记为"独立来源"**——
  这关系到置信度判定与小题共识点的定价（第 6 节）。
- **同一题的多份答案请保持题号一致（都写 `第1题…`）**：`ref_independence.py`
  按**文件名里的题号**分组，题号写乱（如一份写 `第1题-粉笔.txt`、另一份写 `第一题-中公.txt`
  或 `1-中公.txt`）会把不同题的答案并到一组、也会漏掉同题之间的对照，导致"独立来源家数"失真。
- 用户把答案随手丢在工作区根目录时，由助手按 `workspace-layout.md` 的归位流程处理
  （识别不确定的先问用户）。

## 3. 匹配规则（每道题都要走一遍）

1. **提取本题身份**：年份、省份/考试、卷型（县级/乡镇/县乡/市级/副省/地市/行政执法/A/B/C）、题号，
   拼成卷ID（如 `2022河南乡镇`）。
2. **在 `参考答案/{省份}/{卷ID}/` 内匹配**：
   - 命中卷目录 + 题号 → 直接使用；
   - 只命中卷目录、题号不明 → 打开文件确认题号后再用；
   - 只命中 1–2 个字段 → **向用户确认**"检测到 `参考答案/河南/2022河南乡镇/第1题.txt`
     可能是本题的参考，是否采用？"不要自行假定。
   - **不得用"相似卷"代替**：同省相邻年份卷、同题型、同主题的另一套卷的参考答案
     **都不能拿来当本卷口径**（这是长会话里最常见的串味来源，见 `session-isolation.md` R3）。
     唯一例外：用户**明确指定**"就按 XX 卷那套口径看"→ 报告中写"**跨卷参照（用户指定）**"
     并**下调评分置信度**。
3. **多份命中**（真题参考答案 + 多家机构解析并存）→ 优先**真题参考答案**；同时保留机构口径作
   交叉校验，若两者差异明显，在报告中说明差异（不要偷偷取平均分），
   并把"**独立来源家数**"登记下来（用 `工具/ref_independence.py` 按题分组判定，
   **= 分组数**；第 6 节的置信度与小题共识定价看的是独立来源与覆盖度，**不是份数**）。
4. **一道题一份口径**：同一份报告内不要对不同题混用不同来源却不标注。
5. **匹配的是"语义"，不是"用词"**：参考答案与考生作答**用词不同但语义等价**的，
   按同一采分点给分（基本原则见 `SKILL.md` 1.2 纪律 7 与 `essay-judging.md` 1.5）；
   **参考答案只是校准尺**，不得当作"必须出现的原句"。

## 4. 读取方式（按格式）

| 格式 | 做法 |
|---|---|
| `.md` / `.txt` | 直接用 `read` 工具读原文；长文件按题号定位小节 |
| `.docx` | 提取文本（本机有 Python 时可用 python-docx；或交给系统转换工具）；提取后核对是否串行、丢字 |
| `.pdf`（文字版） | 优先 **Python PyMuPDF**（`import fitz`，本机已装）逐页 `get_text()`；MiKTeX 自带的 `pdftotext` 在本机可能因日志目录不可写而失败（报 `log4cxx ... call failed`），失败即改用 fitz，不要反复重试 |
| `.pdf`（扫描件）／图片（jpg/png） | 用**平台自带的图像识别／OCR 能力**转写（多页长图按块切分）；**若本会话没有可用的图像工具，就请用户自行转文本或直接贴文本**，不要硬撑，也不要凭印象"读图" |
| 无法提取 | **不要猜内容**：在报告中写"参考答案存在但无法解析（原因）"，置信度按"无参考口径"处理，并提示用户提供 md/txt 版本 |

**读取后要做的第一件事**：核对它是不是**本题**（题号、题干关键词、分值），再看内容。

> 实测记录（2026 年批改环境）：工作区 `真题/国考/`、`真题/河南/`、`真题/浙江/`
> 共 101 份 PDF（已按 `{卷ID}.pdf` 规范化命名）均为**粉笔整理版，只含题干+给定资料+答题纸格子，
> 不含参考答案**（文字版，可用 fitz 直接提取）。因此"参考答案只能来自用户放入 `参考答案/`"——
> 不要指望从真题 PDF 里翻出答案。
>
> 另注：**`作答记录/` 只收 md/txt**，图像作答先请用户自行转文本（`workspace-layout.md` 第 6 节）；
> 而 `参考答案/` 出现图片时可用 OCR 提取（本表"扫描件／图片"一行的做法），但要在报告里注明"参考口径为
> OCR 转写，可能有字误"。

## 5. 使用边界（九条硬规则）

1. **不是官方标准**：任何输出都不得写"官方答案""标准答案"，只能写
   "`参考答案/{文件名}`（机构/真题参考口径，非官方）"。
2. **不得整段照抄**：给用户的"参考作答/满分答案"必须按本 skill 口径重写
   （要点化、材料原词优先、字数受 `word-count.md` 约束），**照抄参考答案 = 输出一个不受控
   字数、不受控口径的答案**，属禁止行为。
3. **L1 优先**：参考答案与题面作答要求（字数、文体、"不考虑格式"等）冲突时，**以题面为准**。
4. **表述不同 ≠ 考生错**：参考答案写法与考生不同但意思一致，仍按命中处理；
   参考答案没写而材料明显支持的要点，仍应给分（参考答案未必完备）。
5. **只校准、不外扩**：不得因为参考答案用了某个词，就要求考生必须用那个词；
   也不得因为参考答案没提材料里的某个要点，就否认该要点。
6. **必须登记**：用了就要在报告"评分依据声明"里写清文件名/来源/年份/独立来源家数，
   并注明"参考口径仅作校准，与本地重构口径可能不同"。
   **独立来源家数 = `工具/ref_independence.py` 的分组数（同源只算一家），不是文件份数**——
   参考答案份数本身不提高置信度（第 6 节）。
7. **同义表达与异构论证一律允许（基本原则：语义等价 + 逻辑等价）**：参考答案只是**校准尺**，
   **不是"必须出现的原句"**——考生用自己的话把同一意思说清、或换角度换例子论证同一道理，
   一律按命中处理，**不扣分也不加分**。
   **完整规则（含允许清单与判定三问）见 `SKILL.md` 1.2 纪律 7、`essay-judging.md` 1.5、
   `small-questions.md` 铁律 8，本节不重复。**
8. **具体案例不是采分点**：**未引用某个材料案例本身不得作为扣分理由**；
   参考答案里出现某材料案例 ≠ 考生必须引用它。
   **完整规则见 `essay-judging.md` 1.6 与 `scoring-standards.md` 2.2，本节不重复。**
9. **"写没写"决定的是权重，不是对错**（**2026-09-22 修订**）：
   **不得**因为某一家参考答案写了这一点就认定它是采分点（单源属**低权**）；
   **也不得**因为参考答案没写就**删掉**材料确凿支持的点——该点要留在表里，并**先判"重不重要"**：
   **重要 → 按弱共识点计分**；**次要/牵强 → 归"材料推定点"、单列"提醒区"不计分**。
   只有 **≥2 家独立来源命中 ＋ 材料有据**才叫**共识点**
   （≥3 家或 2 家占半数＝强共识；2 家不足半数＝弱共识取主池低档）。
   **家数递减定权：0 家但重要＝弱共识低值｜0 家且次要＝0 分进提醒区｜1 家＝单源低权｜
   2 家＝弱共识｜≥3 家＝强共识**；
   **唯一例外**：本题参考资料**残缺或可判性不足**（疑为节选／**未做同源检测（家数未知）**／脚本不可用）时，
   0 家点**全部按低权计分**并标注、置信度降"低"
   （**"仅 1 家独立来源／无参考答案／全同源"不属于本例外**——家数已判明时走"无共识点"路径，
   点全部按低权计分，**置信度为"中"**；**完整规则见 `small-questions.md` 第四节，本节不重复**）。

## 6. 对评分与置信度的作用

**对小题（核心用途）**：参考答案是**两阶段流程的标定材料＋定价依据**——
① **阶段 A**：**先拿本题参考答案自己试批改**（逐份核对"命中／漏写／多写／表述方式／舍弃了什么"），
从**共同点／差异点／边界情况**生成**本题《动态评分规范》**（7 项，见 `small-questions.md` 第四节阶段 A）；
② **阶段 B 定价**：判**独立来源家数**（`工具/ref_independence.py`，**同源只算一家**），
给每个采分点定 **强共识点／弱共识点／单源点／材料推定点／争议点**；
**家数递减定权（0 家但重要＝弱共识低值；0 家且次要＝0 分进提醒区；2026-09-22 修订）**；分值池目标区为
**共识点（强＋弱）70%–80%、低权点（单源点）20%–30%（硬上限 40%）、单点分值 10%–35%**；**分值池恒等于题目总分**——某点退出计分（0 家且次要／争议点）时其分值**回补**到其余计分点；**例外**（参考资料**残缺或可判性不足**：疑为节选／未做同源检测／脚本不可用）时 0 家点按低权计分并进入计分表，此时低权池不受 20%–30% 目标区与 40% 上限约束、**置信度"低"**；**"仅 1 家／无参考答案／全同源"不走本例外**（家数已判明 → 点全部低权计分、**置信度"中"**）。**冲突顺序**：① 池合计＝总分 → ② 单点 10%–35% → ③ 共识点>单源点（排序）→ ④ 目标区让位（10–15 分题不适用 40% 上限）；**共识点不足 3 个时，可用"0 家但重要"的材料推定点补足（按弱共识计分）；无可判为重要的 0 家点时，单源点转入提醒区、不计分**（细则见 `small-questions.md` 第四节第三步第 2-补 条）。
同时仍用于校准**同义宽严与采分点粒度**（如机构答案把某段拆成两个要点，需复核本 skill
的拆分是否偏粗）。**完整规则见 `small-questions.md` 第四节，本节不重复。**

**对公文**：校准格式要素的实际尺度（是否要求落款、提纲类是否计格式）与语言风格预期；
**内容池同样按家数递减定价（0 家但重要 → 按弱共识计分；0 家且次要 → 不计分、进提醒区；2026-09-22 修订）**。

**对大作文**：参考答案（含范文）是**阶段 A 的标定材料**——先**数范文 → 逐篇六项特征卡 →
梯队画像＋参照档**（这就是大作文的试批改产物），据此生成该卷《动态评分规范》的
**档次锚点**；再校准**立意梯度**（哪个方向算切题、哪个算偏题）与例证详略。
**不作分数锚点**——不存在"与参考答案像 = 高分"，也不做插值。

**对置信度（"采样与校准"口径，判定表见 `scoring-standards.md` 0.4）**：

> ⚠ **参考答案只提高"采样与校准置信度"，不等于"数量多则置信度高"。**
> 它提升的是**同义表述宽严、采分点粒度、档位边界**这三项判断的可靠性，
> **不改变 L1 题面要求的最高地位**，也不构成"范文基准锚点"。

| 情况 | 置信度上限 |
|---|---|
| 题干+材料+作答完整，且可校准口径为**该卷批改规范**，或**来源独立且覆盖本题**的参考答案（**小题**还须该题**有强/弱共识点**，否则至多"中"） | **高** |
| 题干+材料+作答完整，但无可校准口径（`参考答案/` 空或无本卷），或口径只覆盖部分题目 | **中** |
| 参考答案存在但无法解析、来源与本年卷不符、或只有单一起源且只覆盖小题 | **中**（按实际情况说明） |
| 参考答案**不完整**（疑为节选／**未做同源检测**／脚本不可用而家数未知）→ 提醒项只得按**低权计分** | **低**（并在报告说明"参考资料不完整／家数未知"） |
| 材料不全／转写存疑／题干或分值缺失 | **低**（无论有没有参考答案） |
| **无参考答案（家数＝0）／仅 1 家独立来源／全部同源**（资料本身完整、家数已判明） | **中**（写"无可校准口径"或"校准口径单一"；**不是"低"**） |

- **小题附加条件**：小题判"高"**还须该题有强/弱共识点**（该题**独立来源 ≥2 家**命中 ＋ 材料有据）；
  **只有单一独立来源时该题无共识点**（该题的点按"单源点"处理）→ **至多"中"**，
  报告须写明"本题无共识点"及理由（判定表同上，见 `scoring-standards.md` 0.4）。
- ⚠ **分层口径（2026-09-19 修订）**：判"低"看**资料是否可判同源／是否残缺**，不看家数多少——
  **家数未知（未做同源检测／脚本不可用）或资料残缺（疑为节选、材料不全）→ 低**；
  **家数已判明（含 0 家、1 家、全同源）→ 至多"中"**。
- **不看份数看质量**：**同一机构、同一来源的多份答案 ≈ 一份**，**独立来源家数 = 分组数**、
  不是文件份数；**完整规则见 `small-questions.md` 第四节第 3 节与"同源检测怎么做"（下），本节不重复**。
- **来源不明或明显不合本卷**（年份不符、题型不符、疑似网络拼凑）→ **不因此上调置信度**，
  并要在报告里说明"参考口径来源存疑"。
- **与 `批改规范/` 的关系**：批改规范等级更高（官方 → L1/L2；机构/自拟 → L4），
  两者冲突时以等级更高者为准，并在报告中写明。

> 关键纪律：**参考答案只能把"中"提到"高"，不能把"低"提到"高"**——
> 材料不全时，再好的参考口径也补不回缺失的材料。

**同源检测怎么做（可直接复制）**

```bash
python 工具/ref_independence.py 参考答案/河南/2022河南乡镇 --question 1
```

- **独立来源家数 = 分组数**（**不是文件数**）：真实分组一律以脚本对**本卷本题**的实际输出为准，
  不得凭印象指定（`--same` / `--near` 的默认阈值与判读口径见下条所指出处）。
- **判读与复核规则（阈值口径／长度离群／临界相似度／⚠ 告警／`--question` 前置全量检查／
  脚本不可用兜底）唯一出处见 `small-questions.md` 第四节第 3 节，本节不重复。**
- 脚本输出要作为**报告留痕**：把命令与输出写进共识表表头的"**来源指纹 ＋ 同源分组**"
  （缓存路径 `批改报告/.采分点共识/{卷ID}-第N题-共识表.md`；指纹变了就重建共识表）。

> ⚠ **别把两件事混为一谈**：这里的**相似度只用于"参考答案之间"判同源**（回答"算几家独立"）；
> **给分一律走语义采分**（核心动作｜核心对象｜关键限定/结果），
> **不用文本相似度**（`scoring-standards.md` 一.1；`small-questions.md` 第四节）。

## 8. 目录缺失或为空时怎么办

1. **不新建空目录冒充**、不去网上找"看起来像"的答案充数（联网仅作辅助，且必须标注来源与链接）。
2. 正常完成批改：按 L3 模拟重构采分点——**本题无共识点**（无参考答案／仅 1 家／全同源），
   点按"**材料推定点**"处理；**因参考资料不足以判定"机构没写＝不是采分点"，
   本区各点按低权计分**（例外条），**置信度取"中"**（无参考答案／仅 1 家／全同源＝**家数已判明、
   资料完整**，故为"中"；**未做同源检测或疑为节选才降"低"**），并在报告写明原因。
   **同时必须声明"未做本题参考答案试批改（阶段 A 未执行），依据为通用评分规则"**——
   这是"标定缺失"的显式披露，不是免责套话。
3. 在报告末尾**一句话提示**用户可如何补：把该卷**≥2 家独立来源**的参考答案放进
   `参考答案/{省份}/{卷ID}/第N题.txt`（md/txt 优先），下次批改即可**做阶段 A 试批改**、
   生成《动态评分规范》，置信度上限也能从"中"提到"高"；
   若该卷有批改规范（尤其大作文规范），放进 `批改规范/{省份}/` 对置信度与判分准确度帮助更大。
4. 用户同意时可协助入库：新建文件 → 从题干/机构解析整理 → 在 `参考答案/README.md` 登记。

## 10. 与真题库（`真题/{省份}/真题库/`）、作答记录（`作答记录/`）的分工

- `作答记录/`：**用户本人的作答**（批改对象）——读取与匹配规范见 `SKILL.md` 第三节第 1 步、
  字数统计见 `word-count.md` §4.2；**它永远不能被"参考答案"替代或补写**。
- `真题/{省份}/真题库/{卷ID}.md`：**已入库真题的结构化整理**（题面 + 材料要点 + L3 模拟重构的
  参考采分点），索引见同目录 `INDEX.md`，入库模板见 `真题/_TEMPLATE.md`；
  它是**评分工作底稿**（已从 skill 迁到工作区；skill 不内置任何题库数据，**也不含脚本**——脚本在工作区 `工具/`）。
- `批改报告/` 的共识表缓存与复用、`批改规范/` 的引用规则、`参考答案/` 的目录与命名：
  **完整规则见 `workspace-layout.md` 第 1–3、7 节，本节不重复**。
- 三者可以互相校对：若外部口径与库内重构口径差异明显，**以 L1（题面+材料）为裁判**，
  在报告中说明差异，并考虑按 `真题/_TEMPLATE.md` 更新库内采分点。
