# report-template（批改报告模板与填写纪律）

> **用途**：批改报告**逐字可抄的骨架**＋填写纪律。`SKILL.md` 9.2 是"报告质量要求"（10 条判据），
> 本文件是"照着填的模板"。**批改输出时才读本文件**（其余时间不必读）。
> **本文件不含判分规则正文**——规则一律在 `rulings.md`／`scoring-standards.md`／各 references；
> 本文件只写"报告里要出现哪些字段、怎么填"（2026-10-03 结构瘦身，避免多处维护）。

## 一、报告必写块（5 块 ＋ 1 个条件块）

| # | 块 | 写什么 | 细则 |
|---|---|---|---|
| 1 | **批改上下文声明** | 卷ID／本次范围／题面与材料来源／本卷口径与独立来源家数／上一次批改的卷 | 卷级隔离硬要求，见 `workspace-layout.md` 末章（原 `session-isolation.md`）R1–R3 |
| 2 | **评分依据声明** | L1／L2／L3／L4 四层＋固定差异声明＋阶段 A 标定＋置信度与区间 | 层级定义与标注义务见 `scoring-standards.md` 0.1–0.4；本文件 §二 有骨架 |
| 3 | **逐题分数与采分点判定** | 每题：得分／区间／采分点逐条（命中·部分命中·漏）＋**引作答原文** | 小题见 `small-questions.md`；公文见 `gongwen.md`；大作文见 `essay-judging.md` |
| 4 | **字数核验块** | 示例答案/范文：脚本统计值／题目要求／目标区／结论＋核验命令 | **模板在 `word-count.md` §7**，本文件不重复；用户作答只写"⚠ 字数提示" |
| 5 | **大作文刻度与档内定位**（大作文必写） | 范文数／刻度形态与参照档／**刻度改变了哪一处判断**／档内定位表五项 | 见 `essay-exemplars.md` 第 4 节接入点、`essay-judging.md` 档内定位表 |
| +1 | **双评分差行**（条件写） | 两遍大档相同且小档差 0 → **不写**；否则写 `双评分差：A–B，仲裁后取 C` | 规则见 `essay-judging.md`"双评与仲裁"；区间解释为"由双评自然导出的分差" |

**`-v2` 重批**：必须另有"**重批一致性**"块（与 v1 比大档／档内定位／主分，差 ≥1 小档或大档有变须逐项解释并写明以哪一版为准）。

## 二、可复制骨架

```markdown
### 批改上下文声明（卷级隔离，必写）
- 本卷卷ID：…；本次范围：第 N 题／全卷
- 题面/材料来源：根目录 PDF／`真题/{省份}/{卷ID}.pdf`／库内 md／联网链接
  （取不到 → 写"**题面未经核实、置信度低**"，只给档位级结论）
- 本卷口径：批改规范＝…（层级：L1/L2/L4）｜参考答案＝机构 A、B…（**独立来源 K 家**／文件 M 个）
  ｜大作文范文＝N 篇／刻度＝T1 单向·双向·单篇参照·未建（原因）
- 上一次批改的卷：… → 相同／**不同（已执行上下文重置，不沿用其采分点与结论）**

### 评分依据声明
- **最高层依据（L1，官方公开）**：题干作答要求"……"（引原文）；公告/大纲公开的测查能力"……"；
  考场硬规则"超出答题区域作答无效"
- **赋分方式（L2，公开描述）**：小题按点给分；公文三池赋分（内容池按点＋格式池／语言池按检查项，
  不划档）；大作文划档赋分
- **模拟口径（L3，官方细则未公开）**：采分点由依据材料模拟重构，**按来源等级定价**（强共识点／
  弱共识点／单源点／材料推定点／争议点 —— 定义与定价见 `rulings.md` §1 与 4.1）；
  档位区间／三小档／换算表按本 skill 模拟口径；扣分量级与示例答案目标区为训练建议
- **固定差异声明（必写）**：小题不设"逻辑／表达／结构"分池（2026-09-24 用户裁定）；
  部分省份细则含 0.5–2 分条理/表述分，**本 skill 分数与真实得分不可直接对表**
- **该卷批改规范**：`批改规范/{省份}/{卷ID}-批改规范.md`（来源/年份 → 层级判定）；
  官方公开者判 L1/L2（优先于本 skill 模拟口径），机构/自拟/助手提炼草稿判 L4（草稿注"未确认"）；
  无则写"未找到该卷批改规范"
- **阶段 A 标定**：已做／**未做（原因）**｜参与试批改的参考答案 K 家（来源）｜动态评分规范：
  `批改规范/{省份}/{卷ID}-第N题-动态评分规范.md`（L4 草稿，待用户确认；用户手写规范优先）
  ｜试批改记录：`批改报告/.采分点共识/{卷ID}-共识表-全卷.md`「试批改记录」段
- **经验校准（L4，非官方）**：`参考答案/{省份}/{卷ID}/`（来源/年份；文件 M 个 → 同源检测 →
  **独立来源 K 家**，分组：…）；**与 L1 冲突以 L1 为准**；**份数不等于置信度**（同源多份只算一份）
- **小题采分点共识**：强共识点 X 个（占满分池 Y%）／弱共识点 Y 个（含"0 家但经判定重要"Z 个）／
  单源点 Z／**提醒项（0 家且次要）W 个——不计分、不占分母**／争议点 V（不计分）；
  分值池核对：点数与单点分值合规、低权池 W%（目标区 20%–30%，超 30% 须写明原因、未破 40%）；
  共识表见 `批改报告/.采分点共识/{卷ID}-共识表-全卷.md` 本题小节；
  "机构未收录点"表列在报告里（`材料确有、机构 0 家收录`＋**是否计分及理由**＋用户是否写到）
- **大作文范文数与刻度参照（大作文必写，无条件）**：先写 `本卷大作文范文 N 篇（来源：…）`，
  再写刻度形态与**各梯队参照档**，最后写**刻度对本次结论的影响**——
  如 `刻度参照：T1 ×2（…；参照档＝二类上）／T2 ×3（…）；六项：④边界意识与 T1 同层、
  ②论点覆盖弱于 T1；影响：删去"④弱"后五项达中位者 2→3 项，档内定位由二类下改判二类中`；
  或 `刻度：单篇参照（T1-lite，样本仅 1 篇，不参与定档）`；
  或 `刻度：未建（原因：本卷该题无大作文范文／该题不是大作文／素材与本题无关）`。
  **写不出"刻度改了哪一处判断"＝机制空转**
- **评分置信度**：高／中／低 —— 依据（材料完整度、批改规范有无、独立来源家数、共识点覆盖），
  并以区间表述（如 26.5–28.5）；**置信度不到"高"时不写"28.5 分"式数字**
- **【条件写·大作文双评】**：两遍**大档相同且小档差 0** → **不写本行**；否则写
  `双评分差：<第一评>–<第二评>，仲裁后取 <终评>`（复议规则见 `essay-judging.md`"双评与仲裁"）
- **给分口径声明（必写）**：**本次按"从紧口径"给分**（三要素缺一不判满分、部分命中就低不就高、
  泛泛表述 0 分、大作文档内定位默认落"下/中"；**用户多写的内容不扣分**）——见 `guokao-defaults.md` §8
- **以上 L3/L4 内容均为模拟与参考口径，不代表官方评分细则。**
```

**字数核验块**（第 4 块）模板见 `word-count.md` §7；**大作文档内定位表**（五项逐项判定＋原文证据）见
`essay-judging.md`；**小题共识表**见 `small-questions.md` 第四节模板。

## 三、填写纪律（报告"该写什么／不该写什么"）

1. **⛔ 禁止在报告里复述 skill 的规则条文**（2026-10-03 新增，据体检报告 #7）。
   报告是**给用户看的判定结果**，不是 skill 的副本：只写**本题的结论＋依据来源＋作答原文引用**。
   - 应写：`该点判部分命中（缺"对象"）：作答只写"加强监管"，未写监管对象`。
   - **不写**：`根据 4.1 采分点共识模型，强共识点占满分池 60%……` 式的规则解释段。
   - 依据声明里**每个字段只填本次事实值**；"为什么这样规定"一律留在 skill 侧，不抄进报告。
   - 例外：**固定差异声明、给分口径声明、L3/L4 标注**三处是**必须出现的一句话声明**（用户要求知情），
     写成一句话即可，不得展开成段落。
2. **每处扣分／定档必须引作答原文**（引用为原文片段，不得概括转述；未引原文的扣分作废）。
3. **不到"高"置信度不写伪精确数字**，用区间＋说明缺什么。
4. **一切 L3/L4 内容带"模拟／经验／参考口径"前缀，永不写"官方规定"**（禁用话术见 `scoring-standards.md` 0.2）。
5. **材料类事实一律写清来源路径**（批改规范／参考答案／真题库／联网链接），并注明"参考口径仅作校准"。
6. **登记对象是"评分依据"，不是用户作答**（用户作答一律按原文引用）。
7. **卷级隔离自查**：报告头是否有上下文声明；每条采分点／刻度／动态规范的来源路径是否含**本卷卷ID**
   （不含 → 必须重生成，**不得借用相似卷**）；跨卷印象式评语是否已清除。
