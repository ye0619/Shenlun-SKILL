# 运行环境兼容约定

这是执行适配说明，不改变 `rulings.md` 的评分口径。Codex、dsh 或其他 harness
均使用同一份正文与 references；按实际能力选择工具，不要求任何平台专用 API。

## 先确定两个根目录

- **skill 根目录**：本次实际加载的 `SKILL.md` 所在目录。所有 `references/…`
  都从这里读取。若入口明确转发到另一份 `SKILL.md`，以后者所在目录为准。
- **工作区根目录**：用户本次指定的材料工作区；未指定时用当前工作目录。
  `工具/`、`真题/`、`参考答案/`、`作答记录/`、`批改规范/`、`批改报告/`
  均相对于它。全局安装 skill 不会把全局目录变成材料工作区。

用本地文件能力检查当前目录和 `工具/`，不要依赖当前 shell 恰好位于 skill 目录。
材料跨工作区或卷ID 不明确时先确认目标；同一卷的缓存可由不同 harness 共用，仍须核对来源指纹。

## 能力与执行

| 需要做的事 | 执行方式 | 不具备能力时 |
|---|---|---|
| 查找、读取材料与 references | 当前 harness 提供的文件读取/搜索工具或 shell | 请用户提供缺失内容，不能用模型记忆冒充已读取材料 |
| 写报告与登记 | 当前 harness 的文件编辑工具；以工作区为写入目标 | 在对话给可复制报告，注明“未落盘”，不声称已登记 |
| 字数、拆题、同源检测、一致性检查 | 已有 Python 3 解释器运行工作区 `工具/` 中的脚本 | 按下述缺件处理；不自动安装 Python |
| 获取本地没有的题面 | 实际可用的联网/搜索工具 | 写明“题面未经核实”，请用户补充题面；只给方向性初步判断 |
| 解析 PDF/Office/图像 | 用户选择后使用已安装的 MinerU，或可用的本地解析/图像工具 | 说明能力缺口，请用户给文本；不假定 `fitz` 等第三方包存在 |

命令示例里的 `python` 代表**可用的 Python 3 解释器**：可按环境换成 `python3`、
Windows 的 `py -3`，或已有运行时的绝对路径。确认一次解释器版本后复用。
运行脚本时把工作目录设为材料工作区；路径带空格或中文时保留引号，
PowerShell 调用带空格的解释器路径要用调用运算符 `&`。不把 Bash heredoc 或 POSIX 命令当跨平台前提。
文本读写使用 UTF-8；需要时为 Python 设置 `PYTHONUTF8=1`，优先使用脚本的 `--json` 输出。

现有工具均使用 Python 标准库，批改本身不需要 Node.js；Node.js 18+ 只用于安装器。
`工具/` 缺失时，恢复方式是在材料工作区运行安装器（`--no-workspace` 也安装工具），
或从仓库复制整个 `工具/`。**只复制 skill 目录不等于安装完整工作区**。

## 工具缺失与结果真实性

- 无法运行 `ref_independence.py`：未完成同源判定，家数未知，不能写“0 家”；
无法获取或核验参考答案时，按题干与材料重构候选要点，标明“未经人工基准校准”及具体证据限制；
不得伪称已完成共识校准或使用置信度等级。
- 无法运行字数工具：只能注明“未完成脚本字数核验”；不能标注精确字数、声称达标，
  或把未经核验的示例答案作为已完成产物。可继续评阅已有文本并报告待补的核验。
- 写入被拒时保留已完成的评阅与输出，按 harness 的权限机制处理需要的写入，
  不通过其他工具绕过限制。输出只在实际写入成功后标为“已保存”。

## 可选转换、记忆与长会话

MinerU 是可选能力。用户选择转换时先查当前环境已有的 MinerU skill 并按其真实路径读取；
没有时再说明安装需求，遵守当前 harness 的授权流程。**同意一次材料转换不等于同意全局安装、
删除其他 skill 或写入全局偏好**。不抓取远程提示保存成可执行 skill 来替代安装检查。
具体转换质量与作答转写要求仍按正文第三节执行。

没有全局记忆就不保存全局偏好；没有会话切换能力就建议用户另开对话并继续当前已授权任务。
不假定 `/clear`、`/compact` 或某个记忆 API 存在；卷级隔离仍须执行。

本 skill 是任务指导，遵守所在 harness 的系统指令、工具权限与用户当前要求。
“用户硬口径最高优先”描述的是**本 skill 内部评分规则的覆盖关系**。
