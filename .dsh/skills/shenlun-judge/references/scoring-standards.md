# 评分依据与标准详解（依据层级：官方公开要求为最高层）

本文件是 shenlun-judge 评分的**依据登记表**：说明每一处判分依据来自哪里、属于哪一层级、
引用时该怎么标注，然后给出各题型的赋分方式、四维定义与档位标准。

> **总纪律**：**官方公开的考试要求与能力维度是最高层依据**；
> **本 skill 的档位划分、分值换算、采分点拆分属于模拟阅卷模型（经验口径，L3）；
> 工作区 `参考答案/` 的真题参考答案与机构解析属于经验校准（L4）**——
> 两者都必须明确标注，**不得表述为官方规定**。

### 0.1 依据层级（L1 / L2 / L3 / L4）

| 层级 | 依据 | 具体内容 | 用法与标注 |
|:--:|---|---|---|
| **L1**<br>最高层：官方公开的考试要求与能力维度 | 招考公告、考试大纲/考试说明、**题面作答要求**、答题卡与考场规则、官方公开的能力测查维度 | ① 能力维度（阅读理解、综合分析、提出和解决问题、贯彻执行、文字表达）；② 题面要求原文（"观点明确、见解深刻""条理清楚""联系实际""不拘泥于给定资料""不超过 300 字""不考虑格式"等）；③ 考场硬规则（如"超出答题区域的作答无效"） | **直接作为评分的最高依据**：先据此判定"这道题在考什么、必须做到什么"，再谈分数。引用时引 L1 原文（题面/公告原句），不必标注等级 |
| **L2**<br>官方公开的评分方式描述 | 主管部门与官方渠道公开的赋分方式说明、官方阅卷口径通报中的公开表述 | 如小题"**按点给分**"、大作文"**划档赋分**"，以及四维宏观描述（立意深刻／内容充实／结构严谨／语言优美等措辞） | 作为**框架**使用；引用时注明"口径来源：公开描述" |
| **L3**<br>本 skill 的模拟阅卷模型（经验口径） | **本 skill 自建** + 机构解析与批改实践归纳 | ① 档位划分与区间（**按满分占比划档**：一类 ≥80%、二类 60%–80%、三类 30%–60%、四类 <30%；40 分卷即一类 32–40）；**大档再分上/中/下三小档（三.1 换算表）**；② 分值换算表（40/35/45/50/100 分卷，含各大档的上/中/下三小档区间）；③ 采分点拆分与子项分值分配（拆为"核心动作｜核心对象｜关键限定/结果"三要素）；④ 各维扣分量级与**档内定位**（每大档分**上/中/下三小档**，不用 ±1/±0.5 机械加减）；⑤ 公文三项权重（**训练参照**，非官方比例）；⑥ 字数配额与目标区间（85%–95%）；⑦ 卷面与字误量级 | **一律标注**为"模拟阅卷模型／经验口径（官方细则未公开）"；**不得表述为官方规定**（禁止与正确写法见 0.2） |
| **L4**<br>经验校准（参考口径，非官方） | 工作区 **`参考答案/`** 的真题参考答案、机构解析；**`批改规范/`（机构／个人自拟来源）**；真题库中的历史批改结果；用户本人历史作文 | 同义表述的宽严尺度、采分点粒度、档位边界的实际手感、示例答案的详略程度 | **只作校准，不作评分依据本身**；使用时登记文件名/来源/年份，标注"参考口径，非官方"；**与 L1 冲突时以 L1 为准**（细则见 `reference-answers.md`） |

> **`批改规范/` 的层级按来源判定（L4 行说明，细则见 0.3 与 `SKILL.md` 1.1）**：
> 来源为**官方公开**的评分标准／阅卷细则 → 按 0.3 **升级为 L1/L2，优先于本 skill 的 L3 模拟口径**
> （本 skill 的档位区间与档内划分对其让步）；来源为**机构／个人自拟** → 归 **L4 经验校准**，
> 只作宽严与粒度的校准。该卷有批改规范（尤其大作文规范）**就必须引用**，并在报告中登记
> 文件名、来源、年份与被判定的层级。

**申论官方阅卷细则（含具体采分点表与档位分值表）属于考试内部资料，通常不公开**——
因此 L3 不是"抄来的官方标准"，而是**为了让批改可比较、可复现而建立的模拟模型**；
现实中的主观题评分标准往往还要经试评、标杆卷等环节校准后才稳定，这一点本身就是
"不宣称唯一官方公式"的理由。

### 0.2 标注义务（每次输出都必须做到）

1. **报告必须带依据声明 + 评分置信度**，写明四层依据分别是什么、置信度为何是该档
   （模板见 `SKILL.md` 9.2、`reference-answers.md` 第 5 节）。
2. **禁止的表述**（**末四条为 2026 修订新增的禁用话术，属本 skill 模拟口径 L3，
   对应的正确写法见第 3 条末四条**）：
   - "官方规定一类文占满分 80% 以上"／"官方规定一类文 32–40 分"／"按官方评分细则，本题扣 2 分"；
   - "本题官方采分点为……"／"官方标准答案要求……"；
   - "官方要求字数控制在 85%–95%"（字数目标区是本 skill 的训练建议，属 L3）；
   - "官方规定采分点覆盖率≥80% 得满分"（**本 skill 已取消覆盖率阈值**，见 一.1）；
   - "官方规定公文内容占 70%、格式占 20%"（不存在全国统一的官方占比表，见 一.2）；
   - 把 `参考答案/` 里的机构答案称为"标准答案""官方答案"；
   - 用"官方"给 L3/L4 的数字背书，或把 L3 的档位表说成"国家标准"；
   - **"未引用材料中××案例，扣 X 分"／"没用材料里的例子，属于脱离材料"**
     （**具体案例不是采分点**：未引用某个材料案例本身不得作为扣分理由；只有该论点确实缺支撑时，
     才按内容／论证维度扣**质量分**，理由写"缺支撑"，不写"没引用某案例"，见 2.2）；
   - **"没有出现'×××'这几个词，判为偏离"／"与参考答案的论证角度不同，扣分"**
     （**同义表达与异构论证一律允许**：判定看**语义等价 + 逻辑等价**，
     三问成立即给分，见 `SKILL.md` 1.2 铁律 7）；
   - **"立意稍微模糊，按二类封顶"**
     （**"立意稍微模糊"不是硬伤**：只在题意维度扣质量、影响**档内定位**，
     **不封顶、不降档**；只有**实质偏题**才封顶三类，见 2.1、2.5）；
   - **"参考答案有 N 份，所以置信度高"**
     （**参考答案只提高采样与校准置信度**：同源多份只算一份，
     只有**来源独立、覆盖本题**才算有效采样，见 0.4）。
3. **正确的表述**：
   - "本 skill 按**满分占比**划档（一类 ≥80%、二类 60%–80%、三类 30%–60%、四类 <30%），
     再按卷面满分等比换算为分数区间（**经验口径，官方细则未公开**）"；
   - "参考采分点为依据材料原文**模拟重构**（官方细则未公开）"；
   - "题面要求'观点明确、见解深刻'属官方公开的作答要求（L1），据此判定……"；
   - "本条宽严尺度参照工作区 `参考答案/xxx.md`（**机构参考口径，非官方**），用于校准同义表述"；
   - **"具体案例不是采分点：只有该论点确实缺支撑时才按内容／论证维度扣质量分，
     理由写'缺支撑'（未引用某个材料案例本身不构成扣分理由）"**；
   - **"同义表达与异构论证一律允许（语义等价 + 逻辑等价），三问成立即给分"**；
   - **"'立意稍微模糊'只在题意维度扣质量（影响档内定位），不封顶、不降档；
     只有实质偏题才封顶三类"**；
   - **"参考答案只提高采样与校准置信度：同源多份只算一份，来源独立且覆盖本题才算有效采样"**。
4. **不得反向推卸**：不能因为"官方未公开"就不给分；依据不足时给**建议区间 + 较低置信度**
   并写清缺什么（见 0.4），而不是含糊其辞或拒评。
5. **精确度纪律**：**置信度不到"高"，就不要输出精确到小数点的分数**——用一个精确数字
   掩盖不确定性，比给出区间更容易误导用户（申论没有可核验的绝对评分标准）。

### 0.3 待核验清单（随使用更新，核对到更权威来源后升级等级）

- 各省/国考大作文档位区间是否存在官方原文表述（现按**满分占比**划档——一类 ≥80%、
  二类 60%–80%、三类 30%–60%、四类 <30%——再按各卷满分等比换算为分数区间，属 L3）；
- 小题"同义表述/上位概括"的宽严尺度（现由本 skill 模拟口径 + `参考答案/` 的 L4 校准决定）；
- 公文题格式分、语言分的占比（现属经验口径/训练参照）；
- 卷面/错别字扣分的量级（现属经验口径）；
- **官方是否曾公开过某年某省的阅卷细则或评分参考**：若确有公开，该部分可升为 L1/L2，
  并在此登记出处与年份，同时同步修改正文相应标注；
- **`参考答案/` 目录的覆盖情况**：已收录哪些卷、来源与年份是否可靠、**是否属于相互独立的
  来源**（登记表见该目录 `README.md` 与 `reference-answers.md`）。
- **`批改规范/` 的来源认定**：工作区 `批改规范/{省份}/` 里的规范是**官方公开**（→ 可按 0.3
  升级为 L1/L2，并登记出处与年份）、**机构自拟**、还是**来源不明**（→ 只能用来说明
  "该卷可能怎么判"，**不得当作官方标准**）；每次引用都要在报告"评分依据声明"里写明判定结论。
- **大作文"上/中/下三小档"的边界**：现按各档区间三等分取 0.5 分粒度（L3 模拟口径），
  属训练用划分，若日后核到更权威的分档口径，在此登记并同步三.1 换算表。

### 0.4 评分置信度（本 skill 口径，唯一出处）—— **采样与校准**式

**为什么要有它**：申论没有一份可以核验的绝对评分标准。只给一个分数（尤其是 28.5 这种
小数）会制造**虚假的精确感**；给"建议区间 + 置信度"才是诚实的输出方式。

**它是"采样与校准"的置信度，不是"参考材料数量"的函数**：置信度取决于
① 材料与作答的完整度（能不能评），② **有没有可用来校准档位边界的独立口径**（评得准不准）。
参考答案只提高**采样与校准**的可靠程度——**份数多 ≠ 置信度高**：同一来源的多份只算一份，
**来源独立且覆盖本题**才算有效采样；工作区 `批改规范/` 中该卷的批改规范（尤其大作文规范）
命中时，同样可提高置信度（官方公开来源更佳）。

**判定表**（每道题、每份报告都要给；理由必须写出来，不能只写等级）：

| 置信度 | 满足条件（材料完整度 + 可校准口径） | 报告怎么写 |
|:---:|---|---|
| **高** | ① **题干、材料、作答完整**（大作文有头有尾、小题要点齐全）；**且** ② **存在可用作校准的口径**——该卷有**批改规范**（任一来源，官方公开更佳；整卷或大作文规范均可），**或**有**来源独立、覆盖本题**的参考答案（`参考答案/` 对应卷，或真题库中该卷已入库的评分依据；**同源多份只算一份**） | 主分 + 窄区间（±2 分以内）；可直接参与跨次对比 |
| **中** | 材料与作答完整，但**可校准口径缺失或只覆盖部分**——单一起源的答案、答案非本年卷、只有小题口径没有大作文口径、只有机构解析无批改规范等等，**档位边界无法交叉验证**（采分点为纯 L3 模拟重构） | 主分 + 较宽区间（±2～4 分）；注明"档位边界无法交叉验证" |
| **低** | 任一：**材料不全**／作答为**图片转写且有存疑**／**题干或分值缺失**／**题型特殊无同类口径**／用户只给了片段 | **以区间为主**（±4 分以上），可只给档位不给精确分；列出补全后即可精评的材料 |

**其它硬性规则**：

1. **置信度与分数粒度联动**：置信度"中/低"时，**不输出"28.5 分"式结论**（0.5 分粒度只在
   置信度为高、且确有换算依据时使用）；可以说"约 26–30 分，落点偏中"。
2. **不看份数看质量**：`参考答案/` 是**机构口径**（L4），**同一机构同一来源的多份 ≈ 一份**，
   数量本身不提高置信度；参考答案与 `批改规范/` 都属**"参考口径"**，
   与 **L1（题面作答要求、考场硬规则）冲突时以 L1 为准**。
   参考答案与 `批改规范/` 能把置信度提到"高"，前提是材料与作答同样完整、
   且采样**来源独立、覆盖本题**——**材料不全时仍然是低**。
3. **批改规范命中可提高置信度**：该卷 `批改规范/{省份}/{卷ID}*.md` 存在（**尤其大作文规范**）
   并已逐条对照使用时，可视作有效校准口径、提高置信度并登记层级；
   但**来源不明的规范不得当作官方标准**——来源无法核实的一律按 L4 参考口径处理，
   只作宽严与粒度的校准。
4. **不得用低置信度当挡箭牌**：置信度低也必须给出可用的判断（档位 + 区间 + 最要命的
   问题清单），并写清"补什么材料可以升到高置信度"。
5. **可追溯**：报告中置信度的理由要能对上本表条件（哪几条满足、哪条不满足）。

## 一、不同题型的赋分方式（L2 公开描述 + L3 模拟口径）

> 本节说明的是**赋分方式**（L2：公开描述层面）；其中涉及的具体分值分配、采分点表、
> 档位区间均属 **L3 模拟口径**，引用时必须标注（见 0.2）。

### 1. 客观小题（归纳概括、综合分析、提出对策等）—— 按点给分

- **采分点**：答案要点通常来源于给定材料，或是从材料中提炼出的关键词、核心句。
- **赋分方式**：评分标准为每个要点分配分值（具体分值分配属于官方内部资料，不公开；
  本 skill 的采分点与子项分值为**依据材料原文模拟重构**，见 `small-questions.md`）。
- **示例（说明"按点给分"怎么运作，非真实采分表）**：一道 20 分的概括题，要求概括
  "当前社区治理面临的四大难题"，若每个难题 5 分则共 20 分；答案中出现与要点关键词
  意思一致的表述即可得分。**"每个难题 5 分"是本 skill 的模拟拆分（L3）**，
  不是官方分值分配。
- **怎么判一个点给几分（本 skill 口径，L3）**：把采分点拆成
  **核心动作｜核心对象｜关键限定/结果**三要素，按**语义命中程度**判定——
  **同义表达照给分（语义等价 + 逻辑等价）**：判断三要素是否命中**看语义**，
  不看用词是否与参考表述一致——考生用自己的话把同一意思说清，**同样命中、同样给分**，
  不得因为"没出现参考答案那几个词"就判偏离或扣分（见 0.2 禁用话术、`SKILL.md` 1.2 铁律 7）；
  三要素齐 → 该点满分；核心动作与对象命中但限定/结果缺失 → 部分分；
  只有泛泛表述、无可核对的具体指向 → 低分或不得分；材料没有依据 → 0 分。
  **不设"覆盖率阈值"**：不存在"≥80% 满分／40–80% 一半／<40% 0 分"这类机械公式，
  也不用文本相似度代替语义判断（细则与示例见 `small-questions.md` 第四节）。
- **关键词为王**：阅卷人工作量巨大，每道题平均阅卷时间只有几十秒到一分钟，
  他们快速扫描答案，寻找与要点关键词匹配的表述。精准、简洁、突出关键词的
  答案更受青睐。

### 2. 应用文写作（公文题）—— 划档赋分 + 按点给分结合

- **先检查任务与身份（最优先）**：① 题目要你完成的**任务目的**达到了吗；
  ② **身份场景**（发文者、受众、场合、职权）是否对位。这两项错位属于致命失误，
  比格式瑕疵严重得多。
- **再划档**：根据答案整体情况确定档次（一类文、二类文、三类文等）。划档主要依据：
  1. 内容要点是否全面（是否涵盖材料要求的所有核心信息）；
  2. 格式是否正确、完整（标题、称谓、落款等）；
  3. 语言风格是否得体（宣传稿要生动，报告要严谨，上行文要有请示口吻）。
- **后赋分**：在确定的档次内，按内容要点的语义命中逐条给分，再按格式与语言的检查结论
  在档内调整。
- **口径提示（重要）**：**公开大纲从未公布全国统一的"内容 X%／格式 X%／语言 X%"分值表**，
  因此本 skill **不宣称任何官方比例**；`gongwen.md` 第七节给出的占比只是**训练参照
  （L3 经验口径，可按题目要求与参考口径调整）**，引用时必须标注"经验口径"。
  公文题的"档"**不套用**下文大作文的四档区间（三.1 换算表只覆盖大作文）。

### 3. 大作文（议论文）—— 完全划档赋分

主观性最强，但评分维度清晰，从四个方面评价划档：

> ⚠ **口径标注（L2+L3）**：下文四维框架与四字档位描述属**公开描述层面**（L2）；
> 而**分数区间（按满分占比划档：一类 ≥80%、二类 60%–80%、三类 30%–60%、四类 <30%；
> 40 分卷即 32–40／24–31.5／12–23.5／≤11.5）、硬伤清单与修正幅度、档内定位（上／中／下三小档）与换算表均属本 skill 的模拟口径（L3，
> 官方细则未公开）**。报告中引用这些区间时必须标注，不得表述为官方规定（见 0.2）。

| 维度 | 地位 | 考察内容 |
|------|------|----------|
| 一、题意（立意） | 基础分，决定档次 | 是否准确理解材料主题，立意是否深刻、明确。一旦跑题直接封顶四类文、偏题封顶三类文，文笔再好也无用。这是大作文的"生命线"。 |
| 二、内容（论点、论据） | 主体分 | 论点是否鲜明突出；分论点是否清晰、能否支撑总论点；论据是否充实有力，能否有效结合给定材料和自身积累。 |
| 三、结构（逻辑） | 框架分 | 结构是否完成"点题—展开—收束"三项功能（**不要求各自独立成段**）；逻辑层次是否分明，段落之间衔接是否流畅。 |
| 四、语言（表达） | 文采分 | 语言是否流畅、规范、准确；是否具有一定的文采和表现力。 |

**划档示例（以 40 分大作文为例；占比与分数区间为本 skill 模拟口径 L3，非官方规定）**：

| 档位 | 占满分比例 | 分数区间（40 分卷，L3 模拟口径） | 描述（L2 公开描述措辞） |
|------|------|------|------|
| 一类文 | 80% 及以上 | 32–40 | 立意深刻、内容充实、结构严谨、语言优美 |
| 二类文 | 60%–80% | 24–31.5 | 立意明确、内容较充实、结构完整、语言通顺 |
| 三类文 | 30%–60% | 12–23.5 | 立意基本清楚、内容单薄、结构基本完整、语言基本通顺 |
| 四类文 | 30% 以下 | ≤11.5 | 偏离题意、内容空洞、结构混乱、语言不通 |

- **划档口径**：先按**满分占比**定档（一类 ≥80%、二类 60%–80%、三类 30%–60%、四类 <30%），
  再以"占比 × 卷面满分"得出该卷的分数区间（换算表见 三.1）。
- **边界归属**：边界点归**上一档**——80% 计一类、60% 计二类、30% 计三类；
  故二类为 [60%, 80%)、三类为 [30%, 60%)、四类为 30% 以下。
- **粒度**：档内定位保留 0.5 分粒度，故每档上限写到"下一档下限 − 0.5"
  （40 分卷：二类 31.5、三类 23.5、四类 11.5）。

**划档方式：四维综合定基础档位 + 硬伤修正（不设范文锚点）**

本 skill **不使用"范文基准样本"**——不存在"某篇示范文章 = 一类文 = 某个分数"这类锚点，
也不以任何单篇范文折算分数。定档只做一件事：**把作文在四个维度上的实际表现，
逐维与下表的档位描述对号入座，再综合定基础档位、按硬伤清单设上限**。

- 每一维必须独立判定，并各自引用原文证据（铁律 5）；
- 档位由"**主档 + 硬伤修正**"决定：四维综合定基础档位，硬伤只设上限（见 2.5）；
- 档位只由描述性标准决定，与文章是否像"某篇范文"、是否符合某类结构无关。

## 二、四维的操作性定义与档位判定细则（大作文）

> 两条总口径：
> ① 一切判定**以文章实际表现为准**，与是否套用某类模板无关（例如"结构严谨"指逻辑自洽与
> 层次分明，而不是"符合五段三分"）；
> ② 本节的细化条目是**判定用的检查清单**，不是"每项都要有"的强制清单——某项缺失只在
> 对应维度按影响程度减分，不因"清单没打满"整体降档。

### 2.1 题意（立意）——生命线维度

| 子项 | 达标要求 | 判定证据 |
|------|---------|---------|
| 准确 | 中心论点与题干核心概念、材料主旨一致；不偷换概念、不缩小或扩大范围 | 标题、首段中心论点句与题干概念逐字对照 |
| 明确 | 标题与首段能**读出唯一的总论点**（**不限定其所在句**：首段中部、第二段首句均可，设问/引言式开头同样成立） | 全文能否指认出唯一的总论点 |
| 覆盖 | 题干核心概念（含"与/和"等关系词）在标题或首段中**均有落点** | 标题是否漏掉其中一个核心概念 |
| 深刻 | 不止于"是什么"，有"为什么/怎么办"层面的分析，能上升到本质、规律、价值 | 是否有独立成段的机理分析，而非通篇举例 |

**档位信号**

- 一类：立意准确且深刻——点出概念之间的关系或本质，有超越材料表层复述的分析层次。
- 二类：立意明确——中心论点清晰、切题，但分析主要停留在"是什么/要重视"层面。
- 三类：立意基本清楚——方向不偏，但表述含糊、论点与题干概念只是勉强对应。
- 四类：偏离题意——论述相邻概念或只抓次要概念，与题干核心概念无实质关联。

**题意相关的档位上限（由第二步"硬伤修正"统一执行）**：跑题（通篇不涉及题干核心概念）→ 四类文封顶；
偏题（**只谈相邻概念／仅抓住次要概念**）→ 三类文封顶；**"基本切题／立意稍微模糊"不再封顶**——
它属于题意维度的**质量扣分**，体现为第三步**档内定位下移**（落到本档"中"或"下"），**不设档位上限**。
**同义改写照算切题**：考生用与参考答案不同的表述（自己的话）表达**同一立意/同一中心论点** →
**切题**，不降等、不扣分（语义等价 + 逻辑等价，见 `SKILL.md` 1.2 铁律 7）。
**注意**：切题度只决定"上限"，不机械决定档位——基础档位仍由四维综合判定，且**未命中硬伤就不降档**（见 2.5）。

**不算扣分点**：不按某类型框架组织分论点、只深入写"二者相辅相成"一层、标题朴素不华丽。

### 2.2 内容（论点与论据）——主体分维度

| 子项 | 达标要求 | 判定证据 |
|------|---------|---------|
| 论点 | 总论点鲜明；分论点各自独立、共同支撑总论点，不重复、不游离。**分论点的数量与形态（并列/递进/多少条）不作要求** | 分论点句能否与总论点构成"支撑"关系 |
| 论据选材 | 材料内案例或自身积累（案例/数据/政策/理论）**择用即可**；论据真实、典型、与论点相关（**不要求必须引用材料中的某个具体案例，见下"案例不是采分点"**） | 是否通篇只用材料、或通篇空谈道理、或只有口号式表态 |
| 论证充分 | **有例有析**：例后必须有分析句，把案例与论点之间的机理讲通 | 每个例子后是否存在"这说明了……"式推理，而非"观点＋例子"并列堆叠 |
| 材料结合 | 结合给定资料但不照抄——引用材料服务于自己的论证（**未引用材料中某个具体案例本身不构成扣分理由**，见下"案例不是采分点"） | 是否存在整段转抄材料而无论证 |

**档位信号**

- 一类：论据充实且多样，论证有层次（是什么→为什么→怎么办或并列/递进推进），例后有析、析能回扣论点。
- 二类：论点清楚、论据够用，但分析较浅（多为"重要性＋例子"模式）。
- 三类：内容单薄——分论点与总论点关系松散，论据少或与论点关系弱，以口号代替论证。
- 四类：内容空洞——通篇口号、复述材料，无有效论据与论证。

**不算扣分点**：不引用名言警句、不使用政策术语（术语点到为止即可，堆砌术语不加分）。

**案例不是采分点（2026 修订，务必遵守）**

> ⚠ **口径标注**："联系实际／不拘泥于给定资料"属**官方公开的作答要求（L1）**；
> 由它推出的"案例不是采分点"规则属**本 skill 模拟口径（L3，官方细则未公开）**，
> 用于约束阅卷尺度，**不得表述为官方规定**。

- 材料中的**某个具体案例本身不构成采分点**；**未引用某个材料案例本身不得作为扣分理由**。
- 只有当该案例所承载的**观点／事实／逻辑无法被考生其他内容替代**（抽掉它之后论点失去支撑、
  论证链断裂）时，才可能表现为**内容不足或论证不足**；此时扣的是**质量分**，
  理由写 **"缺支撑"**，**不写"没引用某案例"**。
- **"联系实际" ≠ "必须引用材料案例"**：题干要求"联系实际／不拘泥于给定资料"时，
  考生用材料之外的现实案例、公开数据、政策实践或个人观察完成"联系实际"，**同样合规**。
- **不数案例个数**：不把"用了几个材料案例"当作"内容充实"的计量单位——
  "充实／较充实／单薄"的分界仍是"论据是否够用、例后是否有析"（见 2.5 用词口径）。

### 2.3 结构（逻辑）——框架分维度

| 子项 | 达标要求 | 判定证据 |
|------|---------|---------|
| 完整 | 完成"点题—展开—收束"三项**功能**（**不要求三者各自独立成段**：一线串珠、故事贯穿、夹叙夹议均成立） | 能否找出点题处、展开处、收束处；有无"半截文" |
| 层次 | 主体有清晰的组织方式（并列/递进/对比/主次/总分），各层不重复、不交叉、不跳跃 | **能否用一句话说出全文推进路线** |
| 衔接 | 段间有过渡，读者能顺着主线读完；段落长度不过分失衡 | 相邻段落之间是否有承接关系 |
| 收束 | 结尾完成收束、不停在半句话上（**不要求"不照抄首段"——呼应首段属合规收束**） | 结尾末句是否完成收束 |

**档位信号**

- 一类：结构严谨——主线清晰、层次分明、详略得当、收束有力。
- 二类：结构完整——三段齐备、层次可辨，但过渡略生硬或部分段落详略失衡。
- 三类：结构基本完整——有头有尾但主体层次混乱、段落之间跳跃或重复。
- 四类：结构混乱——无明确层次、想到哪写到哪，或明显未写完。

**不算扣分点**（反模板铁律，务必遵守）：非五段三分、故事贯穿、一线串珠、夹叙夹议、
六段/四段结构等，只要点题—展开—收束功能完整、层次自洽，**结构维度一律按实际质量给分**。
**兜底穷举**：段落数量、有无过渡句、有无小标题、是否总分总、是否首尾呼应，
**均不作为扣分理由**。

### 2.4 语言（表达）——文采分维度

| 子项 | 达标要求 | 判定证据 |
|------|---------|---------|
| 规范 | 现代汉语书面语，无网络流行语与口语化表达；标点、数字、称谓使用规范 | 抄录语病句逐句核对 |
| 准确 | 用词与本意精确对应；成语、术语、政策表述使用正确 | 是否有词语误用、成语误用、概念混用 |
| 通顺 | 句子成分完整、搭配得当、逻辑连贯，无病句与歧义 | 长句是否读得通 |
| 文采 | 句式有变化、用词有表现力、有个人辨识度，且不浮夸、不堆砌辞藻 | 是否有自然的修辞与节奏，而非辞藻堆叠 |

**档位信号**

- 一类：语言优美——流畅准确之外，有文采与辨识度（句式变化、比喻贴切、节奏感强）。
- 二类：语言通顺——表达清楚、基本无语病，文采一般。
- 三类：语言基本通顺——语病较多但意思可懂，口语化明显。
- 四类：语言不通——语病严重、表达混乱，影响理解。

**本维度的扣分项清单**（档内定位依据，须逐处引原文；量级为经验口径，官方细则未公开）：

| 瑕疵类型 | 处理 |
|---------|------|
| 错别字 / 标点错误 | 按每 3 处 0.5 分累计，**本项封顶 1 分**（个别错误不计） |
| 成语、词语误用（如"差强人意"用反） | 0.5 分/处，累计**封顶 1 分** |
| 语病、搭配不当、句子读不通 | 0.5–1 分/处，按密度累计，**本维度封顶 1 分** |
| 史实、引文、政策表述错误 | 0.5–1 分/处（同时计入内容维度的"论据可信度"，**只在主要归属维度计一次**） |
| 未写标题 | 1–2 分（语言/规范项）；同时按 2.1"覆盖"补判题意 |
| 卷面：字迹潦草、大面积涂改 | 视程度 0.5–1 分。**仅适用于用户提供手写原件/照片时；电子稿、转写稿一律不评卷面** |
| 严重政治性表述错误 | 不参与档内定位，立即指出并建议重写 |

> 上表量级用于**保证批改尺度一致**，不代表官方分值。引用时可说明"属经验口径"。

### 2.5 档位怎么分：形容词量级即档位分界

公开的档位描述有一个稳定的写法：**同一个维度用不同量级的形容词区分档次**。
判档时对标的就是这些词，而不是字数、段数或结构形态。

| 维度 | 一类 | 二类 | 三类 | 四类 |
|------|------|------|------|------|
| 题意 | 立意**深刻**、准确 | 立意**明确** | 立意**基本清楚** | **偏离**题意 |
| 内容 | 内容**充实** | 内容**较充实** | 内容**单薄** | 内容**空洞** |
| 结构 | 结构**严谨** | 结构**完整** | 结构**基本完整** | 结构**混乱** |
| 语言 | 语言**优美** | 语言**通顺** | 语言**基本通顺** | 语言**不通** |

用词口径（避免同类词互相顶替）：

- **准确 vs 明确**：准确说的是"对不对"（与题干概念、材料主旨一致），明确说的是
  "清不清楚"（能否一眼读出中心论点）。两者是**并且**关系，缺一即不能进一类；
  只有明确而不够深刻 → 二类；准确但表述含糊 → 先按题意维度下调，再看其他维度。
- **充实 vs 较充实 vs 单薄**：以"论据是否够用、例后是否有析"为分界。
  例证足且析透 → 充实；例证够但析浅 → 较充实；例证少或以口号代论证 → 单薄。
- **严谨 vs 完整 vs 基本完整**：以"层次是否分明、收束是否有力"为分界。
  三段齐备但层次跳跃 → 基本完整，不因"没有过渡句"直接判混乱。
- **优美 vs 通顺**：优美是**加分性**描述（有文采与辨识度），通顺是**底线性**描述；
  语言平实但零语病的文章属"通顺"，不因"没文采"降档。

**定档模型：主档 + 硬伤修正**（与 `essay-judging.md` 第二节四步流程一致）

**第一步｜四维综合锚定基础档位（大档）**
- 分别判定题意、内容、结构、语言（各给判定 + 原文证据），再**综合**定基础档位；
- **不取最低档**：某一维偏弱本身不构成整篇降档理由——它只影响"为什么不是更高档"，
  并通过第三步的档内落分体现；
- 综合理由必须写明：哪几维支撑本档、哪一维拖后腿、拖到什么程度；
- 四维整体达到上一档描述水准且无硬伤 → 基础档位直接定在上一档；
- **不设"多数维度计票"规则**：不存在"两维低于本档就自动降一档"这类机械条款。
  若两维以上明显达不到本档描述水准，说明**第一步的档位判断本身就定高了**——
  这时应当重新比对档位描述、把基础档位定到真正匹配的那一档；这是一个"回到描述重估"
  的动作，**不是一条独立的降档公式**（定档是整体判断，不靠数维度）。

**第二步｜硬伤修正（设档位上限，只封顶/降档，不加分）**

| 硬伤 | 判定（须引原文） | 修正 |
|---|---|---|
| 明显跑题 | 通篇不涉及题干核心概念 | 上限 = **四类**（40 分卷 ≤11.5，即满分 30% 以下） |
| 偏题 | 只谈相邻概念或仅抓住次要概念 | 上限 = **三类** |
| 核心任务遗漏严重 | 题干核心任务/文体功能大面积缺失 | 上限 = **三类** |
| 论点与材料主旨明显冲突 | 中心论点与材料主旨相悖或反向解读 | 上限 = **三类** |
| 大面积无法辨认／严重语言障碍 | 语句大面积不成句、语义不可解 | 基础档**下调一档**（裁量项，须写理由） |

- 多项命中 → **取最严的一条**执行；硬伤**只设上限**，不"一票否决到底"；
- **未命中硬伤 → 不做任何降档**（这是与旧"取短板"口径最重要的区别）；
- 反向纪律：**结构形态、是否套模板、有无小标题、段落数量等永远不是硬伤项**。

> ⚠ **"立意稍微模糊"不是硬伤，不封顶**：中心论点方向正确而表述不够鲜明、概括不够精准时，
> **只在题意维度扣质量（影响档内定位）**，由档内定位体现；
> **只有实质偏题才按"偏题"封顶三类**。
> **禁止话术**："立意稍微模糊 → 二类封顶"。
> （**2026 修订：废止旧"基本切题（轻级）→ 上限二类"项**）

**纪律：同一处问题只扣一次**：某一处瑕疵只在其**主要归属**维度计分，其他维度最多作说明，
禁止跨维度重复扣分（典型如"论证单薄"已在内容维度减分，不得再以"素材不足"在结构维度
重复减分）。

**档内定位（档位锚定 + 上／中／下三小档；在第二步给出的上限之内）**

> ⚠ 本节属**本 skill 模拟口径（L3，官方细则未公开）**：三小档区间由各大档区间三等分得出
> （边界点归上一小档），换算表见 三.1。**2026 修订：取消"基准分 = 区间中位数 ±1/±0.5 机械加减"
> 与"档内浮动 ±3 分"的算法**，改为先锚定大档、再在档内定位到上／中／下。

1. **第一步锚定大档**：先按 2.1–2.4 的四维判定与 2.5 第二步的硬伤上限，定出**一个**大档
   （一类／二类／三类／四类）；大档由四维综合与档位描述决定，**不由加减分算出来**。
2. **第二步在档内定位小档**：按下表四项的**实际表现**定位到本大档的**上／中／下**，
   取该小档区间作为落分区间：

   | 小档 | 定位条件（内容质量／论证深度／结构完成度／语言质量四项的实际表现） | 位置 |
   |:--:|---|---|
   | **上** | 四项中**多数达到本档上沿**水准（内容充实且有支撑、论证有层次、结构与语言无可指摘） | 本档区间的**上**三分之一 |
   | **中** | 四项**大体达到本档中位**水准（基准锚点，无明显拖后腿项） | 本档区间的**中**三分之一 |
   | **下** | **仅勉强达到本档下限**（某一两项明显偏弱，但仍明显高于下一档） | 本档区间的**下**三分之一 |

3. **边界点归上一小档**（如 40 分卷二类 29 分归"二类上"、26.5 分归"二类中"）；
   **落分不得越出本大档区间**——想越档是第一步基础档位的事，不是档内定位的调节手段；
   **不得突破第二步的档位上限**。
4. **不设独立加分项**：切入角度新、结构巧、金句好、材料外深度分析等亮点
   （`essay-judging.md` 1.4）**不加分**，只作为上述四项评价项的判断依据——
   "因为论证更有力／结构更贴合论述目标"而在其对应项内**把定位抬到上一小档**，
   而不是另加 1–2 分，也没有"因创新破格升档"的通道。
5. 扣分项（2.4 清单）在语言/内容维度内累计，**同一维度封顶 1 分**，并计入第四项"语言质量"
   ／"内容质量"的实际表现，影响小档定位。
6. 结果保留 0.5 分粒度**仅限置信度为"高"时**；材料不全、存在转写存疑或无可校准口径
   （置信度中/低）时，改给**建议区间 + 评分置信度**，不以单一分收尾
   （见 `SKILL.md` 9.2 与本文 0.4）。

**不设"例外升档"**：不存在"四维齐备才允许升档"这类补丁机制——写得够上一档，
第一步的基础档位就定在上一档；硬伤只负责封顶。

## 三、评分操作总则

1. **先定档，再定位**：大作文先按"**基础档位锚定 → 硬伤修正 → 档内定位（上/中/下）→
   区间与置信度**"四步走（四维用于综合锚定大档与档内定位），小题按语义采分点直接计分。
2. **主档 + 硬伤修正**：基础档位由四维**综合**判定（**不取最低档、也不数维度计票**）；
   只有**决定性硬伤**才设档位上限——**跑题→四类封顶、偏题（只谈相邻概念／仅抓次要概念）→
   三类封顶、核心任务遗漏严重/论点与材料主旨冲突→三类封顶、
   大面积无法辨认或严重语言障碍→下调一档**（见 SKILL.md 第六节与 2.5）；
   未命中硬伤不降档；**"基本切题／立意稍微模糊"不封顶**——它在题意维度扣质量、由档内定位体现；
   **亮点不单独加分**，只能通过四维质量影响档内位置。
3. **小题按语义采分累加计分，无倒扣、无额外加分**：每个采分点按"核心动作｜核心对象｜
   关键限定/结果"的命中程度给分——完整命中给满分、核心概念命中但信息不全给部分分、
   泛泛表述低分或不得分、材料无据 0 分；**不用覆盖率阈值、不用文本相似度**。
   编造不额外扣分，口语化不单独扣分。（采分点清单与子项分值属 **L3 模拟重构**，
   报告中须标注"官方细则未公开"。）
4. **证据原则**：一切扣分、加分、定档判断都必须引用作答原文为证。
5. **分数换算**：档位以**满分占比**为基准（一类 ≥80%、二类 60%–80%、三类 30%–60%、
   四类 <30%），各分值卷按下文"三.1 档位区间的换算表"取数——**先查大档区间，
   再按档内定位取"上/中/下"小档区间**，保留 0.5 分粒度；
   **必须查表，不得现场心算**。
   （换算表属 L3 模拟口径，引用时标注，不得说成官方分值规定。）
6. **四维综合定基础档位 + 硬伤修正（不设范文锚点）**：定档一律依据上述档位描述与
   四维操作性定义，以文章自身表现逐维对号入座、综合定档，再按硬伤清单设上限；
   **不存在"范文基准样本"**，任何单篇示范文章都不构成
   "此篇 = 某一类文 = 某分"的换算依据（详见第二节"划档方式"）。

**三.1 档位区间的换算表（多分值卷通用，L3 模拟口径）**

- 划档以 **满分占比** 为准：**一类文 ≥80%、二类文 60%–80%、三类文 30%–60%、四类文 <30%**；
  分数区间 = 占比 × 该卷满分，按下面的换算表直接查取（**不得现场心算**）。
- **边界归属**：边界点归**上一档**（80% 计一类、60% 计二类、30% 计三类）。
- **粒度**：档内定位保留 0.5 分粒度，故表中每档上限写到"下一档下限 − 0.5"
  （如 40 分卷二类上限 31.5 = 80%×40 − 0.5）。

## 四、什么不算扣分点（避免误伤）

> 大作文各维度的"不算扣分点"已在 2.1–2.3 各节末列出（**以那三节为唯一出处**，
> 本节不重复，避免两处措辞漂移）。本节只列跨维度的通用项。

- **小题总括句**：归纳概括**不写总括句不扣分**；**写了也不扣分**——总括句只按"是否占用
  字数、是否新增采分信息"来评价（无新增信息且挤占要点时**在写作建议里**提示删减，
  不作为扣分项）；题目要求"分类说明/概括主要问题"时，总括句反而是好写法。
- **上位概括**：对材料多个事实做上位概括（材料"部门协同＋数据共享＋办事提效"→
  "提升治理效能"）**不扣分、不减分**；只有**凭常识引入材料不存在的结论**才按 0 分处理
  （"禁止脑补 ≠ 禁止概括"，见 `small-questions.md` 铁律 4）。
- 大作文不采用五段三分/某类型框架、不按"三个分论点"组织、段落数量与有无过渡句、
  有无小标题、是否总分总、是否首尾呼应：**一律不扣分**（穷举清单见 2.3 末条）。
- 不写具体地名/主体名（题干未明确要求时）：泛化表述踩到方向即给分。
- 要点排列顺序、分条格式：按点给分，顺序不影响得分。
- 小题/公文作答写成并列短语、无完整主谓句：不扣分，关键词在即给分。
- 实际字数略多略少（在"X 字左右"的弹性范围内）：不算扣分点。真实阅卷以答题纸
  格子占用与内容完整度粗估，从不数字数；"超出/不足"只通过内容、结构维度（没写完、
  收不了尾、内容单薄）体现，不设机械字数线（详见 `essay-judging.md` 第 3 步
  "字数判断"）。
  ⚠ **这说的是"扣不扣分"，不是"示例答案可以超限"**：示例答案/参考范文必须 ≤ 题目上限且
  落在 85%–95%，须用 `scripts/count_chars.py` 核验后才输出（评分口径与统计口径的分离、
  口径定义、核验闭环与报告写法见 `references/word-count.md`）。
- 电子稿/转写稿：不评卷面、不评字迹（见 2.4 清单末条）。

**2026 修订新增的四条（一律不算扣分点）**

> ⚠ **口径标注**：第 ②③ 条由 `SKILL.md` 1.2 铁律 7、第 ① 条由铁律 8、第 ④ 条由 2.1/2.5
> 推出，属**本 skill 模拟口径（L3，官方细则未公开）**，**不得表述为官方规定**。

- ① **未引用材料中某个具体案例**：具体案例不是采分点，未引用某个材料案例本身不构成扣分理由；
  只有该论点确实缺支撑时才按内容／论证维度扣质量分，理由写"缺支撑"（见 2.2）。
- ② **表达与参考答案用词不同但语义等价**：同义表达照给分（语义等价 + 逻辑等价），
  不因"没出现参考答案那几个词"判偏离（见 一.1、0.2）。
- ③ **论证角度／所用事例与参考答案不同但逻辑成立**：异构论证一律允许，不扣分
  （也不因此加分，见 `SKILL.md` 1.2 铁律 3、铁律 7）。
- ④ **立意"稍微模糊"**：属题意维度的**质量扣分**（由档内定位体现），
  **不封顶、不降档**；只有实质偏题才封顶三类（见 2.1、2.5）。

   （落地处：0.1 L4 行说明、0.4 硬性规则 3）。
