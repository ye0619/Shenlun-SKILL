# 卷级隔离与多卷批改规范（同一对话不串味）

> **口径标注**：本文件属 **L3 工程约定**（本 skill 自建的工作纪律），**不是官方规定**。
> **目的**：同一对话里批改**多套卷**时，防止上一套卷的采分点、参考立意、梯队刻度、
> 档位结论与分数印象**串到下一套卷**——这是长会话里最隐蔽、也最伤批改质量的一类错误。
>
> **一句话**：**卷ID 是隔离键。换卷 = 重新起算，不继承任何东西。**

## 1. 串味长什么样（四种真实故障模式）

| # | 表现 | 后果 |
|:--:|---|---|
| **A** | 把上一卷的采分点套到本卷（**同省相邻年份、同题型**时最容易发生） | 凭空多出给分点、漏掉本卷要点，分值池错位 |
| **B** | 复用上一卷的共识表／梯队画像缓存 | 来源等级与档位定位直接串味 |
| **C** | 用上一卷的档位或分数当锚（"上卷 28 分，这卷应该也差不多"） | 分数漂移，且无法复核 |
| **D** | 材料引用张冠李戴（写"材料3第2段"，其实是上一卷的材料句） | 证据链失效，扣分站不住 |

## 2. 批改上下文锚（**每卷开批前先写，写在对话里**）

```markdown
**批改上下文**
- 工作区：{路径}
- **本卷卷ID**：2022河南乡镇　（年份／省份／卷型：2022／河南／乡镇）
- 本卷题号：第1–4题（本次批改：第2题）
- 本卷材料来源：`真题/河南/2022河南乡镇.pdf`（页码：第3–5页）
- 本卷口径：批改规范＝未找到｜参考答案＝`参考答案/河南/2022河南乡镇/`（**独立来源 3 家**）
  ｜刻度集＝无｜真题库＝`真题/河南/真题库/2022河南乡镇.md`（未入库）
- **上一次批改的卷**：2021河南县级　→　**与本卷不同，已执行上下文重置**
  （不沿用其采分点／共识表／梯队刻度／参考立意／分数印象）
```

- 上一次批改的卷**相同** → 写"与本卷相同，允许复用**同卷**缓存（已比对来源指纹）"。
- 本次是对话里第一次批改 → 写"上一次批改的卷：无"。

## 3. 五条硬性隔离规则

**R1｜采分点必须重新从本卷材料列出。**
无论上一卷与本卷多么相似（同省、相邻年份、同题型、甚至同一主题），
**跨卷复用采分点一律禁止**；采分点表必须是"本卷材料 → 三要素 → 来源等级"重新推出来的。

**R2｜缓存只允许"同卷ID命中"时复用。**
`.采分点共识/{卷ID}-第N题-共识表.md`、`.大作文刻度/{卷ID}-*.md` 的**卷ID 就是隔离键**：
- 复用前先比对**卷ID** ＋ **来源指纹**（文件清单／字节数／修改时间），二者都对上才复用；
- **跨卷一律重建**——即使主题相同、题型相同、年份相邻，也不得"借用"；
- 用户清空缓存 → 退回"无缓存"正常批改（见 `workspace-layout.md` 第 3 节）。

**R3｜参考口径匹配必须"年份＋省份＋卷型＋题号"全中。**
- 只命中部分字段 → **向用户确认**，不要自行假定（见 `reference-answers.md` 第 3 节）；
- **不得用"相似卷"的参考答案或批改规范代替本卷口径**；
- 例外：用户**明确指定**"就按 XX 卷那套口径看"→ 可以做，但报告里必须写成
  "**跨卷参照（用户指定）**"，并**相应下调评分置信度**。

**R4｜结论与印象不得跨卷沿用。**
- 不用上一卷的分数／档位做锚（"上卷 28 分，这卷也差不多"是禁止的）；
- 不写"和上一套卷一样，你的概括题偏弱"这类**跨卷印象式评语**（要说得一样，就必须有本卷证据）；
- 上一卷的"改进方向"不能直接复制成本卷的改进方向。

**R5｜材料引用必须回本卷核对。**
每个采分点／每处扣分的"材料X第Y段"必须来自**本卷材料**；引用前自查该句属于本卷
（同省相邻年份卷的材料常有相似表述，这是 D 类故障的高发区），并写明材料序号与段落。

## 4. 切换检查（每次批改前先问自己三句）

1. **本卷卷ID 是什么？与上一次批改相同吗？** 不同 → 执行 §2 的重置并写明；
2. **我准备用的采分点／参考立意／梯队刻度，来源路径里包含本卷卷ID 吗？**
   不包含 → **停用**，重新从本卷材料与同卷口径生成；
3. **我引用的"材料X第Y段"属于本卷材料吗？** 不确定 → 回卷核对，核不上就删掉这条证据。

## 5. 一次贴多套卷怎么办

- **逐卷独立成报告**：每卷各自一份"批改上下文 ＋ 共识表／刻度 ＋ 总分表 ＋ 结论"；
- **不得合并计分、不得交叉引用**（不能把两卷的采分点放在同一张共识表里）；
- 报告标题与文件名必须带**卷ID**（`批改报告/{省份}/{卷ID}-批改报告.md`）；
- 用户只是"顺便问一句另一卷"时，**同样按新卷重置**，不因为"顺带"就省掉隔离。

## 6. 跨卷比较的合法边界（用户明确要求"对比／趋势"时）

| 允许 | 禁止 |
|---|---|
| 同一题型**维度表现**的定性对比（"本卷概括题的要点覆盖比上卷更全"） | 把上一卷的分数当基准做插值／递推 |
| 列出两卷的档位与维度判定做**并列展示** | 用上一卷的结论替代本卷判定 |
| 标明各自卷ID、报告版本与批改日期 | 把两卷采分点混在一张表里 |

写法：单独一节"**跨卷对比（用户指定）**"，声明"**本节不影响本卷评分**"，
并注明所引各卷的报告版本（v1/v2）——因为口径会随 skill 迭代变化（见 `scoring-standards.md` 五）。

## 7. 与会话卫生（建议，不强制）

- 长会话里**每批完一卷**，可以提示用户"下一卷建议新开对话"（更省 token、彻底无串味）；
- 同一对话**超过 3 卷**时，主动提示一次；
- **不得**因为"建议新开对话"而**拒绝在当前对话批改**——隔离是本 skill 的责任，不是用户的负担。

## 8. 与本文件配套的位置

| 位置 | 隔离体现 |
|---|---|
| `批改报告/.采分点共识/{卷ID}-第N题-共识表.md` | 小题共识缓存的隔离键 = 卷ID（见 `small-questions.md` 第四节） |
| `批改报告/.大作文刻度/{卷ID}-*.md` | 大作文梯队刻度的隔离键 = 卷ID（见 `essay-exemplars.md`） |
| `批改报告/{省份}/{卷ID}-批改报告.md` | 报告按卷落盘，报告头写"批改上下文"（见 `SKILL.md` 9.1） |
| `真题/{省份}/{卷ID}.pdf`、`参考答案/{省份}/{卷ID}/`、`批改规范/{省份}/{卷ID}*.md` | 材料本身按卷ID组织（见 `workspace-layout.md`） |
| 历史报告参照 | **必须同卷**；跨卷只能用于第 6 节的趋势对比 |
