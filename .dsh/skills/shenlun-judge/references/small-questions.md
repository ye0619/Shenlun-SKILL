# 小题作答铁律与采分点评分细则

（归纳概括 / 综合分析 / 提出对策）

> ⚠ **依据层级**：小题"**按点给分**"属公开描述（L2）；**采分点拆分与子项分值分配属
> 本 skill 的模拟阅卷模型（L3 经验口径，官方采分表未公开）**；工作区 `参考答案/` 中的
> 真题参考答案与机构解析属**经验校准（L4，非官方）**，只用于校准同义表述的宽严与
> 采分点粒度。报告中须标为"参考采分点（模拟重构）"，
> **不得写成"本题官方采分点为……"**（标注规范见 `scoring-standards.md` 0.1–0.2）。
>
> **本版重要变化**：**取消"覆盖率阈值"**（不再有"≥80% 满分／40–80% 一半／<40% 0 分"）——
> 一个采分点该给几分，按"**核心动作｜核心对象｜关键限定/结果**"三要素的**语义命中程度**
> 判定（见第四节），不做文本相似度式计分；**归纳概括的"总括句"与"概括词"两条铁律也被放宽**
> （见铁律 3、铁律 4）。

## 一、作答铁律（8 条）

### 1. 字数铁律
- 字数**参考配额**为题目上限的 85%–95%（**写作建议，不是扣分项**）。
- 单条要点不超过 40 字；超过 40 字拆成两条，增加得分机会。
- **口径说明**：这是"写作建议"而非评分倒扣项——小题评分按采分点**语义命中**计算，
  字数上限是硬约束，超出的真实代价是"超出部分可能不被阅卷、挤丢后段采分点"
  （体现在采分点命中情况上），而不是"数实际字数 ×0.5 分"式扣分。详见第四节"字数与
  评分的关系"。
- **但示例答案的字数是硬约束（易错点）**：满分答案/参考答案必须 **≤ 题目上限且落在
  85%–95%**，生成后一律用 `scripts/count_chars.py` 核验、超限先按压缩优先级删减再核验，
  **达标后才输出**；未核验不得标注"（约 X 字）"。作答字数标注写成"X 字（含标点）"。
  口径、命令、压缩优先级、报告块模板见 `references/word-count.md`。
  （评分不因字数扣分 ≠ 示例答案可以超限）

### 2. 句子结构铁律
每条要点 = 动词短语 + 具体对象 + 结果/目的。不写"要""应该""需要"等情态动词。
- 差："政府应该加大对停车设施的财政投入力度"
- 好："将停车设施建设纳入城市更新专项资金，重点投向老旧小区改造"

### 3. 去水铁律
删除无意义短语："在……的过程中""不断""进一步""加大力度""高度重视""充分认识"。
不写"针对……问题，提出以下对策"这类纯帽子句（归纳概括的引入句/总结句见下方注意，
属推荐策略而非铁律）。
**注意（本版放宽）**：**"不写总括句"只是字数紧张时的推荐策略，不是铁律**——
总括句无新增采分信息且占用字数时建议删减，但题目要求"概括主要问题并分类说明"、
或总括句能概括答案逻辑、有助于分类表达时**可以保留，写了不扣分**（细则见第四节）。

### 4. 概括词铁律（本版放宽：禁止脑补 ≠ 禁止概括）
**核心采分概念优先采用材料原词**；当材料给出多个具体事实时，**允许做上位概括**，
前提是**该概括能被材料直接支撑**：
- 材料讲了"部门协同 → 数据共享 → 办事效率提高 → 群众少跑腿" →
  作答归纳为"**提升基层治理效能**"：**合理抽象，给分**；
- 材料只提到"盘山路多、无高速出口" → 作答写"**道路不连通**"：**近义归纳，给分**；
- 材料完全没有相关事实 → 作答写"**产业凋敝**""**打通交通循环**"：**脑补，不得分**。
判定标准是"**这个表述能不能在材料里找到支撑**"，而不是"这个词在材料里有没有原样出现"。
自检："我这个说法，材料里有没有对应的事实？"没有事实支撑就换回材料原词。

### 5. 建议不写问题细节
问题和建议分开呈现时，建议部分不重复问题中的具体细节。

### 6. 不写无采分点废话
不写"借鉴 XX 经验"等无采分点的废话（**材料原文含该表述时可照抄，只禁止自创的帽子句**）。

### 7. 每句自检
写完逐句问："这一句能在采分点上得分吗？"不能就删。

### 8. 同义表达一律允许（判分基本原则：语义等价 + 逻辑等价）

**判分看"意思到了没有"，不看"用词是否与参考答案一致"**——这条同时适用于作答与批改：

- 采分点是"科技赋能基层治理"，考生写"利用数字技术降低治理成本、提升服务效率"
  → **语义等价，按同一采分点给分**；**禁止**"没出现'科技赋能基层治理'这几个词就判偏离／不给分"。
- 考生用自己的话（含材料原词之外的说法）把要点说清、且能被材料直接支撑 → **照给分**；
  允许对材料多个事实做**可被材料直接支撑**的上位概括。
- **只做语义核对，不做文本相似度比对**：不得用"重合 40%／80%"这类算法判分。
- **边界（不是无原则给分）**：讨论的不是同一层意思（如把"基层减负"写成"企业减税"）、
  自造材料没有的内容（脑补）→ 仍按"无据不得分／表述不准"如实判定，
  区分标准是**语义与逻辑**，不是**用词是否相同**。
- 交叉引用：`SKILL.md` 铁律 7、`reference-answers.md` §5 第 7 条。

## 二、材料分析信号词（找点工具）

**8 类信号词**：
- 首位位置：段首句、段尾句（多为段落主旨）
- 最高级：最、根本、关键、第一、核心（重要程度信号）
- 递进词：更、值得、进一步、特别（重点后移）
- 转折词：但、然而、反之、尽管……仍然（重点在转折后）
- 并列词：同时、另外、一方面、序号（并列要点全留）
- 结论词：这些、所以、因此、总之（总结性要点）
- 引出观点：某某表示/强调/指出、资料显示（权威观点）
- 特殊符号：冒号（看前）、破折号（看后）、引号（强调）、分号（并列）

**逻辑阅读**：总分关系 → 留总不留分；并分关系 → 全留或全丢。

**踩点补救**：主题词定位（有问有答即是答案）、高频词圈定（>2 次）、
首尾相接（大长句按逗号单位首尾相连）。

## 三、分题型要点

### 归纳概括题
- 审题四要素：作答范围、作答对象（问题/原因/做法/经验/成效/变化/特点）、
  字数、要求（全面/准确/简明/有条理）。
- 找点：四类标志词——问题词（不足/缺乏/滞后/短板/隐患）、原因词（因为/由于/导致）、
  影响词（有利于/促进了/制约了）、对策词（推动/完善/健全/落实）。
- 加工：同类合并、异类分开；按领域归类（交通/人才/产业/民生 等）。
  **归类方式不影响得分**——只按采分点语义命中给分，不因"归类维度不同"扣分；
  每条 = 上位概括词 + 具体内容（**上位概括词不算总括句，写了不扣分**）。
- 书写：分条序号化，**核心概念优先用材料原词**；**总括句按需**——字数紧张就不写，
  题目要求分类说明或需要概括逻辑时可以写（见第四节"总括句"）。

### 综合分析题
- 4 子类框架（**框架是参考不是强制**，以材料实际内容为准）：
  - 词句理解：表层含义 → 深层内涵（分维度）→ 实质/对策
  - 观点评析：亮明态度 → 合理性与局限性 → 结论
  - 现象分析：概括现象 → 原因（内→外 / 主体→制度→环境）→ 对策方向
  - 关系分析：点明关系本质 → A对B / B对A / AB互动 → 每条回扣题干核心词
    （**展开顺序与维度划分不影响得分，只按采分点语义命中给分**）
- 共性：**建议**用总括句点题（**不是硬性铁律**：材料没给总括空间时，把字数用在采分点上
  同样成立）；"为什么"部分是最重要的得分区；材料末段点题句可直接引用。
- 对策不是核心得分点：材料有对策就抄，没有就一句话收尾，不硬编。

### 提出对策题
- 三来源：概括对策（材料现成做法，照抄）、借鉴对策（他处经验，转化表述）、
  提出对策（问题/原因反推，把名词变动词）。
- 材料里已有的对策不要重新措辞（会把关键词改没）。
- 宁多勿少，要点铺满；一条过长拆两条。

## 四、采分点评分细则（L2 按点给分 + L3 模拟采分点 + L4 口径校准）

### 评分流程
1. **列参考采分点并拆解（模拟重构，L3）**：基于完整给定材料列出采分点、标分值
   （所有子项分值之和 = 题目总分），再把每个采分点拆成三要素：
   **核心动作｜核心对象｜关键限定/结果**。
   - **先对齐 L1**：以题干要求（"全面、准确、有条理""不超过 X 字"等）为最高约束，
     模拟采分点不得与题面要求冲突。
   - **对照 L4**：`参考答案/` 有对应卷时，以它校准点数与粒度（如机构答案把某段拆成
     两个要点、而本 skill 只拆一个，应据此复核），并在报告中登记来源。
   - **粒度控制**：一道题默认拆 **3–6 个采分点**，且**每点 4–6 分**——即点数由分值决定
     （20 分题 → 4–5 点，25 分题 → 5 点，10 分题 → 2–3 点）；同一语义群内细节必须合并为
     一点，不同语义群必须分开；
   - 禁止为"凑点"把同一语义群的细节拆成多点（会虚高得分），也禁止把不同语义群
     合并成一点（会掩盖漏点）。
2. **逐条语义核对（不看覆盖率，看命中程度）**：

   | 命中情形 | 判定 | 怎么写 |
   |---|---|---|
   | 三要素齐（动作＋对象＋限定/结果） | 该点满分 | ✓ 并注明"完整命中" |
   | 核心概念命中、信息不完整 | 部分分（**写明缺哪一要素**，缺得多给得少） | ◐ "核心在，缺'住房、子女教育'等具体限定，给 2/4" |
   | 只有泛泛表述、无可核对的具体指向 | 低分或不得分（写明理由） | △ "只有'重视人才'的口号，无具体指向" |
   | 材料没有依据（自造结论/脑补） | 0 分，**不额外倒扣** | ✗ "材料未提补贴标准" |

   **判定示例**（采分点＝"完善基层人才引进机制，优化人才服务环境，解决住房、子女教育等
   实际问题"，4 分）：作答"完善基层人才引进机制，改善人才生活保障"——动作与对象在，
   但"住房、子女教育"这类**关键限定**缺失、且未体现"服务环境"，属部分命中，
   给 2 分左右；若作答是"完善基层人才引进机制，优化服务，解决住房与子女入学问题"，
   三要素齐，给满分。**不要用"文本重合了 40% 还是 80%"来判断。**
3. **逐句勾划标记**：✓ 完整命中；◐ 部分命中（注明缺什么）；~~删除线~~ 材料无此内容
   （不得分）；**【缺：xxx】** 遗漏要素；△ 表述不准；✗ 严重错误/无据。
4. **汇总得分**：只减不加，无倒扣；**小题不设任何加分项**（大作文也不设"创新分"，
   见 `essay-judging.md` 1.4）。
5. **给区间与置信度**：主分之外给建议区间与评分置信度（判定见 `scoring-standards.md` 0.4）。
   置信度是**采样与校准**口径：该卷有批改规范，或参考答案**来源独立且覆盖本题**时可判"高"；
   **同源多份只算一份**，份数多不等于置信度高（细则见 `reference-answers.md` §6）。

### 计分规则
- 采分点按**语义命中程度**给分：完整命中给满分、部分命中给部分分、没命中不给。
  不存在倒扣，也不设加分；**不存在"覆盖率阈值"**这类机械公式。
- **同义表达照给分**（铁律 8）：考生用自己的话把同一意思说清 → 视为命中；
  **不得**因用词与参考答案不同而判偏离或不给分（语义等价 + 逻辑等价是基本原则）。
- 编造内容：该项不得分，不额外扣分（成本是占字数挤占踩点空间）。
- 口语化/表述不准：不单独扣分；若导致命中不了采分点，该项不得分。
- **字数与评分的关系**：小题/公文的字数限制是"不超过 X 字"的上限约束，评分按采分点
  命中计算，不按"实际字数 vs 上限"机械倒扣。超字数的真实代价是：答题纸格子有限，
  超出部分阅卷人可能不再看，排在后段的采分点被挤丢（体现在命中情况上）。"控制在
  85%–95%"是写作建议（在限内装下最多有效要点），本身不是扣分项。
  **统计口径另算**：作答字数与示例答案字数用 `count_chars.py` 统计（见
  `word-count.md`），示例答案必须落在限额内。

- **同义替换与概括词的四档判定**（批改时对每一处非原词表述套用）：
  | 情形 | 例 | 判定 |
  |------|----|------|
  | 材料原词命中 | 材料"缺乏停车位"，作答"缺乏停车位" | 该点满分 |
  | 材料词素重组/近义归纳 | 材料"盘山路多、无高速出口"→作答"道路不连通" | 该点满分 |
  | **材料多事实的上位概括** | 材料"部门协同＋数据共享＋办事提效＋群众少跑腿"→作答"提升基层治理效能" | **该点满分**（能被材料直接支撑的合理抽象） |
  | 材料没有依据的自造结论 | 材料无此事实，作答"打通交通循环""产业凋敝" | 该点不得分，**不额外扣分** |
  判定依据是"该表述能否在材料中被支撑"，不是"是否与材料用词相同"，也不是"用词是否漂亮"。
- **总括句**：独立成句/成段的总起句是总括句；**每条要点句首的"上位概括词"
  （如"交通：……"）不算总括句**。归纳概括**不写总括句不扣分、写了也不扣分**——
  只按"是否占用字数、是否新增采分信息"给写作建议（见 `scoring-standards.md` 四）。
- 要点顺序、分条格式（"1./2./3."还是"一是/二是"）：按点给分，不影响得分。
- 作答书写为并列短语、无主谓完整句：不扣分，只要关键词在。

### 输出模板（默认精简）
```

- L1 官方公开：题面要求"……"（引原文）；测查能力"……"
- L2 公开描述：小题按点给分
- L3 模拟口径：参考采分点（依据材料模拟重构）／子项分值／字数目标区
- L4 经验校准：参考答案/{文件名}（来源/年份）／无对应参考答案
  **均不代表官方评分细则**

### 逐句勾划
| # | 用户作答 | 分值 | ✓/◐/△/✗ | 得分 | 说明（缺哪一要素） |
|---|---------|:----:|:-------:|:----:|------|
```

### 满分答案标准
- 字数**参考配额**为限制的 85%–95%（写作建议，非扣分项）；**且必须 ≤ 题目上限**——
  生成后跑 `scripts/count_chars.py` 核验，超限先按 `word-count.md` §5 的压缩优先级
  删减再核验，达标后才输出（装不下就减点并标注覆盖不足，**绝不输出超限答案**）；
  **核心概念优先用材料原词**，允许能被材料直接支撑的上位概括，不自造材料无从支撑的结论；
- **总括句按需**：归纳概括可写可不写（写了不扣分，字数紧张时优先删无信息量的总括句）；
  综合分析**建议**写总括句点题，但不是硬性铁律。**总括句的界定**：独立成句/成段的
  总论点句才算总括句；每条要点句首的"上位概括词"不算；
- 附带采分点自检清单（逐条核对 ✓/◐/✗ 并标明该点得分 X/Y）。

## 五、双版本参考答案（可选，用户要求时给出）

| 版本 | 概括词 | 语言 | 适用 |
|------|--------|------|------|
| 直抄版（小马哥式） | 材料原词直用，不提炼 | 干、短、动词+宾语 | 字数紧、要点散的题 |
| 提炼版（白鹭式） | 材料词近义提炼（4–8 字前置词）+ 有据的上位概括 | 规范凝练、轻串联 | 需归纳整合、逻辑重构的题 |

两版都**不得自造材料无从支撑的结论**（脑补）；有据的上位概括两版都可以用。
