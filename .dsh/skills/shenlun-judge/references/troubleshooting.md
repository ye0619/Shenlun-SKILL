# troubleshooting（错误处置手册）

> 自 `SKILL.md` 十一节迁出（2026-10-03 结构瘦身）。用户指正后的**根因定位与处置路径**一律写在本文件；
> `SKILL.md` 十一节只保留**依据层级纪律**与一行指针。
> 处置时按"错误类型"查表；表内未列的新类型 → 先判根因，再补一行到本表（并跑 `工具/lint_rulings.py`）。

## 错误修正流程与常用处置路径

- **错误修正流程**：用户指正 → 先改对该题评判 → 分析根因（哪条规则理解错了）→ 更新本 skill 或 references。
  常用处置路径：
  | 错误类型 | 处置 |
  |---|---|
  | **字数类**（示例答案超限、标注与实测不符；**或把字数算进了评分／自创了扣分换算**） | 用 `工具/count_chars.py` 复核 → 改对数字 → 记入 `word-count.md` §9 历史事故表；**用户作答字数一律不计分**——超限/偏少只单列"⚠ 字数提示（按用户口径不计分）"，**禁止自创扣分公式、禁止降档**（用户 2026-09-27 裁定） |
  | **口径类**（把模拟口径说成官方、漏标经验口径） | 改对该处表述，并在 `scoring-standards.md` 0.2 补对应禁用话术 |
  | **精确感类**（只给精确分、无区间/置信度） | 按 `scoring-standards.md` 0.4 补区间与置信度，并在 `essay-judging.md` 自查表增补自查项 |
  | **参考口径类**（漏查 `批改规范/`、`参考答案/`，用了不登记，把机构答案当官方） | 按 `reference-answers.md` 第 3/5/7 节与 `workspace-layout.md` 第 7 节处置 |
  | **材料归位类**（放错目录、改名不说、含糊名称擅自猜） | 按 `workspace-layout.md` 第 4–5 节回滚重识别，含糊的列清单问用户 |
  | **判分尺度类**（因未引用某案例／"立意略模糊"／用词不同而扣分） | 属硬性禁令，改对评分后在 `essay-judging.md` 自查表与 `scoring-standards.md` 0.2 补禁用话术 |
  | **案例复用误判**（把"两段用了同一批案例"当扣分理由；或反向因"换了新案例"加分） | **高频实际事故**（2026-09-29 用户指正）。按 `scoring-standards.md` 2.2 重判：**"复用同一案例"本身正当（一策双证）**，扣分只能是"**该段未换层／论证空转**"；改对评分后在 `essay-judging.md` 1.2 #13、1.6 反向纪律②与 `scoring-standards.md` 0.2／2.2 补禁用话术，并**同步 `templates/workspace/批改规范/` 两份模板** |
  | **共识模型误用**（用文件数当家数、低权池破 40%、漏冲突分型） | 按 `small-questions.md` 第四节重算，并在报告里更正共识表 |
  | **采分点失真**（把机构 0 家收录的点**不加判断**地全部计入分值；或反过来把重要要点因"0 家"而丢弃） | **高频实际事故**。按 `small-questions.md` 第四节第 2、4 节重定来源等级：**0 家 → 先判"重不重要"**——重要（材料确凿＋直击题干核心任务＋独立要点）→ **按弱共识点计分**；次要/牵强 → 提醒区不计分；**1 家 → 单源点低权**；**2 家且不足半数 → 弱共识取主池低档**；重算分值池并更正共识表与报告得分，**在报告里保留"原分值 → 现分值"的对照**（可追溯）。参考资料不完整时，0 家点一律低权计分并降置信度 |
  | **跳过试批改**（没做阶段 A 就直接批改；或把某一份参考答案当唯一标准答案；或未声明"依据为通用规则"） | **本机制要治的根因**。按 `small-questions.md` 第四节**阶段 A** 补做：逐份试批改参考答案（命中／漏写／多写／表述／舍弃）→ 共同点/差异点/边界情况 → 生成《动态评分规范》（7 项）并落盘 `批改规范/{省份}/{卷ID}-第N题-动态评分规范.md`，再把试批改记录写进共识表「试批改记录」段；**材料不足无法补做时**，必须在报告写明"未做本题参考答案试批改、依据为通用评分规则（L3）"，且该题置信度上限"中" |
  | **试批改结论与速判不一致**（如某点原记"0 家"，逐份试评后发现确有 1–2 家写了） | **以试批改结论为准**：更正来源等级与定价，并在共识表「试批改记录」段登记"原记 → 现记"；**不得沿用速判的家数** |
  | **深刻刻度误用**（不点名层次、单独定档、凭文采降档） | 按 `essay-judging.md` 1.7 重判，并补黑名单话术 |
  | **范文刻度误用**（当分数锚点、因像范文加分、提取形式特征） | 按 `essay-exemplars.md` 第 0、9 节改正并补禁止项 |
  | **刻度机制被"跳过"或"空转"**（有 ≥2 篇范文却写"本卷不建刻度／无 T2 不成刻度"；或建了刻度但报告写不出"改了哪一处判断"） | **高频实际事故**。按 `essay-exemplars.md` 第 1、4、6、7 节**补建刻度并标参照档**（T1 ≥2 篇即建单向刻度；"没有 T2"不是理由），回填报告口径行与"刻度参照（补建）"块，**并按第 4 节四个接入点重判大档／档内定位／扣分项取舍**——**刻度若改变结论，档位与分数要跟着改**（这是该机制的用途）；改动须标注"按新口径重判"并保留原结论可追溯 |
  | **刻度把档位抬/压偏了**（默认"机构范文＝一类文"、参照档标定偏高、机械"低于 T1 就降一档"） | 复核参照档标定（`essay-exemplars.md` 第 4 节接入点 1，只标档位不标分数），逐项对照后重定；冲突无法消解时以 L1 题面＋四维为准并**降半档置信度** |
  | **同源家数误报**（脚本把 H1 范文标题／`（参考答案 N）`／`【机构】` 认错，导致家数少算或空条目） | 用 `工具/ref_independence.py --selftest`（含"自检10"回归用例）复核；按脚本 docstring 第 3 条"切分口径两条硬规则"确认标签写法，必要时**改正 `参考答案/` 里标签的层级**（机构用 H2–H6）后再跑 |
  | **卷级隔离缺失**（跨卷复用口径、报告头漏上下文声明） | 按 `session-isolation.md` 重跑隔离检查，并在 9.2⑧ 补自查 |
  | **非 md 材料未询问**（遇到 pdf/docx/图片直接硬读，没按第三节第 0 步问"是否启用 MinerU"；或用户没同意就装了 mineru） | 回到第三节第 0 步第 6 条重走：**先问、再装、只转当前卷**；未转换而直读原格式时在报告注明。**`.txt` 不提醒**，别多问 |
  | **内置默认被当成官方**（写"国考官方规定…"、把 80/10/10 说成官方比例、把 `guokao-defaults.md` 的档位文字标准当官方原文） | 按 `guokao-defaults.md` §7 改成"内置国考默认口径（经验口径，非官方）"，并在 `scoring-standards.md` 0.2 补对应禁用话术 |
  | **格式/语言占比回潮**（再出现"格式 15%–20%""语言 15%–20%""标题扣 4 分"式分池；或按分项表 4/7/10/9/5 加总） | 按用户 2026-09-22 裁定改回：**公文内容 80%／格式 10%／语言 10%**、**分项表只作证据清单**（`guokao-defaults.md` §4、§5.3） |
