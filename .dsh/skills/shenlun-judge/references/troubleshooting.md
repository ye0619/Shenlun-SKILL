# 常见问题处置

遇到批改争议时先回到 `SKILL.md` 和 `references/rulings.md`，核对题干、材料、作答原文与用户口径，再修正报告。用户明确裁定的口径以 `rulings.md` 为唯一事实源；本表只提供检查顺序，不重复判分规则。

| 问题 | 处置 |
|---|---|
| 题干、材料或作答缺失 | 标明具体缺项；仍可判断的部分给初步模拟意见，无法判断的部分不补造。相应扩大建议区间或不给该部分精确分。 |
| OCR、转写或材料版本可疑 | 保留存疑原文，说明转写方式和影响评分的字句；不把推测改写成确定证据。 |
| 采分点依据不足 | 对照题干任务和材料原文；没有证据的候选点不作为确定采分点。材料确凿支持但参考答案漏收的要点，按 `small-questions.md` 的重要性口径处理。 |
| 多份参考答案有分歧 | 记录文件与分歧内容，回到题干和材料原文判断；来源数量、同源工具和模型试评都不自动决定分值。 |
| 分数、档位或扣分理由冲突 | 逐项复算适用分值表；确认每个扣分都有原文证据、属于允许的项目且没有重复扣分；按用户口径修正并说明变更。 |
| 报告显得过于确定 | 改为模拟得分与建议区间，列出材料完整度、证据覆盖、规则局限和未决争议；移除高/中/低置信度、准确率验证或独立双评等表述。 |
| 范文比较导致档位不稳 | 按 `rulings.md` §1.17 核对两次提交、接触作答前已展示的固定预评记录及版本；作答提前出现或前置记录有实质修订时，不冒称满足严格盲评。检查题目匹配度、逐维双方原文证据与规则版本。移除机构自称档次、文本相似度机械定档或无证据的区间收窄；范文内部参照不等于人工校准。 |
| AI 整理稿被当成正式规范 | 标注“AI整理；未经人工基准校准”，核对题面和适用范围；除非确实安排用户审阅，不写“待用户确认”。 |

若修正影响原分数，报告保留旧分与新分、变更依据和受影响的评分点。修订 skill 后同步唯一事实源和实际使用的模板，避免继续保留互相矛盾的旧规则。历史变更记录统一见 `CHANGELOG.md`。
