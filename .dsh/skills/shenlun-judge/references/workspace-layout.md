# 工作区目录与命名规范（唯一出处）

> 本文件规定**工作区长什么样、材料放哪里、怎么命名**，以及**用户把材料随手放在工作区
> 主文件夹时如何自动归位**。SKILL.md 第三节"材料准备"只负责执行，**口径以本文件为准**。
> 本文件属 **L3 工程约定**（本 skill 自建的工作规范，非官方规定）——它约束的是
> **文件怎么摆**，不约束**怎么打分**。

## 1. 工作区由什么组成

工作区 = **skill 本体（`.dsh/skills/shenlun-judge/`）+ 配套脚本目录 `工具/` + 五个材料目录**。
**除 skill 本体与 `工具/` 外的五个材料目录，各司其职，不要互相混放**：

| 目录 | 放什么 | 谁放 | 是否按省份分类 |
|------|--------|------|:--:|
| `参考答案/` | 各大机构关于某真题的参考答案（含机构解析） | 用户收集 | ✅ |
| `批改报告/` | 批改完成后自动生成的报告（md 母本，可另存 pdf）＋ `.采分点共识/`（小题共识表缓存）＋ `.大作文刻度/`（大作文梯队刻度缓存） | 助手自动落盘 | ✅ |
| `真题/` | 某试卷的原题（PDF 为主）＋ **真题库**（已精读整理的结构化 md） | 用户 / 助手入库 | ✅ |
| `作答记录/` | 用户自己的作答记录（**md / txt 文档**） | 用户 | ✅ |
| `批改规范/` | 某套真题、或某套真题**大作文**（主要）的批改规范 | 用户收集 | ✅ |
| `工具/` | **skill 的配套脚本**：`count_chars.py`（字数核验，答题卡口径）、`ref_independence.py`（参考答案同源检测）——**不属于五个材料目录，但由安装器创建、随仓库发布**；**路径固定，请勿改名或移动**（skill 的文档按 `工具/{脚本名}` 调用它们） | 随仓库发布／安装器创建 | ❌ |

- **真题库已从 skill 迁出**：早期版本把真题库放在
  `.dsh/skills/shenlun-judge/references/real-exams/`，会让 skill 体积膨胀。
  现在**统一放在工作区 `真题/{省份}/真题库/`**，skill 只在需要时去读；
  `.dsh/` 里**只留 skill 必需文件**（`SKILL.md` + `references/*.md`），
  不放任何真题数据、题库、个人作答，**也不含脚本**。
- **两个配套脚本也已从 skill 迁到工作区 `工具/`**：`count_chars.py`（字数核验）、
  `ref_independence.py`（参考答案同源检测）。`工具/` **不属于五个材料目录**，但同样
  **随仓库发布**（用 `npx` 安装器时也会一并放到你的工作区 `工具/`）；**路径固定，请勿改名或移动**
  ——skill 的文档一律按 `工具/{脚本名}` 调用它们。
- **图像不是合法作答格式**：`作答记录/` 只收 md / txt（见第 6 节）。
- skill 需要写入用户工作区时，只用上面五个目录（不存在则创建），
  并可创建/更新各目录的 `README.md` 登记。

## 2. 卷ID：全工作区唯一键

**卷ID = `{四位年份}{省份}{卷型}`**

- **年份**：四位数字（`2022`，不写 `22`）。**同日历年同卷跨年度的，以考试当年为准。**
- **省份**：只写简称，不写"省""申论""答案"。已用简称：
  `国考`、`河南`、`浙江`、`福建`、`四川`、`广西`（新增省份沿用此风格，如 `山东`、`广东`）。
- **卷型**：取值尽量落在下面这张表里；表里没有的**照原卷名取词并登记**：

  | 类别 | 取值 |
  |------|------|
  | 国考 | `副省级`、`地市级`、`行政执法` |
  | 省考（分级） | `县级`、`乡镇`、`县乡`、`市级`、`省市`、`A`、`B`、`C` |
  | 其他 | `下半年`、`通用`（无分卷且无更具体名称时）；确实无卷型的**直接省略卷型** |

- **示例**：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`、`2013浙江`（2008–2012
  浙江未分卷）、`2023福建县乡`、`2023四川市级`（原卷名"省市卷"，依惯例归市级）。
- **附加说明**：需要保留"网友回忆版"等来源说明时，写在卷ID后的小括号里：
  `2026河南市级(网友回忆版)`。
- **多版本**：同一卷有多个来源/多稿时用 `-v2`、`-v3`（**不覆盖、不用日期命名**）。

**为什么必须统一**：同一卷ID串起五个目录，批改时只要知道卷ID，
就能一次定位原题、参考答案、作答、批改规范、历史报告——
`真题/河南/2022河南乡镇.pdf` + `参考答案/河南/2022河南乡镇/第1题.txt` +
`作答记录/河南/2022河南乡镇.txt` + `批改规范/河南/2022河南乡镇-大作文批改规范.md` +
`批改报告/河南/2022河南乡镇-批改报告.md`。

## 3. 五个目录的落位规范

```
工作区/
├── .dsh/skills/shenlun-judge/            # skill 本体（分发内容，不含任何数据，也不含脚本）
├── 工具/count_chars.py                   # skill 配套脚本：字数核验（答题卡口径，标准库实现）
├── 工具/ref_independence.py              # skill 配套脚本：参考答案同源检测（判"几家独立"）
├── 真题/
│   ├── _TEMPLATE.md                      # 真题入库模板
│   └── {省份}/
│       ├── {卷ID}.pdf                    # 试卷原题（L1 题面与材料）
│       └── 真题库/{卷ID}.md              # 已入库真题（题面+材料要点+重构参考采分点）
│       └── 真题库/INDEX.md               # 本省索引（入库清单 + 本地真题源）
├── 参考答案/{省份}/{卷ID}/第N题.txt       # N 用阿拉伯数字：第1题…第5题
├── 作答记录/{省份}/{卷ID}.txt             # 整卷一份；分题存 {卷ID}/第N题.txt
├── 批改规范/{省份}/{卷ID}-批改规范.md      # 整卷规范
│                             {卷ID}-大作文批改规范.md   # 仅大作文规范（主要形态）＋档次锚点
│                             {卷ID}-第N题-动态评分规范.md  # 阶段 A 试批改产物（L4 草稿，待用户确认）
└── 批改报告/{省份}/{卷ID}-批改报告.md      # 多版本 -v2；.字数核验/ 存留痕
    ├── .采分点共识/{卷ID}-第N题-共识表.md   # 小题：试批改记录 + 采分点共识表缓存与来源指纹，同卷复用
    └── .大作文刻度/                        # 大作文：试批改（数范文→特征卡→画像＋参照档）缓存，同卷复用
        ├── {卷ID}-素材清单.md              # 参与刻度的文件：路径/来源/年份/字节数/修改时间＝来源指纹＋生成日期
        ├── {卷ID}-特征卡.md                # 每篇范文一张六项特征卡（立意方向/论点覆盖/因果层次/边界意识/落点具体度/材料运用）
        └── {卷ID}-梯队画像.md              # T1/T2/T3 梯队画像 ＋ 各梯队参照档（批改时只读这一份）
```

> **两阶段落的文件（2026-09）**：**阶段 A 的产物有两份**——
> ① **可引用、可确认的《动态评分规范》** → `批改规范/{省份}/{卷ID}-第N题-动态评分规范.md`
> （大作文题并入 `{卷ID}-大作文批改规范.md`）；
> ② **过程留痕（逐份试批改 ＋ 共同点/差异点/边界情况）** → `.采分点共识/` 的共识表「试批改记录」段
> （大作文即 `.大作文刻度/` 的三件）。**阶段 B 只读这两份，不重读参考答案原文。**

- 文件扩展名：作答 `.txt` / `.md`；参考答案 `.txt` / `.md`（原为 docx/pdf 的可转换后存放）；
  原题 `.pdf`；报告与规范 `.md`。
- **批改报告 `.字数核验/` 的历史文件名保持原样**（历史报告里记录了当时的命令与文件名，
  改名会失去可追溯性），新写的留痕可用规范名。
- **缓存目录的隔离键 = 卷ID（硬性）**：`批改报告/.采分点共识/{卷ID}-…`、
  `批改报告/.大作文刻度/{卷ID}-…` **只允许同卷ID 命中时复用**——
  **跨卷一律重建**，哪怕两卷同省、相邻年份、同题型、同主题；借用他卷缓存 = 串味
  （见 `session-isolation.md` 第 3 节 R2）。
- **两个隐藏缓存目录遵循同一条纪律**：**来源指纹 ＋ 可复用 ＋ 可删可重建**——
  表头/清单里记下参与素材的**文件清单＋字节数＋修改时间**（＝来源指纹），**指纹变了就重建**；
  同卷再批（含 `-v2`）**直接复用**，口径保持一致；**用户可以清理它们**，下次批改**自动重建**。
  - `.采分点共识/`：**小题首次批改该卷时**自动建。
  - `.大作文刻度/`：**该卷大作文首次批改时**自动建（本卷该题参考答案里有 ≥2 篇范文即建 **T1 单向刻度**，
    另有 ≥2 篇 T2 样本才升级双向；仅 1 篇 → 单篇参照；**一篇都没有／该题不是大作文／素材与本题无关**才不建）。
    **建刻度时必须同时给每个梯队标"参照档"**（如"T1 参照档＝二类上"，**只标档位、不标分数**）——
    参照档是刻度**参与划档与评分**的入口（`essay-exemplars.md` 第 4 节）；
    没有参照档的画像只能讲"好在哪"，等于白建。
    **"没有 T2 样本"不是不建的理由**；真不建时报告写"刻度：未建（原因）"。
    用户清理后，下次大作文批改同样**自动重建一次**（不是退回"永远无刻度"）。
  - 两者的判定口径均属 **L3 模拟口径 ＋ L4 经验校准（非官方）**：小题共识表见
    `small-questions.md` 第四节，大作文刻度集见 `essay-exemplars.md`（第 1、6、7 节）；
    **本节只规定它们放在哪、叫什么、什么时候建**。

## 4. 自动归位流程（用户把材料丢在主文件夹时）

**触发时机**：第三节第 0 步——每次批改开始前；用户说"我放了个文件/帮我归档"时也直接做。

**步骤**

1. **扫描**：工作区根目录 + 五个目录内不符合规范的散落文件/文件夹
   （含 `新建文件夹`、压缩包解出的目录）。
2. **识别四要素**（文件名优先，文件名信息不足时**读内容**）：
   | 要素 | 识别线索 |
   |---|---|
   | 年份 | 文件名年份、题干"××××年"、材料内落款年份 |
   | 省份 | 文件名省份词、卷头"××省公务员考试"、机构答案标题 |
   | 卷型 | 副省级/地市级/行政执法/县级/乡镇/县乡/市级/A/B/C；无则省略 |
   | 材料类型 | PDF 原题→`真题/`；多机构答案/解析→`参考答案/`；"我的作答/答题"→`作答记录/`；"评分标准/档次/采分要求"→`批改规范/` |
3. **判定与执行**：四要素齐全且无冲突 → 移动到位并按第 3 节命名；
   **在对话里列出"原路径 → 新路径"清单**（**不许静默改名**）。
4. **不确定就不猜**：命中第 5 节任一情形 → **停下来问用户**，不要自作主张。
5. **收尾**：更新对应目录的 `README.md` 登记表；新真题入库时更新
   `真题/{省份}/真题库/INDEX.md`。

**工具**：移动/改名用 `Move-Item -LiteralPath <旧> -Destination <新>`
（Windows 下 `Rename-Item` 传完整路径作新名会报 "represents a path or device name"；
偶发 `IOException`（文件被占用）**重试一次**，仍失败就如实报告）。

## 5. 命名含糊时必须提醒用户（禁止猜测）

出现下列任一情形，**先问再动**，并把四件事写清楚：
**① 文件 ② 已识别到的信息 ③ 缺失/冲突的信息 ④ 建议的规范名**。

| 情形 | 例子 | 提醒话术要点 |
|---|---|---|
| 文件名含糊 | `申论.pdf`、`答案.txt`、`新建文件夹`、`副本(1)`、`未命名.docx` | 看不出年份/省份/卷型，问是不是某卷 |
| 年份或卷型冲突 | 同卷已有 `2022河南乡镇`，又来了一个"河南乡镇卷" | 问是哪一年，或是否同一卷的另一版本 |
| 一份文件含多套卷/多题 | 一个 txt 里同时有县级卷与乡镇卷的作答 | 问是否拆分、按什么命名 |
| 同名文件已存在 | 已有 `2022河南乡镇.txt` | 问是**替换**还是加 `-v2` **并存** |
| 来源不明 | 无标题的"评分标准.docx" | 问是官方/机构/自拟，属于哪一卷 |
| 图像/扫描件 | `1.jpg`、`作答照片/`、扫描版 pdf | 说明只收 md/txt，请用户自己转文本（第 6 节） |

**提醒模板**

> 我在工作区根目录发现 3 个还没归位的文件，其中 2 个我识别不出年份，请你确认后我再移动：
> 1. `申论.pdf` —— 能看出是"河南省考县级卷"，但**看不出年份**；建议命名为
>    `真题/河南/{年份}河南县级.pdf`，请问是哪一年？
> 2. `答案.txt` —— 内容是某卷参考答案，但**没有卷名**；建议放
>    `参考答案/河南/{卷ID}/第1题.txt`，请确认是哪一卷。
> 3. `22河南乡镇.txt` —— 可识别为 2022 河南乡镇卷作答，我将归位为
>    `作答记录/河南/2022河南乡镇.txt`（年份补足四位、按省份分目录），可以吗？

## 6. 作答记录：只收文本，图像请用户自己转

- `作答记录/` **只收 md / txt**；整卷一份（内部按 `第X题` 分块）或按题拆分。
- **检测到图像（jpg/png/webp/heic、扫描版 pdf）时**：
  1. **先请用户手动转成文本**，并给出目标路径与建议文件名
     （如 `作答记录/河南/2026河南县级.txt`）；
  2. 说明理由：**OCR 转写难免字误，而字误会直接影响采分点判定**，
     所以宁可请用户花几分钟手动转换；
  3. 用户明确说"先帮我转/我没时间转"之后才 OCR（`vision_ocr`；多页长图
     `vision_long_screenshot_ocr`），并在报告开头注明**转写方式**、附转写稿、
     字误单列（⚠ 疑似转写错误不扣分，待用户确认）。
- 不要把图像直接"归档"进 `作答记录/` 就算完事——那会破坏"只收文本"的约定。

## 7. `批改规范/` 的接入与引用（有就必须引用）

1. 批改某卷前，查 `批改规范/{省份}/{卷ID}-批改规范.md`、`{卷ID}-大作文批改规范.md`，
   以及**阶段 A 试批改产出的 `{卷ID}-第N题-动态评分规范.md`**。
2. **命中即必须引用**；**批改大作文时，该卷大作文批改规范优先于本 skill 的 L3 模拟口径**
   （档次标准、分档区间、硬性要求、禁止性口径逐条对照）。
   **《动态评分规范》是对该题专门的标定**（核心采分点／可接受的同义表达／部分命中规则／
   不应机械扣分的情况／材料使用要求／联系实际要求／档次锚点），**阶段 B 必须逐条对照**。
3. **层级按来源判定并登记**：
   - 官方公开的评分标准/阅卷细则 → 按 `scoring-standards.md` 0.3 升级为 **L1/L2**，
     优先于本 skill 模拟口径；
   - 机构或用户自拟 → **L4 经验校准**，只调宽严与粒度，**不得覆盖 L1 题面要求**；
   - **助手提炼的草稿**（第三条来源类别）→ **L4**。含两类：
     ① 从 N 篇范文／用户标注样本提炼的**大作文规范**；
     ② 由**本题参考答案试批改**提炼的《**动态评分规范**》。
     文件头须标"**来源：助手对本题参考答案试批改提炼（L4 经验校准，非官方）**"与
     "**状态：待用户确认**"，**可用于批改但报告必须注明"未确认草稿"**；
     **用户手写规范优先、不覆盖**（已有手写规范时草稿另存 `(助手提炼)` 版本，
     报告说明"两份并存，以用户手写那份为准"）；提炼内容与禁止项见
     `essay-exemplars.md` 第 5 节、`small-questions.md` 第四节阶段 A；
   - 来源不明的 → 只能用来说明"该卷可能怎么判"，**不得当作官方标准**（要在报告里写明来源不明）。
4. **冲突处理**：与题干作答要求（L1）冲突时以题面为准；与 `参考答案/` 冲突时以层级更高者为先；
   两种情况都要在报告"评分依据声明"里写明冲突点与取舍理由。
5. 未命中时如实写"未找到该卷批改规范"，按 L3 模拟口径执行，**不找替代、不凭记忆编造**；
   **若该题有 ≥2 家参考答案，仍应先做阶段 A 试批改**（动态规范属助手草稿，不属"未命中即放弃"）。

## 8. 题面获取与真题入库

**8.1 题面获取（必做，见 `SKILL.md` 第三节第 4 步）**——题面与给定资料是 **L1 最高依据**，
按三级来源依次取：

| 级别 | 来源 | 说明 |
|:--:|---|---|
| 1 | **工作区主文件夹（根目录）**的真题 PDF/文本 | 用户常直接丢在根目录；先按第 4 节**读首页识别年份/省份/卷型**并归位为 `真题/{省份}/{卷ID}.pdf`，再读题面 |
| 2 | **`真题/{省份}/`** | `{卷ID}.pdf`（**L1 最高依据**，优先）→ 其次 `真题库/{卷ID}.md`（重构稿，与 PDF 冲突以 PDF 为准） |
| 3 | **联网搜索** | 以上都没有时用联网检索；**必须登记来源与链接**，并提示"网络来源可能不准确，请核对" |
| 兜底 | 请用户贴题面原文 | **必须在报告里声明"题面未经核实、置信度低"**，只给档位级/方向级结论，不给精确分 |

- PDF 读取：优先 Python PyMuPDF（`import fitz`）；不可用 → 平台 PDF 读取/OCR（关键处人工校对）；
  仍不可用 → 请用户贴文本。

**8.2 真题入库（可选，批改后再做）**

- 有 `真题/_TEMPLATE.md` 时：复制它 → 写成 `真题/{省份}/真题库/{卷ID}.md` →
  在 `真题/{省份}/真题库/INDEX.md` 补一行（卷ID｜年份｜卷型｜主题关键词｜文件）。
- **工作区没有 `_TEMPLATE.md` 时**（全新 `npx` 工作区常见），**按下面字段自行创建**，
  不要因为"没有模板"就跳过入库：
  `卷ID｜年份｜省份/考试｜卷型｜时限与分值｜给定资料要点（分材料编号）｜
  各题作答要求原文（含字数与文体）｜各题参考采分点（小题/公文）｜
  大作文参考立意方向与材料要点｜来源（真题 PDF 文件名/网址）｜入库日期`。
- 只有小题/公文才写"参考采分点"；**大作文不取采分点**，只记题干原文、材料要点与
  参考立意方向（评分仍按四维划档）。
- 整理时**沿用卷ID**，不要另造命名；来源与年份写进文件头。

## 9. 维护

- 目录规范变更 → 改**本文件**，并同步 `SKILL.md` 第三节与各目录 `README.md`
  （避免三处口径不一致）。
- 各目录 `README.md` 由助手在归位/落盘后顺手更新，登记表至少含：
  文件名/卷ID、来源、年份、日期、状态。
- 本文件与 `reference-answers.md`（参考答案口径）、`scoring-standards.md`（层级与置信度）
  的分工：**本文件管"东西放哪、叫什么"，后两者管"拿到了怎么用"**。
