# assets/

这个目录放根 `README.md` 里用到的图片，目前预留两类：

| 用途 | 建议文件名 |
|---|---|
| 批改效果截图 / 录屏 GIF | `example-report-01.png`、`example-report-02.png` |
| 粉笔 PDF 下载插件界面截图 | `fenbi-plugin-01.png` |

- 命名建议：`小写英文-序号.扩展名`，同一类用同一个前缀，方便按次数往下加。
- 根 `README.md` 里对应的图片引用行**已经用 HTML 注释写好**（《批改效果》与《配套插件》两节各一处），
  把图片放进本目录后，**取消那两行注释并把文件名改成真实文件名即可**。
- 图片请自行确认不含个人信息与隐私内容（见根 README 的《免责声明》）。
