# 参考答案/

## 放什么

真题的参考答案、机构解析、老师讲义、你自己整理的答案要点。

**注意：这里的东西都不是官方阅卷标准。** 批改时用于候选要点、表达差异和来源记录，
与题面作答要求、考试大纲等公开要求冲突时，一律以公开要求为准。

**过程文件按条件建立**：助手核对参考答案的共同点、差异与边界，按 `references/rulings.md` §1.3 判断是否必须建立动态规范、共识表和大作文刻度文件。条件满足必须建立，少量题目或材料不适用时在报告说明豁免；这些过程记录不构成人工校准。
**同一题最好放 ≥2 家不同答案口径**（家数按 `references/rulings.md` §1.2 统计，同一机构的不同答案可分别计家，同源转抄去重）；
只有 1 家时仍可记录该来源的要点覆盖与局限；是否建档按本次条件判断，不设两家门槛。无参考答案的题免建共识表，不编造来源。
报告内展示按 `references/rulings.md` §1.3.1：不论题量，小题／公文内嵌共识表，大作文内嵌刻度表及全部合格候选的逐篇数值评分；无可用材料保留状态、已检查路径及原因，独立建档豁免不免报告栏目。

**来源数量与候选点计分**按 `references/rulings.md` §1.2 执行：来源少本身不降分；满足用户条件的非计分补充仅在参考答案中列出并标注“不计分”，来源未知不记为零家。

## 目录与命名

```
参考答案/{省份}/{卷ID}/第N题.txt
```

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略
- 每题一个文件：`第1题.txt`、`第2题.txt`……

示例：

```
参考答案/河南/2022河南乡镇/第1题.txt
参考答案/河南/2022河南乡镇/第2题.txt
参考答案/国考/2026国考行政执法/第3题.txt
```

## 格式

- 优先 `md` / `txt`，助手可以直接读取
- `docx` / `pdf` / 图片请自己先转成文本再放进来
- 文件名不必纠结：放到工作区根目录或本目录都行，助手会按规范自动归位重命名，
  命名含糊时会先问你
- **一份文件里放多家时**，每家单独起一层：**机构／名师名独立成行**（`## 粉笔` 这类标题最好），
  或写成 `【粉笔】答案正文…`（标签与正文同行也支持）。**别用 `—— 华图 ——` 这类装饰性写法**
  ——工具会认不全，家数会被静默低估（2026-10-11 已加强识别与告警，仍以人工清点为准备）
- **大作文请尽量保留多家完整范文**（2026-10-22）：批改大作文时，助手会从本卷范文里挑档位最高的
  一篇作报告"示例范文"，**整篇照录，不删段、不节选**；字数超限或不足均不影响选取、排序或模拟评分，只核验提示，见 `references/rulings.md` §1.8。实际截断、只留点评、多个来源拼接的文本用不了，不能仅因字数少判截断；
  一家一篇完整作文最好（写清来源机构／名师名，便于报告注明出处与选取理由）
