# 批改报告/

## 放什么

助手给你出的批改报告落盘的地方：模拟得分、建议区间、校准状态、采分点对照、
失分原因、修改示范都在里面。你一般不需要手动往里写东西。

## 目录与命名

```
批改报告/{省份}/{卷ID}-批改报告.md
```

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略

示例：

```
批改报告/河南/2022河南乡镇-批改报告.md
批改报告/国考/2026国考行政执法-批改报告.md
```

## 同一套卷批改多次

- 第二份报告追加版本号：`批改报告/河南/2022河南乡镇-批改报告-v2.md`
- 版本号只递增，**不使用日期命名**，保证同卷版本可以排序、便于对比进步
- 报告里的「字数核验」等留痕放在 `批改报告/.字数核验/` 下，不用管
- **每道非大作文题（小题、公文）的批改都附一份「参考答案（示例答案）」**（2026-10-02 用户裁定），
  由助手综合本题候选要点撰写、**字数经脚本核验达标**，可直接模仿；大作文报告按 `essay-exemplars.md`
  先对可比范文模拟评分划档，再与考生作文逐维比较
- 小题的**采分点共识表**（说明"哪些点是共识点、哪些只是低权的单源点/材料推定点"，
  属 L3 模拟口径、非官方）放在 `批改报告/.采分点共识/` 下，
  **助手自动生成与复用，可删可重建**，不用管
- 大作文所用范文的**预评分与比较证据**应写入本次报告；只有跨次复用确有价值时才按卷保存，
  并记录来源、题目匹配度、规则版本和“模型模拟；未经人工基准校准”。它不是外部校准材料。
- **批改收尾**：助手会跑 `python 工具/卷级一致性检查.py --paper {卷ID}` 核对本卷留痕是否齐备
  （报告／规范／共识表／字数核验／刻度／本文件的登记行）并交叉核对参考答案家数；
  有缺件会先补齐再交付。本文件的登记表因此**必须有一行本卷记录**（登记＝批改完成的一部分）

## 提醒

本目录是你的个人批改记录，默认不进公开仓库（见仓库根 `.gitignore`）。
想公开请自行检查是否含个人信息。
