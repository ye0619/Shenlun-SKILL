# 批改报告/

大作文严格盲评的两次提交、前置预评记录及报告留痕按 `references/rulings.md` §1.17 执行；先完成范文预评，再接收考生作答，作答提前出现时不得补称盲评。
第一阶段的材料正文只读已确认的题干、材料与参考范文；未分类文件只看文件名／路径，第二阶段用户提交或指定作答后再识别内容并归档。报告记录本次相关延后识别文件及第二阶段处理结果，具体边界见该条与 `references/workspace-layout.md` §4。

## 放什么

助手给你出的批改报告落盘的地方：模拟得分、建议区间、校准状态、采分点对照、
失分原因、修改示范都在里面。你一般不需要手动往里写东西。

## 目录与命名

```
批改报告/{省份}/{卷ID}-批改报告.md
```

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略

示例：

```
批改报告/河南/2022河南乡镇-批改报告.md
批改报告/国考/2026国考行政执法-批改报告.md
```

## 同一套卷批改多次

- 第二份报告追加版本号：`批改报告/河南/2022河南乡镇-批改报告-v2.md`
- 版本号只递增，**不使用日期命名**，保证同卷版本可以排序、便于对比进步
- 报告里的「字数核验」等留痕放在 `批改报告/.字数核验/` 下，不用管
- **每道非大作文题（小题、公文）的批改都附一份「参考答案（示例答案）」**（2026-10-02 用户裁定），
  由助手综合本题候选要点撰写、**字数经脚本核验达标**，可直接模仿；大作文报告按 `essay-exemplars.md`
  先对可比范文模拟评分划档，再与考生作文逐维比较
  小题／公文确有容量冲突时，按 `references/rulings.md` §1.9 附限字正文与完整要点清单，列正文未覆盖项及原因，不把覆盖不足正文称满分答案；正文和清单分开核验范围。
- **大作文报告都附一篇「示例范文」**（2026-10-22 用户裁定）：从本题 `参考答案/` 收录的范文里选
  模拟档位最高的一篇**整篇原样照录，不删段、不节选**，字数偏差如实标注，并注明来源／字数／档位／选取理由；本卷没有可用范文时如实写
  "未收录"，不编造。范文只作范例展示，**不改变考生得分**（`references/essay-exemplars.md` §5）
  收录完整范文的字数超限或不足均不影响候选、排序与模拟评分，按 `references/rulings.md` §1.8 仅核验提示，不因字数删改原文。
- **国考整套试卷**（全部题目都已作答并批改）的报告另附「全卷模拟总分」块：各题合计 → 整套压分
  修正 −10.0 → 压分后总分 → 压分后区间，声明为 L3 经验口径；单题、缺题、省考卷不写
  （`references/guokao-defaults.md` §7）。登记表里该卷得分写 `压分后/满分（压分前 X）`
- 小题的**采分点共识表**（记录来源覆盖、重要性依据与计分状态；来源少本身不降分，非计分补充按 `references/rulings.md` §1.2 仅列参考答案，
  属 L3 模拟口径、非官方）放在 `批改报告/.采分点共识/` 下，
  **按 `references/rulings.md` §1.3 条件独立建档或复用**；不论题量，报告本题内还须直接展示共识表，不能只给路径。无可用参考答案时保留栏目并列状态、已检查路径及原因（§1.3.1）。
- 大作文所用范文的**预评分与比较证据**应写入本次报告；刻度三件套的独立保存或豁免也按 `references/rulings.md` §1.3 判断，
  并记录来源、题目匹配度、规则版本和“模型模拟；未经人工基准校准”。它不是外部校准材料。
  **示例全文另行核验**：本卷 `参考答案/` 有合格同题完整候选时择优一篇整篇照录；没有时在“示例范文”栏目写“状态：无可照录的本题完整范文”、已检查路径及原因，已有比较参照仍照常使用（`references/rulings.md` §1.3.1；`references/essay-exemplars.md` §5）。
- **报告内必须有“大作文刻度表”和“范文逐篇评分”表**，覆盖全部通过粗筛的完整可比候选，以唯一范文ID对应，逐篇列数值模拟得分／满分、档位及原文依据；入选全文注明同一ID。
- 同题范文按本题评分，异题弱参照按各自原题、材料与满分评分；刻度表须列参照类型、原题依据和可比与不可比维度，允许逐篇满分不同。比较只使用明确可比的维度及双方原文，不按原始分、百分比或异题档位直接给考生定档；示例全文只从本题合格候选中选取（`references/rulings.md` §1.3.1）。
- **大作文区域必须有“论点表”**：试批改时逐篇提炼，表头依次为“来源、题目、总论点、分论点1、分论点2、分论点3”，超过三个按实际最多数量连续扩列。每篇一行，来源用“范文ID · 来源”与刻度及评分表对应，题目填范文自身标题，论点附原文依据；较少者如实标明。无可比范文时三张表分别登记“状态：无可用完整可比范文”、已检查路径及原因；示例全文的缺失条件及状态单独核实，不能相互代替（`references/rulings.md` §1.3.1／§1.19）。
- **考生作文另列“档内定位表”**：按 `references/report-template.md` 第二节逐项填五项作答证据与定位理由，范文表不能代替；无范文仍须填写，四类文不细分小档。此表目前人工复核，工具尚不自动检查。
- 范文三张表与示例全文的ID、来源按实际文字对应；行内代码、粗体及强调的排版差异不算错配，实际字符差异、漏篇和重复ID仍检查（`references/rulings.md` §1.19）。
- **批改收尾**：助手运行 `工具/卷级一致性检查.py`，显式传入本次题号、题型、参考答案与范文条件（参数见 `工具/README.md`），检查报告逐题必需正文、表格、范文数值评分与ID覆盖，以及条件必建的规范／共识／刻度文件、字数留痕、登记及来源声明。
  条件未知须先核实，不能写成无材料；必建缺件补齐后交付，豁免项说明原因。本文件的登记表**必须有一行本卷记录**（登记＝批改完成的一部分）。

## 提醒

所有题型按 `references/rulings.md` §1.5 统一从严给分，复合点核对必要子项的实际覆盖；历史两套红笔分来源未核实，不作松紧依据。组织呈现、字数和其他已确认的免扣分口径继续有效。

本目录是你的个人批改记录，默认不进公开仓库（见仓库根 `.gitignore`）。
想公开请自行检查是否含个人信息。
