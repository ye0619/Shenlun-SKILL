# 批改规范/

> **本目录有两类文件**：① 你手写／收集的**该卷批改规范**（`{卷ID}-批改规范.md`、
> `{卷ID}-大作文批改规范.md`）；② 助手**阶段 A 试批改**产出的**《动态评分规范》**
> （`{卷ID}-第N题-动态评分规范.md`，标"助手提炼草稿（L4，非官方）／待确认"）。
> **你手写的那份优先**——助手不会覆盖它。空白模板见 `_模板.md` 与 `_动态评分规范模板.md`。

## 放什么

针对某一套卷（或某一类大作文）形成的**批改口径**：这道题怎么给分、采分点怎么拆、
哪些是硬伤、字数怎么算、语言分怎么给。它让同一套卷的多次批改口径保持一致。

助手在批改时会先读这里的规范；你自己写也可以，写清楚的规范会被优先遵守。

## 目录与命名

```
批改规范/{省份}/{卷ID}-批改规范.md
批改规范/{省份}/{卷ID}-大作文批改规范.md
```

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略
- 小题规范用 `-批改规范.md`；只针对大作文的用 `-大作文批改规范.md`

示例：

```
批改规范/河南/2022河南乡镇-批改规范.md
批改规范/国考/2026国考行政执法-大作文批改规范.md
```

## 建议写什么

- 本题的作答要求（字数、身份、文体）和采分逻辑
- 采分点清单与分值来源（标明是题面要求、公开大纲，还是模拟口径）
- 硬伤清单：哪些错误直接压档位/扣分
- 特别提示：这道题最容易套模板的地方

## 没有本卷规范时会怎样（默认口径）

**没命中本目录的规范 → 助手改用 skill 内置的默认国考标准**
（`.dsh/skills/shenlun-judge/references/guokao-defaults.md`）：

- **国考卷直接套用**；
- **河南、浙江等没有本省规范的卷**，**套用国考口径并做总分适配**（占比不变、按满分查换算表；
  公文三池＝内容 80%／格式 10%／语言 10%）；
- 报告写"未找到该卷批改规范，采用**内置国考默认口径（经验口径，非官方）**"。

> **形式类扣分上限（2026-09-23 补例外）**：**除用户对该题另有明确裁定外**，
> 格式/语言/卷面/标题/字数类扣分**合计 ≤ 题目总分的 10%**；字数类罚则一律不采纳（只作 L1 合规提示）。
> 若某题经用户裁定豁免（如"严格照某份口述标准执行"），须在该题规范文件头**写明依据**，
> 并在批改报告中登记该例外。

## 提醒

官方阅卷细则通常不公开。本目录的规范**按来源定级**：

- 若是**官方公开**的评分标准/阅卷细则（务必在文件里写明来源与年份）→ 助手按 **L1/L2**
  优先使用，**优先于 skill 自带的模拟口径**；
- 若是**机构解析或你自己拟定**的 → 属 **L4 经验校准**（只用于校准宽严与粒度），
  **不得表述为官方规定**；
- **来源不明**的 → 只能用来说明"这套卷可能怎么判"，**不得当作官方标准**。

本目录默认不进公开仓库（见仓库根 `.gitignore`）。
