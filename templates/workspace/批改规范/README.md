# 批改规范

本目录保存有明确来源、版本和适用范围的真题评分规范。用户提供或手写的规范按其来源和范围使用；官方公开内容仅在其公开范围内作为官方依据。机构、自拟及 AI 整理材料均标为非官方参考，不能证明评分准确率。

## 文件命名

```text
批改规范/{省份}/{卷ID}-批改规范.md
批改规范/{省份}/{卷ID}-大作文批改规范.md
```

小题动态评分稿可选，不是批改前置条件，也不要求先试评参考答案。若确需保存，文件名可用 `{卷ID}-第N题-动态评分规范.md`，文件头写“AI整理；未经人工基准校准”，注明实际输入材料与版本。只有明确安排用户审阅时才写“待用户确认”。已有用户规范不覆盖，冲突时检查题面、来源和适用范围并在报告说明。

## 建议字段

记录题干要求、题目分值、适用材料、候选采分点及其原文依据、可接受的语义表达、分值理由、明确的用户口径、来源和未决问题。不要从机构答案出现次数自动推算分值或准确性，也不要从范文推断阅卷档位。

空白模板见 `_模板.md` 和 `_动态评分规范模板.md`。评分准确性边界和报告要求见 skill 的 `SKILL.md` 与 `references/report-template.md`。
