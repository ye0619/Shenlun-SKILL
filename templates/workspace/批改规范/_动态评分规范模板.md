# {卷ID} 第{N}题 · 动态评分规范（**阶段 A 试批改产物**）

> **用法**：本文件是**一题一份**的《动态评分规范》模板。复制为
> `批改规范/{省份}/{卷ID}-第{N}题-动态评分规范.md`，然后逐项填写。
> **大作文题**不用本文件，直接并入 `{省份}/{卷ID}-大作文批改规范.md`（档次锚点写在那里）。
>
> **它是什么**：真实阅卷是"**先试批改 → 定标尺 → 再正式阅卷**"。
> 本文件就是那道"标尺"——**批改用户答卷之前**，先拿本题参考答案**自己试批改一遍**，
> 从**共同点／差异点／边界情况**里提炼出**本题专用的 7 项规范**；
> 形成之后，**才允许批改用户答卷**（阶段 B）。
>
> **口径唯一出处**：`references/small-questions.md` 第四节「阶段 A」。
> **层级**：本文件属 **L4 经验校准（非官方）**，**不是官方评分规范**；
> 在 `批改规范/` 里，**官方公开（L1/L2）＞机构/用户手写（L4）＞本文件（L4 草稿）**。
> 引用时须写"**助手对本题参考答案试批改提炼（L4，非官方，待用户确认）**"。
>
> **本文中所有 `{}` 包裹的内容都是占位符。**

## 三、动态评分规范（**必须含 7 项**）

### 1. 核心采分点（共同点）

> **拆点粒度按题型分化（用户口径 2026-09-25，`small-questions.md` §1.5）**：
> **分析题**（原因/启示）**从严**——要素各成一点、不合并语义群，**单点 ≤ 总分 15%**；
> **概括题·对策题从宽**——按主体/层面分块（通常 3–5 块），**单点 ≤ 总分 30%**，抓住块即给该块主要分值。
> **下列内容不是采分点**：数据与口语化表达（4.1）；带"等"的列举式**任选一项＋"等"即完整命中**（4.2）。

| 点号 | 要点（核心动作｜核心对象｜关键限定/结果） | 材料原文依据 | 独立来源家数 |
|:--:|---|---|:--:|
| ① | `{…}` | `{材料X第Y段"……"}` | `{N 家}` |
| ② | … | | |

### 2. 可接受的同义表达（差异点里的措辞清单）

> 判分时**照给**（同义／异构一律允许，见 `small-questions.md` 铁律 8）——**不得因用词不同机械判错**。

| 采分点 | 可接受的表述（含各家原话） |
|:--:|---|
| ① | `{例："提升办事效率"≈"优化政务服务"≈"放管服改革提效"}` |

### 3. 部分命中规则

| 命中情形 | 给分 |
|---|---|
| 三要素齐（核心动作＋核心对象＋关键限定/结果） | 该点**满分** |
| 核心动作与对象在、**关键限定**缺失 | 该点 `{60%–80%}` 的**低端**（**就低不就高**，写明缺哪一要素） |
| 只有泛泛表述、无可核对的具体指向 | **0 分**（**从紧口径，2026-09-22**；旧"低分"已废止） |
| 材料没有依据（自造结论） | **0 分**，不额外倒扣 |
| **用户多写的额外内容** | **不扣分**（不倒扣，只在报告提示；题面明确限条数的除外） |
| **数据／月份／数量／百分比**缺失（**非采分点**，用户口径 2026-09-25 铁律 4.1） | **不扣分、不判"部分命中"**（题干明确要求"概括数据"等定性限定词时除外） |
| **口语化／口号式语句**缺失（4.1） | **不扣分**（反向：只有口号而无具体指向 → 仍按"泛泛表述"给 0） |
| **列举式带"等"**（4.2）：写出了 ≥2 项中的**任意一项** ＋"等" | 该点**完整命中**（**不必是第一项**，不得因"没写第一项"判部分命中） |
| `{本卷特有的边界情形}` | `{本卷的具体尺度}` |

### 4. **不应机械扣分的情况**（边界情况直接落在这里）

> 这一项是**试批改最值钱的产出**：各家"可写可不写"的内容，**未写不扣、写了不加**。

- `{例：材料 9"实施成效"段是否算"条件"，各家分歧 → 不作为机械扣分依据}`
- `{例：提纲类公文是否计格式，各家分歧 → 按题面要求，未要求则不扣}`
- `{例：某点只需点出方向、不要求展开细节}`

### 5. 材料使用要求

- 题面限定范围：`{例：资料 2、4、5、6}`——**范围外内容不作为得分点**；
  若作答**以范围外材料替换**了范围内内容 → 按缺项计；作为**补充** → 不加分也不扣分。
- "**不拘泥于给定资料**"＝**可补充资料外的合理论据**，**不等于**替换指定范围。

## 四、使用与维护

1. **阶段 B 必须逐条对照本规范**：核心采分点／可接受的同义表达／部分命中规则／
   **不应机械扣分的情况**／材料使用要求／联系实际要求（／大作文档次锚点）。
   **同时执行"从紧给分"（2026-09-22，细则见 skill 的 `references/guokao-defaults.md` §8）**：
   三要素缺一不判满分、部分命中就低不就高、泛泛表述 0 分、低权点取区间下限；
   **用户多写的内容一律不扣分**；报告"评分说明"须写明"本次按从紧口径给分"。
   **同时执行用户硬口径（2026-09-25，最高优先级，见 skill 的 `SKILL.md` 顶部总表）**：
   数据／口语化不属采分点（4.1）、列举式任选一项＋"等"即完整命中（4.2）、
   提纲格式按题区分（`gongwen.md` 第三节）、**字数按 `⌈超出达标上限 ÷ 50⌉` 扣分**（`word-count.md` §4.2）。
2. **本规范与 `批改规范/{省份}/{卷ID}-批改规范.md`（整卷）并存**：整卷规范管全局口径，
   本规范管**本题**；冲突时**以等级更高者为准**（官方公开 ＞ 机构/用户手写 ＞ 本文件草稿），
   与 L1 题面冲突一律**以题面为准**。
3. **用户手写规范优先**：若 `批改规范/{省份}/` 已有用户手写的同题规范，
   **不覆盖**——本文件另存 `{卷ID}-第{N}题-动态评分规范(助手提炼).md`，
   报告说明"两份并存，以用户手写那份为准"。
4. **失效与重建**：参考答案有变动（比对共识表的**来源指纹**：文件名＋字节数＋修改时间）→
   **重做试批改、重建本规范**，并在报告注明"动态评分规范已因参考答案更新而重建"。
5. **卷级隔离**：本规范**只对本卷本题有效**；跨卷（哪怕同省相邻年份、同主题）**一律重做**，
   不得借用（见 `references/session-isolation.md` 第 3 节 R2）。
6. **不得**把本规范表述为"官方评分规范"；**不得**用试批改给参考答案打分再据此折算考生分数。
