# 真题/

## 放什么

申论真题原卷（PDF）和从卷子里整理出来的纯文本题面。

## 目录与命名

原卷 PDF：

```
真题/{省份}/{卷ID}.pdf
```

整理成文本的题面（助手批改时优先读这一份）：

```
真题/{省份}/{卷ID}.md
```

查找时兼容旧路径 `真题/{省份}/真题库/{卷ID}.md`，已有题库文件不移动。主路径与旧路径均须核对；同卷内容不一致时回原卷核实，不自动覆盖。新整理文本使用主路径，已有可用文本先复用，不重复入库。

配套的两个文件：

- `真题/{省份}/INDEX.md` —— 该省**入库索引**（已入库真题清单 + 本地真题源 PDF 清单）；旧 `真题/{省份}/真题库/INDEX.md` 仍可读取。更新实际使用的索引并记录真实文件路径，索引缺失时直接核对题面文件；
- `真题/_TEMPLATE.md` —— **入库模板**，复制它来整理新卷。

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略

示例：

```
真题/河南/2022河南乡镇.pdf
真题/河南/2022河南乡镇.md
真题/国考/2026国考行政执法.pdf
```

## 题面文本建议包含

- 卷面信息：年份、省份、卷型、时限
- 每题完整作答要求（含字数限制、身份设定、文体要求）
- 材料可以只留要点，但**作答要求必须逐字准确**

## 提醒

真题资料仅供个人学习研究，保留来源信息并遵守原始来源的使用要求。真题、参考答案及不含隐私的批改规范可随仓库发布；`作答记录/`、`批改报告/` 只发布目录框架，个人内容留在本地。克隆仓库包含已收录资料；npx 安装仅提供 skill、工具和目录模板，不附带题库与参考资料。
文件名不必纠结，丢到工作区根目录也会被自动归位；命名含糊时助手会先问你。
包含大作文且处于严格盲评第一阶段时，未分类文件只查看文件名／路径，待第二阶段接收或指定作答后再识别内容；第一阶段只读取已确认的题干、材料和参考范文，缺必需材料时请用户明确指定，见 `references/rulings.md` §1.17。

组织呈现默认提醒；题干明确要求分类且实际不符合时，按当前 skill 的 `references/rulings.md` §1.1 全题酌扣，最多本题总分 10%，在内容得分内处理，不与同处内容失分重复。引用题干和作答证据，仅“有条理”不触发分类扣分。
