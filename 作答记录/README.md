# 作答记录（用户本人作答）

> 本目录存放**你自己的申论作答**，是 `shenlun-judge` skill 批改的**对象**。
> 批改时 skill 会先在这里按"**年份 + 省份 + 卷型（+题号）**"找对应的作答文件；
> 对话里已贴出的作答优先，找不到时会明确告诉你"未在 `作答记录/` 找到本卷作答"。

## 一、目录规范

```text
作答记录/
├── README.md
├── 国考/                      ← 省份只写简称：国考 / 河南 / 浙江
├── 河南/
│   ├── 2022河南乡镇.txt        ← 卷ID = {四位年份}{省份}{卷型}
│   ├── 2024河南县级.txt
│   ├── 2025河南市级-v2.txt     ← 同卷多稿：卷ID 后加 -v2 / -v3
│   └── …
└── 浙江/
```

- **卷ID = `{四位年份}{省份}{卷型}`**，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`。
  与 `真题/`、`参考答案/`、`批改报告/`、`批改规范/` **共用同一套卷ID**，便于四处互相定位。
- **整卷一份**：`作答记录/{省份}/{卷ID}.txt`，文件**内部按"第X题"分块**（写 `第一大题` / `第1题` 均可，
  脚本按题切块统计字数）。
- **按题拆分**：`作答记录/{省份}/{卷ID}-第3题.md`，或按卷建子目录 `作答记录/{省份}/{卷ID}/第3题.md`。
- **同卷多稿**：`2022河南乡镇-v2.txt`、`2022河南乡镇-2稿.md` —— **不要覆盖旧稿**，批改时可对比进步。

> 完整规范（卷ID 定义、五个目录落位、材料自动归位与命名提醒）见 skill 的 `references/workspace-layout.md`（`.dsh/skills/shenlun-judge/references/workspace-layout.md`）。

## 二、格式要求（重要）

**本目录只收 `md` / `txt` 文本。**

| 格式 | 是否直接批改 | 说明 |
|---|:--:|---|
| `txt` / `md` | ✅ 直接批改 | **本目录的合法格式**，最省事，可直接统计字数、逐句语义采分 |
| `docx` / 文本型 `pdf` | ⚠ 需提取 | 非标准格式：助手会先提取文本，报告里注明"经提取，非转写"；**建议你另存为 txt/md 后放入** |
| **图片 / 扫描件**（jpg、png、webp、扫描版 pdf） | ❌ **不属于本目录的合法格式** | **请你自己先转成文本再放进来**，见下条 |

### 图像 / 扫描件：请用户先自行转成文本

1. **检测到图像时的处理**：助手在本目录（或工作区里以卷型命名的图片文件夹）发现
   `jpg` / `png` / `webp` / 扫描 pdf 时，**不会直接批改**，而是先提示你：
   - 这些是**作答**还是**试卷材料**；
   - 建议你**手动转成文本**，并给出**目标路径与建议文件名**，
     例如"请把转写文本存为 `作答记录/河南/2026河南县级.txt`"。
2. **只有在用户确认后**，助手才可能做 **OCR 转写**；转写必须遵守
   `shenlun-judge` 的转写纪律：
   - 报告开头注明"**转写稿经用户校对**"，并**附上转写稿**；
   - 报告"作答来源"一栏写明**转写方式**（如"`vision_ocr` 本地 tesseract 引擎"／
     "长图分块 `vision_long_screenshot_ocr`"）；
   - 字误须区分 **⚠ 疑似转写错误（标注存疑、不扣分，待用户确认）** 与
     **作答本身错误（按语言维度扣分）**，并列出字误清单。
3. **为什么要你自己转**：手写体 OCR 的准确率有限，转写错字会直接污染采分点判定，
   看起来像"你答错了"而其实是"机器认错了"。你自己誊录一遍最可靠。
4. **照片建议归档位置**（helper 才能按卷定位）：`作答记录/{卷ID}/1.jpg`、`2.jpg`…
   放在工作区别处的照片需要你告知是"作答"还是"试卷"。

> ⚠ **别把试卷照片和作答照片混在一起**：工作区里以卷型命名的图片文件夹如果同时含试卷材料与
> 手写作答，批改前请说明哪些是作答；否则 skill 会先向你确认，再决定 OCR 哪几张。

## 三、正文里的辅助说明

- 想写"这是第几次作答／用时多久"之类的说明，**单独写在文件开头一段**，
  以 `【说明】` 或 `【批注】` 开头（**到空行为止**）：`count_chars.py` 会自动识别并剔除，
  **不计入作答字数**（脚本会提示"已剔除 N 段说明文字"）。
- 行内标注如 `（转写存疑）`、`（此处略）` 同样不计入。
- 批改时助手会先跑 `scripts/count_chars.py`（整卷加 `--split` 一次切块）**精确统计每题字数**，
  并在报告"字数核验"块留痕，避免出现无核验来源的字数标注。

## 五、批改时会发生什么

1. skill 读取本目录文件 → 按题切块 → 跑 `scripts/count_chars.py` **精确统计每题字数**；
2. 先查 `批改规范/{省份}/{卷ID}-批改规范.md`——**该卷有规范就必须引用，大作文规范必须逐条对照使用**
   （档次标准、分档区间、硬性要求与禁止性口径）；
3. 逐条做**语义采分**（核心动作｜核心对象｜关键限定/结果）；大作文按"档位锚定 → 硬伤修正 →
   档内定位（上/中/下三小档）"划档赋分；
4. 报告落盘到 `批改报告/{省份}/{卷ID}-批改报告.md`，并给出**建议区间 + 评分置信度**；
5. 若 `参考答案/{省份}/{卷ID}/` 里有同卷参考答案，会用它做**经验校准**并登记来源
   （**来源独立且覆盖本题**时可校准到"高"；同源多份只算一份，一般只能到"中"）。
