# 作答记录/

## 放什么

你自己手写/机打的申论答案，也就是要被批改的对象。

## 目录与命名

```
作答记录/{省份}/{卷ID}.txt
```

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略
- 整卷写在一份文件里即可，按题分段；也可以按题拆成 `第1题.txt`、`第2题.txt`

示例：

```
作答记录/河南/2022河南乡镇.txt
作答记录/国考/2026国考行政执法.txt
```

## 多稿（同一套卷写第二遍）

- 第二稿、第三稿追加版本号：`作答记录/河南/2022河南乡镇-v2.txt`
- 版本号只递增，**不要用日期命名**，否则同卷的稿子排不出先后
- 助手会自动取最新一稿批改，也可以明确说「批改 v2」

## 格式

- **只收 `md` / `txt`**（纯文本，便于逐字统计字数、核对采分点）
- 图片、照片、`docx`、`pdf` 请自己先转成文本再放进来
- 手写稿建议直接照抄成文本，批改时助手会看字数和语言，转写质量会影响批改结果
