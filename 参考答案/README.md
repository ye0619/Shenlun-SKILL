# 参考答案（L4 经验校准，非官方）

> 本目录存放各卷的**真题参考答案 / 机构解析 / 名师口径汇编**，供 `shenlun-judge` skill
> 批改时做**经验校准（L4）**：校准采分点粒度、同义表述的宽严尺度、公文格式尺度、
> 大作文立意梯度，并据此决定该次批改的**评分置信度**。
>
> ⚠ **定位说明**：这里的答案**不是官方标准答案**（申论官方阅卷细则与采分表通常不公开）。
> 批改时它只作校准，**与题面作答要求（L1）冲突时以题面为准**；报告里必须登记
> 文件名 / 来源 / 年份，并写明"参考口径，非官方"。
> 规范细则见 `.dsh/skills/shenlun-judge/references/reference-answers.md`。
>
> **文件级命名已于 2026 年统一**（原 `国考答案/`→`国考/`、`河南省考答案/`→`河南/`，
> 卷目录去掉"年/卷"字并统一为 `{卷ID}`，答案文件由 `第一题.txt` 改为 `第1题.txt`，
> 共重命名 33 个目录 + 133 个文件）。

## 一、目录规范

```text
参考答案/
├── README.md
├── 国考/                      ← 省份只写简称：国考 / 河南 / 浙江
│   ├── 2018国考副省级/         ← 卷ID = {四位年份}{省份}{卷型}
│   │   ├── 第1题.txt           ← 题号用阿拉伯数字
│   │   ├── 第2题.txt
│   │   └── …
│   └── 2026国考行政执法/
└── 河南/
    ├── 2022河南乡镇/
    └── 2026河南市级/
```

- **卷ID = `{四位年份}{省份}{卷型}`**，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`。
- **省份**只写简称：`国考` / `河南` / `浙江`（与 `真题/`、`作答记录/`、`批改报告/`、`批改规范/` 共用同一套卷ID）。
- **卷型**：`副省级` / `地市级` / `行政执法` / `县级` / `乡镇` / `市级` / `A` / `B` / `C`；无分卷则省略。
- **答案文件**：`第N题.txt`（N 用阿拉伯数字，1–5；不要写"第一题"）。一题一文件，
  文件内可并列**多家机构/名师口径**，用 `**粉笔**`、`站长`、`某笔：` 等标签分隔。

> 完整规范（卷ID 定义、五个目录落位、材料自动归位与命名提醒）见 skill 的 `references/workspace-layout.md`（`.dsh/skills/shenlun-judge/references/workspace-layout.md`）。

| 浙江卷 | **0** | `真题/浙江/` 有官方 PDF（含 A/B/C 卷），但本目录**尚无浙江参考答案**（缺口，见第六节） |

**读法**：一个 `第N题.txt` 里通常并列**多家机构/名师口径**。批改时把"多口径的交集"
当作高置信采分点，把"只有一家讲到的"当作可选点，**口径之间的归属差异一律不加减分**（见第五节）。

> **参考答案数量多 ≠ 评分置信度高。** 本目录只提高**采样与校准**的可靠程度：
> - **来源独立、覆盖本题**的参考答案可用于交叉验证采分点与档位边界 → 评分置信度可到"高"；
> - **同一来源的多份只算一份**（如某一家机构的 5 道题口径）→ 一般只能到"中"；
> - 完全没有 → 只能按 L3 模拟重构采分点，置信度为"中/低"。
>
> 它**不会**把 L3/L4 抬成官方标准，也**不会**因为"这里有 10 家机构答案"就让一份作答多得分。
> 判定条件见 `.dsh/skills/shenlun-judge/references/scoring-standards.md` 0.4。

## 四、格式优先级与文件头

- 格式优先级：**md / txt ＞ docx ＞ pdf ＞ 图片**（md/txt 可直接读取并核验字数）。
- 建议在每个 `第N题.txt` 文件头写清：**题面原文（L1）＋ 来源（真题参考答案／某机构解析／网友回忆）＋ 年份 ＋ 覆盖题目**。
  文件头写清来源的，批改时可直接在报告"评分依据声明"里按原文登记。

## 五、使用边界与口径分歧（批改前必读）

1. **一律作 L4 校准，不作品分依据本身**：报告中须登记文件名与来源，写明"参考口径，非官方"；
   与题面作答要求（L1）冲突时**以题面为准**。
2. **口径分歧不加减分**（已留痕的四处典型分歧）：
   - 2022 河南乡镇卷第2题："一组一会／红色物业"的归属（粉笔归"小切口"、飞扬归"铁脚板"）；
   - 2023 河南市级卷第2题："中科院研究中心"归类（中公／华图归"服务员"、站长／半月谈／粉笔归"推车手"）、
     第3题层次划分（粉笔按"竞争力／供应链／市场布局"、华图按"企业／政府／物流"、中公按"企业／政府／环境"）；
   - 2024 河南市级卷第1题：称呼与落款写法（仅华图、王鹍写全，其余只写标题）、
     第2题"合规指导"归属（多归 W 市全产业链，亦有并入 S 市上市服务者）；
   - **2024 河南县级卷**：第1题分栏方式（某笔／岭南贡院按"企业＋政府"两主体，某图按"渠道／管理／技能／激励"四要素，
     某公另立"党建引领"一条）；第2题组织方式（多数按"空间／文化空间／体系／设施"四层，
     逸学公考把"儿童友好博览会"单列、并把题干总括句写成要点，属机构答案瑕疵）；
     第3题层次划分（某笔／某图／某公／超格李崇立为"释义＋问题＋对策"，飞扬只列"表态＋六项表现＋同理心"，
     小马哥另设独立对策层）；第4题立意与取材（6 家范文均含"硬设施＋软服务＋多方参与"，
     但**四海飞扬老师为唯一"素材外迁型"**，分论点取材凤凰古镇／社区食堂／口袋公园／托育中心等材料外场景，
     且 6 家均未使用"绿化带隔离栅栏三方分歧"这一材料内部争议性素材）。
3. **机构范文不等于满分模板**：机构答案的长处是采分点覆盖广、语言凝练；短处是
   **不天然满足考场约束**（常见超字数）与**不必然切中本卷材料的独特落点**。
   实例：2026 国考行政执法卷的粉笔口径在本 skill 口径下得 **79.5/100**
   （小题稳、大作文仅 23/35 落二类下沿），第1、2 题还各超字数 2–3 字。
   **不得把机构范文整段照抄为"示例答案"**（示例答案须自行重组并跑 `count_chars.py` 核验）。
4. **大作文类答案只作立意梯度与详略校准**：不设"某篇范文＝一类文＝某分"的锚点
   （见 `.dsh/skills/shenlun-judge/references/scoring-standards.md` 三.1 与 `essay-judging.md` 第四节）。
5. **优先级低于 `批改规范/`**：若该卷在 `批改规范/{省份}/` 下有批改规范（尤其是大作文规范），
   批改时**优先引用规范**（大作文规范必须逐条对照使用），本目录的参考答案只在其后作校准。
   若该卷规范被判定为**官方公开**来源，其等级（L1/L2）**高于**本目录的 L4，
   两者冲突时以规范为准（最终仍以题面 L1 为准），并在报告中一并说明。

## 七、新增答案怎么放

1. **直接丢到工作区根目录或本目录下即可**，不必自己建目录、改文件名——助手会按命名规范
   自动归位到 `参考答案/{省份}/{卷ID}/第N题.txt`，并同步更新本 README 第三节的登记表。
2. **命名含糊时会先问你**：只写"河南卷""某年真题""参考答案1"这类无法定位年份／卷型的信息时，
   助手会先确认"这是哪一年、哪个省份、哪一卷、第几题"，**确认后才归位**，不猜。
3. 归位后助手会：① 在第三节对应行补登记（来源标签、题号覆盖、备注）；
   ② 若该卷有历史批改报告，在报告"评分依据声明"的 L4 条目同步补登记；
   ③ 判分时据"有无对应参考口径"决定**评分置信度**（有 → 可到"高"；无 → 一般为"中/低"）。
