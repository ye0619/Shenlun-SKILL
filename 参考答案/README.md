# 参考答案/

## 放什么

真题的参考答案、机构解析、老师讲义、你自己整理的答案要点。

**注意：这里的东西都不是官方阅卷标准。** 批改时它只作为「经验校准」使用，
与题面作答要求、考试大纲等公开要求冲突时，一律以公开要求为准。

**它还是「试批改标定」的材料**：批改答卷之前，助手会先拿这些答案**自己试批改一遍**
（逐份核对"命中／漏写／多写／表述方式／舍弃了什么"），从**共同点／差异点／边界情况**
生成本题《动态评分规范》，**然后才批改**——即"**先标定，后评分**"。
**同一题最好放 ≥2 家不同来源的答案**（同一机构的不同答案各算 1 家；同源转抄只算 1 家）；
只有 1 家时不做标定，助手会在报告里说明"依据为通用评分规则"。

## 目录与命名

```
参考答案/{省份}/{卷ID}/第N题.txt
```

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略
- 每题一个文件：`第1题.txt`、`第2题.txt`……

示例：

```
参考答案/河南/2022河南乡镇/第1题.txt
参考答案/河南/2022河南乡镇/第2题.txt
参考答案/国考/2026国考行政执法/第3题.txt
```

## 格式

- 优先 `md` / `txt`，助手可以直接读取
- `docx` / `pdf` / 图片请自己先转成文本再放进来
- 文件名不必纠结：放到工作区根目录或本目录都行，助手会按规范自动归位重命名，
  命名含糊时会先问你

## 提醒

机构解析仅供参考，不必照抄；本目录内容有版权，不要公开传播。
