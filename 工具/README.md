# 工具/

这个目录放 **skill 的配套脚本**（skill 的文档按**固定路径**调用它们，**请不要改名或移动**）：

| 脚本 | 干什么 | 典型命令 |
|---|---|---|
| `count_chars.py` | **单块字数统计**（答题卡口径：含标点，不含空格换行）。**示例答案/参考范文的标注字数必须由它产出** | `python 工具/count_chars.py 作文.txt --limit 1000 --approx` |
| **`卷面核验.py`** | **整卷字数一次过核验**（把整份作答按题切块 → 一屏 ASCII 表格 → 达标/超限判定）。**批改用户作答时用这个，不要再用"写临时文件＋反复跑 count_chars"那套** | `python 工具/卷面核验.py 作答记录/浙江/2019浙江A.txt --spec "1:300,2:300,3:300,4:approx1000" --md 批改报告/.字数核验/2019浙江A-字数.md` |
| **`split_reference.py`** | **参考答案汇总件按题拆分**（一次调用切出 `第N题.txt`；**只新增、不动源件**，已存在默认跳过） | `python 工具/split_reference.py "参考答案/浙江/2026浙江B/.原始件/x.md" --outdir "参考答案/浙江/2026浙江B"` |
| `ref_independence.py` | **参考答案同源检测**：对同一题的多个参考答案两两算文本重合率并分组，输出**独立来源家数**（＝分组数），供"小题采分点共识模型"判"几家独立" | `python 工具/ref_independence.py 参考答案/河南/2022河南乡镇 --question 1` |
| **`卷级一致性检查.py`** | 逐题检查报告内采分点、共识表、参考答案、作文刻度表、范文逐篇数值评分、论点表及入选全文栏目；同时核对条件必建过程文件、字数留痕和登记 | `python 工具/卷级一致性检查.py --paper 2019国考地市级 --questions 1,2 --essay 0 --reference-questions 1,2` |

- 五个脚本都是 **Python 3 标准库实现、零第三方依赖**，各带 `--selftest` 自检：
  `python 工具/count_chars.py --selftest`、`python 工具/卷面核验.py --selftest`、
  `python 工具/split_reference.py --selftest`、`python 工具/ref_independence.py --selftest`、
  `python 工具/卷级一致性检查.py --selftest`。
- **卷级收尾必跑**：按下方“条件建档检查”传入本次范围与已核实条件；退出码 1＝报告正文缺项或条件必建缺件，2＝条件未核实或参数错误，0＝结构齐备且条件已确认（一般提示按需处理）。
- **分题标号只认"第X题/第X大题"**（含 `## 第一题`、`**第二题**`、`答题纸 第一大题`）。作答文件若用"一、城市照明整治对策"式标题，`卷面核验.py` 现在会输出 `WHOLE` 行、判定 `NA`、stderr 给 WARNING 并返回**退出码 4**——**不可把它读成"第 1 题超额上千字"**；把分题标题改成"第一题"式（**副本即可、正文一字不动**）后重跑即可。（2026-10-21 修复：旧版在无法切块时**静默**把整篇当第 1 题并套用第 1 题上限，实测把 2026国考副省级整卷 1398 字误报为"Q1 超额 1148 字"。）
- **省 token 纪律（2026-09-27 实测后新增）**：这三件事**各只允许一次调用**——
  整卷字数 → `卷面核验.py`（一次出表，`--md` 直接产出报告块）；
  汇总件拆题 → `split_reference.py`；同源家数 → `ref_independence.py`。
  **禁止**写 `.dsh/_*.txt` 临时件再回读、**禁止**为一次拆分现写 `.py` 脚本
  （历史实测：单卷因此多花 ≈12 步、约 1.5 万 output tokens）。
- **控制台中文会乱码**：`卷面核验.py` / `split_reference.py` 的屏幕输出**刻意只用 ASCII**
  （写进文件的中文走 `--md`）；`count_chars.py` 的结论行含中文，若显示乱码，
  加 `--json` 读结构化结果，不要靠"再跑一遍"来确认。
- **口径纪律**：`ref_independence.py` 的相似度**只用于参考答案之间判同源**，
  **不参与给分**（给分看语义，不看文本相似度）；阈值 `--same 0.80` / `--near 0.60` 属经验口径。
- **同源检测诊断参数**：`--question`／`--same`／`--near`／
  `--min-chars`／`--json`／`--quiet`／`--no-split`／`--sensitivity`／`--no-autojunk`／`--selftest`。
- **来源覆盖须回读原文核对**：逐份核对后若发现某点实际有来源提及，应更正共识记录；计分依 `references/rulings.md` §1.2，不能从来源家数直接定价，建档条件见 §1.3。
- **家数采信条件（硬性）**："独立来源家数"只有在**同时跑了 `--sensitivity`**、
  **输出无 ⚠ 告警**、且**临界相似度（0.55–0.65）与长度离群（字数比 >3 倍）已人工复核**时，
  才可直接采信；否则一律按 `small-questions.md` 第四节第 3 节的**四条复核硬规则**
  人工复核后登记，**不得只抄一个家数**。
- **三条已知边界**（判读结论时必须知悉）：
  1. **`SequenceMatcher` 的长度稀释**：短文本照抄长原文时 ratio 会被长度拉低
     （100 字节选照抄 1000 字原文，ratio 可能只有 0.18）→ 可能把同源判成"独立"，
     须人工复核字数比；
  2. **并查集传递串联**：A≈B、B≈C 会把 A、C 并入同组（即使 A 与 C 并不像），
     组会越滚越大 → 家数可能少算，临界情形须跑 `--sensitivity` 看稳定性；
  3. **`autojunk` 对长文本的影响**：difflib 默认把长文本中的高频字符当"垃圾元素"，
     长文本相似度可能被推高或压低 → 用 `--no-autojunk` 交叉验证结论稳不稳。
- **脚本不可用时如实标明来源关系未核实**：不得把未知写成零家，不因来源未知降低点值，也不虚构确定的独立来源数；按 `references/rulings.md` §1.2 和运行兼容说明处理。已有可用参考答案但同源未明，不等于“无参考答案”，不能据此豁免条件必建的共识表。
- **切分口径的两条硬规则（2026-09 修订，修正两处实测误判）**：
  1. **H1（`# …`）不认白名单外的名字**：参考答案文件里 H1 通常是**范文/公文标题**
     （如 `# 做隐形冠军`），一旦误认，就会把整篇范文切成两个条目、并让紧随其后的机构名
     变成"0 字空条目"。机构标签的惯例是 H2–H6（`## 粉笔`／`### 站长`）；
     **H1 只认括号包裹的未知名字**（`# 【先声夺人】`）。实测：2018 浙江 A 第 3 题
     原报"3 家 + 1 空条目"，修正后为 **5 家**。
  2. **剥掉"另一份答案"式的尾部括号限定**：`中公（参考答案 1）`＝`中公`、`华图【答案二】`＝`华图`；
     但 `粉笔（某笔）` 这类**别名不剥**（那是另一条产品线）。实测：同上题，
     两条中公答案原被并成 1 条，修正后各计 1 家。
  ⚠ 若你的答案文件用 `# 粉笔` 这种 H1 写机构名，请改成 `## 粉笔`（或用 `--no-split`）。
  自检含**回归用例**（`--selftest` 的"自检10"专测这两条），共 10 项。
- 用 `npx` 安装时，安装器会自动把本目录放到你工作区的 `工具/` 下；
  清空或删掉本目录会导致"字数核验""同源检测""汇总件拆题"不可用（重新安装即可恢复）。
- 你可以打开这几个脚本查看逻辑，也欢迎按自己的需要改；但改了以后记得同步 `README.md` 里
  对命令的说明（`.dsh/skills/shenlun-judge/references/word-count.md`、
  `references/reference-answers.md` 与 `references/small-questions.md` 第四节都引用了这里的命令）。

## `卷级一致性检查.py` 条件建档检查

唯一建档规则见 skill 的 `references/rulings.md` §1.3。助手先核实本次范围与材料条件，再调用脚本；不用整卷旧缓存推断本次题号，不默认最后一题是大作文。用户不需要手填命令参数。

- `--questions 1,2,3`：本次实际批改题号；不传时只尝试读取选中报告的题标题，不能从旧规范反推。
- `--essay N`：已核实的大作文题号；本次无大作文填 `--essay 0`。本次题号不含该题时免建大作文文件。
- `--reference-questions 1,2`：本次有可用参考答案的小题／公文题号（仅一家也算有）；无则传 `--reference-questions none`。此参数不包含大作文，范文另行声明。
- `--exemplars available` 或 `--exemplars none`：本次大作文是否有可用完整可比范文，含符合条件并标明局限的异题弱参照；不能只因存在题目文件就认定有完整范文。本次包含大作文时即须核实，不受题量豁免影响。
- `--sample-essay available` 或 `--sample-essay none`：本卷参考答案中是否有可照录的同题、完整、可追溯范文；与比较参照分别核实。本次包含大作文时须显式传入，未核实保持 `unknown`（默认值），退出码 2；已确认有本题示例候选时须先预评分并纳入参照，因此不能同时声明 `--exemplars none`。
- `--report "批改报告/…-批改报告.md"`：选择本次报告，显式指定优先；未传时在同卷基础报告、规范命名的 `…-批改报告-v2.md`／`v3.md` 与兼容的旧式 `…-v2-批改报告.md` 中，按修改时间取最新文件，不按版本号大小选择。重批建议显式传入，避免读取其他版本；相似卷ID的报告不作为本卷候选。
- `--no-counts`：跳过来源声明与同源工具输出的交叉核对，不跳过必建文件检查；同源工具输出是机器估计，不是确定的来源身份。

本次仅 1—2 题免独立过程文件；3 题及以上按条件检查动态规范、共识表和刻度。共识表支持合卷表 `批改报告/.采分点共识/{卷ID}-共识表-全卷.md`（用 `## 第N题` 标题覆盖相关题号）或分题表 `{卷ID}-第N题-共识表.md`，允许两者组合；旧合卷表只含其他题不算覆盖本题。空的必建文件不算完成记录。

**报告正文检查不受题量豁免影响**（`rulings.md` §1.3.1）：即使只批1题，也要显式传题型、参考答案及适用范文条件。报告采用 `report-template.md` 的题目与栏目层级、固定列名；小题／公文含“采分点表”“参考答案共识表”“参考答案”，大作文含“大作文刻度表”“范文逐篇评分”“论点表”“示例范文”。表格须有实质数据行，代码块示例、HTML注释、占位、附件链接不能替代。

论点表按 `rulings.md` §1.19 核验：表头严格依次为“来源、题目、总论点、分论点1、分论点2、分论点3”，更多分论点连续增加列，不得漏号；每格有实质内容，较少者写明“无（本篇仅N个分论点）”。来源写“F1 · 来源”，ID及来源须与本题刻度和逐篇评分表逐篇对应，不新增前置ID列。工具核结构、单元格与对应覆盖，标题真实性、论点提炼是否忠实及分论点是否漏提仍须人工回源核对。
ID和来源比较忽略行内代码、粗体、强调的排版标记，按实际文字核对；代码内的下划线或星号等字面字符保留，真实来源或ID变化、漏篇及归一化后重复的ID仍报错。示例全文标注的范文ID适用相同排版处理。

刻度与评分表范文ID唯一且来源一一对应，刻度表另须有“参照类型”“原题依据”“可比与不可比维度”列；参照类型填“同题”或“异题弱参照”，原题依据登记可追溯的原题、材料及满分出处。每篇数值使用 `32/40` 或有据的区间 `30–32/40`，逐篇须在0至自身满分内，允许各篇满分不同，不缩放原题分数。工具只核字段及数值完整性；原题是否匹配、分母是否真实、可比范围是否合理须回源核对。有合格示例候选时所选全文写 `- 范文ID：F1`（ID不含空格），须属于两表且刻度表参照类型为“同题”。无可用参考答案时共识栏目写 `- 状态：无可用参考答案`；无可比范文时三张范文表分别写 `- 状态：无可用完整可比范文`；无可照录的本题示例全文时示例栏目另写 `- 状态：无可照录的本题完整范文`。每项缺失说明均须有 `- 已检查：实际路径`、`- 原因：具体原因`；不能相互代替，也不能在条件未核实时按无材料跳过。有参照、无示例全文时，三张表仍须正常展示。

检查只验证结构与数值完整性，不能验证材料真伪、所有候选是否收齐、评分合理性或范文全文是否完整；这些仍须回原文复核。旧报告不会自动改写，按当前要求检查时可能报缺项，应另存新版。
允许不同满分针对各自原题的异题弱参照；同题范文使用本题满分，工具仍核对同题候选之间的分母一致性，不因允许异题参照而放宽同题满分错配。

考生作文的“档内定位表”按 `report-template.md` 第二节人工核对五项作答原文、表现与定位理由；当前工具尚不自动检查该表，不能因工具通过就认定该表齐全。四类文保留五项证据，但不细分小档。

含 `<!-- shenlun-rule-status: superseded -->` 标记的旧规范已过期，即使文件存在且非空也判为须重建；仅在本次达到对应建档条件时要求补齐，不取消 1—2 题免建。重建并核对现行点位／子项／分值理由后才能移除标记，历史考生得分不自动重算。

```text
python 工具/卷级一致性检查.py --paper 2023浙江C --province 浙江 --questions 1,2,3 --essay 3 --reference-questions 1,2 --exemplars available --sample-essay available
python 工具/卷级一致性检查.py --paper 2023浙江C --province 浙江 --questions 3 --essay 3 --reference-questions none --exemplars available --sample-essay none
python 工具/卷级一致性检查.py --paper 2023浙江C --province 浙江 --questions 1,2 --essay 0 --reference-questions 1,2
python 工具/卷级一致性检查.py --paper 2099国考示例 --questions 1,2,3 --essay 0 --reference-questions none
```

报告、登记和适用字数留痕的要求不因过程文件豁免而取消。`--json` 的 `results` 区分 `skip`（条件豁免）与 `unknown`（条件未核实）；`unverified` 非空时 `ok` 为 false、退出码 2，不把未知当成无材料。`--selftest` 覆盖少量题、无作文、无参考、无范文、必建缺件、合卷／分题覆盖、空文件、报告版本选择与三种退出码。

## `lint_rulings.py`（**维护用**：已废止口径残留检查）

> ⚠ 本节这个脚本**不是**批改流程的四个配套脚本之一，**skill 文档不调用它**，也不参与批改；
> 它是 **skill 维护工具**（体检报告 2026-10-03 第六节第 3 条提出）。

**用途**：改完 skill 后跑一次，检出**已废止口径特征串的残留**（例如旧字数弹性"±10%"、
旧三池比例"60–70"、旧"0 家点三层口径"、旧分值池取值"3＋3＋4"、过期体积标注"119 KB"……），
把过去靠人工专项写《冲突检测报告》的做法变成**一条命令的例行检查**。

**用法**：

```bash
python 工具/lint_rulings.py                        # 扫默认三处：skill 本体 / templates/workspace / 批改规范
python 工具/lint_rulings.py --root <目录>           # 只扫指定目录（可多次指定，覆盖默认）
python 工具/lint_rulings.py --show-suppressed      # 连"废止说明上下文"里的命中也列出来
python 工具/lint_rulings.py --json                 # 机器可读（落盘留痕）
python 工具/lint_rulings.py --selftest             # 自检
```

- **扫描范围**：`--root` 指定的目录（默认：`.dsh/skills/shenlun-judge`，仅有 Codex 时用 `.agents/skills/shenlun-judge`；另扫 `templates/workspace`、
  `批改规范`，**存在才扫**），递归、只扫 `*.md`。
- **允许上下文（自动忽略，共四类）**——命中记为**已忽略**（默认不报、不计入残留数）：
  1. 命中行**本身或它的前一行**含
     `已废｜废止｜⛔｜~~｜修订记录｜补注｜修正｜历史｜旧口径｜被取代｜2026-09-19｜2026-09-22｜2026-09-25｜2026-09-27`
     （`~~` 计入：Markdown 删除线＝该段被废止）；
  2. 命中行的**后 1–3 行**含 `补注｜修正`（例：紧跟其后的"（2026-10-03 补注：…）"）；
  3. 命中行含"旧→新"对照（`→`）且其**紧邻上一段**是 `**2026-xx-xx …修订…**` 批次标题
     （中间最多隔 2 个空行）——只认这种极窄形态：**光有批次标题不豁免，仍须本行含 `→` 对照**，
     且不许跨正文段落；
  4. **误报豁免（负向上下文，只作用于 L05／L11）**：命中行本身就是在**禁止这件事**
     （含 `不得再写｜禁止｜不得｜禁用话术｜⛔`）或**描述性/引用性**地使用该旧措辞
     （含 `不空喊口号｜正面描述｜描述性用法｜解释性引用｜引用性`）时不报——
     真残留行内没有这些标志（如 `不合格＝空喊口号、…`），照旧报出。
- **输出**：`<相对路径>:<行号>: [L07] <说明> :: <行内容（截断 100 字符）>`，
  结尾一行统计 `残留 N 项；已忽略（废止说明／误报豁免）M 项`；
  `--show-suppressed` 时每条忽略项后附**忽略理由**（如 `<忽略：后 2 行注记（「补注」）>`）。
- **`--json`**：`residues`／`suppressed`／`counts`／`roots` 与条目键
  （`file`／`line`／`rule`／`desc`／`text`／`suppressed_by`）**保持不变**；
  `suppressed` 条目**新增** `reason`（一句话说明为何忽略）。
- **`--selftest`**：逐项打印 `OK｜FAIL`——规则命中、本行/前一行/后 1–3 行忽略、
  `~~` 删除线、批次标题＋旧→新对照、L05／L11 负向豁免、**真残留必须报出**（两条 L11 ＋ 一条 L05），
  外加三条"不得过度豁免"的反向控制项（批次标题无 `→`、`→` 无批次标题、后 3 行无注记）。

**退出码**：`0` ＝ 无残留；`1` ＝ **有残留**（需人工确认：这些旧句是否缺少废止标注）；
`2` ＝ 参数错误。

**什么时候跑**：① **每次修订 skill／templates 之后**（提交前）；② 发布 npm 包前；
③ 排查"某处口径不一致"时先跑一遍缩小范围。**有残留不等于错**——先看它是否只是缺少废止标注，
确认是真残留再改写为现行口径。
