# 批改报告（登记表）

> 本目录存放历次申论批改报告的 **md 母本**（同名 pdf 为打印/导出件），
> 以及 `.字数核验/` 里的**字数核验留痕**。
>
> **命名规则**：`批改报告/{省份}/{卷ID}-批改报告.md`，同名 pdf 共用同一基名；
> **同卷多次批改**追加版本号 `-v2`、`-v3`（追加在**卷ID 之后**、`-批改报告` 之前），
> **不覆盖旧报告**，便于对比追踪。
> 例：`批改报告/河南/2022河南乡镇-批改报告.md`（**实存**）、
> `批改报告/河南/2022河南乡镇-v2-批改报告.md`（**命名示例，本卷尚未有 v2**）。
>
> **卷ID = `{四位年份}{省份}{卷型}`**，与 `真题/`、`参考答案/`、`作答记录/`、`批改规范/` 共用同一套ID。
>
> 完整规范（卷ID 定义、五个目录落位、材料自动归位与命名提醒）见 skill 的 `references/workspace-layout.md`（`.dsh/skills/shenlun-judge/references/workspace-layout.md`）。
>
> **新报告的必备项**（规范见 `.dsh/skills/shenlun-judge/SKILL.md` 9.1/9.2）：
> ① 每题**建议区间 + 评分置信度（高/中/低 + 理由）**——置信度是**采样与校准**的置信度，
>    **不是参考材料数量的函数**：要"来源独立且覆盖本题"才算高，同源多份只算一份；
> ② "评分依据声明"写全 **L1 官方公开要求 / L2 公开描述 / L3 模拟口径 / L4 经验校准**四层；
> ③ **该卷批改规范必须查、有就必须引用**：`批改规范/{省份}/{卷ID}-批改规范.md` 与
>    `{卷ID}-大作文批改规范.md`（大作文规范**必须逐条对照使用**），登记**文件名 + 来源 +
>    年份 + 层级判定**；无则写"未找到该卷批改规范"；
> ④ L4 须登记 `参考答案/` 的文件名与来源（无则写"未找到参考答案"）；
> ⑤ **作答来源**须写明（对话作答 / `作答记录/{省份}/{卷ID}.txt`，含是否经 OCR 转写及转写方式）；
> ⑥ 小题用**语义采分**（核心动作｜核心对象｜关键限定/结果）核对，不使用覆盖率阈值；
> ⑦ 大作文按"**档位锚定 → 硬伤修正 → 档内定位（上/中/下三小档）**"赋分，
>    **不写"创新加分"**、不做 ±1/±0.5 机械加减；
> ⑧ **字数核验块**（脚本统计值 / 题目要求 / 占比 / 结论）+ 核验命令，示例答案文本存 `.字数核验/`。
>
> 下方**历史报告（v1 系列）保留当时的计分口径原文**，属留痕，**不作追溯性改写**；
> 其中原有的旧路径写法已在 2026 年统一命名时**同步更正为现行路径**（改动仅限路径，判分内容未动）。

## 二、`.字数核验/` 留痕（文件名保持历史原样）

`批改报告/.字数核验/` 存放**示例答案文本、字数核验命令输出与扫描脚本**，用于使报告里的
字数标注**可复核、可追溯**（禁止出现无核验来源的示例答案字数标注）。

**⚠ 该目录下的文件名一律保持历史原样，不做规范化改名。**
原因：历史批改报告在正文里**逐字记录了当时的核验命令与文件名**
（如 `python scripts/count_chars.py .字数核验/2022河南乡镇卷-第一题示例答案.txt --limit 300`），
一旦改名，报告里记录的命令就会指向不存在的文件，**字数核验将失去可追溯性**。
因此该目录保留 `2022河南乡镇卷-…`、`2023hn-xianji-…`、`2026gk-xzf-…` 等**旧写法与缩写**，
它们与现行 `{卷ID}` 命名**并存但不冲突**（该目录不参与按卷ID 的匹配）。

目录内容（共 42 个文件）：

| 类别 | 文件（示例） | 说明 |

| 示例答案文本 | `2022河南乡镇卷-第一题示例答案.txt`、`2023hn-xianji-第1题示例答案.txt`、`2023河南市级卷-第二题示例答案.txt`、`2024河南县级卷-第三题示例答案.txt`、`2024河南市级卷-第四题正文.txt`、`2026gk-xzf-第5题标题.txt`、`2025hn-xianji-第1—5题示例答案.txt` 等 | 供 `count_chars.py` 核验的纯文本；标题/正文分开存放的（如大作文）按原样保留 |
