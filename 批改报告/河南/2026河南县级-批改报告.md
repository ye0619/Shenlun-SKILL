## 第一题（20 分）词句理解——"我为你做了什么 / 我们一起成就了什么"：**16 分**

**踩点核对**

| 采分点 | 作答判定 |
|--------|:--------:|
| 总括解读：价值不止于单向付出，更在共创共成 | ✓ |
| 小君：提供技术、鼓励自创、众星拱月格局 | ✓ |
| 小然：老屋→陶艺馆；村民参与、闲置资源变产品、返乡就业 | ✓ |
| 观念转变、自发参与（关停养殖场、改造池塘） | ✓ |
| 小宁：进士文化研学 + 共创中心 + 规模效应 | △（笔误） |
| 效果意义：带动就业、自豪感荣誉感 | ✓ |
| 深层对比：单向"为你做"的局限 vs"一起成就"的内生价值 | ✗ 未展开 |
| 总结升华 / 启示收尾 | ✗ 缺失 |

**扣分证据（引用原文）**
1. "再以**共享中新**为枢纽设计文旅动线"——材料原文为"**共创中心**"，用词错误（-1）；
2. 总括只复述"不仅……更要……"，未解释"我为你做了什么"（单向输血、村民被动）为何不如"我们一起成就了什么"（双向激发、内生动力），理解停在表面（-2）；
3. 结尾在"自豪感和荣誉感"处收住，无总结升华（-1）。

**改进**：加"表层→深层"分析层；结尾补共创共享对乡村振兴/内生动力的意义；校对"共创中心"。

## 第二题（20 分）——B 区如何实现"宽而有制，从容以和"：**16 分**

**踩点核对**

| 采分点 | 判定 |
|--------|:----:|
| 理念定调：不是"随便摆"、不是"禁摆"一刀切，合规找平衡 | ✓ |
| 试点 + 线上申报系统，申请→审核→许可（自下而上） | ✓ |
| 柔性审核：不影响交通、不扰民即尽量满足 | ✓ |
| 商户自律 + 约束：每月 2 次自检照片、抽查、3 次违规取消 | ✓ |
| 多部门方案 + 多角度研判（居民/业态/就业/经济活力） | △ 角度空洞 |
| 听取民意（占道、音量 → 区域与音量约束） | △ 半覆盖 |
| 整合资源、做好"一件事"服务 | ✗ 漏 |
| 一街一策、全区逐步推广 | ✓ |

**扣分证据**
1. 第 1 点概括虚："快速行动、及时探讨"非材料词，未落出"对街道社区/居民有利、激发业态、促进就业、提升经济活力"角度（-2）；
2. 漏"整合相关资源，做好'一件事'服务"（-1.5）；
3. 民意回应不完整：老年居民对占道、音量的意见对应"规定区域、控制音量"，只写了"不扰民"（-0.5）。

**改进**：第 1 点补研判角度；补"一件事"集成服务；民意听取与音量约束单独成点。

## 第三题（25 分）——北城街道经验发言提纲：**18 分**

**核对**
- ✓ 标题 + 总起定位（"物业+政务"、打破藩篱）
- ✓ 一、一站式政务智能终端进小区（领域覆盖较全）
- ✓ 二、片区式管理 + 公共收益街道把关
- △ 三、物业管家兼网格员：写了培训班 + 补贴，漏核心机制——"亮明网格员身份、联合居委会启动'惠·议厅'议事机制调解矛盾"（黄大爷渗水案）
- ✓ 四、养老"六助"（24 小时随叫随到）
- ✓ 五、居民合作社 / 主理人

**扣分证据**
1. 网格员段漏"惠·议厅"议事调解机制与"亮明身份协助政务"（-3，重点经验缺失）；
2. 公共收益漏正面功能"反哺小区软硬件建设或改善居民生活"（-1.5）；
3. 缺成效收束"小事不出社区、大事有人帮办"（-1.5）；
4. 开头未点"最后一百米"堵点背景（-1）。

**改进**：第三点补议事调解机制；公共收益补"反哺"；结尾用"小事不出社区、大事有人帮办"收束。

## 第四题（35 分）大作文《社区发展需以人为本》：**26 分，二类文**

### 一、立意判定：切题
题干三层次（呼应人的需求 → 焕发人的价值 → 社区持续生长的内在力量）被准确译为中心论点：
"社区发展应回应人的需求，激发每个人的价值，做到以人为本"，以党的二十大"人的现代化"
为理论支点。标题、首段、结尾一致 ✓。

### 二、四维划档

| 维度 | 得分率 | 判定 | 证据 |
|------|:------:|------|------|
| 题意 | 0.75 | 明确欠深刻 | 分论点②"服务员"对"呼应需求"、③"引路人"对"焕发价值"扣题；未深入"为何人的参与能生成持续生长的内在力量"；①"思想风向标"与主线扣合偏弱 |
| 内容 | 0.70 | 较充实欠厚 | 论据全来自材料且能跨材料迁移（香湖电梯/公益基金/陶家村池塘/B区外摆）；"联系实际"近空白——除"党的二十大"外无自身积累案例 |
| 结构 | 0.85 | 严谨 | 开头 + 三并列分论点 + 结尾，观点句对仗（风向标/服务员/引路人），衔接自然 |
| 语言 | 0.75 | 流畅有文采，有小瑕 | "见他所见、思他所思""力贯长虹、正中靶心"有表现力；"落实需要有力，又要**精惟**"笔误（应为"精准"） |

### 三、得分与微调
基准二类中位；结构 +1、语言对仗 +1、笔误 −0.5、联系实际薄弱 −1.5、深度不足 −2
→ **26 / 35，二类文**。
字数：正文约 866 汉字（981 字符），略低于 1000–1200 下限（约差 2 行）。按阅卷口径
不机械扣分（结尾完整收束），但提示内容厚度不足。

### 四、改进方向（按优先级）
1. **深化机理**：补"为什么"——需求被呼应→人愿参与→价值被看见→善意有回音→社区获得
   自我更新的内生动力，扣回郭院长"持续生长的内在力量"；
2. **补"联系实际"**：加入材料外实例或政策语境，满足"参考但不拘泥"；
3. 分论点①从"宣传思想"改为更贴主线角度（如"以文化人、回应精神需求"）；修正"精惟"笔误。
