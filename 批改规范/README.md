# 批改规范

> 本目录存放**某套真题（尤其是其大作文）的批改规范**，即该卷的**评分标准／档次划分／采分要求**
> 等参考资料，供 `shenlun-judge` skill 批改该卷时**优先引用**。

## 一、为什么单独建这个目录

申论的**官方阅卷细则与具体采分表通常不公开**，skill 默认用的是自建的**模拟阅卷模型（L3 经验口径）
＋ `参考答案/` 的经验校准（L4）**。

但有些卷**确实能拿到更贴近阅卷的东西**——例如某省公开的评分参考、某机构发布的**分档标准与采分表**、
或用户自己依据题面与材料整理出的规范。这类材料比"逐题猜采分点"更可靠，
所以单独建目录存放，并在批改时**优先引用**。

> ⚠ **重要：批改规范一旦存在，批改时会被优先引用。**
> 尤其是**大作文**——凡本目录存在该卷的大作文批改规范（`{卷ID}-大作文批改规范.md`），
> **批改该卷大作文时必须引用**，其档次标准与分档区间**优先于** skill 自带的模拟口径。

## 二、目录规范

> 下面的树是**布局示例**（`{}` 处为占位符）；带"（示例）"的文件**尚未建立**，
> 建规范时按此命名新建即可。当前实存文件只有 `README.md` 与 `_模板.md`（省份子目录已建但为空）。

```text
批改规范/
├── README.md
├── _模板.md                                ← 空白模板，新建规范时复制它
├── 国考/
│   ├── 2026国考行政执法-批改规范.md          ← 整卷规范（示例）
│   └── 2026国考行政执法-大作文批改规范.md     ← 只针对大作文的规范（示例）
├── 河南/
│   └── 2022河南乡镇-大作文批改规范.md         ← （示例）
└── 浙江/
```

- **整卷规范**：`批改规范/{省份}/{卷ID}-批改规范.md`
- **只针对大作文的规范**：`批改规范/{省份}/{卷ID}-大作文批改规范.md`
- **卷ID = `{四位年份}{省份}{卷型}`**，与 `真题/`、`参考答案/`、`作答记录/`、`批改报告/`
  **共用同一套卷ID**（例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`）。
- **省份**只写简称：`国考` / `河南` / `浙江`（子目录按需创建）。
- 整卷规范与大作文规范**可以同时存在**：前者管全卷各题，后者只细化大作文；
  同一部分冲突时，**更专门的那份（大作文规范）优先**。

> 完整规范（卷ID 定义、五个目录落位、材料自动归位与命名提醒）见 skill 的 `references/workspace-layout.md`（`.dsh/skills/shenlun-judge/references/workspace-layout.md`）。

## 三、内容要求（写规范时逐项核对）

每份规范必须写清以下**三项基本信息**，缺一不可：

| 必填项 | 说明 |
|---|---|
| **卷ID / 年份** | 必填。没有年份的规范无法与真题、参考答案、作答记录对齐 |
| **来源** | 必须三选一并写明具体出处：**官方**（文件名称/文号）／**机构**（机构名＋产品名）／**自拟**（谁依据什么拟的） |
| **可靠性** | 官方 / 机构 / 自拟三档，直接决定它在报告里的引用等级（见第四节） |

建议同时写清：整卷各题采分要求、大作文档次标准与分档区间、特别强调/禁止的判分口径。
空白模板见 `_模板.md`。

## 四、来源等级：来源不明的规范不能当作官方标准使用

规范的价值**完全取决于来源**。批改引用时按下列等级登记，**不得越级表述**：

| 来源 | 引用等级 | 报告里的写法 | 能否当"官方标准" |
|---|---|---|---|
| **官方**（人事考试机构／命题单位公开的评分参考、阅卷细则、评分说明） | 按 `scoring-standards.md` 0.3 **升级为 L1／L2**，**优先于** skill 的 L3 模拟口径 | "依据 XX 官方公开的评分参考（文件名称，年份）" | ✅ 可以，但须写清文件出处与年份 |
| **机构**（某培训机构发布的采分表／分档标准／阅卷口径） | **L4 经验校准** | "参考口径（来自 XX 机构《XX》，年份），非官方" | ❌ **不可以** |
| **自拟**（用户或助手依据题面与材料整理） | **L4 经验校准**（由 L1 题面＋材料推演而来，仍属经验口径） | "本人依据题面（L1）与给定资料整理的经验口径，非官方" | ❌ **不可以** |
| **来源不明**（拿到的文件没有出处、没有年份、不知道谁写的） | **不得引用为规范** | 只能在报告"不确定性"里提一句"存在来源不明的评分材料，未采用" | ❌ **绝对不可以** |

**硬规则**：
1. **来源不明的规范不能当作官方标准使用**——不写来源的"评分标准"在批改中**一律不引用**，
   或至多按"自拟（L4 经验校准）"降级使用，并在报告里写明降级理由。
2. **不得把机构规范、自拟规范表述为"官方规定"**（skill 的禁用话术见
   `.dsh/skills/shenlun-judge/references/scoring-standards.md` 0.2）。
3. **规范与题面（L1）冲突时以题面为准**：题面作答要求是最高层依据，
   任何来源的规范都不能推翻题面明写的要求；冲突点与取舍理由须写进报告。
4. 引用本目录规范时，报告"评分依据声明"里必须登记
   **文件名 + 来源 + 年份 + 被判定为哪一层（L1/L2/L4）**。
5. **大作文批改规范必须逐条对照使用**（档次标准、分档区间、硬性要求、禁止性口径），
   不得"只查不看"；有规范却不引用，属报告缺陷。

## 五、新增一份规范时

1. 复制 `_模板.md` → 改名放入 `批改规范/{省份}/{卷ID}-批改规范.md`（或 `-大作文批改规范.md`）；
2. 填完"基本信息"三项（卷ID/年份、来源、可靠性等级）与各题采分要求、大作文分档标准；
3. **来源与年份写不清的，宁可不建**——一份来源不明的"规范"比没有更危险
   （它会被当成硬标准，把正确的作答判成错的）；
4. 之后批改该卷时，报告会**优先引用**本规范，并在"评分依据声明"里登记
   文件名、来源、年份与层级判定；该卷若无规范，报告须写"未找到该卷批改规范"。

---

*本目录内容用于**提高批改口径的可靠性**，不代表任何官方评分标准；
官方阅卷细则与采分表通常不公开，凡机构或自拟来源的规范**一律按 L4 经验校准标注**。*
