# 批改规范

保存有明确来源、版本和适用范围的卷级、题级及大作文规范。用户提供的原件不覆盖；官方公开内容仅在实际公开范围内作为官方依据，机构、自拟与 AI 整理稿均标为非官方参考。

## 命名与使用

```text
批改规范/{省份}/{卷ID}-批改规范.md
批改规范/{省份}/{卷ID}-大作文批改规范.md
批改规范/{省份}/{卷ID}-第N题-动态评分规范.md
```

卷ID 使用四位年份、省份和卷型，例如 `2026国考行政执法`。模板见 `templates/workspace/批改规范/`；模板本身不是可引用规范。

批改前核对当前题的有效规范、题干、来源及用户裁定，并登记实际使用范围。未找到规范时，采用本次 skill 的 `references/guokao-defaults.md`，注明“经验口径，非官方”；不得借相似卷的题级数值替代。

## 建档与维护

动态规范、共识表和大作文刻度文件是否必建，统一按 `references/rulings.md` §1.3 的本次条件判断，豁免理由写入报告。AI 整理稿注明“未经人工基准校准”，只有确实安排用户审阅时才写“待用户确认”。

规范记录题干要求、分值、适用材料、候选点及原文依据、可接受表达、分值理由、来源版本与未决问题。不得从来源家数自动定价，不把范文预评视为人工评分基准。

已标记失效的旧模拟规范已清理；今后如需对应题的规范，应按现行裁定重新建立，不能把历史报告中的旧文件引用当作有效文件。用户已确认保留的 2026 国考行政执法第 1 题规则继续保存在该题规范中，具体例外见 `rulings.md` §1.12—§1.15。

本目录的公开文件纳入仓库；含个人作答、得分或复盘的文件按根 `.gitignore` 留在本地。历史批改报告保持原记录，不因规范清理自动重算。
