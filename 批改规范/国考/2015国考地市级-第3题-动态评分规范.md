### 2. 可接受的同义表达（差异点里的措辞清单）

| 采分点 | 可接受的表述 |
|:--:|---|
| ① | "费时费力、不准确"≈"效率低、准确度差"≈"数据不清、滞后" |
| ② | "环境差"≈"污染严重"；"制度执行有问题"≈"缴费缺乏依据"≈"治污费收取难" |
| ③ | "一户一档"≈"为每户建立档案"；"五大模块"≈"养殖生产、防疫、检疫、流通、溯源五个模块"（**可用简称，但五个功能不能合并成"各模块"**） |
| ④ | "实时更新"≈"动态管理"≈"随时修改"；"效率高更准确"≈"快捷准确" |
| ⑤ | "三级网络"≈"市镇村三级"；"专职管理人员"≈"专人负责收集更新" |
| ⑥ | "缴费信息对照存栏数"≈"数字对不上及时发现"；"长效管理"≈"制度全面推行" |
| ⑦ | "全程"≈"从出生到屠宰"≈"出生免疫、出售检疫、屠宰检疫" |
| ⑧ | "与农业部动物追溯系统联网"≈"与动物追溯系统联网"；"追溯源头"≈"来源可靠可查" |

### 3. 部分命中规则（**从紧口径，2026-09-22**）

| 命中情形 | 给分 |
|---|---|
| 三要素齐（动作＋对象＋关键限定/结果） | 该点**满分（2 分）** |
| 动作与对象在、**关键限定缺失**（如只写"分门别类的各管理模块"而丢掉"五大模块／50 类数据"） | **60%–75%，取低端（1.2–1.5 分）** |

| 材料无据（自造结论，如"工作体系臃肿"） | **0 分**（**不倒扣**；仅在报告提示） |
| **多写**（把材料细节写得更全） | **不扣分**（8.4 硬边界） |

### 4. **不应机械扣分的情况**

- **是否分条**：某公未分条、整段叙述 → **不扣内容分**（只作"改进方向"提示）；
- **是否写具体数字**（2.45万户／96个村／1053户）：**无一家机构单列** → **未写不扣**；
- **线形图／柱状图、收费标准公开**：单家收录 → **低权，未写不扣**；
- **标题自拟与否**：题面未要求标题 → 写了不加分、只作格式观感；
- **个别错别字**：**不单独扣分**；若导致关键词不可辨，按该点表述不准处理。

### 5. 材料使用要求

- 范围＝**"给定资料 3"**；**范围外内容不作得分点**。
- 三要素中的"**关键限定**"多以**数字与引号内容**出现（"一户一档""5个模块""50类数据"
  "2.45万户""市、镇、村三级""96个行政村""出生免疫、出售检疫、屠宰检疫""农业部动物追溯系统"）
  —— **这类信息按原文写才能拿满，概括即降到部分命中**。

### 6. 联系实际要求

- **不适用**（题面要求的是"**全面准确，符合实际**"——"符合实际"指**所述做法须与资料 3 的实际一致**，
  **不是**要求补充材料外案例）。**自造做法（材料无据）反而按"材料无据"0 分处理。**

### 7. 大作文档次锚点

- **不适用**（本题为公文题，**不设档位**）。
