## 2. 可接受的同义表达（照给分，铁律 8）

- "智能经济之'核'初步形成" ＝ "智能经济核心初步形成"＝"政策体系／创新平台／区域集聚初具形态"。
- "基础性关键环境要素建设滞后" ＝ "关键要素滞后"＝"物联网等基础建设落后于智能制造发展需求"。
- "缺'核'少'芯'" ＝ "缺乏核心控制技术"＝"核心技术依赖进口、成果转化不足"。
- "主体意识不强" ＝ "存在不懂、不敢、不愿三种态度"＝"改造步伐慢"。
- "动力强、基础扎实" ＝ "（传统产业）内生需求十分强烈"＝"传统产业占比高、是主战场与大市场"＝"**面临东南亚与发达国家的双面夹击**（外部压力）"——四者同出材料1第35行同一语义段；**仅写"夹击"而未写"动力强／基础扎实"，按部分命中就低不就高，给①该子项的一半**（不得判为材料无据）。
- "重硬轻软" ＝ "观念落后"＝"不能接受生产性服务外包"。
- "引导创新协同" ＝ "打造／构建创新创业共同体"＝"产学研用协同"。
- "生产性服务业集聚平台" ＝ "集聚区"＝"综合对接平台"。
- "工匠型"企业 ＝ "专精特新"企业（材料中并列出现，**不作同义合并**：⑤中两者分别对应"培育工匠型企业"与"开展试点示范培育专精特新企业"）。

## 3. 部分命中规则（三要素：核心动作｜核心对象｜关键限定/结果）

- **三要素齐 → 该块满分**（概括题"抓住块即给该块主要分值"）。
- **核心概念在、限定缺失 → 该块给 60%，且就低不就高**。例：②只写"智能制造基础薄弱"而未点出缺"核"少"芯"或关键环境要素 → 给 1.5/2.5。
- **只有泛泛表述、无可核对的具体指向 → 0 分**。例："要重视智能制造""加强人才培养"而不落到"强基工程／四基／工匠型企业"等具体指向。
- **材料无据 → 0 分**，不额外倒扣。
- **块内子项缺失不重扣**（从宽）：②漏"国际合作乏力"、④漏"共享机制"等，**只在该块内按就低不就高处理**，不跨块扣分。
- **三方面（成绩／问题／建议）有一方面整块未答** → 该块 0 分；**不得**因此判定"内容不全面"再额外降分。

## 4. 不应机械扣分的情况（未写不扣、写了不加）

- "重硬轻软""制造企业不能接受生产性服务外包""服务资源整合共享机制未建立"——**材料有、多数机构不写**，属可写可不写。
- "示范项目不断涌现""机器人小镇""电商经济创新园区""N 市定制制造和定制电商生产性服务业集聚区""生产服务业综合对接平台"等**具体例证／专名**——**具体案例不是采分点**，未写不扣。
- 缺"智能制造标准指数""国际技术合作服务乏力"（仅 2 家）——**弱共识子项**，未写只影响②的完整度，**不单独扣点**。
- "传统产业面临东南亚国家与发达国家的双面夹击"（**0 家收录，但材料1第35行有原文**）——属①的可写背景子项；**写了不单独加分、未写不扣分**；**严禁**判为"材料无据／外部环境推演"，也**不得**据此扣分。
- **分层、总括词、条理**——**写作建议，不加分、不扣分**（逻辑／结构分池不设）。
- **字数（375 字，超上限 25 字）**——**只核验、不计分**，报告单列"⚠ 字数提示"，不扣分、不降档。
- 错别字／标点／分条格式（"1./2."与"一是/二是"）——**不单独扣分**，只要关键词可辨。
