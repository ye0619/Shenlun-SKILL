## 3. 部分命中规则（分析题：须"核心动作＋核心对象"齐全）

- 三要素齐 → 该点满分。
- **核心概念命中、信息不完整 → 部分分且就低不就高**。例：只写"要吸收传统文化"而未落到"体味其中的智慧和美"→ 给 1/2。
- **仅"上位概括已覆盖"不足以判完整命中 → 判部分命中**。例：只写"人的'慧'就是要有人文关怀"，未拆到②③④任一具体指向 → 该点判部分命中或不命中。
- 泛泛表述（"要做好设计""设计很重要"）而无具体指向 → **0 分**。
- 材料无据（如中公"发挥想象力"、仅凭常识的延伸）→ 0 分，不额外倒扣。
- **分析题须细拆**：不得因考生"合并成语义群"就整体给满分；应按点逐一核对，缺哪点扣哪点。

## 4. 不应机械扣分的情况

- **具体案例**（"美味中国"智能炊具、多功能拼接沙发、割草／扫地／清洗游泳池全自动机器、D 市杯）——**具体案例不是采分点**，未写不扣。
- 未点"现在不是科技推动设计的时代"原句 → 并入①，不额外扣。
- **"物的'智'"中"一个内核多种运用"细节** → 可写可不写。
- **字数（340 字，超上限 40 字）**——只核验、不计分，报告单列"⚠ 字数提示"。
- **总括句写不写** → 综合分析**建议**写，**非硬性**；写了不加、不写不扣。
- **分条形式、要点顺序** → 不影响得分。
