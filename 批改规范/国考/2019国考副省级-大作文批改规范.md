## ① 立意梯度（哪些方向切题、哪些偏题）

**能标定性**：3 篇范文互为独立来源（`工具/ref_independence.py --question 5 --quiet --sensitivity`：3 条目 → 3 组），长度 1128／1200／1272 字（最大/最小＝1.13，无离群），**建 T1 单向刻度**。详见 `批改报告/.大作文刻度/2019国考副省级-梯队画像.md`。

| 梯度 | 方向 | 判定 |
|---|---|---|
| **切题（一等）** | 以"**城市文明与乡村文明互补**"为主线，并同时处理题干三层：①二者应且可以互补 ②人造文明与自然文明的关系 ③理想的生活状态在城、乡之间自由游走 | 3 篇 T1 均落在**这一梯度**（对第三层的展开程度不一） |
| **切题（二等）** | 落在"互补"但只处理"城乡关系/乡村振兴"，把"人造文明与自然文明"与"自由游走的理想生活"完全略去 | 仍属切题，档内定位受影响 |
| **基本切题** | 只谈"乡村振兴／乡村建设"而不谈**城与乡的关系**；或只谈"新型城镇化"而不谈乡村 | 未抓住"互补"这一核心关系 → 基本切题 |
| **偏题** | 单方面主张"城市文明优于乡村文明"或"乡村文明优于城市文明"；或把"城乡一体化"写成"城乡一样化"（材料5 明示的误区） | 与材料主旨冲突 → **三类封顶** |
| **跑题** | 通篇谈"文化自信""生态文明""脱贫攻坚"等与城乡文明关系无关的话题 | **四类封顶** |

**重心该落在哪一侧**：重心在"**互补**"这一关系判断，而非任一方的优劣或单方的建设路径；**材料5 的误区（城乡"一样化"）是立意分水岭**——批驳该误区的稿件立意层次更高。

## ② 核心论点池（本题绕不开的 3–5 个论点）

依据 3 篇 T1 覆盖面交集：

1. **城与乡两种文明类型没有高下之分**，不是谁高于谁，而是相互依存、功能互补（材料5 专家语）。
2. **不可把城乡一体化变成城乡"一样化"**：村庄大量被拆、乡土旅游资源丧失、不利于现代农业建设；须防止"一步把农村变成城市"的单线思维。
3. **乡村文明是不可替代的精神资源与基础文明**：乡村是城市文明的根基，承载乡愁；乡村提供资源储备与精神依托（可与材料4 的"个异性""永恒""共有共享"对接）。
4. **城乡互补的路径**：以工哺农、城乡要素平等交换与双向流动、公共资源向农村倾斜；统筹城乡发展，宜城则城、宜乡则乡。
5. **落点**：理想的生活状态在城、乡之间自由游走；城与乡协调统一、同样美丽（"两条腿"并行）。

> **机构覆盖面提示**：三篇 T1 **均未**把第 5 点（"自由游走"）作为**独立展开**的落点（华图仅一句、站长以一句收束、粉笔以末段一句收束）。→ 用户稿**缺失该展开不构成独有短板**，不得据此扣分或压档（接入点 4）。

## ③ 常见失分点（这题最容易写成什么样、最容易漏什么）

- **写成"乡村振兴倡议书"**：通篇罗列乡村建设举措（产业、文化、设施），把"城与乡的关系"搁置——最常见，落点滑向"农村发展对策"（T1 中的【粉笔】已有此倾向，故为边界情形，需与"完全搁置"区分）。
- **单边褒贬**：断言城市文明先进／乡村文明落后，或反之，直接落入材料5 所批的误区。
- **把"互补"写成并列陈列**：分别介绍两类文明各自的好处，缺少"为什么必须互补"的因果分析（T1 中【华图】即偏此，故属"未达上沿"而非"硬伤"）。
- **漏"人造文明与自然文明"这一层**：只写"城与乡"，不处理"人造／自然"的对应关系。
- **漏落点**：全篇没有回到"理想的生活状态"。
- **材料堆砌**：大段抄录材料原文而无解释。

## ④ 硬性与禁止口径

**题面硬性要求（L1）**：自拟题目、自选角度；观点明确、见解深刻；**参考"给定资料"但不拘泥于"给定资料"**；思路清晰、语言流畅；**字数 1000～1200 字**。

**不得作为扣分／降档理由的清单**（出现即该扣分作废）：

- 未出现某几个特定词句、未引用材料某案例；**引用材料不加分、未用材料不扣分**（两路径等价）。
- 未采用"五段三分""提出—分析—解决"等**模板形态**；段落数、分论点数量与 T1 不同。
- 与参考答案**角度不同**。
- 标题偏窄（题干允许自拟题目，**只作提示不扣分**）；未写标题只作提示。
- **"立意稍微模糊"不是硬伤**，不封顶、不降档。
- **泛泛表述本身**不扣分、不降档；**"口号式"表述不单独扣分降档**。
- 两段复用同一案例、只有机构范文故不建刻度、机构 0 家收录故不计分——均属黑名单判语。
- **字数不计入评分**：本题要求 1000～1200 字，**只核验、只提示，不扣分、不降档**。
- 具体案例不是采分点；数据与口语化表达不属采分点。

**硬伤（只设上限，未命中不降档）**：明显跑题 → 四类封顶；偏题／核心任务遗漏严重／论点与材料主旨冲突 → 三类封顶；大面积无法辨认／严重语言障碍 → 下调一档。
