## 3. 部分命中规则（核心动作＋核心对象＋关键限定/结果）

|---|---|
| 点1（3分） | 只写"争取帮扶资金"而无任何具体投向 → 1 分；有资金＋1 类具体设施（基地/路灯/道路/学校）→ 2 分；有资金＋2 类以上具体设施且含公共服务设施（学校/幼儿园等）→ 3 分 |
| 点2（3分） | 只写"成立合作社"无"土地流转"或"现代农业"要素 → 1 分；土地流转＋合作社 → 2 分；土地流转＋合作社＋现代设施农业/养殖或经济作物＋资金支持 → 3 分 |
| 点3（3分） | 只泛写"发展乡村旅游"无任何依托（自然资源/历史印记/文化元素/水文章/不收门票/农家乐）→ 1 分；给出 2 项以上依托 → 2 分；依托＋具体景点或民俗活动＋（格局或主线）→ 3 分；**只写"确立发展格局"而不写格局内容 → 该要素按半项计（就低）** |
| 点4（3分） | 只写 1 处文化设施且无"丰富群众文化生活"的成效指向 → 1.5 分；2 处以上设施或设施＋成效 → 2 分；设施齐备（活动场所＋球场/艺术墙等多类）且有效果指向 → 3 分 |
| 点5（2分） | 只写"传承家风家训"无"立家规/制牌挂门口/征集/家训村"任何动作 → 1 分；动作＋"以家风推动良好社会风气"结果 → 2 分 |
| 点6（2分） | 只写"自然条件好但贫困"而无成效或阶段性目标 → 1 分；成效（脱贫/美丽乡村/卫生村/小康村）齐或有接续推进表述 → 2 分 |

**通则**：三要素缺一不判满分；部分命中**就低不就高**。

## 4. 不应机械扣分的情况

- **具体案例不是采分点**：未写"杨自龙""吉隆田合作社""17 座大棚草莓""180 平方米""10 盏""3 公里""3.5 公里"等**人名、组织名与数据**，只要类别要素在，**不扣分**。
- 提纲的**条数、顺序、小标题有无**不影响内容池得分（本题题面只要求"内容具体、条理清晰"）。
- 提纲**无需落款、无需称谓**；写了也不加分、不扣分。
- 只有标题、标题写作"关于山岔村做法的调研报告"与题面"调研报告提纲"措辞略有差异，**不扣格式分**。
- 个别错别字（如"长城墙"写作"长城情"）属**语言池**问题，**不在内容池重复扣分**。
- 材料外的做法（如别村经验）**不加分**；未使用材料某细节**不扣分**。
