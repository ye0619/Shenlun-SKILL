## 3. 部分命中规则

| 采分点 | 缺项处理 |
|---|---|
| 点1（2分） | 只写"基础在乡村现代化"而未及"从城乡关系思考中国发展问题"→ 2 分仍给（后者为展开性限定）；若只写"要重视乡村"→ 0 分 |
| 点2（2分） | 只写"既解决具体问题又要有大目标"→ 2 分；只写"要有大目标/大视野"而无"具体问题"→ 1 分；缺"立足局部、着眼全局"**不单独扣分** |
| 点3（2分） | 写出"不局限物质建设"＋"全方位改革"＝2 分；**列举改革领域时遗漏"环境"或"社会"→ 1.5 分**（从紧口径：关键领域列举不全按部分命中）；只写"不局限物质建设"无"全方位"→ 1 分 |
| 点4（2分） | "教育事业为中心"＋"研究事业突出位置"＝2 分；只写其一 → 1 分；把"研究事业"写成"中心位置"（材料为"突出位置"）**视为同义，不扣分** |
| 点5（2分） | 社会建设（公共文化娱乐/公共事业/社会工作运动/培育新人民）与自治建设（大众出钱出力支持、形成大众管理方式）**各自成项**；环境建设仅一句无内容 → 0.5 分；社会建设写足但环境建设空 → 1.5 分；社会＋自治写足、环境空 → 1.5 分 |
| 点6（2分） | 只写"以经济建设为中心"而无理由（富力→负担力→国力／最能动员民众）→ **1 分**（从紧口径：只给结论不给依据，按部分命中） |
| 点7（2分） | 命中"城乡人口供给"＋"城市原料恐慌"＋"城市问题"三类中 2 类 → 1.5 分；只写"乡村为城市供给人口"→ 1 分 |
| 点8（2分） | "以工辅农/工农互动"＋"企业投资乡村并获发展/培训人才"＝1.5 分；"人的现代化/立人"＝0.5 分；两者齐 → 2 分 |

**通则**：三要素缺一不判满分；部分命中**就低不就高**。

## 4. 不应机械扣分的情况

- **人物事迹属背景、不是采分点**：未写卢作孚生平（"生于世代农耕家庭""没上过大学""乡村建设三杰"）**不扣分**。
- 未写"北碚""西部科学院""兼善实业股份有限公司""近千名"等**专名与数据**，只要研究事业/以工辅农的要素在，**不扣分**。
- 理念与意义的**归类顺序**：把"以经济建设为中心"的理由写在"现实意义"下（本题用户答案即如此），**不因归类位置扣分**，只按该要素本身是否命中判定。
- 未使用材料外案例、未联系当下政策**不扣分**。
- 导学材料**无需落款、无需称谓**；写了不扣分。
- 分条形式（"一、二、三"或"1.2.3."）**不影响得分**，只要层次清楚。
