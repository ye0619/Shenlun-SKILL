## 0. 题面（L1，原文）

“给定资料5”提到“跟着时代的大潮往前走，尽到我所有的力量，做好我要做的事情”，请深入思考这句话，自选角度，联系实际，自拟题目，写一篇文章。（40分）
要求：（1）观点明确，见解深刻；（2）参考“给定资料”，但不拘泥于“给定资料”；（3）思路清晰，语言流畅；（4）字数1000～1200字。

## 1. 评分方式（四步：大档锚定 → 硬伤封顶 → 档内定位 → 区间与置信度）

- 档位区间一律查 `scoring-standards.md` 三.1 换算表（**40 分卷**）：一类 32–40（下 32–34／中 34.5–37／上 37.5–40）；二类 24–31.5（下 24–26／中 26.5–28.5／上 29–31.5）；三类 12–23.5（下 12–15.5／中 16–19／上 19.5–23.5）；四类 ≤11.5。
- 四维（题意／内容／结构／语言）**综合**锚定大档，不取最低档、不数票；硬伤只设**上限**，不因文采或结构精巧而跳过。
- 档内定位五证据项：①题意质量②内容质量③论证深度④结构完成度⑤语言质量。中＝≥3 项达本档中位；上＝≥4 项达本档上沿；从紧默认落“下／中”。逐项须引作答原文为证。

## 3. 可接受的同义表达

1. “时代大潮”可写作“时代潮流／大势／洪流／召唤／际遇”。
2. “尽到我所有的力量”可写作“竭尽全力／做好本分／把岗位上该做的事做到最好”。
3. “不要去挑生活，让生活来挑你”可写作“不挑拣、不抱怨、随遇而安、听从时代安排”。
4. “为国利民”可写作“家国情怀／以人民为中心／把个人价值融入国家发展”。
5. 只做语义核对，不做文本相似度比对；用自己的话把意思说清且能被材料直接支撑 → 照给分。

## 4. 部分命中与硬伤规则

- 题意是**语义**判定：围绕“个人与时代的关系＋尽力做好该做的事”立意即为切题；**“立意常规、未提炼出统摄性分析框架”只影响题意质量定位，不封顶、不降档**。明显跑题 → 上限四类；偏离主线（如通篇只写三农／脱贫／基层而与“时代与个人”脱钩）→ 上限三类。
- 引用材料**双向免分**：引用了不加分；未引用材料而把论点证明充分也不扣分、不降档（本题明示“不拘泥于给定资料”）。
- **未写标题**：本题要求“自拟题目”，缺标题按**形式项**处理，**只提示、不扣分、不降档**（用户口径）。
- 错别字／标点 0.5 分／3 处、本项封顶 1 分；词语误用 0.5 分／处封顶 1 分；语病 0.5–1 分／处封顶 1 分；史实／引文／政策表述错误 0.5–1 分／处，**只在主要归属维度计一次**。
- 字数（1000～1200，达标）**只核验、不计分**：不扣分、不降档；明显截断另按“结构完成度”如实反映。

## 5. 不应机械扣分的情况（未写不扣、写了不加）

1. 未用材料案例（彭士禄／苏和／张玉滚）而用自家素材论证充分 → 不扣分（题面允许“不拘泥于给定资料”）。
2. 三段并列式、无递进 → 只在“结构完成度／论证深度”如实反映，不另设扣分。
3. 未写政治理论术语、未引名言 → 不扣分；反之也不加分。
4. 与 T2 范文同样缺失的项，不得单独作为压档理由。

## 6. 材料使用要求

- 题面允许“不拘泥于给定资料”：使用材料内素材与自身积累均为合法路径，两条路径等价。
- 不得自造与材料主旨冲突的事实；史实／引文／政策表述错误按 §4 计一次。
- 严重政治性错误：不参与档内定位，立即指出并建议重写。
