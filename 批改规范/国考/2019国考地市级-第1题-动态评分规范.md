## 2. 可接受的同义表达
1. 六个方面可用“农业／销售／生活／环境／精神／流向”等自拟小标题统摄——**只是组织方式**，不额外计分，也不因未写小标题而扣分。
2. 点1“生产方式／经营方式转变”可写作“农业产业化／规模化经营／现代化”；“包装技术培训”可写作“技术培训”，“真空包装、低温保鲜”可写作“包装保鲜技术”。
3. 点2“销售方式转变”可写作“销售渠道拓宽／由线下转线上／借电商平台销售”；“电商平台”可写作“电商／网购平台”。
4. 点3“生活水平提高”可写作“物质生活改善／收入增加／腰包鼓了”；“主动退出低保”可写作“摘了帽／脱贫”。
5. 点4“精神面貌转变”可写作“思想观念转变／心态变化／精神文化需求提高／对生活有信心”；“盼有跳舞下棋的地方”可写作“对文体活动场所的期待”。
6. 点5“基础设施与人居环境改善”可写作“村容村貌改善／生活环境变好／公共设施完善”。
7. 点6“人口与资金流向改变”可写作“资源回流／人才与资金回流／城乡要素流动反转”。
8. 只做语义核对：用自己的话表达同一变化、且能被材料直接支撑 → 照给分。

## 3. 部分命中规则（三要素：核心动作｜核心对象｜关键限定或结果）
- 三要素齐备 → 该点满分。
- 缺任一要素（含“只有上位概括、没有政策内容落地”）→ 判**部分命中**，取该点分值 **60%** 并按 **0.5 粒度就低取值**（2 分点→1 分；1.5 分点→0.5 分；1 分点→0.5 分）。
- 只有方向性表述（如“家乡变化很大”“生活越来越好”）而无可核对的内容 → **0 分**。
- 与材料无关或材料无据的表述 → 0 分，不额外倒扣。
- 作答多写的内容（超出采分范围的无害补充）→ 不倒扣，仅在报告中作一句提示。

## 4. 不应机械扣分的情况（未写不扣、写了不加）
1. **年份／时间点／数字不单独计分**：写对不加分、写错或未写不扣分。“前年”“上个月”“500多户”“4家快递公司”等均属限定细节。
2. **机构普遍不写的单源细节不计分、不列为失分点**：如“枇杷品质优良也卖不上好价钱”“快递刚进镇时全镇每天收发包裹只有几十个”“三轮车陷进泥里”等，只作背景（已并入点2、点3），不单列计分。
3. **条理／分层／总括词只作写作建议**：加分不加、扣分不扣（“不加不扣”）；纯罗列不倒扣。
4. **字数超上限只核验、只提示**：不扣分、不降档（用户 2026-09-27 裁定）。
5. **未使用材料原句不扣分**：同义概括、自述语言一律允许。
6. **机构名或数据与材料不符只提示不扣分**：作答中的名称、数字、时间与材料不一致时，只在报告中作一句提示。
