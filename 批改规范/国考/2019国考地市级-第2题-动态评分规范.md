## 2. 可接受的同义表达
1. 标题可写作“关于花椒酱产业发展经验的发言提纲／发展花椒酱产业经验介绍／交流发言提纲”等——**具“关于……的发言提纲”之意即可**。
2. 称呼可写作“各位同志”“各位领导、同志们”“各位扶贫干部”等；称呼与问候语（“大家好”）合写亦可。
3. 点1“背景交代”可写作“先讲村情／说明来意／介绍本村贫困状况”；“地薄、只够糊口”可写作“自然条件差、产量低”。
4. 点2“调研定方向”可写作“走访摸底、市场调研、选准特色产业”；“走遍省内大型超市、批发市场”可概括为“跑市场、比对同类产品”。
5. 点3“论证聚共识”可写作“专家论证、科学论证、咨询可行性、打消群众顾虑”；“统一了大家的思想”可写作“凝聚共识、赢得干群信任”。
6. 点4“合作办企业”可写作“成立集体企业、村民入股、多方合作”；“技术入股或半成品入股”不必区分，写“入股”即可证成。
7. 点5“借力扩种”可写作“申请贷款、扩大种植、建立原料基地”；“绿色银行”可写作“稳定增收来源”。
8. 提纲分“一、二、三、四”或“一是、二是”均可——**只是体例**，不额外计分；经验条目**顺序不限**（“先公司后调研”不扣分）。

## 3. 部分命中规则（三要素：核心动作｜核心对象｜关键限定或结果）
- 三要素齐备 → 该点满分。
- 缺任一要素（含“只有上位概括、没有政策内容落地”）→ 判**部分命中**，取该点分值 **60%** 并按 **0.5 粒度就低取值**（2 分点→1 分；1.5 分点→0.5 分；1 分点→0.5 分）。
- 只有方向性表述（如“发展产业、带动脱贫”）而无可核对的内容 → **0 分**。
- 与材料无关或材料无据的表述 → 0 分，不额外倒扣。
- 作答多写的内容（超出采分范围的无害补充）→ 不倒扣，仅在报告中作一句提示。
- 格式池、语言池**不套用三要素规则**：按上表“有则给分、缺则扣该池分”核验。

## 4. 不应机械扣分的情况（未写不扣、写了不加）
1. **年份／时间点／数字不单独计分**：写对不加分、写错或未写不扣分。“2015年”“2016年10月”“2017年初”“66万元”“1000棵树苗”“500多亩”等均属限定细节。
2. **机构普遍不写的单源细节不计分、不列为失分点**：如“‘狗不叫干部’”“老韩说‘咱们村干部都认定你了’”等，只作背景，不计分、不列为“漏点”。
3. **条理／分层／总括词只作写作建议**：加分不加、扣分不扣（“不加不扣”）；分条不整齐不倒扣（可提示）。
4. **字数超上限只核验、只提示**：不扣分、不降档（用户 2026-09-27 裁定）。
5. **未使用材料原句不扣分**：同义概括、自述语言一律允许。
6. **机构名或数据与材料不符只提示不扣分**：如把“省食品研究院”“省中小企业公共服务平台”“池口农副产品开发有限责任公司”写错，或数字与材料不一致，只在报告中作一句提示。
