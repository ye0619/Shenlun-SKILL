## 2. 可接受的同义表达
1. 六个“转变”可用“思想认识／本领作风／工作方法／群众感情／为民办事／工作业绩”等自拟小标题统摄——**只是组织方式**，不额外计分，也不因未写小标题而扣分。
2. 点1“思想观念转变”可写作“摆正位置／放下架子／不再自视甚高／理解农民不易／服务意识增强”。
3. 点2“实践能力转变”可写作“从空谈到实干／学到真本领／学说方言、下地干活／能吃苦”；“每天‘服役’两个小时”可写作“坚持到老乡家干农活”。
4. 点3“工作方法转变”可写作“改进工作方法／讲究方式／把理说通／情理并重”；“把尺绳拽得紧紧的”可写作“死守原则、不懂变通”。
5. 点4“群众感情转变”可写作“与群众熟络／拉近关系／融入村民／赢得信任”。
6. 点5“主动为群众办实事”可写作“帮助困难户／申办救济／调解矛盾纠纷／解决群众急难愁盼”。
7. 点6“业绩与作用发挥”可写作“发挥专业优势／打造杂粮品牌／打开销路／带动村民增收致富”。
8. 点7“获得认可”可写作“评价提高／得到村民和组织认可／获得荣誉”；称呼由“那个大学生”变“小吴”属题面给定事实，写进作答即可，不要求逐字复述材料原句。
9. 只做语义核对：用自己的话表达同一变化、且能被材料直接支撑 → 照给分。

## 3. 部分命中规则（三要素：核心动作｜核心对象｜关键限定或结果）
- 三要素齐备 → 该点满分。
- 缺任一要素（含“只有上位概括、没有政策内容落地”）→ 判**部分命中**，取该点分值 **60%** 并按 **0.5 粒度就低取值**（2 分点→1 分；1.5 分点→0.5 分；1 分点→0.5 分）。
- 只有方向性表述（如“小吴成长了、进步了”）而无可核对的内容 → **0 分**。
- 与材料无关或材料无据的表述 → 0 分，不额外倒扣。
- 作答多写的内容（超出采分范围的无害补充）→ 不倒扣，仅在报告中作一句提示。
- 只写“变化”不写“由……到……”（起点或落点缺一）→ 该点按**部分命中**处理。

## 4. 不应机械扣分的情况（未写不扣、写了不加）
1. **年份／时间点／数字不单独计分**：写对不加分、写错或未写不扣分。“2016年”“每天两个小时”“一次两个小时”“4个人”“去年”等均属限定细节。
2. **机构普遍不写的单源细节不计分、不列为失分点**：如“这大学生下地还得跟个提鞋的”“水田地补偿款”“核发水田地补偿款量土地”等，只作背景（已并入点2、点3），不单列计分、不列为“漏点”。
3. **条理／分层／总括词只作写作建议**：加分不加、扣分不扣（“不加不扣”）；纯罗列不倒扣（题面“条理清晰”只作提示）。
4. **字数超上限只核验、只提示**：不扣分、不降档（用户 2026-09-27 裁定）。
5. **未使用材料原句不扣分**：同义概括、自述语言一律允许（如把“学说土方言”写成“学习群众语言”）。
6. **机构名或数据与材料不符只提示不扣分**：作答中的名称、数字、时间与材料不一致时，只在报告中作一句提示。
