## 2. 可接受的同义表达
1. “种种‘遮蔽’”可写作“障碍／束缚／隔阂／问题／不良倾向”，**不必保留引号**；“拿不出有份量的作品”可写作“写不出好作品／难以产生精品”。
2. 各类遮蔽的命名可自拟（如“历史遮蔽／自我遮蔽／技术遮蔽／金钱遮蔽／城乡遮蔽”“四重隔阂”）；把“技术”与“金钱”合写为“技术与金钱的遮蔽”**不额外扣分**（合并命中点5、点6）。
3. 点1“含义本质”可写作“总起句：遮蔽即创作脱离现实、时代与人民的问题，须打破才能出精品”。
4. 点2“危害后果”可写作“后果／影响／危害”；“牵强附会、哗众取宠”可写作“媚俗、不严肃、不尊重历史”。
5. 点3 可写作“为迎合娱乐精神而戏说历史／混淆古今、脱离历史语境”。
6. 点4 可写作“沉溺个人小情绪／只写自己／缺乏他人视角与百姓情感”。
7. 点5 可写作“依赖网络与搜索、闭门造车、在虚拟想象中写作”；点6 可写作“为流量与收益写作、高产却不满意、忘记初心”。
8. 点7 可写作“不了解基层与农村／城乡之间缺少沟通／缺乏基层实践”。
9. 点8 可写作“对策／启示”：尊重历史、深入生活、行走基层、书写他人、个人情感与国家命运相连。
10. 结构与顺序不限：先“含义→表现→危害→对策”或“总—分—总”均可，**只是组织方式**，不额外计分。

## 3. 部分命中规则（三要素：核心动作｜核心对象｜关键限定或结果）
- 三要素齐备 → 该点满分。
- 缺任一要素（含“只有上位概括、没有政策内容落地”）→ 判**部分命中**，取该点分值 **60%** 并按 **0.5 粒度就低取值**（2 分点→1 分；1.5 分点→0.5 分；1 分点→0.5 分）。
- 只有方向性表述（如“文艺创作存在很多问题”）而无可核对的内容 → **0 分**。
- 与材料无关或材料无据的表述 → 0 分，不额外倒扣。
- 作答多写的内容（超出采分范围的无害补充）→ 不倒扣，仅在报告中作一句提示。
- 只写“遮蔽的表现”而不作**理解性概括**（无含义句、无对策句）→ 点1、点8 按部分命中或 0 分处理。

## 4. 不应机械扣分的情况（未写不扣、写了不加）
1. **年份／时间点／数字不单独计分**：写对不加分、写错或未写不扣分。“快十年”“上个月”“80后”“改革开放40周年”等均属限定细节。
2. **机构普遍不写的单源细节不计分、不列为失分点**：如“乙以一个乡村媳妇的身份认真生活”“丁的新作是脱贫致富的故事”“黑虎庙小学式的地名类比”等，只作背景，不单列计分、不列为“漏点”。
3. **条理／分层／总括词只作写作建议**：加分不加、扣分不扣（“不加不扣”）；先分后总还是先总后分不倒扣。
4. **字数超上限只核验、只提示**：不扣分、不降档（用户 2026-09-27 裁定）。
5. **未使用材料原句不扣分**：同义概括、自述语言一律允许（如把“自我编织的虚幻氛围”写成“闭门想象”）。
6. **机构名或数据与材料不符只提示不扣分**：作答中的名称、数字、时间与材料不一致时，只在报告中作一句提示。
