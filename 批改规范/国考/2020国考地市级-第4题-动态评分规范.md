## 2. 可接受同义表达
- 脏乱＝「环境差／卫生差／乱」；过道窄＝「通道狭窄／空间拥挤」；积水＝「排水不畅」；对准问题改造＝「原址改造／改造升级／就地改造」
- 过渡场所＝「临时市场／过渡市场／就近划定区域」；闲置老厂房＝「闲置厂房／废旧厂房／闲置资源」
- 规范稳定交易场所＝「固定市场／规范农贸市场／常设交易场所」；边营业边整改＝「就地整改／有序整改／不停业整改」
- 三位一体不科学＝「存放、宰杀、售卖未分离／未分区」；占道经营＝「乱摆乱放／店外经营」

## 3. 部分命中规则（从紧给分，就低不就高）
- 三要素缺一即**不判满分**。**③的"缺少规范稳定的农副产品交易场所"是本市场核心问题**（10/10 家均写）：漏写该核心问题而只写"扰民／影响出行／管理难"→ 判**部分命中**，取低端。
- 措施只写方向而不具操作性（如"加强管理"无对象、无做法）→ 该点**部分命中或 0 分**；措施与问题不对应、材料无据 → 0 分。
- ⑥若只写"边营业边整改"而漏"多方参与／制度层面"，或只写"分离活禽摊位"而漏"安全防范"→ 部分命中。
- **对策题从宽**：抓住市场块与"问题—措施"配对即给该块主要分值，**不因条数多少或个别子项缺失而重扣**。

## 4. 不应机械扣分的情况
- **数据**（40 年、二三十厘米、1 个社区→七八个、四五万人）与**人名**（刘阿姨、王女士、廖主任、范书记、丁工程师、李主任）**不属采分点**。
- 措施与问题**是否逐条一一对应、是否加小标题、三市场顺序** → 形式项，不扣分。
- 材料外延伸措施（四海飞扬"定点屠宰场统一宰杀"、天琦教育"开听证会／发放问卷"，各 1 家）→ 判**可写可不写**，同判命中，不扣分、也不额外加分。
- 花木君式"三市场问题合并成一段再统一对策"→ 粒度差异照给；但题面 L1 明示"**分别**梳理三个市场"，**完全不分市场**仍须在报告提示。
- 字数超限 → 只作提示、不计入评分；错别字不单独扣分。
