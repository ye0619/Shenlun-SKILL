## 2. 可接受的同义表达
1. 点1“制定核算方法”可写作“建立GEP核算体系／核算标准”；“评估核算”可写作“测算生态产品价值”。
2. 点2“明确生态优势与竞争力”可写作“摸清生态家底／找出优势”；“开发项目”可写作“发展生态旅游、户外运动等特色产业”；“企业付费购买”可写作“企业为使用生态产品付费／生态补偿式购买”。
3. 点3“生态强村公司”可写作“生态公司／村集体公司”（名称不全不扣分）；“供给主体与交易主体”可写作“卖方主体／市场经营主体”。
4. 点4“使用经营权质押担保”可写作“以经营权抵押贷款”；“GEP贷”可写作“生态贷／绿色信贷产品”。

## 3. 部分命中规则（三要素：核心动作｜核心对象｜关键限定或结果）
- 三要素齐备 → 该点满分。
- 缺任一要素（含“只有价值类型概括、没有做法落地”）→ 判**部分命中**，取该点分值 60%，按 0.5 粒度就低取值（1 分点→0.5；1.5 分点→1.0；2 分点→1.0—1.5）。
- 只写“直接价值／间接价值／潜在价值”分类而不写做法 → 分类本身 0 分。
- 与材料无关或材料无据的表述 → 0 分，不额外倒扣。
- 多写的无害补充（如材料未要求的评价）→ 不倒扣，报告中一句提示。

## 4. 不应机械扣分的情况（未写不扣、写了不加）
1. **具体数字／比例不单独计分**：如“每块板50元”“一户60多块板”等，写错或未写均不扣分。
2. **机构名不全只提示**：写“生态公司”而非“生态强村公司”，不扣分。
3. **分类小标题（直接／间接／潜在）只作组织方式**：不加分、不扣分。
4. **条理／分层只作写作建议**：不加不扣。
5. **字数超上限只核验、只提示**：不扣分、不降档。
6. **未用材料原句不扣分**：同义概括一律允许。
