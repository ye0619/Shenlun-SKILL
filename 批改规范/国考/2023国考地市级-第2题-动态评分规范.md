### 1.2 格式池（1.5分，10%）
- 标题 0.5：居中，含主体名＋“案例摘要”（如“L市知识产权信息服务中心案例摘要”）。
- 体例 0.5：案例体——不设主送机关、不写发文机关署名与成文日期；可用“摘要：”领起。
- 层次 0.5：总—分（三案例并列）—收束；分条或“一是/二是/三是”。

### 1.3 语言池（1.5分，10%）
- 准确 0.5：第三人称客观陈述，术语规范（地理标志产品、商标注册、授权）；**技术名称须与材料一致**（高垄种植技术，误写“高端种植技术”扣本项）。
- 简明 0.5：≤300字，概述体，不复述对话、不堆数据。
- 条理 0.5：三案例顺序一致、句式并列、不交叉重复。

## 2. 可接受的同义表达
1. “案例摘要”可写“优秀案例摘要／实践摘要”；标题含中心名称或“L市”均可。
2. “专项组进驻”可写“派驻服务组／下沉乡镇”。
3. “高垄种植技术”为唯一可用名称；“提档升级”可写“品质提升”。
4. “分批申请”可写“分期申报／逐类注册”。
5. “企业＋地理标志商标＋标准化＋农户”可简写“地标＋标准化＋农户”联动模式。
6. 只做语义核对：同一动作换说法且材料可支撑 → 给分。

## 3. 部分命中规则
- 三要素齐备 → 满分；缺要素（缺动作、缺对象或缺意义）→ 取该点 60%，按 0.5 粒度就低。
- 只有“意义”没有“做法”，或只列案例名称 → 对应点 0—0.5 分。
- 与材料矛盾的技术名称、机构职能错误 → 该点按部分命中，并在语言池扣 0.5。
- 多写的无害内容不倒扣。

## 4. 不应机械扣分的情况
1. 未写“2017年10月”“2018年”等时间不影响总起点满分（时间不单独计分）。
2. 未写“60余种”具体数字不扣分。
3. 未用“摘要：”领起不扣分（可用导语代替）。
4. 字数不足下限只提示（本题为上限型要求，无下限）。
5. 结构选择（分案例／分类别）不加不扣。
