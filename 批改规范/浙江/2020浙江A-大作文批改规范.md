## 二、四样提炼（不提炼分档分数线）

### 1. 立意梯度（切题 / 偏题判定）

- **题眼是"变"**——话题出自资料 5 习近平总书记讲话（"客观实际不是一成不变的""准确把握我国不同发展阶段的新变化、新特点，
  使主观世界更好符合客观实际，按照实际决定工作方针"），并落在资料 7 的"大变局、大变革、大事件都摆在那里……战胜挑战就是新机遇，
  克服困难就能再上新台阶，**这就是辩证法**"。
- **切题内核**：中心论点须**扣住"困难与机遇同在、挑战与希望并存"的辩证关系**，并与之**紧密结合给定资料**——
  本卷 4 篇范文**无一例外都把落点放在浙江制造业/传统制造业改造提升上**（这是本卷资料 1—4、6、7 的绝对主线）。
- **合格重心**（任取 2–3 项）：① 把握变化（准确认识国际国内环境变化、使主观符合客观）；② 顺应/拥抱变化（科技革命、智能化转型）；
  ③ 在困难中创造机遇（危中寻机、化危为机）；④ 浙江实践（改造提升、疫情技改、"最多跑一次"改革与减负）；
  ⑤ 精神力量（浙商不畏惧不退缩）。
- **⚠ 本卷最关键的判定**：题面要求"**紧密结合给定资料**"（与 2021／2024／2025／2026A 等卷的"不拘泥于给定资料"**方向相反**）。
  因此——**通篇以材料外案例为主、浙江本地素材严重不足的，按"内容质量"实质扣分**；这**不构成偏题**（话题仍扣住），
  但**必须写出"结合不紧"差在哪**（引原文）。
- **偏题信号**：通篇泛论"变化"的人生哲理或国际形势，**完全不涉及制造业/浙江发展**；或只抓"变化"而丢掉"机遇与困难并存"的辩证一侧。

### 2. 论证梯度（核心论点清单）

把握变化（认识新变化新特点、主观符合客观）／顺应与拥抱变化（科技革命、智能化数字化）／危中寻机、化危为机／
浙江制造业改造提升的实践与成效／政府改革与服务保障（"最多跑一次"、减负降成本）／浙商精神。
**覆盖 3 个及以上且每项都回扣"困难与机遇并存"→ 论证深度进入本卷 T1 水准。**

### 3. 材料使用要求（**本卷特别强调**）

- **题面要求"紧密结合给定资料"** → **材料 1—7 的浙江素材（传统制造业地位与矛盾、改造提升成效数据、块状经济、宁波企业与 C 公司、
  疫情技改与金华 H 机器人、"最多跑一次"改革与减负额度、制造强省目标）是本题的内容主体**。
- **材料外案例可以使用**（T1 华图、T2 粉笔均用了材料外内容），**但不能替代材料主线**；以材料外案例为主、
  浙江素材仅作点缀的 → **按内容质量扣分，理由写"材料结合不紧"，不写"没引用某案例"**。
- **具体案例不是采分点**：未引用某个材料案例本身不得作为扣分理由；但**整卷浙江素材系统性缺失**属**内容质量问题**。

### 4. 禁止性口径（红线）

- 不得因"未引用某则材料／某个案例"扣分；不得因"用词与范文不同"扣分；不得因"结构不是某模板"扣分；
- 不得把"**立意稍微模糊**"当硬伤封顶（方向正确而表述不鲜明 → 只在题意维度扣质量分）；
- **"材料结合不紧"属内容质量问题，不属偏题**——只有"只谈相邻概念或仅抓次要概念"才按偏题封顶三类；
- 不得默认"机构范文＝一类文"；**本卷 2 篇范文残缺，更不得据其篇幅判断考生作答"不够长"**；
- 从紧口径（2026-09-22）：**档内定位默认落"下／中"**，只有 **≥4 项达本档上沿**才给"上"。

**接入点（阶段 B 必用其一，否则刻度空转）**：

1. **参照档约束大档**（三行规则）：六项**无一项明显弱于 T1** → 大档**不得低于二类上**；
   **介于 T1 与 T2 之间** → 大档落在**二类中—二类上**；**多项明显弱于 T2** → 大档**不得高于二类中**。

2. **画像定档内位置**：六项多数贴近 T1（且 T1 参照档与当前大档重叠）→ 本档**上**；大体在 T1／T2 之间 → **中**；

3. **撤掉／确认不成立的扣分项**：本卷 **T1 两篇都兑现了"紧密结合给定资料"、也都有边界表述** →
   **"材料结合不紧""缺边界意识"在本卷可作真短板证据**（**卷内结论，不得跨卷套用**）；
   但仍**只作内容质量与论证深度的一项证据，不单独压整个大档**。
4. **从紧给分（2026-09-22 用户裁定）**：档内定位默认落"下／中"，**≥4 项达本档上沿才给"上"**；硬伤一律执行；
   语言类扣分如实累计；**亮点不加分**。
5. **置信度**：本卷刻度为**双向**且指纹可核 → 大作文**校准置信度可上调半档**（"中"→"中偏高"）；
   因 **T2 两篇残缺**，**不得直接到"高"**。
