## 一、立意梯度（"梦想、创新、实干"）

| 层 | 形态 | 判据 |
|:--:|:--|:--|
| 第1层 | 单侧表态 | 只写三词中的一个，或三词并列但每词只有定性判断（"梦想是动力""创新是第一动力""实干是关键"），**无任何因果或条件关系** |
| 第2层 | 双向立意 | 三词并列成文，且**至少两词之间**给出因果／条件关系（"创新基于梦想、实干成就创新"），但机制解释不成链 |
| 第3层 | 传导链 | 三词串成一条链并解释**机制**：梦想→方向与动力、创新→路径与方法、实干→落地与转化；每一环回答"为什么"，形成完整因果链 |
| 第4层 | 传导链＋成立条件边界 | 在第3层基础上指出三词的**限度与成立条件**（梦想须以客观规律与国情为界；创新须以实干为落点、否则悬空；实干须以创新为方向、否则低效重复；"三足"缺一不成鼎），并给出条件性、可证伪的判断 |

- 本题题面第（2）项明确要求"**内容充实，论述深刻**"，故深刻度四级刻度（复述型／明理型／见地理型／洞见型）**参与定档**；但**不得单独定档**，必须落到六项特征与档内定位五项上。
- 本卷 T1 范文实测梯度分布：第2层 **5/7 篇**、第3层 **4/7 篇**、第4层 **0/7 篇** → 第4层是本卷"一类"与"二类"的实质分界。

## 三、常见失分点

1. 三词平均用力、各自"定性判断＋例证"，全篇不回答"为什么能成就伟大事业" → 停在**第2层**，内容质量只能判"较充实"。
2. 案例堆砌（嫦娥探月、三峡、北斗、5G）后**直接以号召句收束**，例后无析 → 本卷 T1 范文的通病（5/7 篇），也是**参照档封顶的直接原因**。
3. 只谈创新或只谈实干，**缺一足**，或把"梦想"从分论点中删去 → 题意完整性受损。
4. **引文误写**（如把"积力之所举，则无不胜也；众智之所为，则无不成也"写成"权力之所举……积智之所为……"）→ 记入**语言质量**，不升格为硬伤封顶。
5. **病句与语义重复**（如"若每个人都劲往一处使，则事无成"逻辑倒置；"诞生的伊始"重复）→ 记入语言质量。
6. 分论点之间只是**同义反复**、无递进 → 结构完成度判"完整"而非"严谨"。
7. 大段照录材料原句（如整段抄材料3、材料2/4）→ 记入材料运用与语言质量；**但"引用得当"本身不加分，"引用不当"也不加分**。

## 四、硬性与禁止口径

硬伤封顶表（**只设上限、未命中不降档**）：

| 硬伤 | 处理 |
|:--|:--|
| 明显跑题（与"梦想、创新、实干"话题无关） | 四类封顶 |
| 偏题（只写其中一个词且未扣"伟大事业"） | 三类封顶 |
| 核心任务遗漏严重（写成记叙文/散文，无论证） | 三类封顶 |
| 论点与材料主旨冲突 | 三类封顶 |
| 大面积无法辨认 | 下调一档 |
| 未命中上述任何一项 | **不降档** |

禁止口径（出现即该处判分作废）：
1. 不因结构形态、是否模板化（三段式、小标题、"总分总"）而扣分或加分。
2. 不因"没出现某个词"就判偏离。
3. 不因"没引用材料某个案例"而扣分。
4. 不因"立意稍微模糊"就二类封顶——须给出可核验的偏离证据。
5. 不写"不够深刻"而不点名缺哪一层（须落到上一节四级刻度与六项特征）。
6. 不因"与某篇范文相似"而加分。
7. 不因"某机构写了这个点"就必须给分（**家数只决定权重**）。
8. 反向禁止：不把"复用同一案例"当扣分理由（一策双证合法）。
9. "写得泛泛／口号式表述"本身不得扣分或降档；要扣只能落到"内容空洞＝既无材料事实也无替代性支撑、论证乏力"并**引原文**；反向，用了排比或警句也**不加分**。
10. **材料引用双向免分**：引用得当不加分、引用不当也不加分；**未使用材料而把论点证明充分 → 不得扣分、不得降档**。自检法＝"除掉这段材料，论点还立得住吗？"

其他纪律：
- **用户字数只核验不计分**：报告单列"⚠ 字数提示：超出题干上限 X 字（按用户口径不计分）"，不扣分、不降档，压缩建议照给。
- 双评与仲裁：第二遍只能用缓存的规范与画像、**不得重读原材料**；大档相同且小档差 0 → 取第一遍、报告不写分差块；不一致 → 强制复议，取证据更充分一方，证据相当取较低一档，写 `双评分差：<第一评>–<第二评>，仲裁后取 <终评>`；**不得取平均**。
