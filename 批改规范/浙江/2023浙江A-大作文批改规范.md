## 二、四样提炼（不提炼分档分数线）

### 1. 立意梯度（切题 / 偏题判定）

- **题眼在"对此，你有怎样的思考？"**——题干把**两种取向并列摆出**（物质标准上升 ←→ 基层吃苦的获得感），
  要求考生**就这组张力作答**。因此：
  - **最切题**：**直接回应张力**，或**辨析两者并不对立**（"个人需要与社会需要并非对立""追求收入舒适稳定没有错，但不应止步于此"），
    或**明确给出自己的价值取向**（"超越'小确幸'，心怀'大担当'"）。
  - **次之**：只承接其中一侧展开（如只谈"到基层去"），未处理另一侧。
  - **偏弱**：只做**对策罗列**（如何促就业），**通篇不回应"思考"**——本卷 2 篇范文（展鸿、千寻）即此路径，
    归入较低梯队（**注意：这不构成偏题封顶，只在题意质量上扣分**）。
- **合格重心**（任取 2–3 项）：① 尊重个人择业自由、承认"收入／舒适／稳定"诉求的合理性；
  ② 提升到价值取向（家国情怀、大担当、向下扎根）；③ 辨析两组关系（物质与精神、个人与集体、小我与大我）；
  ④ 引导与保障（就业观教育、高校培养、政策护航）；⑤ 基层成才的现实意义。
- **偏题信号**：通篇不谈就业与择业观；或只把"就业"当成经济议题、完全不涉及"价值取向"这一层。
- ⚠ **本卷 T3 的教训**：中公范文直接判定"收入舒适稳定"为"**物欲的、短视的择业观**"——**单边褒贬、不给对立方正当性**，
  属**论证分寸不足**（对照 T1 两篇均先正名再提升）。这类写法**不判跑题／偏题**，但在**论证深度**上扣质量分。

### 2. 论证梯度（核心论点清单）

尊重择业自由与个人合理诉求／超越"小确幸"心怀"大担当"／物质与精神、个人与集体的关系辨析／
到基层和中西部去同样能实现人生价值并收获成就感／就业观与择业观的教育引导／高校培养与市场需求对接、学以致用／
政策护航与人才引向基层。**覆盖 3 个及以上且每个论点都"回应张力"→ 论证深度进入本卷 T1 水准。**

### 3. 材料使用要求

- "**不拘泥于给定资料**"＝ **可以且鼓励使用材料外的真实案例、政策、数据**。
- **只复述材料案例不构成加分，也不构成扣分**；**通篇无任何具体锚点**（如 T3 的粉笔）→ 属"**缺支撑**"，
  按**内容质量／论证深度**扣质量分，**理由写"缺支撑"，不写"没引用材料某案例"**。
- **"联系实际"**（本题题面**明确要求**）：合格线＝至少一处**材料外**真实案例／政策／数据并能回扣论点；
  **仅复述材料不构成硬伤、不封顶**，只在内容与论证维度体现。

### 4. 禁止性口径（红线）

- 不得因"未引用某则材料／某个案例"扣分；不得因"用词与范文不同"扣分；不得因"结构不是某模板"扣分；
- 不得把"**立意稍微模糊**"当硬伤封顶（方向正确而表述不鲜明 → 只在题意维度扣质量分）；
- **"没有直接回应题面追问"属题意质量问题，不属偏题**——只有"只谈相邻概念或仅抓次要概念"才按偏题封顶三类；
- **本卷 T1 两篇都有"为收入／舒适／稳定正名"的边界句** → **"缺边界句"在本卷可作为论证深度的短板证据**
  （**注意：与其他卷不同，不得跨卷套用"T1 同层薄"的结论**）；但仍**不得单独据此压整个大档**；
- 不得默认"机构范文＝一类文"；**本卷范文多为节选，更不得据其篇幅判断考生作答"不够长"**。

**接入点（阶段 B 必用其一，否则刻度空转）**：

1. **参照档约束大档**：六项**无一项明显弱于 T1** → 大档**不得低于二类上**；
   **介于 T1 与 T2 之间** → 大档落在**二类中—二类上**；**多项明显弱于 T2** → 大档**不得高于二类中**。
2. **画像定档内位置**：六项多数贴近 T1（且 T1 参照档与当前大档重叠）→ 本档**上**；大体在 T1／T2 之间 → **中**；多数贴近 T2 及以下 → **下**。
3. **撤掉不成立的扣分项**：某项目不弱于 T1 → 不得据此压档；**反之，T1 两篇都具备的"边界意识"若考生缺失，可作为真短板证据**
   （但仍只作论证深度的一项，不单独压大档）。
4. 本卷刻度为**双向** → 大作文**校准置信度可上调半档**（"中"→"中（偏高）"）；
   但因 **5 篇范文残缺**，**不得上调到"高"**。
