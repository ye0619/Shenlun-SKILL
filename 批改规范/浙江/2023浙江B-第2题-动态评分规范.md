# 2023浙江B 第2题《当数字技术遇上传统农业》短评 动态评分规范（本卷专用）

> **性质声明**：本规范为**经验口径（L3，非官方）**。官方采分细则不公开，档位、权重与拆分均系模拟。唯一硬依据为题面要求与大纲能力（L1）及公开赋分描述（L2）。

## 一、题面与身份（L1 硬依据）

- **题干**："资料4"是《P市日报》拟刊发的一篇新闻报道，请你围绕这则报道，以"当数字技术遇上传统农业"为题，写一则短评，与该报道一同刊发。（30分）
- **要求**：（1）观点鲜明，论述深刻；（2）结构完整，条理清晰；（3）不超过600字。
- **题型判定**：**短评（新闻评论）** → 按公文框架处理，**文章类**（标题＋正文），不要求称呼落款。
- **题面已给定标题**：`当数字技术遇上传统农业` → 格式池标题项：**照题干写即得**；自创相似标题亦不扣。
- **身份场景**：以《P市日报》评论员/评论作者身份，与新闻报道**同期刊发** → 需与报道形成"事实报道＋观点评析"的分工关系。
- **写作目的**（本题核心，容易写偏）：**不是复述报道，而是对报道事实作出评析**——即回答"数字技术为什么会/如何能与传统农业融合，这件事意味着什么"。
- **⚠ 本题最大陷阱**：写成"报道要点摘编"。摘编型作答即便信息齐全，也只能在内容池得部分分，且"观点鲜明"一项失分。

- 示例参考答案目标区 ＝ **510–570 字**（85%–95%）。

## 七、本题易错点（评分提示）

1. **写成报道摘编**——最常见。表现为全篇"数字化助力××"＋事实罗列，无解释性判断、无评论语汇。内容池可取 C2–C4 的论点句与论据分，但 C1、C5 大量失分，语言池再扣"评论文体"1–2 分。
2. **只有列举、没有递进**——三个分论点平铺且彼此边界模糊（如"精准控制"与"绿色循环"都写水肥控制），C3/C4 重复计分须去重。
3. **脱离报道自说自话**——通篇宏观政策表述、不见报道事实，C2–C4 的"事实论据"分不得。
4. **把标题当正文首句**——标题即题干句时，正文首句重复该句属冗余，语言池可 −0.5。
5. **字数**——不计分。
