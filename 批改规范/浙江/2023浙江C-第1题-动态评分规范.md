## 2. 可接受的同义表达

- "大部制改革"≈"深化机构改革""系统性重塑体制机制""一枚印章管审批"。
- "市管社区扁平化"≈"不坐机关坐社区""直接治理模式""社区联合党委党建统领"。
- "一网统管"≈"数字化治理""靠智治""数字赋能""市级指令直达社区贯通网格"。
- "三大百亿级产业集群"可写产业名（印刷包装、新型材料、绿色纺织），也可写"百亿级产业集群"。
- "引进顶尖团队"可写成"与高校／科研院所智联合作"；"与大医院智联合作"可写成"与温医大附一院合作、全面运营管理"。
- "新城崛起"可写作"建设未来之城""城市更新"。
- 分条格式（1./2. 或"一是/二是"）、要点顺序均不影响得分；用四大类＋子项或直接列 6–12 条小点均可。

## 3. 部分命中规则

每块三要素：**核心动作**｜**核心对象**｜**关键限定/结果**。

| 缺项 | 给分 |
|---|---|
| 三要素齐、表述准确 | 该块满分 |
| 缺"关键限定/结果"（如只写"大部制改革"，不写重塑体制机制组织架构与运行体系原则） | 该块 60%（3 分） |
| 缺"核心对象"（写"改革"而不写改革的具体领域／对象） | 该块 50%（2.5 分） |
| 只有领域名（"行政改革""产业发展"）而无具体做法 | 该块 0 分（泛泛表述，无可核对指向） |
| 漏整块 | 扣该块 5 分 |

- 同一块内**子项漏一两个**但主干在（如行政改革只写大部制＋市管社区、漏"一网统管"）：该块给 70%–80%（3.5–4 分），**就低不就高**。
- **多写不扣分**：写"一窗通办""话务并轨""110与12345并轨""与高校智联合作"等材料细节，均不加分也不扣分。

## 4. 不应机械扣分的情况

- 未写"一窗通办""话务并轨""BOPE 材料"——**未写不扣**（列举式细节，口径2）。
- 未写任何数字（1146项、80%、54.5%、10件、15个子项目、67公顷、56亿元）——**不扣分**（口径1：数据不属采分点）。
- 未写"撤镇设市背景""40%行政资源承接100%职能"——**不扣分**（背景）。
- 写了"与高校达成智联合作"而材料原文为"与温医大附一院"——**同义，不扣分**。
- 总分结构（"一是…二是…"）与机构答案的四大类不同，只要内容覆盖——**不扣分**。

## 5. 材料使用要求

- 必须**以材料1为唯一取材范围**；全部做法点均可在材料1找到出处（硬门槛）。
- 允许上位概括（"县级行政运行体系""多元共治""战略性新兴产业"），**不允许自造结论**（如"推行'县管校聘'""建立河长制"等材料无据内容）。
