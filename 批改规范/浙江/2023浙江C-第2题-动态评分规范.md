## 2. 可接受的同义表达

- "共享法庭"释义可写作："架构在数字空间、虚拟在群众身边的人民法庭""数字化司法服务的创新载体""将法庭搬到群众身边"。
- 技术手段可**列举也可概括**为"数字化手段／大数据等技术"（列举不全不扣分）。
- "就地调／指导调／邀请调"可写作"一般纠纷就地调、复杂纠纷指导调、涉诉纠纷邀请调"，也可写作"分级分类调解""把矛盾化解在基层"。
- "行业纠纷行业解"≈"依托行业调解组织解纷""专业性纠纷专业解"。
- "在线旁听"≈"组织群众旁听庭审""以案释法"。
- "执行 e 站"可写作"执行工作站""执行触角延伸至村社"。
- 论点顺序、是否加总括句均不影响得分。

## 3. 部分命中规则

| 情形 | 给分 |

| 释义三要素齐（核心动作＝设立／核心对象＝人民法庭／关键限定＝数字空间·虚拟在身边·数字技术） | ①满分（4） |

| 写"执行难"但只写"解决执行难"不写"执行 e 站／网格化管理／延伸末端" | ⑧给 2 分 |
| 通篇只有"是创新举措、有重要意义"式评价 | 全题 0–3 分 |
| 漏整点 | 扣该点全部分值 |

- **多写不扣分**：写"未来应继续发挥'共享法庭'作用""必要性"整段、引用岱山衢山岛等具体案例，均不加分也不扣分。

## 4. 不应机械扣分的情况

- 采用"必要性—做法—意义"结构（中公式）而非"释义—作用—意义"结构——**不扣分**（两种都是"理解"的合法组织方式）。
- 未列案例人名（毛某与贝阿婆）——**不扣分**（具体案例不是采分点）。
- 未写"东海渔嫂"这一具体主体，写"基层组织／调解员"——**同义，不扣分**。
- 未单列"未来展望"——**不扣分**（可写可不写）。
- 未写数据（"2021年11月30日""10余名业主代表"）——**不扣分**（口径1）。
