## 一、题型 / 分值 / 题面要求（L1 原文）

| 项 | 内容 |
|---|---|
| 题型 | 议论性文章（大作文，划档赋分） |

| **题面作答要求（原文照录）** | （1）主旨明确，结构完整，思路清晰；（2）内容充实，论述深刻，语言流畅；（3）不拘泥于给定资料；（4）字数 1000-1200 字 |

## 二、四样提炼（不提炼分档分数线）

### 1. 立意梯度（切题 / 偏题判定）

- **本卷主旨（据 6 篇范文与材料 2—7 的共同指向）**：**科技服务社会、造福人民**——
  即科技发展要回应人民需要、惠及民生（工程科技"源于生活需要，又归于生活之中"；"人民的需要和呼唤，
  是科技进步和创新的时代声音"；科技成果要弥合数字鸿沟、满足消费需求）。
- **切题内核**：中心论点须落到"**科技为民／科技惠民／科技服务社会民生**"这一侧；
  仅泛论"科技很重要／科技促发展／建设科技强国"而**不把"服务人民"作为中心论点**的 → **题意重心偏移**（扣题意质量分）。
- **合格重心**（任取 2–3 项即可）：① 科技回应人民需要、解决急难愁盼；② 科技改善民生、提升生活品质（适老化、
  智能家电、公共服务）；③ 科技助力产业与经济发展，最终让群众受益；④ 科技赋能乡村与城市治理，让成果共享；
  ⑤ 科技向善的边界（防止技术滥用）。
- **角度自由**：可写"科技为民"的机制（华图）、"基建—乡村—民生"三线（千寻）、"产业＋民生＋自主创新"（粉笔）
  ——**均合规**；题面明示"自选角度"。
- **偏题信号**：通篇只谈科技成就／科技强国／数字化进程而不回到"人"与"民生"；把主旨写成"科技创新方法"。
- ⚠ **"围绕资料主旨"是本题的硬要求**（比一般"结合给定资料"更紧）：**重心与主旨错位 ≠ 跑题**，
  但**必须扣题意质量分**（本卷 T3 两篇范文即因重心偏移而落在较低梯队）。

### 2. 论证梯度（核心论点清单）

回应人民需要（青蟹养殖、盐碱地改良等）／改善民生与公共服务（一键养老、弥合数字鸿沟、远程教育医疗）／
赋能产业与经济（盾构机、光伏、新能源汽车、智能小家电）／成果共享与乡村振兴（数字乡村、乡村大脑、
数字生活馆）／自主创新与成果落地（创新中心、成果转化）／科技向善的边界与纠偏。
**覆盖 3 个及以上、且每个论点都写出"科技如何让人受益"→ 论证深度进入本卷 T1 水准。**

### 3. 材料使用要求

- "**不拘泥于给定资料**"＝ **可以且鼓励使用材料外的真实案例、政策、数据**（本卷 T2 粉笔用"油车 vs 电动汽车"、
  T3 王鹍用"苹果产业大数据中心""学习强国·在家上学"）。
- **只复述材料案例不构成加分，也不构成扣分**；但**通篇无任何具体锚点**（如 T3 小马哥）
  → 属"**缺支撑**"，按**内容质量／论证深度**扣质量分，**理由写"缺支撑"，不写"没引用材料某案例"**。
- ⚠ **材料外案例必须真实**：自撰的泛化描述**不构成支撑**。
- **"联系实际"**（本题题面**明确要求**，不同于 2025／2026 卷）：合格线＝至少一处**材料外**真实案例／政策／数据
  并能回扣主旨；不合格＝只有空泛表态而无事实/机制/论证支撑、通篇复述材料、编造无据事实（"口号式表述"本身不构成扣分／降档理由）。
  **注意：仅复述材料不构成硬伤、不封顶**，只在内容与论证维度体现。

### 4. 禁止性口径（红线）

- 不得因"未引用某则材料／某个案例"扣分；不得因"用词与范文不同"扣分；不得因"结构不是某模板"扣分；
- 不得把"**立意稍微模糊**"当硬伤封顶（方向正确而表述不鲜明 → 只在题意维度扣质量分）；
- **不得仅以"缺边界句"压档**——本卷 T1 的千寻、T2 两篇都没有边界句（见画像第三节接入点 4）；
- 不得默认"机构范文＝一类文"，不得把范文当分数锚点或插值；
- **核心概念/用词写错**（如"数实融合"误作"素食融合"）属**语言与准确性**问题，**按质量分扣，不构成跑题偏题**。

**接入点（阶段 B 必用其一，否则刻度空转）**：

1. **参照档约束大档**（三行规则）：六项**无一项明显弱于 T1** → 大档**不得低于二类上**；
   **介于 T1 与 T2 之间** → 大档落在**二类中—二类上**；**多项明显弱于 T2**（尤其是"立意重心偏移"＋"缺支撑"）→ 大档**不得高于二类中**。
2. **画像定档内位置**：六项多数贴近 T1（且 T1 参照档与当前大档重叠）→ 本档**上**；大体在 T1／T2 之间 → **中**；
   多数贴近 T2 及以下 → **下**。
3. **撤掉不成立的扣分项**：某项目不弱于 T1 → 不得据此压档（**尤其"边界意识"**）。
4. 本卷刻度为**双向** → 大作文**校准置信度可上调半档**（"中"→"中（偏高）"），**不得直接到"高"**。
