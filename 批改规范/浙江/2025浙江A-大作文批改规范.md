## 二、四样提炼（不提炼分档分数线）

### 1. 立意梯度（切题 / 偏题判定）

- **切题内核**：必须建立"**生产性服务业 → 新质生产力**"的**作用关系**，即说明前者**通过什么机制**赋能后者
  （技术革命性突破／生产要素创新性配置／产业深度转型升级——材料 6 给的三条路径）。
  只并列谈"生产性服务业很重要"和"新质生产力很重要"而不写作用机制 → 属**立意偏浅**。
- **合格重心**（任取 2–3 项即可）：① 数智技术／创新中心推动技术突破；② 科技金融与人才服务促进要素创新性配置；
  ③ 物流与制造业融合（两业融合）重塑产业链供应链；④ 政策体系与现代服务业体系建设；⑤ 绿色低碳转型方向。
- **角度自由**：机制分析角度（华图式）、路径对策角度（千寻、中公式）**均合规**（题面明示"自选角度"）。
- **偏题信号**：通篇只写"服务业发展成就"不落到"新质生产力"；把"生产性服务业"与"生活性服务业"混为一谈而不作区分；
  把话题写成"以旧换新"或"服务型制造的浙江实践"（那是第 1、2 题的范围）。

### 2. 论证梯度（核心论点清单）

技术突破（创新中心主导研发、共性技术攻关）／要素配置（科技金融、人才银行、知识产权与数据要素）／
两业融合（物流嵌入产业链、制造与服务协同）／政策引领（现代服务业体系、示范培育）／绿色与智能化方向。
**覆盖 3 个及以上、且每个论点都写出"为什么能赋能"→ 论证深度进入本卷 T1 水准。**

### 3. 材料使用要求

- "**不拘泥于给定资料**"＝ **可以且鼓励使用材料外的真实案例、政策、数据**。
- **只复述材料案例不构成加分，也不构成扣分**；但**通篇无任何具体锚点**（如 T3 样本的粉笔）
  → 属"**缺支撑**"，按**内容质量／论证深度**扣质量分，**理由写"缺支撑"，不写"没引用材料某案例"**。
- **"联系实际"**：本题题面**未写**"联系实际"，只写"不拘泥于给定资料" → **不按"联系实际"单列检查项**，
  仅在内容与论证维度看"是否有材料外的真实支撑"。
- ⚠ **材料外案例必须真实**：自撰一个"某某公司如何如何"的泛化描述（无据）**不构成支撑**，按"缺支撑"处理。

### 4. 禁止性口径（红线）

- 不得因"未引用某则材料／某个案例"扣分；不得因"用词与范文不同"扣分；不得因"结构不是某模板"扣分；
- 不得把"**立意稍微模糊**"当硬伤封顶（方向正确而表述不鲜明 → 只在题意维度扣质量分）；
- **不得仅以"缺边界句"压档**——T1 两篇（华图、千寻）都没有边界句（见画像第三节接入点 4）；
- 不得默认"机构范文＝一类文"，不得把范文当分数锚点或插值；
- **核心术语写错**（如把"生产性服务业"写成"生产**型**服务业"）属**语言与题意质量问题**，
  **按质量分扣，不构成跑题偏题**。

**刻度形态＝T1 单向**（T1 ×2；T2 仅 1 篇，不足以构成双向）→ **下沿无锚**。

**接入点（阶段 B 必用其一，否则刻度空转）**：

1. **"不低于 T1"的下不封顶约束**：用户作文六项若**无一项明显弱于 T1** → 大档**不得低于二类上**；
   若四维判定更低，必须写出**差在哪一项、差多少**。
2. **画像定档内位置**：六项多数贴近 T1（且 T1 参照档与当前大档重叠）→ 本档**上**；大体等同 T1 → **中偏上**；
   明显弱于 T1 的项集中于"②论点覆盖／⑤落点具体度／⑥材料运用" → **中或中偏下**。
   （**注意**：单向刻度只提供"上沿一侧"的锚，**不得据此定"下"**——"下"只能由四维实据支撑。）
3. **撤掉不成立的扣分项**：某项目不弱于 T1 → 不得据此压档（**尤其"边界意识"**）。
4. **置信度**：**单向刻度不上调校准置信度**（只有双向刻度才可上调半档）。
