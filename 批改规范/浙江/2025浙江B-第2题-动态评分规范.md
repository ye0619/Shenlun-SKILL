## 3. 部分命中规则（三要素：核心动作｜核心对象｜关键限定/结果）

- **完整命中**（观点＋材料支撑齐）→ 该点满分（6 分）。
- **只有话题转写、无实质判断**（如"文化之光照亮乡村共富路，我们要重视文化"）→ **取半 3 分**（本题用户①即此情形）。
- **观点到位但材料支撑薄**（泛泛举例、不落到两村）→ **4–5 分**。
- **漏写某个采分点** → 该点 0 分（不因"写满其他点"补分）。
- **只列做法、无观点句** → 该点按"论述/评论不足"在**语言池**体现（不重复在内容池扣）。
- **泛泛表述、无可核对的具体指向** → 0 分（从紧，2026-09-22）。

## 4. 不应机械扣分的情况

- **标题**：题面**已给定**标题 → 照抄即可、**不能自拟**（自拟属格式池"标题不符"）；标题抄错字另计。
- **称呼／落款／日期**：文章类短评**不要求**，未写**一律不扣**。
- **引用材料原数据（20.49 万人次／315 万元／15216→36187 元）**：不加分、不写不扣。
- **超出资料1、2 的案例**：不加分、不扣分（不得因"未引用某案例"扣分）。
- **分论点数量与命名方式**（"一是/二是"或小标题或散文化）：不因"不像某类型"扣分，也不因"套用某框架"加分（判语黑名单双向封禁）。
- **字数**：题干"不超过600字"须核验，但**不计入评分**——超限只在报告单列提示，不扣分、不降档。
- **正文段落数量**：不作为格式扣分项（只核"是否分段"）。

## 7. 格式池与语言池检查项

**格式池 3 分**
- 标题：**已给定 → 须照抄原标题**（自拟／改动 → 扣该要素 1 分）
- 正文分段：不分段 −0.5~−1（分段且层次顺＝不扣）
- 称呼、落款/日期：文章类**不要求**，未写不扣

**语言池 3 分**
- 文体（短评的评论性）：多为材料转述、缺"这说明/可见/正因如此"式评论句 → −1（先例：2025浙江A 同一处理）
- 准确性：数据／专名写错 → −1（本题扣"旅游收入占比超50%"应为"超80%"）
- 流畅度：口语化/公文腔堆砌 −0.5~−1；身份感错位 −1；病句按语言通顺度处理
- **各池扣分合计 ≤ 总分 10%**（小额原则）；格式/语言只作小额修正，不得成为主要区分度来源
