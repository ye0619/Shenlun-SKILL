## 二、四样提炼（不提炼分档分数线）

### 1. 立意梯度（切题 / 偏题判定）

- **切题内核**：必须建立"**电力自由 → 产业竞争优势**"的**因果联结**，而不是并列谈两个话题。
  "电力自由"的义项至少覆盖"**稳定可靠 / 成本可控 / 绿色低碳**"之一以上，并落到**竞争结果**（成本、市场份额、
  交付能力、出口准入、产业链安全）。
- **合格重心**（任取 2–3 项即可，**不必求全**）：① 稳定供应保障生产连续性（含电能质量、零闪动）；
  ② 电价稳中有降降低实体成本；③ 充沛电力支撑新质生产力与算力；④ 绿电与碳核算突破绿色贸易壁垒；
  ⑤ 智能化提升系统柔性；⑥ 电力技术装备体系形成全球竞争新优势；⑦ 电力自主可控化解能源安全风险。
- **角度自由**：企业视角／区域视角／国家视角／能源安全视角**均合规**（题面明示"自选角度"）；
  六篇范文中公道公考取"能源自主权"、千寻取"实现路径"，均判切题。
- **偏题信号**（据 L1 与范文画像）：只谈"电力发展成就／浙江电力蝶变"而不回到"产业竞争优势"；
  只谈"电力重要"而无"自由"与"竞争"的因果；把"电力自由"窄化为"电价越低越好"而无稳定／绿色维度。

### 2. 论证梯度（核心论点清单）

稳定供应保障生产连续性（含精密制造电能质量）／电价稳中有降降低实体经济成本／充沛电力支撑算力与新质生产力／
绿电与碳核算突破碳关税等绿色贸易壁垒／AI 与电力系统融合提升系统柔性／电力技术与装备体系输出形成全球优势／
电力自主可控保障产业链安全。**覆盖 3 个及以上且层层有落点 → 论证深度进入本卷 T1 水准。**

### 3. 材料使用要求

- "**不拘泥于给定资料**"＝ **可以且鼓励使用材料外的真实案例、政策、数据**（如 T1 的"平顶山增量配电网"
  "远景能源绿氨出口韩国"）。
- **只复述材料案例不构成加分，也不构成扣分**（具体案例不是采分点）；但**通篇无任何具体锚点**
  （如 T3 样本）→ 属"**缺支撑**"，按**内容质量／论证深度**扣质量分，**理由写"缺支撑"，不写"没引用材料某案例"**。
- **"联系实际"合格线**：至少一处材料外真实案例／政策／数据，并能**回扣中心论点**；
  **不合格**＝只有空泛表态而无事实/机制/论证支撑、通篇复述材料、编造无据事实（"口号式表述"本身不构成扣分／降档理由）。**注意：仅复述材料不是硬伤、不封顶**，只在内容与论证维度体现。

### 4. 禁止性口径（红线）

- 不得因"未引用某则材料／某个案例"扣分；不得因"用词与范文不同"扣分；不得因"结构不是某模板"扣分；
- 不得把"**立意稍微模糊**"当硬伤封顶（方向正确而表述不鲜明 → 只在题意维度扣质量分）；
- **不得仅以"缺边界句"压档**——T1 的华图同样无边界句（见画像第三节接入点 4）；
- 不得默认"机构范文＝一类文"，不得把范文当分数锚点或插值。

**接入点（阶段 B 必用其一，否则刻度空转）**：

1. **参照档约束大档**：用户作文六项与 T1／T2 画像逐项对照 → "不低于 T1"则大档不得低于二类上；
   "介于 T1 与 T2 之间"则大档落在二类中—二类上；明显低于 T2 则大档不得高于二类中。
2. **画像定档内位置**：六项多数贴近 T1（且 T1 参照档与当前大档重叠）→ 本档**上**；
   大体在 T1／T2 之间 → **中**；多数贴近 T2 及以下 → **下**。
3. **撤掉不成立的扣分项**：某项目不弱于 T1 → 不得据此压档（尤其"边界意识"）。
4. 本卷刻度为**双向**（T1×2 ＋ T2×3，来源指纹可核）→ 大作文**校准置信度可上调半档**
   （"中"→"中偏高"），**不得直接到"高"**（刻度本身是 L4、参照档是助手推断）。
