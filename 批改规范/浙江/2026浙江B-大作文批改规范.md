## 二、四样提炼（不提炼分档分数线）

### 1. 立意梯度（切题 / 偏题判定）

- **题眼是"辩证之道"**——话题把"小切口"与"大健康"作为**一对关系**给出，并要求写**讨论性文章**。
  因此**必须处理两者之间的关系**，而不是罗列"小切口有哪些"。
  - **最切题**：把"辩证"落成**可论证的双向结构**（如 T1 隐隐于斯的"小处着手／大处着眼／落脚于人"三问），
    或至少**明确界定两者的关系**（如 T1 月月申论"'小切口'是具体举措、'大健康'是宏大目标，二者相互关联、相互促进"）。
  - **次之**：以"切口类型"（治已病／防未病／医心病）平行展开，**"大健康"只作被保障的对象**（本卷 T2 胡荣展即此路径）。
  - **偏弱**：通篇罗列健康举措与成效，**不出现"小切口"与"大健康"的关系判断**。
- **合格重心**（任取 2–3 项）：① 小切口是破解大健康难题的**路径**（精准发力、资源用在刀刃上）；
  ② 大健康是统摄小切口的**价值坐标／框架**（从个别探索上升为普惠制度）；
  ③ **落脚于人**（以群众需求为原点）；④ 小切口如何与大健康**相互转化**（试点→制度、局部→全域）。
- **角度自由**：分领域（心理／基层医疗／科普）、分层（路径／坐标／目的）、分环节（治已病／防未病／医心病）**均合规**。
- **偏题信号**：通篇不谈健康状况与健康治理；或只谈"看病就医"而不涉及健康浙江的公共治理层面。
- ⚠ **本卷 T2 的教训**：只写"三类小切口"而不论"辩证"，**不构成偏题**（关系的一侧仍在），
  但**必须在题意质量上扣分**——这是本卷与 T1 的主要差距所在（见画像第三节接入点 4）。

### 2. 论证梯度（核心论点清单）

小切口精准发力（对症下药、资源用在刀刃上）／大健康统筹全局（系统观念：身心全领域、老中青全年龄、防治管全流程）／
以小见大、落脚于人（群众需求为原点）／试点探索上升为普惠制度／政府社会家庭个人多方协同／
科技赋能（数字化、AI）让服务可及。**覆盖 3 个及以上且每个论点都回答"小与大如何相互作用"→ 论证深度进入本卷 T1 水准。**

### 3. 材料使用要求

- "**不拘泥于给定资料**"＝ **可以且鼓励使用材料外的真实案例、政策、数据**。
- **只复述材料案例不构成加分，也不构成扣分**；但**通篇无材料外增量**（本卷三篇范文均有材料外背景或政策）→ 属"**联系实际偏弱**"，
  按**内容质量／论证深度**扣质量分，**理由写"缺支撑／缺增量"，不写"没引用材料某案例"**。
- **"联系实际"**（本题题面**明确要求**）：合格线＝至少一处**材料外**真实案例／政策／数据并能回扣论点；
  **仅复述材料不构成硬伤、不封顶**，只在内容与论证维度体现。
- ⚠ **材料外案例必须真实**，自撰的泛化描述不构成支撑。

### 4. 禁止性口径（红线）

- 不得因"未引用某则材料／某个案例"扣分；不得因"用词与范文不同"扣分；不得因"结构不是某模板"扣分；
- 不得把"**立意稍微模糊**"当硬伤封顶（方向正确而表述不鲜明 → 只在题意维度扣质量分）；
- **"未处理辩证关系"属题意质量问题，不属偏题**——只有"只谈相邻概念或仅抓次要概念"才按偏题封顶三类；
- 不得默认"机构范文＝一类文"，不得把范文当分数锚点或插值；
- 引用/史实/政策表述错误（如机构名、数据）按 `guokao-defaults.md` §5.4 计 0.5–1 分/处。

**接入点（阶段 B 必用其一，否则刻度空转）**：

1. **"不低于 T1"的下不封顶约束**：六项若**无一项明显弱于 T1** → 大档**不得低于二类上**；
   若四维判定更低，必须写出**差在哪一项、差多少**。（**单向刻度不提供下沿锚**。）
2. **画像定档内位置**：六项多数贴近 T1（且 T1 参照档与当前大档重叠）→ 本档**上**；
   大体等同 T1 → **中偏上**；弱于 T1 的项集中于"①立意方向（是否处理辩证）②论点覆盖⑤落点具体度" → **中或下**。
   （**单向刻度不得据此定"下"**——"下"只能由四维实据支撑。）
3. **撤掉／确认不成立的扣分项**：本卷 **T1 两篇都处理了辩证、都有边界表述** →
   **"未处理辩证关系""缺边界意识"在本卷可作为真短板证据**（**卷内结论、不得跨卷套用**），
   但仍只作题意质量与论证深度的一项，**不单独压整个大档**。
4. **从紧给分（2026-09-22 用户裁定）**：**档内定位默认落"下／中"**，只有**五项中 ≥4 项达本档上沿**才给"上"；
   **硬伤一律执行**；**语言类扣分如实累计**；**亮点不加分**。
5. **置信度**：**单向刻度不上调**校准置信度（只有双向刻度可上调半档）。
