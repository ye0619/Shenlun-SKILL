# 真题（试卷原题库）

## 一、用途

`真题/` 存放**试卷原题**（PDF 为主），是题面与材料的**最高依据（L1）**，按省份分类。

本目录同时存放**真题库**：把已经精读过的真题整理成结构化 md（含题面、材料要点与重构参考采分点），位于 `真题/{省份}/真题库/`。

> 依据层级提醒：原题 PDF（题面 + 材料）是 L1；真题库 md 中的"重构参考采分点"是**基于材料的重构推演，不是官方答案**；`参考答案/` 里的机构解析只作经验校准。

## 二、目录结构

```
真题/
├── README.md                 ← 本文件
├── _TEMPLATE.md              ← 真题库 md 模板
├── 国考/
│   ├── {卷ID}.pdf            ← 原题 PDF
│   └── 真题库/
│       ├── INDEX.md          ← 该省真题库索引
│       └── {卷ID}.md
├── 河南/   （同上）
└── 浙江/   （同上）
```

可能出现的省份目录：`国考` / `河南` / `浙江` / `福建` / `四川` / `广西`。
其中 **福建、四川、广西目前只有真题库 md，没有原题 PDF**。

## 三、命名规范

### 卷ID

**卷ID = `{四位年份}{省份}{卷型}`**，例如 `2022河南乡镇`、`2026国考行政执法`、`2024浙江A`。

- **省份**只写简称：`国考` / `河南` / `浙江` / `福建` / `四川` / `广西`（不写"省""申论""答案"）。
- **卷型**取值：`副省级` / `地市级` / `行政执法` / `县级` / `乡镇` / `市级` / `县乡` / `省市` / `A` / `B` / `C` / `下半年`；**无分卷则省略卷型**。

同一套卷在 `真题/`、`参考答案/`、`作答记录/`、`批改报告/`、`批改规范/` 里使用**同一个卷ID**，便于互相匹配。

### 文件命名

| 类型 | 命名 |
| --- | --- |
| 原题 PDF | `{卷ID}.pdf` |
| 真题库 md | `{卷ID}.md` |
| 真题库索引 | `真题库/INDEX.md` |
| 真题库模板 | `真题/_TEMPLATE.md` |

## 五、新增真题怎么放

直接把新下载的真题 PDF **丢到工作区根目录或 `真题/` 下即可**，助手会按上述命名规范自动归位并重命名：

- 能唯一识别省份与卷型的 → 直接改名放入 `真题/{省份}/`；
- 文件名含糊（如 `申论.pdf`、`新建文件夹`、`2024年真题.pdf`）→ **先向用户确认**是哪个省、哪一年、哪个卷型，再归位；
- 归位后同步更新本 README 的对照表。

## 六、同一套卷的多个来源版本

如果同一套卷新增了**别的来源版本**，用 `{卷ID}-v2.pdf`、`{卷ID}-v3.pdf` 之类的后缀区分，**不要覆盖**原文件；并在真题库 md 里注明各自来源与可信度差异。
