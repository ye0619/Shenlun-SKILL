# 真题/

> **本目录的入库策略（2026-09-22）**：仓库**只上传"框架"**——本说明、`.gitkeep`，
> 以及 **`国考/` 目录下的 `.md` 文件**（由作者整理后添加）；
> **PDF 原卷与其它省份内容不入库**（版权与体积原因）。你本地放进去的 PDF 不受影响。

## 放什么

申论真题原卷（PDF）和从卷子里整理出来的纯文本题面。

## 目录与命名

原卷 PDF：

```
真题/{省份}/{卷ID}.pdf
```

整理成文本的题面（助手批改时优先读这一份）：

```
真题/{省份}/真题库/{卷ID}.md
```

配套的两个文件：

- `真题/{省份}/真题库/INDEX.md` —— 该省**入库索引**（已入库真题清单 + 本地真题源 PDF 清单），
  助手匹配题面时先看它；
- `真题/_TEMPLATE.md` —— **入库模板**，复制它来整理新卷。

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略

示例：

```
真题/河南/2022河南乡镇.pdf
真题/河南/真题库/2022河南乡镇.md
真题/国考/2026国考行政执法.pdf
真题/国考/2026国考行政执法.md        ← 已整理的 md（入库）
```

## 题面文本建议包含

- 卷面信息：年份、省份、卷型、时限
- 每题完整作答要求（含字数限制、身份设定、文体要求）
- 材料可以只留要点，但**作答要求必须逐字准确**

## 非 md 材料（2026-09-22 新增）

检测到 **pdf／docx／图片**形式的真题时，助手会先问你**是否启用 MinerU** 转成 md
（同意才安装、只转当前这套卷；见 skill 的 `SKILL.md` 第三节第 0 步第 6 条）。
`.txt` 不会触发提醒。
