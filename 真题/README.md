# 真题/

> **本目录的发布范围**：已收录的真题文本与 PDF 原卷可随仓库发布，各省份采用相同规则；保留来源信息，移除个人批注、身份信息和密钥。克隆仓库包含已入库资料；npx 安装仅提供 skill、工具和目录模板，不附带题库。

## 放什么

申论真题原卷（PDF）和从卷子里整理出来的纯文本题面。

## 目录与命名

原卷 PDF：

```
真题/{省份}/{卷ID}.pdf
```

整理成文本的题面（助手批改时优先读这一份）：

```
真题/{省份}/{卷ID}.md
```

查找时兼容旧路径 `真题/{省份}/真题库/{卷ID}.md`，已有题库文件不移动。主路径与旧路径均须核对；同卷内容不一致时回原卷核实，不自动覆盖。新整理文本使用主路径，已有可用文本先复用，不重复入库。

配套的两个文件：

- `真题/{省份}/INDEX.md` —— 该省**入库索引**（已入库真题清单 + 本地真题源 PDF 清单）；旧 `真题/{省份}/真题库/INDEX.md` 仍可读取。更新实际使用的索引并记录真实文件路径，索引缺失时直接核对题面文件；
- `真题/_TEMPLATE.md` —— **入库模板**，复制它来整理新卷。

- `{省份}` 用简称：`国考`、`河南`、`浙江`……
- `{卷ID}` = `{四位年份}{省份}{卷型}`，例：`2022河南乡镇`、`2026国考行政执法`、`2024浙江A`
- 卷型取 `副省级 / 地市级 / 行政执法 / 县级 / 乡镇 / 县乡 / 市级 / 省市 / A / B / C / 下半年`，不分卷就省略

示例：

```
真题/河南/2022河南乡镇.pdf
真题/河南/2022河南乡镇.md
真题/国考/2026国考行政执法.pdf
真题/国考/2026国考行政执法.md        ← 已整理的 md（入库）
```

## 题面文本建议包含

- 卷面信息：年份、省份、卷型、时限
- 每题完整作答要求（含字数限制、身份设定、文体要求）
- 材料可以只留要点，但**作答要求必须逐字准确**

## 非 md 材料（2026-09-22 新增）

检测到 **pdf／docx／图片**形式的真题时，助手会先问你**是否启用 MinerU** 转成 md
（按授权范围安装、只转当前这套卷；见 skill 的 `references/workspace-layout.md` 第 6 节）。
`.txt` 不会触发提醒。

## 提醒

真题资料仅供个人学习研究，保留来源信息并遵守原始来源的使用要求；本目录按上方发布范围维护。
文件名不必纠结，丢到工作区根目录也会被自动归位；命名含糊时助手会先问你。
