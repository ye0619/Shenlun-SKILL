# 真题库索引 · 四川

## 一、本目录用途

本目录存放**四川已入库真题**的结构化 md：每份含题面、给定材料要点、重构参考采分点（小题/公文）与"主档 + 硬伤修正"评分依据（大作文）。**批改时优先用库内已入库真题匹配题面**——命中后直接加载对应 md 的题面与采分点口径，不得跳过它凭记忆重构。

> **依据层级**：题面与材料 = L1（最高层，本省暂无原题 PDF，暂以库内 md 照录的题面原文为准，建议尽快补 PDF）；库内"重构参考采分点"= L3 模拟口径（官方采分表未公开，输出须标注）；`参考答案/` 机构解析 = L4 经验校准（非官方）。
> **通用匹配规则与取用优先级见工作区 `真题/README.md`**；卷ID 命名规范同该文件。

> **判分基准取用顺序**（不得跳过前几级凭记忆重构）：`参考答案/` 参考口径（L4，非官方）→ 本省原题 PDF（L1 题面与材料）→ 库内 md（L3 重构采分点）→ 用户题目原文 → 模型知识。

## 五、匹配与取用速查

1. 关键词**交集 ≥3 个** → 高置信度匹配，加载对应 md；但**该卷标"仅索引/部分入库"的题目不得按其采分点判分**——处理顺序：① 争取拿到原题 PDF 取题面原文；② 退回"用户题目原文 + 通用流程"评判，并向用户说明该题尚未入库、可在批改后按 `真题/_TEMPLATE.md` 补齐。
2. 交集 **1–2 个** → 中等置信度，先向用户确认"检测到您的题目可能是【XX年XX卷 第X题】，是否正确？"。
3. 交集 **0 个** → 未匹配，使用通用评估流程，事后询问用户是否入库。
4. 四川卷卷型：**省市卷**（枚举含 `省市`；本库该卷现存文件名为 `2023四川市级`）偏宏观政策与产业发展、**县乡/乡镇卷**（枚举作 `县乡` / `乡镇`）偏基层治理与乡村振兴——定位卷型时优先看题干身份与场景。

## 六、如何新增入库

1. 新题批改完成后，按工作区模板 `真题/_TEMPLATE.md` 的结构补齐：题面原文（L1 逐句照录）、给定材料概要、关键词、小题参考采分点（标注 L3 经验口径）/ 大作文"主档 + 硬伤修正"评分依据。
2. 文件落位：`真题/四川/真题库/{卷ID}.md`（卷ID = `{四位年份}四川{卷型}`，如 `2023四川市级`）。**卷型取值**（工作区统一枚举）：`副省级` / `地市级` / `行政执法` / `县级` / `乡镇` / `市级` / `县乡` / `省市` / `A` / `B` / `C` / `下半年`；无分卷则省略卷型（`县乡`、`省市` 均为合法取值）。
3. 在本 INDEX 第二节的表格里**补一行**（卷ID / 年份 / 卷型 / 主题关键词 / 文件），并在第三节补该卷的详细匹配关键词；补齐 `[待补充]` 字段后同步更新本节的"部分入库"说明。
4. **优先补原件**：把四川原题 PDF 按 `{卷ID}.pdf` 放入 `真题/四川/`，使题面回到 L1 可核状态。
5. 若同卷已存在，用 `-v2`、`-v3` 后缀区分版本，不覆盖旧文件。
