# 2018年国家公务员考试申论（地市级）

## 全卷概况

- **考试名称**：2018年国家公务员考试申论（地市级）
- **试卷主题**：城市治理理念——从"有"（建设/硬件/经济）与"无"（公共空间/人文/留白）的辩证关系切入，探讨城市建设的价值取向
- **给定材料概要**：材料1-2 农村土地承包政策发展过程与"人地矛盾"（沙坝村、L村）；材料3 城市公共空间缺失问题（瑞丽花园"景有了人没了"、南平巷过度商业化、中心城区文化公园"化人"）；材料4 公共空间的社会功能（巴黎新桥"社会平衡器"、圣保罗贫富分异、工业遗存改造为公共空间）；材料5 S市月亮湾地下综合管廊建设经验；材料6 老子"有之以为利，无之以为用"与城市公共空间启示

## 各题详情

### 第1题
- **题型**：归纳概括（概述发展过程）
- **分值**：10分
- **原题**："给定资料1"和"给定资料2"反映了改革开放以来我国农村土地承包政策的发展过程，请你概述这一发展过程。（不超过200字）
- **给定材料概要**：沙坝村"分田到户"→承包期3-5年→中央一号文件15年以上→再延长30年→十九大"第二轮到期后再延长三十年"；L村机动地"增人增地减人不减地"难以为继、人地矛盾
- **关键词**：分田到户、承包期延长、稳定长久不变、增人增地、人地矛盾
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）**（参考）：
  1. 家庭联产承包责任制初步落实（分田到户、土地所有权不变、经营权使用权分离）
  2. 承包期由短到长逐步稳定（3-5年→15年以上→再延长30年→长久不变）
  3. 政策从"不许流转"到允许、鼓励流转（经营权放活）
  4. 出现人地矛盾与调整需求（增人增地难以为继、个别农户要求调整）
  5. 依法依规调整受限（承包地不得随意调整、以户为单位、减人不减地）

### 第2题
- **题型**：综合分析（原因分析）
- **分值**：10分
- **原题**：分析L村村支书为什么感到"压力很大"。（不超过200字）
- **给定材料概要**：村民李某等要求收回重分；张某主张按30年不变；万老汉等想流转难流转、土地撂荒；国家政策"小调整、大稳定""承包期内不得调整"；法院判决村委会返还石某土地
- **关键词**：人地矛盾、政策限制、法律约束、流转困难、撂荒
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）**（参考）：
  1. 人地矛盾突出：增人不增地导致人口多家庭地少、不公平感强烈
  2. 政策刚性约束："承包期内发包方不得调整承包地""小调整大稳定"间隔5年且限于个别农户
  3. 法律明确限制：土地承包法确立"以户为单位、减人不减地"，法院判决在先
  4. 各方诉求多元难调和：要地的与不要地的并存，流转不畅、撂荒
  5. 调与不调两难：调整违反政策法律、不调整激化矛盾

### 第3题
- **题型**：综合分析（词句理解）
- **分值**：20分
- **原题**：谈谈对"城市建设与管理的目的如果仅仅是为满足经济或某种美观诉求，显然是片面的，甚至是短视而危险的"这句话的理解。（不超过300字）
- **给定材料概要**：瑞丽花园重景观轻实用（"景有了，人没了"）；南平巷过度商业化破坏文化生态；新桥公共空间促进阶层交流；圣保罗公共空间衰败引发治安与投资流失；文化公园"建设是基础、化人更重要"
- **关键词**：片面、短视、危险、公共空间、人文价值、社会平衡器、化人
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）**（参考）：
  1. 解释含义：城市建设管理不能只看经济和美观
  2. 片面：忽视人的需求与公共空间功能
  3. 短视：透支文化生态与长远价值
  4. 危险：公共空间衰败引发社会对立、治安恶化、投资流失
  5. 对策/启示：建设与"化人"并重，突出共享与人文价值

### 第4题
- **题型**：公文写作（讲解稿）
- **分值**：20分
- **原题**：S市"城市样板工程展示会"上，就地下管廊建设情况撰写一份讲解稿。（不超过400字）
- **给定材料概要**：月亮湾地下综合管廊（920米T形长廊、管线入地、预留空间）；领导小组统筹规划；多元投融资（管廊开发公司）；系统化标准化智慧化（监控感知、智能管理）；收费机制与利益共同体
- **关键词**：综合管廊、统筹规划、多元融资、智慧管理、利益共同体、收费机制
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）**（参考）：
  1. 讲解稿格式（称呼、开场、正文、结束语）
  2. 管廊基本概况（长度、结构、功能、运行）
  3. 建设经验：高位统筹（领导小组）、规划先行、系统化标准化智慧化
  4. 建设经验：多元投融资（组建开发公司、股东结构、财政补贴兜底）
  5. 建设经验：收费机制创新与利益共同体、入廊积极性
  6. 语言符合讲解场合（口语化适度、有现场感）

### 第5题
- **题型**：大作文（命题作文）
- **分值**：40分
- **原题**：围绕给定资料反映的城市建设理念中的问题，联系实际，以"试谈'有'与'无'"为题写一篇文章。（总字数1000字左右）
- **给定材料概要**：老子"凿户牖以为室，当其无，有室之用"；瑞丽花园"景有了人没了"；南平巷过度商业化；新桥/圣保罗公共空间的社会功能；文化公园"化人"；S市管廊"无"的利用（地下空间、预留余地）
- **核心立意方向**（参考，非评分标准）：
  1. "有"是基础（硬件、建设、经济发展），"无"是功用（公共空间、人文价值、留白）——"无之以为用"
  2. 批判重"有"轻"无"的城市建设倾向（只见高楼地标、忽视人的活动空间与人文体验）
  3. 公共空间的治理价值：社会平衡、消解对立、增进归属
  4. 对策方向：精细化管理、拓宽公共空间、创新空间利用（如地下管廊留余地）、共建共治共享
- **评分依据（主档 + 硬伤修正，档位区间按满分占比划档：一类 32–40（≥80%）/ 二类 24–31.5（60%–80%）/ 三类 12–23.5（30%–60%）/ 四类 ≤11.5（<30%））**：
  - **第二步·硬伤核查（本题重点）**：①"有"与"无"只谈一端（只写城市建设、经济发展、硬件投入等"有"，不写公共空间、人文价值、留白等"无"） → 偏题（上限三类）；②材料主旨是批判"重'有'轻'无'"（瑞丽花园"景有了人没了"、南平巷过度商业化为反面案例，老子"无之以为用"为正面主张），若把重景观、重商业开发当作正面经验来主张 → 论点与材料主旨明显冲突（上限三类）；③题干要求"联系实际"，若通篇复述瑞丽花园、南平巷、新桥、圣保罗、月亮湾管廊等材料案例而无材料外论据 → 核心任务遗漏严重（上限三类）
  1. 题意：紧扣"有"与"无"的辩证关系与城市建设理念（切题）；能点出"无之以为用"的机理（深刻）
  2. 内容：论点与论据是否充实（城市公共空间、管廊等案例＋自身积累），例后是否有分析
  3. 结构：引论-本论-结论是否完整、层次是否自洽（不要求特定结构形态）
  4. 语言：规范、准确、通顺、是否有文采
  > 大作文按"主档 + 硬伤修正"划档（四维综合定基础档位），**不设"采分点"**；采分点只适用于小题与公文。
