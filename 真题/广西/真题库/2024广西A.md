# 2024年广西公务员考试申论A卷

## 全卷概况

- **考试名称**：2024年广西公务员考试申论A卷（2024多省联考）
- **试卷主题**：城乡融合发展中的传统与现代、数字化治理、慈善事业
- **给定材料概要**：全卷共4则材料。材料1围绕C市城乡融合发展实践（交通、水源、人才、产业）；材料2围绕Q市数字化治理能力提升（一体化智能平台、智治平台、交通配时）；材料3围绕Z市慈善事业高质量发展（慈善促富、慈善信托、慈善基地）；材料4围绕C市地铁"背篓专列"——菜农背着背篓乘地铁进城卖菜，引出"文明之所以文明，就是因为它既容纳了现代的行为方式，也包容了传统的生活习惯"的核心命题。

## 各题详情

### 第1题

- **题型**：归纳概括题
- **分值**：15分
- **原题**：根据"给定资料1"，概括C市在推进城乡融合发展方面的主要做法。（15分）
  要求：（1）全面准确，条理清晰；（2）不超过200字。
- **给定材料概要**：材料1介绍C市推进城乡融合的举措——交通互联互通（城际公交、高速免费通行）、水源共享（跨区域供水工程）、人才双向交流（干部挂职锻炼）、产业协同发展（新能源项目共建、企业生态圈打造）、公共服务均等化。
- **关键词**：C市、城乡融合、交通互联、水源共享、人才交流、产业协作、公共服务
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）**：
  1. 交通基础设施互联互通 — 4分
  2. 人才双向交流机制 — 4分
  3. 产业协同发展 — 4分
  4. 公共服务资源共享 — 3分

### 第2题

- **题型**：综合分析题
- **分值**：20分
- **原题**：请根据"给定资料2"，分析Q市数字化服务能力提升的原因。（20分）
  要求：（1）分析全面，条理清晰；（2）不超过300字。
- **给定材料概要**：材料2介绍Q市以一体化智能化公共数据平台建设为抓手，通过数据汇聚共享（52346类数据、76个市级部门）、能力组件体系（303项上架组件）、"快办"平台（2866个政务服务事项、53项"一件事一次办"）、三级数字化治理中心（市—区县—镇街）、智治平台（7万余网格）、交通信号配时中心、医疗影像互认、智慧养老、数字文旅等场景，全面提升数字化服务能力。
- **关键词**：Q市、数字化、服务能力、原因分析、公共数据平台、智治平台、三级治理中心、数据共享
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）**：
  1. 数据底座夯实：汇聚海量数据资源，构建统一数据仓 — 6分
  2. 平台能力开放：能力组件体系支撑多场景应用 — 5分
  3. 三级治理架构：市—区县—镇街分工明确、协同高效 — 5分
  4. 场景驱动落地：以"一件事"思维谋划应用场景、解决实际问题 — 4分

### 第3题

- **题型**：公文写作题（汇报提纲）
- **分值**：25分
- **原题**：市相关领导计划近期召开专题会议，听取Z市《慈善事业高质量发展规划》落实情况，假如你是慈善总会工作人员，请根据"给定资料3"，拟写一份汇报提纲。（25分）
  要求：（1）紧扣资料，内容全面；（2）准确简明，条理清晰；（3）不超过400字。
- **给定材料概要**：材料3介绍Z市落实慈善事业高质量发展规划的成效——出台《规划》并设立慈善共富服务专区提供集成服务；突破慈善信托体制障碍形成"穿透开票"等改革成果；开展"爱心小书房""暖厨计划""学子自强计划"等品牌慈善项目，累计撬动慈善资金近亿元；成立慈善文化研究院、发布"慈善一日捐"扫码捐赠标识、首批16个慈善基地形成矩阵效应。
- **关键词**：Z市、慈善事业、高质量发展、汇报提纲、慈善促富、慈善信托、慈善基地、第三次分配
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）**：
  1. 制度建设：出台《规划》、设立服务专区、突破信托障碍 — 8分
  2. 项目落地：品牌慈善项目（爱心小书房、暖厨计划、学子自强计划）的量化和案例 — 8分
  3. 文化营造：研究院成立、扫码捐赠、慈善基地矩阵 — 5分
  4. 格式规范：汇报提纲文体格式正确、条理清晰 — 4分

### 第4题

- **题型**：大作文
- **分值**：40分
- **原题**："文明之所以文明，就是因为它既容纳了现代的行为方式，也包容了传统的生活习惯。"请结合给定资料，以"现代与传统"为话题，自选角度，自拟题目，写一篇议论文。（40分）
  要求：（1）立意明确，观点深刻；（2）内容充实，论证有力；（3）参考给定资料，但不拘泥于给定资料；（4）1000-1200字。
- **给定材料概要**：材料4以C市地铁为菜农设"背篓专列"为核心正面案例，展示城市治理在现代化进程中如何包容传统生活习惯——石船镇菜农每天背着背篓乘首班地铁进城卖菜，C市地铁非但没有驱赶，反而增设专人引导、设置专门车厢。材料引用乘客语录"文明之所以文明，就是因为它既容纳了现代的行为方式，也包容了传统的生活习惯"点题。同时以部分地区盲目城镇化导致"千村一面"、南橘北枳为反面案例，强调保留乡村特色的重要性。
- **题干引文**："文明之所以文明，就是因为它既容纳了现代的行为方式，也包容了传统的生活习惯。"
- **主题关键词**：现代、传统、城乡融合、社会文明、背篓专列、菜农、C市、地铁、包容、生活习惯、行为方式
- **核心立意方向（参考，非评分标准）**：现代与传统互为条件、相辅相成，共构社会文明
- **分论点方向（仅作构思参考，不构成评分维度）**：
  1. 传统是根基：包容传统生活习惯为社会文明提供稳定性和人文温度（"压舱石"）
  2. 现代是引擎：接纳现代行为方式为社会文明提供发展动力和治理效能（"主引擎"）
  3. 两者融合：传统与现代有机融合，方使城乡社会在守正创新中行稳致远（"双向奔赴"）
- **评分依据（40 分卷，主档 + 硬伤修正）**：
  - 档位区间（40 分卷，按满分占比划档，查 `.dsh/skills/shenlun-judge/references/scoring-standards.md` 三.1 换算表）：一类 32–40（≥80%）/ 二类 24–31.5（60%–80%）/ 三类 12–23.5（30%–60%）/ 四类 ≤11.5（<30%）
  - **第二步·硬伤核查（本题重点）**：①"现代"与"传统"两个核心概念只谈其一（只写数字化、现代化而丢掉传统生活习惯，或只写怀旧复古而丢掉现代行为方式） → 偏题（上限三类）；②材料主旨是以C市地铁"背篓专列"正面肯定"包容传统生活习惯"，若反向解读为"菜农背篓进城影响城市形象应当取缔""传统生活习惯落后应被淘汰" → 论点与材料主旨明显冲突（上限三类）；③题干要求"参考给定资料，但不拘泥于给定资料"，若通篇复述背篓专列等材料案例、无材料外论据 → 核心任务遗漏严重（上限三类）
  - **题意**：是否紧扣"现代与传统"的包容共生关系（切题）；是否点出二者对社会文明的意义（深刻）
  - **内容**：论点与论据是否充实（材料案例＋自身积累），例后是否有分析
  - **结构**：引论-本论-结论是否完整、层次是否自洽（**不要求"三个分论点"、"篇幅均衡"等特定形态**）
  - **语言**：规范、准确、通顺、是否有文采
  - 分论点数量、是否必须引用 C 市背篓专列、标题是否含题干全词 —— **均不构成扣分点**（标题仅按"核心概念覆盖度"在题意维度微调）
