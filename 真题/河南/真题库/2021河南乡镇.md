# 2021年公务员多省联考《申论》题（河南乡镇卷）

## 全卷概况

- **考试名称**：2021年公务员多省联考《申论》题（河南乡镇卷）
- **考试时限/总分**：150 分钟 / 100 分
- **试卷主题**：以"群众得便利、乡村有奔头"为主线——医保数字化带来的就医便利、易地扶贫搬迁群众从"磕绊"到"有奔头"的适应过程、乡村阅读推广的微光成炬、闲置农房盘活利用发展乡村产业
- **给定材料概要**：材料1 F省医保"码时代"（医保码就医购药、互联网医院在线复诊慢病续方、医保个人账户家庭共济、跨省异地就医线上办）；材料2 大娄山脉双河村小冯一家易地扶贫搬迁进城，从生活/就业/子女教育的不适应到脱贫摘帽；材料3 李石村李姐的"微光书苑"（零门槛借阅、奖励激励、家人支持、公益捐赠、合作伙伴与志愿团队、第二课堂）；材料4 Z市盘活利用闲置农房（新泉中学→越红博物馆、唐仁村私塾→越庄酒坊、岭北镇闲置农房储备平台）

## 各题详情

### 第1题
- **题型**：归纳概括（按"不同群众"分组）
- **分值**：15分
- **原题**：请根据"给定资料1"，梳理概括F省医保跨入"码时代"后，给不同群众带来的新便利。（15分）要求：准确、全面、有概括性，不超过300字。
- **给定材料概要**：老王扫医保码完成挂号、诊间结算、取药取报告、预约复诊，全程不到半小时，不用窗口排队，平均节省等待时间约43分钟，医保码还可用于院外买药（630万余参保人员开通、236家医院近7500家药店实现结算）；蔡先生视频问诊→电子处方→药师在线审方→医保在线结算，在家收到寄来的药品，近3个月实体医院有就诊记录即可在线复诊、慢病续方、医保自动结算，降低线下就诊感染风险；黄阿姨用丈夫医保个人账户的钱买药，2020年7月起全国率先实现医保个人账户家庭共济、省内不同地方成员可加入；林阿姨（60岁赴广州10年）不再垫付医疗费、不再奔波报销，凭医保码全国办理医保业务，政务通App在线办跨省异地就医备案、参保关系转移、参保缴费证明打印，自助查询个人账户/待遇/消费明细/报销结果
- **关键词**：医保码、码时代、不同群众、等待时间、院外买药、云医疗、在线复诊、慢病续方、医保在线结算、药品寄送到家、家庭共济、流动人口、随迁人员、免垫付、免奔波报销、政务通App
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）（参考）**：
  1. 患者（就医购药群众）：扫码完成挂号等全环节、全程不到半小时、不用窗口排队缴费、平均节省等待时间约43分钟；医保码可用于院外买药（4分）
  2. 线上就医群众：视频问诊、电子处方、药师在线审方、医保在线结算、在家收到药品；近3个月实体医院有就诊记录即可在线复诊、慢病续方、医保自动结算；解决线上看病买药不能报销痛点、降低线下就诊感染风险（4分）
  3. 家庭成员：医保个人账户家庭共济、省内不同地方成员可加入共济账户、可分享个人账户资金（3.5分）
  4. 流动人口/随迁人员：不用再垫付医疗费、不用大老远奔波报销；凭医保码全国办理医保业务；政务通App在线办经办业务、自助查询个人数据（3.5分）

### 第2题
- **题型**：提出对策（工作建议）
- **分值**：15分
- **原题**：小冯向社区反映了他的"物业费困惑"。请你根据"给定资料2"，为社区提出处理问题的工作建议。（15分）要求：考虑全面，有针对性、可行性。不超过250字。
- **给定材料概要**：资料2中与"物业费"直接相关的原文仅三处——小冯成为新市民后的不适包含"垃圾得倒进楼下的垃圾桶，要开始交物业费了"；"让小冯尤其困惑的就是物业费：'住的是自己的房子，为啥每月还得交钱？'"；"听过社区干部们耐心细致的解释后，他慢慢习惯了社区生活"；末句"啥事儿都有个过程嘛，懂了就习惯了"
- **关键词**：物业费困惑、新市民、适应社区生活、耐心细致解释、工作建议、可行性
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）（参考）**：
  1. 加强物业宣传解释：利用公示栏、宣传栏、微信群、业主大会等载体，普及物业管理相关概念，讲清物业费用于公共区域保洁、绿化、安保、设施维护等服务，讲明"自己的房子为何每月还要交钱"，提升业主认识（4分）——**材料现成做法即"社区干部们耐心细致的解释"**
  2. 明确并公开收费标准与服务项目：在小区显著位置、收费地点及物业服务合同中标明服务项目与收费标准，公开物业费收支使用情况（4分）
  3. 提高物业服务质量：严格履行物业服务合同，增强服务意识，提供全面、细致、便利的服务，以可见成效提升居民满意度（4分）
  4. 做好针对性解答、畅通诉求渠道：对仍有困惑的业主逐户走访面谈、了解需求、解疑释惑；设意见箱等渠道收集意见、及时回应，好建议审核后实施（3分）
  > **判分警示**：资料2**通篇未交代物业费的构成与用途**，作答中凡出现"物业费用于社区工作者工资／社区活动资金／社区就业技能培训"等具体用途清单，均属材料之外自拟内容，不得分（不额外扣分）；亦无"居民大会""张贴公告""微信群""意见箱""调查表""居委会"等原词，仅可作为合理推演的载体，不可替代"耐心细致解释"这一材料明写要点。

### 第3题
- **题型**：综合分析（词句理解）
- **分值**：20分
- **原题**：请结合"给定资料2"，分析理解"尽管有些磕磕绊绊，但日子越过越有奔头"这句话。（20分）要求：准确、全面，深入，有逻辑性，不超过300字。
- **给定材料概要**：双河村地处大娄山脉、道路不畅、木房变形腐烂、不足3亩陡坡地、靠天吃饭、没撑几年成贫困户；2018年7月全家5口搬进县城100平方米新房成为新市民，随之而来的是垃圾入桶、交物业费等不适，尤其困惑物业费；社区干部耐心细致解释后慢慢习惯；就业上缺炒菜技术、缺店面租金，社区开展厨师等就业技能培训，2018年底在社区帮助下用凑齐的5万元租下门面开小餐馆，月收入七八千、早已脱贫；孩子此前随打工频繁换学校，返乡上学反而不习惯，老师专门家访谈心，小冯转变"教育只靠学校"的观念，孩子认识新朋友、成绩稳定；末段"从搬出大山到在县城安家扎根，实现了脱贫摘帽，但这不是终点，而是新生活、新奋斗的起点"
- **关键词**：磕磕绊绊、有奔头、易地扶贫搬迁、新市民、不适应、就业技能培训、脱贫摘帽、新生活新奋斗的起点
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）（参考）**：
  1. 总括释义：指以小冯为代表的易地扶贫搬迁贫困户从搬出大山到在县城安家扎根，虽几经波折，但生活有希望、前途光明（4分）
  2. "磕磕绊绊"的表现：搬迁前住山区道路不畅、居住条件差、靠天吃饭、收入微薄；搬迁后社区生活不适应、就业缺技术缺资金、孩子返乡上学不适应（4分）
  3. "有奔头"的支撑：社区干部耐心细致解释解惑、逐渐习惯社区生活；就业技能培训＋社区帮助租门面经营小餐馆、月收入七八千、实现脱贫；老师家访谈心、家长转变教育观念、孩子融入新环境成绩稳定（5分）
  4. 深层内涵：脱贫摘帽不是终点，而是新生活、新奋斗的起点；有波折不可怕，只要不懈奋斗就能迎来更美好生活（4分）
  5. 有逻辑性：释义—磕绊—奔头—升华层层推进并收束（3分）

### 第4题
- **题型**：公文写作（评论/短评，文章类格式；**非大作文**）
- **分值**：25分
- **原题**：结合"给定资料3"，以"用光点亮光，让心温暖心"为题，写一篇评论。（25分）要求：观点明确，说理充分，语言流畅。不超过500字。

  1. 观点明确：开篇或分论点句点明主旨——推广阅读以驱赶心灵的荒芜，微光虽微却能点燃火种、照亮乡村、温暖人心（4分）
  2. "用光点亮光"层：李姐拒绝支麻将桌、自掏腰包购书并拿出藏书、超市辟阅读空间；零门槛借阅（不要证件、不办手续、不收钱）；奖励孩子并扩大到大人；小手拉大手、大手拉小手，阅读氛围越来越浓（5分）

  - 格式（3分）：标题采用题干给定标题、文章类格式（标题＋正文，无称呼落款正常）

### 第5题
- **题型**：公文写作（调研报告提纲，提纲类不要求落款）
- **分值**：25分
- **原题**：假如你是调研组成员，请结合"给定资料4"模拟起草一份调研报告提纲。（25分）要求：紧扣资料，内容全面，层次分明，逻辑清晰，不超过500字。

- **关键词**：闲置农房、盘活利用、乡村产业、近50万平方米、2018年办法、农村产权交易平台、公开竞拍、越红博物馆、茶文化、越庄酒坊、非遗传承、储备平台、预收预储、招商推介、共同入股、包袱变财富、因地制宜
- **参考采分点（模拟重构，L3 口径，官方采分表未公开）（参考，公文按内容/格式/语言的**训练参照**权重模拟：内容16＋格式4＋语言5——**非官方比例**，引用须标注）**：
  1. 调研背景：城镇化致闲置农房增多；截至2020年底Z市有激活意愿、尚待开发利用的闲置农房近50万平方米；2018年8月出台办法明确可盘活房屋范围与"加固修缮后可进行旅游、休闲等三产开发利用"的规定；2017年以来各地着力探索（4分）
