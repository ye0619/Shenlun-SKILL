# 真题库索引 · 河南

## 一、本目录用途

本目录存放**河南已入库真题**的结构化 md：每份含题面、给定材料要点、重构参考采分点（小题/公文）与"主档 + 硬伤修正"评分依据（大作文）。**批改时优先用库内已入库真题匹配题面**——命中后直接加载对应 md 的题面与采分点口径，不得跳过它凭记忆重构。

> **依据层级**：题面与材料 = L1（最高层，以 `真题/河南/` 下原题 PDF 为准）；库内"重构参考采分点"= L3 模拟口径（官方采分表未公开，输出须标注）；`参考答案/` 机构解析 = L4 经验校准（非官方）。
> **通用匹配规则与取用优先级见工作区 `真题/README.md`**；卷ID 命名规范同该文件。

> **判分基准取用顺序**（不得跳过前几级凭记忆重构）：`参考答案/` 参考口径（L4，非官方）→ 本省原题 PDF（L1 题面与材料）→ 库内 md（L3 重构采分点）→ 用户题目原文 → 模型知识。

## 五、匹配与取用速查

1. 关键词**交集 ≥3 个** → 高置信度匹配：本目录 md 均为"已入库"，直接加载对应文件，按其中的题面/采分点（小题）或评分依据（大作文）评判。
2. 交集 **1–2 个** → 中等置信度，先向用户确认"检测到您的题目可能是【XX年XX卷 第X题】，是否正确？"。
3. 交集 **0 个** → 未匹配，读 `真题/河南/` 下同卷 PDF 取题面原文走通用流程；批改后按 `真题/_TEMPLATE.md` 入库。
4. ⚠ **多省联考材料共用提示**：河南卷常与同年其他省份卷**共用给定材料**（如 2023 年河南县级卷与福建县乡卷的材料高度重合：曾林社区／近邻聚邻惠邻／山核桃／天目／天生记）。批改时务必先按**卷型与作答要求**确认是哪一卷，**不得跨卷套用另一卷的采分点**——材料相同，题目问法与分值可能不同。

## 六、如何新增入库

1. 新题批改完成后，按工作区模板 `真题/_TEMPLATE.md` 的结构补齐：题面原文（L1 逐句照录）、给定材料概要、关键词、小题参考采分点（标注 L3 经验口径）/ 大作文"主档 + 硬伤修正"评分依据。
2. 文件落位：`真题/河南/真题库/{卷ID}.md`（卷ID = `{四位年份}河南{卷型}`，如 `2025河南市级`）。**卷型取值**（工作区统一枚举）：`副省级` / `地市级` / `行政执法` / `县级` / `乡镇` / `市级` / `县乡` / `省市` / `A` / `B` / `C` / `下半年`；无分卷则省略卷型。
3. 在本 INDEX 第二节的表格里**补一行**（卷ID / 年份 / 卷型 / 主题关键词 / 文件），并在第三节补该卷的详细匹配关键词。
4. 若同卷已存在，用 `-v2`、`-v3` 后缀区分版本，不覆盖旧文件。
