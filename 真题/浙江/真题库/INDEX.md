# 真题库索引 · 浙江

## 一、本目录用途

本目录存放**浙江已入库真题**的结构化 md：每份含题面、给定材料要点、重构参考采分点（小题/公文）与"主档 + 硬伤修正"评分依据（大作文）。**批改时优先用库内已入库真题匹配题面**——命中后直接加载对应 md 的题面与采分点口径，不得跳过它凭记忆重构。

> **依据层级**：题面与材料 = L1（最高层，以 `真题/浙江/` 下原题 PDF 为准）；库内"重构参考采分点"= L3 模拟口径（官方采分表未公开，输出须标注）；`参考答案/` 机构解析 = L4 经验校准（非官方）。
> **通用匹配规则与取用优先级见工作区 `真题/README.md`**；卷ID 命名规范同该文件。

> **判分基准取用顺序**（不得跳过前几级凭记忆重构）：`参考答案/` 参考口径（L4，非官方）→ 本省原题 PDF（L1 题面与材料）→ 库内 md（L3 重构采分点）→ 用户题目原文 → 模型知识。

## 五、匹配与取用速查

1. 本目录暂无已入库 md，题面匹配走 PDF 通道：按**年份 + 浙江 + 卷型（A/B/C）**定位 `真题/浙江/{卷ID}.pdf`，读原文取题面与材料。
2. 若某卷已入库，交集 ≥3 个关键词 → 高置信度匹配，直接加载 md；交集 1–2 个 → 先向用户确认；0 个 → 通用流程。
3. 浙江卷卷型差异：A 卷偏综合管理与宏观政策、B 卷偏基层与执法实务、C 卷偏乡镇（基层一线）——定位卷型时优先看题干身份与场景。
4. ⚠ 浙江卷 2013 年后多与**多省联考**共用材料，务必按卷型与作答要求确认是哪一卷，不得跨卷套用采分点。

## 六、如何新增入库

1. 新题批改完成后，按工作区模板 `真题/_TEMPLATE.md` 的结构补齐：题面原文（L1 逐句照录）、给定材料概要、关键词、小题参考采分点（标注 L3 经验口径）/ 大作文"主档 + 硬伤修正"评分依据。
2. 文件落位：`真题/浙江/真题库/{卷ID}.md`（卷ID = `{四位年份}浙江{卷型}`，如 `2025浙江B`；2008–2012 年不分卷则省略卷型，如 `2011浙江`）。**卷型取值**（工作区统一枚举）：`副省级` / `地市级` / `行政执法` / `县级` / `乡镇` / `市级` / `县乡` / `省市` / `A` / `B` / `C` / `下半年`；无分卷则省略卷型。
3. 在本 INDEX 第二节的表格里**补一行**（卷ID / 年份 / 卷型 / 主题关键词 / 文件），并在第三节补该卷的详细匹配关键词。
4. 若同卷已存在，用 `-v2`、`-v3` 后缀区分版本，不覆盖旧文件。
